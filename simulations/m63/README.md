# M63 direct-simulation registry

This folder is the future A2 registry for the active M63/R202 single-field candidate in appendix Y.

At draft-108, analytic/candidate checks cover the local canonical filter bank, topological partition identity, finite-width osmotic force, current dictionary, ideal weak-scattering tracker, and frozen-coefficient relative harmonic-bath GLE/FDT. A canonical full-Hamiltonian trajectory runner is still missing, so Q3-1-A2 and Q3-2-A2 remain unreviewed.

A complete M63 direct simulation should use one fixed parameter family and report at least:

1. kink stability together with signal/frame/reservoir sector separation;
2. finite-time Schrödinger-envelope error for R202B;
3. direct conditional mean force versus k_B T partial_X log rho and equivalent-PN-well position weights;
4. density-port and weak-scattering signal distortion versus prepared action N_0, testing N_0^{-1} suppression;
5. the real-space T-symmetric scattering trajectory and frame velocity versus j/rho;
6. frame tracking under the load generated by the relative reservoir;
7. frozen and slowly varying reservoir force autocorrelation, memory kernel, FDT, and Ohmic/Markov reduction;
8. the combined forward drift versus j/rho + nu partial_X log rho;
9. Peierls--Nabarro well relaxation and hopping statistics;
10. the finite-time generator error relative to R161.

Until those trajectory-level checks are reproducible from a documented runner, no M63 candidate value is a validated theorem bound or an A2 witness.
