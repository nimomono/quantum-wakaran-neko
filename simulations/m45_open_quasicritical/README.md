# M45開放自己組織化準臨界準備モデル

このフォルダーは、論文で採用するM45の数値シミュレーションを自己完結して収録する。周期反応座標 $s$ と対数内部座標 $r$ の開放Langevin方程式を直接積分し、準備領域、位相すべり、大振幅離脱運動、有限時間帰還を軌道から測る。

## 直接積分する方程式

局所ポテンシャルは

```math
U_C(s,r)
=
U_0(1-\cos s)
+
\frac{\Theta}{2}
\log
\left[
1+
\left(
\frac{r-c\sin s}{r_0}
\right)^2
\right]
```

である。$s$には低速で注入、高速で抑制するRayleigh型能動項を加え、$s$と$r$には熱雑音と受動摩擦を加える。確率規約はItô規約である。雑音は加法的なので、座標と運動量の方程式自体はStratonovich規約でも同じ形になる。

位相すべり率、瞬間リセット、外部時計、量子基底状態は運動方程式へ入力しない。位相すべりは周期セル番号の変化として、帰還は位相すべり後に分離エネルギー未満へ一定時間滞在した事象として、積分後に検出する。

## 2種類の検査

1. **直接Langevin検査**

   M45の局所方程式から、分離面近傍の準備殻、位相すべり、有限時間帰還、対数状態体積を測る。

2. **条件付き位置作用素検査**

   無偏向位置拡散、時間比例の準備率、位置核の周辺可逆性を仮定し、対称準備作用素、主固有関数、Doob変換、量子基底密度、定常Nelson則を検査する。この検査は、粒子位置核を局所Langevin軌道から導出した証拠ではない。

## 実行方法

依存関係を導入する。

```text
python -m pip install -r simulations/m45_open_quasicritical/requirements.txt
```

短縮回帰検査を実行する。

```text
python simulations/m45_open_quasicritical/verify.py --quick
```

基準計算、収束検査、図の生成を実行する。

```text
python simulations/m45_open_quasicritical/run.py
```

集約結果は`reference/`へ、論文用の図はリポジトリ直下の`figures/`へ保存する。大容量の生軌道は保存しない。

## 主張の境界

- 能動項を維持するには、熱浴とは別に非平衡自由エネルギー源が必要である。
- 雑音そのものが臨界現象を作るとは主張しない。準備殻を作る中心は、能動注入、非線形飽和、散逸、周期障壁の釣り合いである。
- 厳密な自己組織化臨界現象、べき則、熱力学極限、無調整の臨界到達は主張しない。
- 一般の時間依存Nelson流、励起状態、位相量子化、スピンは対象外である。
