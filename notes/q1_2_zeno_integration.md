# Q1-2へのZeno効果統合記録

## 運用状態

draft-59で旧Q1-4のZeno効果をQ1-2へ統合した。draft-82まではBorn分布、同軸反復分布、異軸逐次分布だけが現行結果で、Zeno部分を固定目標上の残件としていた。draft-83ではR187の同一M37 W2信号系へR189A--R189Cを接続し、零傾斜Rabiを停止しない有限2回のZeno証人まで閉じる。

## 旧結果

draft-43までのM38/M42模型ではR101--R103が固定有限回の反復測定履歴と短時間遷移抑制を扱った。旧模型は現行Q1 W型2モード手順の根拠へ戻さない。旧式は、各測定区間の反転重み $q_j$ に対する

```math
\pi_N(s_1,\ldots,s_N)
=
\prod_{j=1}^N
\left[
(1-q_j)\mathbf1_{s_j=s_{j-1}}
+q_j\mathbf1_{s_j=-s_{j-1}}
\right]
```

であった。

## 現行Zeno導出線

現行主線は次である。

1. R187で同じM37弱結合W型の最低2正常モードに零傾斜Rabiを実装する。
2. R189Aで零傾斜Rabiを走らせたまま左右未処理作用を有限正準指針変数へ保持する。理想未使用運動量では保持機構自身の信号反作用は零である。
3. 固定済み作用容量だけをR170の固定済み容量入力系へ渡し、R164作用殻、R161静的整合、R162有限衝突、選択結果固定をW2信号から切り離して実行する。
4. R189BでR170の有限後段窓に階数1制御付き選別機構を作用する。選別中も零傾斜Rabiを停止しない。中間傾斜、局所外部記録、方向を変えない振幅再調整は使わない。
5. R189Cで $N=2$、$\Omega_\kappa T=\pi/2$ を固定し、時刻 $T/2$ に1回だけ中間射影選別を置く。
6. 同じ作用保持、作用殻、有限衝突、選択結果固定、時計自由度を動かしながら選別機構だけを開かない空操作対照を置く。
7. 終端 $T$ では全対照に同じR143/R181D読出しを使い、無反応を含む完全履歴を比較する。

## Zenoと呼ばないもの

現行R189Cの中間測定では傾斜を使わない。従って次はZeno機構として数えない。

1. 傾斜による左右離調。
2. 障壁増大によるトンネル分裂低下。
3. 測定処理中のRabi Hamiltonian停止。
4. 摩擦または散逸による遷移抑制。
5. 方向を変えない振幅再調整による中間状態準備。
6. 無反応または生存結果だけを残す事後選別。

終端読出しの傾斜固定は $t=T$ より後に全対照へ共通に作用するので、Zeno余裕を生成する時間発展へ含めない。

## 有限誤差と資源

測定運転ではR187全状態誤差、R189A作用保持誤差、正則化、固定済み容量R170系、選択遅延、走行中選別による測定後状態誤差、終端読出しを各1回だけ数える。空操作対照では選別機構の状態更新項を含めず、作用保持と補助選択系の残留反作用を独立に数える。

R187の弱結合極限で $\Omega_\kappa\to0$ とできるため、固定有限時間の選択機構を無限高速化せずに、選択遅延と選別窓のRabi重なりを任意に小さくできる。R189Aの対称有限窓平均誤差は $O(\!\Omega_\kappa^2)$ である。固定有限誤差和が $1/4$ 未満なら正のZeno余裕が残る。

新規に必要な中間資源は左右作用容量指針変数、固定済み容量からの作用殻・有限衝突・選択機構、1個の選別機構用未使用作業領域、時計自由度、完全履歴である。中間局所記録、方向を変えない振幅再調整、周期末リセットは達成証人に使わない。

## 残る強化課題

Q1-2達成は、M37ばね網、作用容量保持、R164作用殻、R190/R162の混合・衝突、R170選択機構、R189B選別機構を有限能動部分系＋Hamiltonian無限浴の単一ミクロ装置へ統合したことを意味しない。有限浴化、ポンプからリセットまでの全微視的仕事・熱・エントロピー収支、無期限反復、一般 $N$ の一様資源評価、$N\to\infty$ のZeno極限も別課題である。
