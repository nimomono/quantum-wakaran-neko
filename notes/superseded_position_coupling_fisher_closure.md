# 位置結合による Fisher 力密度閉鎖経路の置換記録

## 1. 元の版とモデル

draft-13では、粒子座標と誘導場座標を結合し、全 Liouville 方程式から得る粒子運動量収支

```math
m\rho_N
\left(
\partial_t
+
v_N\cdot\nabla
\right)v_N
=
-\rho_N\nabla V
+
\rho_N\overline F_{{\rm G},N}
-
\frac1m
\nabla\cdot
\left(
\rho_N\Sigma_{p,N}
\right)
```

を出発点にした。誘導場反作用と運動量流束の和を Fisher 応力へ収束させる構成則を中心課題としていた。

## 2. 置換理由

この経路では、浴が最初に運動量拡散または乱雑力として現れ、配置密度の Fisher 項へ進むために追加の力密度閉鎖が必要になる。その閉鎖は未証明であり、場の射影、枝内部幅、枝間流束、反作用を同時に制御しなければならなかった。

draft-14では、粒子と誘導場を

```math
P^{\mathsf T}C_N\Pi
```

で結合し、配置速度へ

```math
Y_N
=
C_N\Pi
```

を直接入れる。配置変位の短記憶極限から二側配置拡散へ進み、Fisher 項を前後ドリフト差から運動学的に得る。

## 3. 保存する知見

- 全 Liouville 方程式から配置流束と1次モーメントを取る手順。
- 有限浴では相関と記憶核が準周期的で、再帰前の観測窓が必要になること。
- 条件付き分散を無根拠に捨てると、余分な古典圧力または流束を隠すこと。
- 自己共役な二側 Green 核だけでは Nelson の時間対称 Newton 則を導けないこと。
- 選択的な弱漏れだけでは Fisher 項を作れないこと。

## 4. 現行理論での位置づけ

位置結合による力密度閉鎖は M13 の不採用モデルとする。計算誤りにより棄却したのではなく、より直接的な運動量結合経路へ置き換えた。

新経路でも未解決問題は残る。配置変位の Brown 極限、反作用記憶の局所化、配置変数だけの Markov 性、条件付き速度分散の制御、時間対称 Newton 則を別々に示す必要がある。

## 5. 再検討条件

具体的な有限位置結合モデルについて、反作用と運動量流束が Fisher 応力へ一様誤差付きで収束する定理または数値的に安定した機構が得られ、運動量結合経路より仮定が少なくなる場合に再検討する。
