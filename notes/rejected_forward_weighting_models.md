# 順時間的重みづけモデルの不採用理由

> **位置づけ。** M6「局所記録後の順時間的共有浴」とM7「結果依存滞在時間」の不採用記録。draft-10の第7.10節、第8.5節、第8.9節、付録C.11から、再利用価値のある否定的結果だけを整理した。現行論文の論証には用いない。

## 1. 検討した目的

局所結果が形成された後の共通未来で、共有浴、到達時間、滞在時間、反応座標の通過速度を利用し、Bell 型の結果重みを順時間的に生成できるかを検討した。

## 2. M6 順時間的共有浴

記録形成後の4領域を $\Gamma_{AB}$、共有浴を含む後段 Hamiltonian 流れを $\Psi^t$ とする。Liouville 測度に対して

```math
\mu(\Psi^t\Gamma_{AB})
=
\int_{\Gamma_{AB}}
\left|
\det D\Psi^t
\right|
d\Gamma
```

であり、

```math
\det D\Psi^t=1
```

だから

```math
\mu(\Psi^t\Gamma_{AB})
=
\mu(\Gamma_{AB})
```

となる。局所記録後の体積保存流は、全試行を1回ずつ数えた結果領域質量を変えない。

終端関数を加えれば

```math
\mu_R(\Gamma_{AB})
\propto
\int_{\Gamma_{AB}}
G_R(\Psi^Tz)
d\mu(z)
```

となり、質量は変わり得る。しかし重みを変えるのは共有浴雑音そのものではなく、流れと終端条件を組み合わせた2境界再重みづけである。したがってM6は `[R]` の順時間的導出にならない。

## 3. M7 結果依存滞在時間

$n$ 番目の試行結果を $\kappa_n=(A_n,B_n)$、有限完了時間を $\tau_n$ とする。全試行を結果に関係なく1回ずつ数える頻度

```math
\frac1N
\sum_{n=1}^{N}
\mathbf1_{\{\kappa_n=(A,B)\}}
```

は $\tau_n$ に依存しない。滞在時間が変えるのは時刻占有率または有限期限までの完了率である。

結果依存の未完了試行や時間切れ試行を除外すれば、観測分布は

```math
P_{\rm obs}(A,B\mid a,b)
=
\frac{
P_{\rm rec}(A,B\mid a,b)
\eta_{AB}(a,b)
}{
\sum_{A',B'}
P_{\rm rec}(A',B'\mid a,b)
\eta_{A'B'}(a,b)
}
```

へ再重みづけされる。$\eta_{AB}$ は完了効率であり、この機構は2境界試行測度ではなく事後選別である。

自由反応座標を距離 $\ell_g$ だけ進ませる設計では、利用可能エネルギーを $x$、質量を $M_g$ とすると

```math
\tau_g(x)
=
\ell_g
\sqrt{
\frac{M_g}{2x}
}
```

となる。この式は結果依存の完了時間を明示するが、全試行の結果頻度を変えないという結論は同じである。

## 4. 不採用理由

- M6は位相体積を保存するため、記録済み結果領域の試行数を変えない。
- M7は試行番号頻度と時刻占有率を混同する。欠測を利用すれば事後選別になる。
- どちらも `[R]` の初期・終端積測度を生成しない。

## 5. 再利用できる知見

Bell 型試行測度を提案するときは、開始数、記録数、完了数、再初期化数を分ける必要がある。流束、占有率、完了率を試行番号頻度の代わりに使ってはならない。

## 6. 再検討条件

順時間的機構を再検討するのは、全開始試行を結果に依存せず保持したまま、非体積保存な開放過程から一意な定常試行測度を導き、その測度が観測時間や打切り条件に依存しないことを示せる場合に限る。
