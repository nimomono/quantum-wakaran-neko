# 終端関数・中央比較器モデルの置換記録

## 1. 元の版とモデル

draft-11の第II部は、局所結果符号化器、共通未来の中央比較器、2モード作用分配系、相補的内部時計、Bell 固有の終端統計原理 `[R]` を組み合わせていた。

終端比較器は、ソフトモードエネルギー $h$ と差作用 $\kappa I_-$ を比較し、

```math
\Pi_R(T)
=
E_*+\kappa I_- -h
```

を有限幅パルスでも厳密に読み出した。固定総作用を2モードへ分ける幾何から $h$ の一様周辺を得て、終端半空間 $\Pi_R(T)\geq0$ の体積を線形な Bell 重みへ変換した。

## 2. 不採用理由

比較器と相補時計は終端半空間を力学的に実現するが、その半空間に入る履歴だけを物理的試行として数える原理を与えなかった。共同確率には

```math
\rho_R
\propto
\rho_S
G_R\circ\Phi_{a,b}^{T}
```

という追加の終端統計入力が必要だった。

この構成は数式上は整合していたが、欲しい結果重みをどの試行測度で数えるかという問題を `[R]` へ残した。現行モデルでは、結果別の終端関数を使わず、3モード共通作用殻を境界適合条件で切った残余ファイバー体積から重みを得るため、不採用とした。

不採用分類は「必要な仮定が強すぎ、より明確なモデルに置き換えた」である。終端比較器の Hamiltonian 計算自体が誤りだったという分類ではない。

## 3. 再利用価値のある結果

次はモデルを再検討する場合に再利用できる。

- 和・差作用が実2次元ベクトルの内積から余弦を生む計算。
- 2モード固定作用殻の条件付き一様分配。
- 比較生成子が読出し作用と可換なら、有限幅パルスでも終端運動量を厳密に積分できるという設計原理。
- 終端関数を Hamiltonian で実現することと、その終端領域を試行測度として採用することは別であるという否定的結果。
- 相補的な2つの終端半空間を等重みで平均すると余弦項が消えるという結果。

2モード一様分配は、現行モデルでは固定 $J_+$ の残余ファイバー内部の $U(2)$ 条件付き分布として読み替えられる。ファイバー間の相対質量を決める結果としては使わない。

## 4. 現行モデルとの置換関係

| draft-11 | draft-12以降 |
|---|---|
| 中央比較器 | 静的な和・差正常モード |
| 2モード作用分配系 | 3モード共通作用殻 |
| 終端半空間の体積 | $J_+=I_+^{AB}$ の残余ファイバー体積 |
| Bell 固有の終端関数 `G_R` | 全殻 $U(3)$ 等方拡散の定常 Liouville 測度 |
| `[R]` による履歴再重みづけ | 共通殻測度の境界適合解空間への押し出し |

現行モデルでも共通未来を含む2境界条件付けは残る。削除したのは、結果重みを直接担う独立な終端関数である。

## 5. 再検討条件

次のいずれかが成立した場合に限り、補助モデルとして再検討する価値がある。

1. 終端半空間の採用を、事後選別なしの試行周期から明示的に導ける。
2. 共通作用殻モデルより少ない仮定で、同じ非信号共同確率を得られる。
3. 相補時計が Bell 重み以外の独立な観測量を予測する。
4. 終端比較器の有限幅厳密性が、別の境界値問題の装置設計に必要になる。

完全な旧章と付録はこのメモへ複製せず、draft-11の版履歴で保存する。
