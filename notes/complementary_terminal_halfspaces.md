# 相補終端半空間の等重み平均

> **位置づけ。** M9「2つの相補終端半空間の等重み平均」の不採用記録。draft-10の第8.4節と付録C.4から、不採用理由と再検討条件を整理した。相補的内部時計の正準構成そのものは現行論文に残す。

## 1. 検討した構成

終端読出しを

```math
\Pi_R(T)
=
x-h,
\qquad
x
=
E_*+\kappa I_-
```

とする。$h$ は $0\leq h\leq E_\ell$ で一様とする。正向き半空間を $\Pi_R(T)\geq0$、相補的半空間を $\Pi_R(T)\leq0$ とすると、各累積重みは

```math
F_+(x)
=
\frac{x}{E_\ell},
```

```math
F_-(x)
=
1-\frac{x}{E_\ell}.
```

## 2. 否定的結果

2つの半空間を等重みで平均すると

```math
\frac12
\left[
F_+(x)+F_-(x)
\right]
=
\frac12
```

となる。$x$ に含まれる差動作用 $I_-$ の余弦依存性が消えるため、無向きの時計相補性だけでは Bell 重みを保てない。

## 3. 現行構成との区別

現行論文に残す相補時計は、順序付きの終端半空間

```math
\Pi_R(T)\geq0
```

へ時計向き保存の意味を与える。これは正準力学上の結果である。一方、その半空間だけを物理的試行として数える `[R]` は別の統計原理であり、時計相補性からは導かれない。

## 4. 不採用理由

M9は時間向きを対称に扱う最も単純な平均だが、求める角度依存まで相殺する。Bell 重みを得る機構として採用できない。

## 5. 再検討条件

時間反転した半空間で比較パルスの符号、結果符号、または境界密度も共変に変換し、2つの向きを合わせても余弦項が消えない明示構成が得られた場合に再検討する。その場合も、完成した試行測度と事後選別の有無を別に監査する。
