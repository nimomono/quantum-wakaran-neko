# 不採用となった3モード Bell 作用殻

## 位置づけ

このメモは draft-12 から draft-15 で採用していた3モード Bell 作用殻を保存する。現行模型では、同じ2成分場の低ランク対モード、共通未来の比較 Hamiltonian、2モード比較作用殻へ置き換えた。

旧模型は数学的に誤りとして撤回したのではない。比較作用の生成が抽象的で、Bell 重みを作るために $U(3)$ 共通殻準備を必要とし、余分な基準作用が理想可視度を下げるため、現行の物理模型には採用しない。

## 旧模型の中心構成

位相同期した左右の実2次元伝達ベクトルから、和・差作用

```math
I_\pm^{AB}
=
I_0
\left[
1
\pm
ABV\cos\Delta_{ab}
\right]
```

を作る。3つの複素境界モードについて、

```math
J_+
+
J_s
+
J_r
=
C_0
```

という共通作用殻を置き、境界適合条件

```math
J_+
=
I_+^{AB}
```

で切る。残余ファイバー体積は

```math
W_{AB}
\propto
C_0-I_+^{AB}
=
J_*+I_-^{AB}
```

となる。

対称sector、共通分解能、共通 coarea Jacobian の下で、

```math
P(A,B\mid a,b)
=
\frac14
\left[
1
-
V_{\rm eff}
AB\cos\Delta_{ab}
\right],
```

```math
V_{\rm eff}
=
\frac{I_0}{J_*+I_0}V
```

を得る。

## 保存する数学的結果

1. 一般3モード殻容量は $\Omega_3(C_0)=(2\pi)^3C_0^2/2$ である。
2. $U(3)$ 不変な固定殻確率測度は一意である。
3. その測度で $J_+$ の周辺密度は
   ```math
   p_+(x)
   =
   \frac{
   2(C_0-x)
   }{
   C_0^2
   }.
   ```
4. 固定 $J_+$ 後の残余2モード $U(2)$ 混合はファイバー内部を一様化する。
5. 残余 $U(2)$ だけでは、異なる $J_+$ のファイバー間質量を決めない。任意因子 $f(J_+)$ が残る。
6. 共通境界測度を生成側へ引き戻すと、完全履歴分布は一般に設定へ依存する。

## 不採用理由

- $I_+^{AB}$ を3モード共通殻のどの正準自由度へ移すかが抽象的だった。
- 残余2モードの $U(2)$ だけでは不足し、$J_+$ を含む全3モードの $U(3)$ 準備が必要だった。
- 正の基準作用 $J_*$ が $V_{\rm eff}<V$ を生み、理想余弦可視度を下げた。
- 同じ2成分場の固定モードとして比較器を物理的に解釈する接続が弱かった。
- 最も重要な共通境界測度の物理的準備は、3モード化しても解決しなかった。

## 現行模型との対応

| 旧3モード模型 | 現2モード模型 |
|---|---|
| 和・差作用 $I_\pm^{AB}$ | 低ランク相関作用 $K_{AB}$ |
| 固定 $J_+=I_+^{AB}$ | $A_\partial^{AB}=\Gamma^2K_{AB}/2$ |
| 3モード全殻の $U(3)$ | 比較2モード殻内の $U(2)$ |
| 残余ファイバー容量 | 結果sectorごとの2モード全殻容量 |
| 基準作用 $J_*$ | 追加基準作用なし |
| 抽象的な比較作用 | $H_{\rm read}$ による明示的転送 |

## 再検討条件

次のいずれかが見つかれば再検討する価値がある。

1. 3モード共通殻が同じ誘導場から2モード模型より自然に準備される明示 Hamiltonian。
2. $J_*$ を物理的に不可避とし、その可視度低下を観測量として支持する機構。
3. 3モード模型だけが一般測定器または高次元複合状態へ拡張できる証明。

現時点では、現2モード模型の方が比較作用の生成と余弦重みの関係を明示的に保てる。
