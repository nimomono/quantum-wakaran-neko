## 旧M46の目的

M46は、M37/M42の物理的複素振幅場、M45のlimit cycle、指数capacity、共通作用ポートを接続し、次の三角形因果律を採用する開放模型だった。

```math
b
\longrightarrow
q(b)
\longrightarrow
X
\longrightarrow
I
```

局所複素振幅場 $b$ の相対位相を $90$ 度比較強度へ変え、非負rate $q$ を作り、実現配置 $X$ を動かし、$X$ がcapacity $I$ を消費する。capacityは同時刻の場または位置へ保存力として戻さない非相反結合だった。

## 不採用理由

新しいW型M47では、複素振幅を独立した実在場として置かず、実現配置 $X$ と浴 $\xi$ の共同統計から再構成する。因果の向きは

```math
\mu(dX\,d\xi)
\longrightarrow
(\rho,C)
\longrightarrow
K_W
\longrightarrow
\psi_W^{\rm stat}
```

である。

この解釈の下でM46を同時に採用すると、$X$ と浴の統計から複素振幅を作り、その複素振幅からrateを作って $X$ を動かす循環になる。循環を避けるには、複素振幅を使わないミクロrateを先に定め、その条件付き平均がM46 rateへ一致することと、対応するmatching fiberの不変性を証明する必要がある。旧M46にはその定理がない。

さらに旧M46には次が残っていた。

1. 三角形非相反結合を具体的負性抵抗回路から導出していない。
2. phase-preserving純散逸と位置依存frequency shiftの分離を導出していない。
3. 任意複素rank-one状態の自律準備を与えない。
4. nodeでrateが特異になる。
5. 一般graph-to-continuum一様誤差を持たない。
6. 準備modeと伝播modeを内部反応座標で切り替えるが、切断時の共同測度受渡しを証明していない。

これらは個別の技術的未完成だけでなく、新しい統計場解釈と因果律が一致しないため、M46全体を現行模型から外す。

## R130の再利用範囲

指数capacity

```math
P(I>a)
=
\exp
\left(
-\frac{a}{\mathcal J_0}
\right)
```

の無記憶性と、固定経路に対する生存因子

```math
\exp
\left[
-\frac1{\mathcal J_0}
\int_0^tW(X_s)\,ds
\right]
```

は正しい補助計算として残す。ただし、複素振幅、rank-one統計核、$X$ の時間発展を導かない。

## R131の再利用範囲

phase-preserving線形散逸式

```math
\dot z
=
-\frac{W}{2\mathcal J_0}z
```

を仮定した後の半減衰は正しい。二値thresholdの共有だけでは平方根因子は出ない。R131は条件付き線形応答補題として残し、物理的複素場またはM47の統計振幅の導出には使わない。

## R132の再利用範囲

線形Lyapunov級数と単純最大固有値の下で、臨界側のtrace規格化共分散が主固有射影へ集中する有限次元定理は残す。

ただしR132は次を与えない。

- 非線形Hopf定常測度のrank-one集中誤差
- 実現配置周辺とのmatching
- 一般複素相対位相の準備
- 切断後のmatching保存
- 励起重ね合わせの自然な選別

## R133の扱い

旧R133は、$\rho_i=|\psi_i|^2>0$ 上で

```math
q_{i\to j}^{\rm ct}
=
\frac{|h_{ij}|}
{2\mathcal J_0\rho_i}
\left|
\psi_i
+
i e^{i\gamma_{ij}}\psi_j
\right|^2
```

と定め、正味差が辺流へ一致することを示した。この有限グラフ恒等式自体は旧模型内で正しい。

しかし、rateを作る入力 $\psi$ を $X$--bath共同統計として後から定義するM47では、この式をミクロ因果律に使わない。R133は不採用模型内の解析結果として版履歴に残す。

## R134の扱い

旧R134は、Schrödinger型伝播、Madelung表示、R133の連続極限を仮定した後、Nelson時間対称加速度が

```math
ma_N=-\nabla V
```

を満たすことを示した。これは仮定後の代数的恒等式として正しいが、有限古典ミクロ系から一般時間依存Nelson流を因果的に導出した結果ではない。

M47はW型最低二modeの左右占有振動を対象とし、R134を使用しない。R134も不採用模型内の条件付き解析結果として管理する。

## M42との境界

M42/R113も物理的複素振幅場から最小rateを作るため、M47とは存在論と因果律が異なる。ただしR113--R121、Q1・Q2の測定構成、Q3-4・Q3-5の固定時刻位置読出し、付録F、既存回帰がM42へ依存している。

draft-43ではM42を既存結果に限定した暫定現行模型として残し、M47の根拠には使わない。M42を直ちに不採用へ移すと、既存達成判定と論文前半を同時に再構成する必要があるためである。

M42の全面退役は、transducerなしの共同統計から次を再導出した後の独立改訂とする。

1. Q1の排他的結果と測定後状態。
2. Q2の共同配置と二端記録。
3. Q3の固定時刻位置読出し。
4. 既存R118--R121に対応する有限古典装置。

## 再検討条件

M46またはR133を現行模型へ戻すには、少なくとも次のいずれかが必要である。

1. 複素振幅を独立した実在場として再採用し、統計場解釈を撤回する。
2. 複素振幅を使わない局所ミクロrateからR133を条件付き平均として導く。
3. $X$--bath matching fiberの準備と不変性を同じミクロ方程式で証明する。
4. node正則化、有限帯域、非相反回路、切断時受渡しを一つの開放装置で導く。

現行M47ではこれらを仮定しないため、current transducerを不採用のまま維持する。
