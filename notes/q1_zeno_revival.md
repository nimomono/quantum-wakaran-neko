# Q1-4 Zeno効果の再開記録

## 運用状態

Q1-4の固定目標と達成判定基準は削除しない。draft-44から科学的現在地を未達へ戻して凍結していたが、draft-56で運用上の凍結を解除し、未達の研究課題として再開する。この再開は旧結果の現行根拠への復帰でも、新しい定理・模型・数値結果の追加でもない。

## 旧結果

draft-43までのM38/M42模型では、R101--R103が固定有限回の反復測定履歴と短時間遷移抑制を扱った。完全な旧本文、付録、検証コードは公開コミット [`18b607d`](https://github.com/nimomono/quantum-wakaran-neko/commit/18b607dfbc7bc9cdfa7a2dd60c9427ea41b7ed7a) から参照できる。

旧模型の中心式は、各測定区間の反転重み $q_j$ に対する有限履歴則

```math
\pi_N(s_1,\ldots,s_N)
=
\prod_{j=1}^N
\left[
(1-q_j)\mathbf1_{s_j=s_{j-1}}
+
q_j\mathbf1_{s_j=-s_{j-1}}
\right]
```

であった。これはM42/R113の実現配置更新とM38の条件付き場準備に依存するため、M47の証拠として再利用しない。

## 傾斜固定との違い

M47の新しい測定では、左右エネルギー差 $\varepsilon_m$ により2モード遷移振幅を

```math
P_{L\to R}(t)
\leq
\frac{4J^2}{\varepsilon_m^2+4J^2}
```

へ抑える。これはHamiltonianを離調させた状態固定である。測定間隔を短くすることで未測定Hamiltonian下の遷移を抑えるZeno効果とは機構が異なる。

次をZeno効果とは呼ばない。

1. 傾斜で左右エネルギー差を作ること。
2. 障壁を高くしてトンネル分裂 $J$ を小さくすること。
3. 記録中だけ駆動またはトンネル項を停止すること。
4. 摩擦、散逸、resetで遷移を抑えること。
5. 生存枝だけを選ぶ事後選別。

## 再開後の検証線

Q1-4では、少なくとも次を同じM47測定操作で構成する。

1. 傾斜を解除した同一の未測定Rabi対照。
2. 各測定後の枝別共分散と実現配置matching。
3. 測定中も対象Rabi項を停止しない有限時間操作。
4. 無反応を含む全履歴分布。
5. 測定間隔、操作時間、傾斜、漏れ、記録、resetを分離した誤差評価。
6. 有限回で正の抑制余裕が誤差上界を上回る対照。
7. 反復回数に伴うテンプレート、記録、使用済み状態の資源評価。

総時間 $T$ と零傾斜Rabi周波数 $\Omega$ を固定し、測定なし対照と等間隔 $N$ 回測定の理想比較目標を

```math
P_{\rm free}(T)=\frac{1+\cos(\Omega T)}{2},
\qquad
P_N(T)=\frac{1+\cos^N(\Omega T/N)}{2}
```

とする。これらはM47から導出済みの結果ではない。有限幅測定、重なり、tilt、自由発展、無反応を含む合成誤差を評価し、有限 $N$ で正の差が誤差上界を超えることが必要である。これらが揃うまで、旧M38の有限Zeno達成判定を現行Q1へ引き継がない。
