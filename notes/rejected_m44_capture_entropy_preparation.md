## 2. M44が目指したもの

M42のBorn型等変性は、開始時の実現配置分布が複素振幅場の作用比と一致することを必要とする。M44は、物理ポテンシャル$V(X)$の定常基底状態に限り、目的固有関数を装置へ直接入力せずに、この初期分布を準備することを目指した。

物理構成は、粒子、座標--運動量整合伝送路、入口鞍点を持つ準安定捕捉器、多数の内部調和モード、捕捉失敗と脱出を運ぶ出射場から成っていた。概念的な全Hamiltonianは

```math
H_{\mathrm{M44}}
=
H_{\mathrm p}
+H_{\mathrm{line+match}}
+H_{\mathrm{cap}}
+H_{\mathrm{loc}}
```

であり、粒子部分を

```math
H_{\mathrm p}
=
\frac{P^2}{2m_{\mathrm b}}
+V(X)
```

とした。$V(X)$は粒子側へ1度だけ入れ、捕捉器側には位置によって変化する利用可能エネルギーとして現れることを意図した。

## 3. 再利用可能な計算

### 3.1 ミクロカノニカル捕捉流束

```math
W(x)=V(x)-V_{\min}\geq0
```

とする。入口分割面を内向きに通過した後、$R$個の内部調和モードへ使える基準エネルギーを$E_*$とした。入口Jacobianに同次数の余分な位置依存性がない理想条件では、捕捉流束比は

```math
a_R(x)
=
\left(
1-\frac{W(x)}{E_*}
\right)^R
```

となる。これはBoltzmann分布を入力した結果ではなく、位置エネルギーを差し引いた後に残る内部位相体積の比である。

### 3.2 有限容量の指数極限

```math
E_*
=
\frac{4m\nu R}{\delta}
```

という尺度整合を置くと、$R\to\infty$で

```math
a_R(x)
\longrightarrow
\exp
\left[
-\frac{\delta W(x)}{4m\nu}
\right]
```

となる。有限$R$補正は対数展開から評価できた。ただし、$E_*$と位置拡散係数$\nu$の関係はM44のHamiltonianから導かれた保存則ではなく、外から置いた尺度整合条件だった。

### 3.3 対称準備作用素

基準位置核と捕捉端点因子が

```math
K_\delta
=
I+\delta\nu\Delta+o(\delta),
```

```math
A_\delta(x)
=
\exp
\left[
-\frac{\delta W(x)}{4m\nu}
\right]
```

を満たすと仮定し、

```math
G_\delta
=
A_\delta K_\delta A_\delta
+o(\delta)
```

とすると、

```math
G_\delta
=
I
-
\frac{\delta}{2m\nu}
\left(
H_V-V_{\min}
\right)
+o(\delta),
```

```math
H_V
=
-2m\nu^2\Delta+V
```

を得る。この作用素計算自体はM44固有ではない。現行M45では、位置拡散、時間比例準備率、周辺可逆性を明示的な橋渡し条件として分離した上で、R129に書き直す。

### 3.4 左右因子と平方密度

一般の正作用素では、左主固有関数$l$と右主固有関数$r$により定常密度は$lr$に比例する。作用素が対称なら$l=r=h$となり、

```math
\rho_{\mathrm{ready}}
\propto
h^2
```

が得られる。1つの順方向因子だけを正規化しても一般には$h^2$にならない、という点は再利用できる。

### 3.5 Doob変換と定常Nelson則

$h=\phi_0$が$H_V$の正の基底固有関数なら、Doob変換した位置過程の前進・後退ドリフトは

```math
b_+
=
2\nu\nabla\log\phi_0,
\qquad
b_-
=
-2\nu\nabla\log\phi_0
```

となる。定常密度$\rho_0=\phi_0^2$についてNelsonの時間対称加速度を作ると、基底固有方程式から

```math
m a_N
=
-\nabla V
```

を得る。この結論は対称短時間作用素を仮定した後の条件付き結果であり、M44のミクロ軌道加速度から直接導かれたものではない。

## 4. 数値検査で確認していた範囲

旧`tools/verify_capture_entropy_preparation.py`は、次を有限格子上で検査した。

- 有限$R$捕捉因子の指数極限
- 対称準備作用素の主固有関数
- Doob核の確率保存と詳細釣り合い
- 左右形成因子の積による平方密度
- 定常Nelson加速度
- Fisherエネルギー恒等式

これらは、仮定した縮約作用素の内部整合性を検査したものである。有限Hamiltonianから基準位置核、反復捕捉、尺度整合を導く検査ではなかった。数値コードは現行ツリーから削除し、上記コミットのGit履歴で保存する。

## 5. 不採用理由

M44を現行補助モデルから外した理由は次の4点である。

1. 座標--運動量整合を提案したが、一般の非線形$V$の下で無偏向位置拡散核を導けなかった。
2. 固定された捕捉位相体積比を、短時間$\delta$に比例する局所準備率へ変換できなかった。
3. 1つの有限捕捉器が、使用済み相関の再帰なしに準備、離脱、帰還を定常反復することを示せなかった。
4. 捕捉器の形成・保持方向と、位置作用素の左・右固有関数を同一視する周辺可逆性を示せなかった。

M44は計算誤りだけで不採用になったのではない。必要な確率構造を有限Hamiltonian候補から導いた範囲と、縮約作用素として仮定した範囲が離れすぎていたため、物理モデルとしての説明力が不足した。

## 6. M45との関係

M45は、有限閉鎖Hamiltonianへの持ち上げを採用条件とせず、周期反応座標と対数型エントロピーreservoirを開放Langevin方程式で直接動かす。能動注入、非線形飽和、熱雑音、散逸を明示し、分離面近傍の準備殻、位相すべり、有限時間帰還を同じ方程式から数値検査する。

一方、M45でも次は橋渡し条件として残る。

1. $W(X)$を内部利用可能エネルギーへ移す局所結合
2. 1周期の選別を時間比例準備率へ変える尺度整合
3. 能動捕捉器を消去した位置核の周辺可逆性

従って、M44の未解決問題を解決済みと呼び替えたわけではない。M45では、直接運動として具体化した部分と、条件付き位置作用素として仮定した部分を分けて管理する。

## 7. 再検討条件

次の全てを1つの有限Hamiltonianまたは制御された有限時間極限から示せた場合に限り、M44型経路を再検討する。

- 位置拡散係数$\nu$と捕捉エントロピー係数が同じ保存量または結合尺度から決まる。
- 一般の滑らかな$V$に対して位置核の余分なドリフトと位置依存拡散を制御できる。
- 捕捉、離脱、帰還を再帰前の時間窓で反復できる。
- 位置へ射影した準備核の可逆測度を示せる。
- ミクロ条件付き加速度とNelsonの時間対称加速度の差を評価できる。
