# 置換済み2成分誘導場経路

## 位置づけ

draft-19までの現行模型は、物理空間上の実在2成分誘導場、粒子との位相接続、標本場のコヒーレント集中、粒子密度・流束との同期を力学側の主線に置いていた。draft-20で、有限正準位相担体の相関行列力学へ置き換えた。

旧章の完全な内容はdraft-19の版履歴で保存し、このメモへ複製しない。

## 不採用理由

1. 各標本場が残差付き Schrödinger 型方程式に従うことを先に仮定し、その集団平均から代表場を作る構造だった。
2. 高速整合、標本場の集中、粒子密度・流束との同期が独立条件として残った。
3. 実在場と粒子が別のエネルギー保有系になり、粒子誘導と反作用の役割が複雑になった。
4. 節近傍の正則化位相接続、半正定値方向、時間依存射影、非線形再励起を含むミクロ残差上界を完成できなかった。
5. 位置入口作用殻と Bell 対モードの主要計算は、連続実在場を必要としなかった。

不採用は旧模型の全ての有限次元計算が誤りであることを意味しない。現行主線に必要な仮定が強く、相関行列模型より構造が複雑だったため採用をやめた。

## 再利用価値のある結果

- 実正準対の極座標表示と共通回転生成子。
- 固定作用下の局所作用欠陥平方分解。
- 厳密規格化単体上の局所正準座標。
- 正定値2次模型の低速・高速スペクトル分離。
- 同型有限補助系による高速成分の可逆交換。
- 有限作用交換浴の全作用保存と短記憶近似。
- 配置拡散、Fisher項、Guerra--Morato作用に関する補助計算。

これらは有限 Hamiltonian の準備・縮約技法として再利用できるが、現行相関行列模型の定理または誤差評価には使わない。

## 現行模型での置換先

| 旧構成 | 現行構成 |
|---|---|
| 実在2成分誘導場 | 有限正準位相担体 |
| 標本場のコヒーレント集中 | 相関行列の階数1または近似階数1条件 |
| 代表場 | 階数1相関の因子 $\chi$ |
| 場強度と粒子密度の同期 | 相関対角成分から位置入口作用殻への条件付き接続 |
| 位相接続粒子 Hamiltonian | 現行模型では置換せず、粒子の連続運動を未解決とする |
| 連続単価場の循環量子化 | 現行模型では置換せず、Wallstrom 問題を未解決とする |

## 再検討条件

次のいずれかが得られた場合に、旧計算の一部を補助模型として再検討できる。

1. 相関行列模型の非線形閉包に、旧低速・高速分離が直接必要になる。
2. 粒子の連続流束を有限正準位相担体から導く際、旧位相接続の局所計算が循環なく再構成できる。
3. 空間グラフ上の位相量子化を連続極限へ進める際、旧単体局所座標が誤差評価に必要になる。
4. 共通源の再初期化に、旧作用交換浴または高速交換補助系が局所的に使えることが示される。
