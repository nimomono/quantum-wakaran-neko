| $\varepsilon_j$ | $j-\mathcal J_\phi r^2$ | 固定作用最小配置 |

## 8.3 Born 型入口流束の誤差

理想重みは

```math
P_i^{(0)}
=
r_i^2\Delta V.
```

主要誤差は次である。

| 誤差 | 内容 |
|---|---|
| $\varepsilon_{\rm flux}$ | 法線速度、障壁、coarea Jacobian、解多重度のチャンネル差 |
| $\varepsilon_{\rm mix2}$ | 2モード殻準備の異方性と有限混合時間 |
| $\varepsilon_{\rm action}$ | $A_i-A_{\rm tot}r_i^2\Delta V$ |
| $\varepsilon_{\rm exclusive}$ | 複数入口チャンネルの同時開放 |
| $\varepsilon_{\rm reset}$ | 標本化後の活性場再埋め込みと明反応座標復元 |

直接作用分配方向が $q\neq1$ なら、これは小さい摂動ではなく構造的な変更であり、

```math
P_i
\propto
\left(
r_i^2\Delta V
\right)^q
```

となる。線形 Born 型重みは失われる。

正規化されたsector集団の $U(2)$ 混合だけでは $\varepsilon_{\rm flux}$ を零にできない。共通未規格化境界密度の準備は独立な課題である。

## 8.4 Bell 対モードの誤差

反対称源の理想行列からのずれを

```math
C_{\rm src}
=
C_0+\delta C
```

とする。枝作用の1次変化は

```math
\delta K_{AB}
=
2\operatorname{Re}
\left[
\left(
C_{AB}^{(0)}
\right)^*
\delta C_{AB}
\right]
+
O
\left(
\|\delta C\|^2
\right).
```

主要誤差は次である。

- 反対称源の振幅非対称。
- 2源チャンネルの相対位相散逸。
- 対モードから他モードへの漏出。
- 左右分析器の角度誤差と交差応答。
- 設定窓の時間重なり。
- 戻り伝達の損失、分散、チャンネル混合。
- 共通内部回転対称性を壊す結合。
- 平面内2出力モード近似からのずれ。

位相雑音が対称なら主効果は可視度 $V_\phi$ の低下である。振幅または損失が結果依存なら、総規格化と周辺対称性も変わる。

## 8.5 比較器と境界測度の誤差

理想比較作用を

```math
A_{\partial,0}^{AB}
=
\frac{\Gamma^2}{2}K_{AB}
```

とする。有限装置では

```math
A_\partial^{AB}
=
A_{\partial,0}^{AB}
+
\delta A_{\rm pulse}^{AB}
+
A_{\rm bg}^{AB}.
```

境界質量を

```math
\widetilde W_{AB}
=
\frac14
\Lambda_\partial
\Omega_2
\left(
A_{\partial,0}^{AB}
\right)
\left[
1+\delta_{\partial}^{AB}
\right]
```

と書く。$\delta_\partial^{AB}$ には次を含む。

- 比較器の初期座標・運動量。
- 有限比較パルスと入力自由発展。
- $U(2)$ 混合不足。
- 結果別の境界密度または流束因子。
- coarea Jacobian と解多重度の差。
- 結果sector基準多重度の非対称。
- spectator体積の結果依存。
- 作用零近傍の有限幅背景。
- 比較、逆計算、再初期化の失敗率。
- 時計面の複数交差または未到達。

共通の $\delta_\partial^{AB}$ は規格化で相殺するが、結果依存成分は共同確率を変える。非信号性には、遠隔設定を変えたときも結果別偏差が周辺和で相殺する追加条件が必要である。

## 8.6 CHSH超過と可視度

共同法則が

```math
P(A,B\mid a,b)
=
\frac14
\left[
1
-
V_{\rm Bell}
AB\cos\Delta_{ab}
\right]
```

を保つ場合、

```math
|S_{\rm CHSH}|
=
2\sqrt2V_{\rm Bell}.
```

古典上限を超える条件は

```math
V_{\rm Bell}
>
\frac1{\sqrt2}.
```

確率誤差が各設定で全変動距離 $\delta_{\rm TV}$ 以下なら、粗い上界

```math
\left|
\delta S_{\rm CHSH}
\right|
\leq
8\delta_{\rm TV}
```

を用いられる。従って十分条件は

```math
2\sqrt2V_{\rm Bell}
-
8\delta_{\rm TV}
>
2.
```

理想余弦則が $2\sqrt2$ を与えることと、一般的な Tsirelson 原理を導くことは別である。

## 8.7 否定的結果と適用限界

1. 閉鎖 Hamiltonian 流は、一般に低次元の coherent多様体へ永久的に吸引しない。有限浴を含む全系も Hamiltonian であり、対象部分の有効減衰は準備窓で浴へエネルギーを移すことを意味する。
2. 固定作用下のエネルギー最小配置と有限特異 Hamiltonian の低速枝は、それだけでは一般初期値からの動力学的準備を意味しない。
3. 作用交換浴を観測中も作動させると、必要な相対位相運動を変え得る。準備窓と観測窓を分ける必要がある。
4. rank-one 2次モーメントだけでは非線形位相接続の標本平均を閉じない。
5. $\kappa=\mathcal J_\phi^2/(2m)$ は内部回転対称性だけから従わない。
6. 同期差保存は、同期多様体への復元力ではない。
7. 条件付き循環量子化は、節を含む Wallstrom 問題の全面解決ではない [19]。
8. 位置入口の Born 型流束は、任意基底の一般 Born 則ではない。
9. 直接作用分配方向が複数なら、入口重みは一般に作用の高いべきになる。
10. 低ランク相関 $C$ は独立した配置空間場ではない。
11. 低ランク相関と局所回転だけでは Bell 頻度は生じない。
12. 共通未来比較器だけでは、前向き因果として過去の結果頻度を変更できない。
13. 比較器の Hamiltonian 読み出しだけでは殻容量に比例するsector質量を生成しない。
14. $U(2)$ 混合は正規化されたsector総質量を変えない。
15. Bell 重みには共通境界測度の準備が必要である。
16. 現行局所装置は既存の2値sectorを符号化するが、一般的な唯一結果形成を与えない。
17. 異なる結果履歴を同じ全位相点へ押しつぶす完全resetは Hamiltonian ではない。
18. Bell 余弦則は、一般 Born 則、Wallstrom 問題、一般 Tsirelson 原理を単独では解かない。
19. 現Bell模型は平面内の2出力分析設定に限定される。
20. 配置拡散経路の Brown 極限、配置 Markov 閉鎖、時間対称 Newton 則は未完成であり、現行主線には使わない。

## 8.8 反証に使える観測量

現行模型は次の量で反証または制約できる。

- coherent集中誤差と活性場2次モーメントの非 rank-one 成分。
- $j-\mathcal J_\phi r^2$ と $r^2-\rho$ の時間発展。
- 準備終了時の $P_i$、$\delta J_i$、欠陥エネルギー、時間平均、観測中の再成長率。
- $\mathcal J_\phi$ と全 Hamiltonian の保存誤差、浴モード数、温度、切断時刻、再帰時間への依存性。
- $\kappa-\mathcal J_\phi^2/(2m)$。
- 巻数と粒子流速循環の不一致。
- チャンネル別の位置入口流束因子 $\lambda_i$。
- 入口頻度の $r_i^2\Delta V$ からのずれ。
- 反対称源からの $\delta C$ と源チャンネル相対位相。
- 局所分析器の角度誤差と遠隔交差応答。
- 戻り信号の利得、分散、位相保持。
- 比較読み出し後の $A_\partial^{AB}-\Gamma^2K_{AB}/2$。
- 比較殻上の異方性と混合時間。
- 結果別・設定別の境界密度、coarea Jacobian、解多重度。
- 作用零sectorの背景率。
- 開始数、局所記録数、比較完了数、外部記録数、reset完了数の不一致。

## 8.9 最重要の未解決問題

現在の最重要課題は次の順に整理できる。

1. 2モード比較殻へ容量に比例する共通境界密度を、事後選別なしの実験周期として準備する。
2. 設定生成器、局所結果形成、増幅、記録を同じ周期へ含める。
3. 比較後の結果を外部へ保持しながら、比較、戻り伝播、分析器、場を可逆に再初期化する。
4. 位置入口側の標本化後に、活性場を coherent部分空間へ再埋め込みする。
5. 局所作用整合準備を、動的振幅、有限温度、有限浴再帰、浴切断後の長時間安定性まで含む一様な誤差評価へ進める。
6. coherent集中と密度同期を準備し、coherent多様体上の縮約作用が有限 Hamiltonian 粗視化運動を実際に支配することを示す。
7. 節を含む位相接続と循環量子化を制御する。
8. 反対称対モードを生成する有限 Hamiltonian 源と長時間の位相保持を構成する。
9. 平面内2出力を超える一般測定器と複合状態構成へ拡張する。
10. 非対称準備と有限誤差を含む一般的な非信号条件を示す。

中心的な測度上の課題は、殻容量の線形性ではなく、同じ密度で異なる殻を数える物理的境界集団をどう準備するかである。

## 8.10 最終結論

有限2成分場の正準構造と位相接続を用いると、coherent縮約多様体上で Madelung 作用と局所 Schrödinger 型方程式を得る。保存位相作用は有効作用定数となり、単価な非零場は条件付き循環量子化を与える。この主線は配置拡散を前提にしない。

局所作用整合と動径低速化については、有限特異 Hamiltonian の正確な消去により有界な低速枝を構成し、共通位相回転に不変な有限作用交換浴と振幅浴を準備窓へ加えた。固定振幅・短記憶・低温の準備近似では欠陥エネルギーが減少する。これは coherent多様体全体の導出ではなく、$\varepsilon_j$ と $\varepsilon_{\rm radial}$ の準備を部分的に具体化した結果である。

2モード作用殻の Liouville 流束は、共通流束因子と単一の直接作用分配方向の下で、位置の Born 型入口密度を与える。

同じ2成分場の2つの直交源チャンネルは、反対称低ランク相関を通じて Bell 余弦作用を与える。共通未来の2つの比較モードは、その相関振幅の実部と虚部を比較総作用へ転送する。共通境界測度を仮定すれば、2モード殻の線形容量から Bell 共同確率、CHSH値、非信号周辺を得る。生成側へ引き戻した完全履歴測度は設定に依存し、Bell の測定設定独立性を満たさない。

本論文は、Schrödinger 型力学、その法線欠陥の有限時間準備、位置の Born 型入口重み、Bell 余弦作用、2モード比較作用を1つの2成分場アーキテクチャへ整理した。しかし、coherent集中、密度同期、共通境界測度、一般的な結果形成、coherent場の再埋め込み、反復可能な完全周期を1本の有限 Hamiltonian から導いていない。この境界を超えて主張しない。
