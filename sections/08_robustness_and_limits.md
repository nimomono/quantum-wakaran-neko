## 8.1 弱開放性と主要誤差

現行モデルでは、有限装置部分の1周期収支を

```math
\Delta E_{\rm fin}
=
W_{\rm src}
+
W_{\rm set}
+
W_{\rm pulse}
+
W_{\rm reset}
+
Q_{\rm in}
-
Q_{\rm out}
```

と分ける。定常運転では装置の入口巨視状態が周期ごとに再現されるため、長時間平均で

```math
\left\langle
\Delta E_{\rm fin}
\right\rangle_{\rm cycle}
=
0
```

が必要である。これは各項が零であることを意味せず、仕事供給と外部への排熱が釣り合うことを意味する。

1試行の閉鎖補助モデルを用いる小さい量は

```math
\varepsilon_{\rm open}
=
\frac{
\sup_{0\leq t\leq T}
\left|
E_{\rm fin}(t)-E_{\rm fin}(0)
\right|
}{
E_{\rm ref}
}.
```

2モード作用分配系には、総作用漏れ $\varepsilon_\ell$、有限時間混合誤差 $\varepsilon_{\rm mix}$、局所パルス誤差 $\varepsilon_{\rm pulse}$、終端応答幅の無次元量 $\varepsilon_R$ が加わる。しきい値が作用殻の端点から離れ、各誤差が結果と測定設定に一様な範囲では、Bell 共同法則の補正を

```math
O
\left(
\varepsilon_{\rm open}
+
\varepsilon_\ell
+
\varepsilon_{\rm mix}
+
\varepsilon_{\rm pulse}
+
\varepsilon_R
\right)
```

と整理する。この式は誤差の分類であり、全係数を与えた一様定理ではない。各小さい量を独立に変え、閉鎖補助モデルとの比較と収束試験を行った範囲でのみ近似結果として採用する。

結果または測定設定に相関したエネルギー漏れ、混合誤差、リセット失敗、完了率は、単なる可視度低下では済まない。規格化因子、設定頻度、一側周辺、高次調波を変え得るため、次を別々に測る必要がある。

1. 生成源が開始した試行数。
2. 左右の指針が確定した記録数。
3. 終端比較が完了した試行数。
4. 次試行の入口状態へ再初期化できた回数。
5. 各段階の結果別・設定別の交換エネルギーと所要時間。

## 8.2 2モード条件と終端幅

一様密度からのずれを

```math
p(h)
=
\frac1{E_\ell}
\left[
1+\varepsilon r(h)
\right],
\qquad
\int_0^{E_\ell}r(h)dh=0
```

と書くと、累積整合重みは

```math
F(x)
=
\frac{x}{E_\ell}
+
\frac{\varepsilon}{E_\ell}
\int_0^x r(h)dh
```

となる。$x=C-ABK\cos\Delta$ を代入したとき、第2項は一般に高次調波を生む。

第6.8節の多モード補助比較では、ソフトモードが $N$ 個の残余作用モードと総作用を共有すると

```math
F_N(x)
=
1-
\left(
1-\frac{x}{E_\ell}
\right)^N
```

となり、$N>1$ では線形でない。この厳密な否定的結果は、多モード構成を現行モデルへ採用するためではなく、純粋な余弦則に必要な2モード条件を示すために用いる。

理想終端関数

```math
G_R
=
\mathbf1_{\{\Pi_R\geq0\}}
```

を幅 $\epsilon_R$ の滑らかな応答 $g_{\epsilon_R}$ へ置き換えると、

```math
F_{\epsilon_R}(x)
=
\int_0^{E_\ell}
\frac{dh}{E_\ell}
g_{\epsilon_R}(x-h)
```

となる。$x$ が $0$ と $E_\ell$ の両端から十分離れ、応答核が平行移動共変なら、主要項は $x/E_\ell$ である。両端へ近づくと切断補正が入り、零しきい値領域にも有限の背景重みが生じ得る。

終端幅を小さくするだけでは物理的予測が改善するとは限らない。記録雑音、作用漏れ、有限パルス誤差より狭い終端幅を選べば未記述の補正が支配するため、

```math
\epsilon_R
\gg
\left|
\delta\Pi_R
\right|
```

を保ちながら角度依存を分解できる範囲が必要である。

## 8.3 `[R]` の物理的地位

閉鎖有限 Hamiltonian 系は再帰を持ち得る。時間反転可能な方程式は終端境界条件を数学的に許す。しかし、有限性、再帰性、時間反転対称性、弱開放な再初期化を合わせただけでは

```math
d\mu_R
\propto
\rho_S
G_R\circ\Phi^T
d\Gamma
```

を物理的確率法則として一意に選べない。`[R]` は、本構成を通常の初期値統計力学から区別する未導出の統計原理である。

相補的内部時計はこの区別を明確にする。$\Pi_R(T)\geq0$ は、初期に選んだ時計向きの順序が終端まで保存された条件として導ける。しかし $\Pi_R(T)<0$ の軌道も Hamiltonian 解であり、時計向きが交換されるだけである。従って時計相補性は $G_R$ の半空間を説明するが、$G_R$ を履歴確率へ変換しない。

初期境界密度 $\rho_S(z_i)$ と終端関数 $G_{\rm or}(z_f)$ を同一 Hamiltonian 履歴として照合する規則を追加すれば、

```math
d\nu
\propto
\rho_S(z_i)
G_{\rm or}(z_f)
\delta
\left(
z_f-\Phi_{a,b}^{T}z_i
\right)
d\Gamma_i\,d\Gamma_f
```

から `[R]` の積形式を得る。ただし2つの境界密度を掛けて照合する規則自体が、追加の全履歴統計原理である。

従って、`[R]` を仮定した終端整合体積の計算が厳密であることと、実験の無条件試行頻度がその測度に従うことを分ける。後者は予想・未解決であり、`[R]` に仮説依存する。

## 8.4 対称準備の適用限界

第7章の非信号性は `[S]` の対称準備を必要とする。一般の基準結果重みを $w_{AB}$ とすると、

```math
P_w(A,B\mid a,b,R)
=
\frac{
w_{AB}
\left[
C-ABKc
\right]
}{
\displaystyle
\sum_{A',B'}
w_{A'B'}
\left[
C-A'B'Kc
\right]
},
```

```math
C=E_*+\kappa I_0,
\qquad
K=\kappa I_0V,
\qquad
c=\cos\Delta_{ab}.
```

同時符号反転対称性

```math
w_{++}=w_{--},
\qquad
w_{+-}=w_{-+}
```

があれば一側結果周辺は $1/2$ に保たれる。しかし偶奇領域の基準質量が異なると、全整合体積が測定設定に依存し得る。結果周辺と設定頻度の両方を最も単純に保つ条件は $w_{AB}=1/4$ である。

従って `[S]` の非信号性は対称準備についての成立条件であり、任意準備についての定理ではない。偏った準備装置まで含む2境界問題で非信号性が回復するかは未解決である。

## 8.5 Tsirelson 限界と Wallstrom 問題

本構成が直接与えるのは、実2次元の等振幅伝達ベクトルと2次差動比較器による

```math
I_-
\propto
1-AB\cos\Delta
```

である。従って

```math
\left|
\mathcal S
\right|
=
2\sqrt2V_{\rm eff}
\leq
2\sqrt2
```

は $0\leq V_{\rm eff}\leq1$ と、この比較器設計の帰結である。一般の非負スカラー比較関数を許せば異なる相関表を構成できるため、Tsirelson 限界を独立な一般原理から導いたとは言えない。

第I部の Nelson 表示から一般の Schrödinger 理論を再構成するには、配置空間の閉路に沿う位相循環を量子化する必要があり、Wallstrom 問題が残る [19]。第II部の余弦は伝達ベクトルの内積から生じるが、配置空間位相 $S(x)$ の閉路条件

```math
\oint\nabla S\cdot d\ell
\in
2\pi\hbar\mathbb Z
```

を導かない。従って Bell 型余弦共同確率は Wallstrom 問題を解かない。

## 8.6 反証に使える観測量

モデルを区別する主要な観測量は次である。

1. 比較パルス前後の $I_-$、$h$、$\Pi_R$ を測り、2つの作用保存と読出し誤差を検査する。
2. 有限装置部分の流入、流出、制御仕事を測り、$\varepsilon_{\rm open}$ と $\varepsilon_\ell$ を評価する。
3. ソフトモードエネルギーの累積分布と Bell 角依存性の高次調波を測り、2モード作用分配系からのずれを検査する。
4. 偏った結果種準備で非信号性残差を測り、`[S]` の適用範囲を検査する。
5. 開始数、記録数、完了数、再初期化数を分け、結果依存の欠測と事後選別を検査する。
6. 局所パルス幅、外部結合、混合時間、終端幅を独立に変え、補正の収束次数を検査する。
7. 次試行の入口分布が前試行の結果または設定に依存しないかを検査する。

具体的な実行命令、標本数、許容誤差、検査結果は `VALIDATION.md` に置く。

## 8.7 残る課題

最重要の未解決問題は次である。

1. 弱開放な準備、測定、記録、消去、再初期化を1周期の明示 Hamiltonian と外部結合で構成し、エネルギー収支を閉じられるか。
2. `[R]` の2境界照合規則を、その試行周期またはより大きな境界値理論から導けるか。
3. 設定、到来変数、装置微視状態から結果を形成する一般の局所 Hamiltonian 測定相互作用を構成できるか。
4. 弱開放ミクロモデルから第I部の線形 Gauss 型確率表示を導き、Markov・白色雑音・線形化誤差を評価できるか。
5. 微視的時間発展が Nelson 作用の停留点を選ぶ機構を示せるか。
6. 有限非線形混合器の混合時間、再帰時間、総作用漏れを定量化できるか。
7. 偏った準備装置まで含めた2境界問題が非信号性を回復するか。
8. 2次比較器と Tsirelson 限界を追加原理から選べるか。
9. Nelson 位相と生成源の作用角位相を結び、Wallstrom 量子化へ進めるか。

## 8.8 最終結論

第I部で厳密に確立したのは、指定した線形 Gauss 型確率表示に対する、繰り込み済み粗視化作用形式の定量的パラメータ $C^1$ 収束である。これは弱開放ミクロモデルからの縮約、微視的 Hamiltonian 運動による Nelson 停留点選択、量子力学全体の導出ではない。

第II部では、実2次元差動比較器、2モード作用分配系、相補的内部時計を有限 Hamiltonian 部品として接続し、閉鎖比較窓で

```math
\Pi_R(T)
=
E_*+\kappa I_- -h
```

を有限幅でも厳密に読み出した。固定作用殻の一様密度、対称準備、`[R]` を仮定した後の Bell 型余弦共同確率も厳密に計算できる。Bell の前提違反は測定設定独立性に位置する。

一方、`[R]` は現行モデルの力学と試行周期から導かれておらず、局所装置も一般測定相互作用には達していない。従って物理的な Bell 予測は予想・未解決であり、`[R]` に仮説依存する。現在の到達点は Bell 型確率構造の完全な力学的導出ではなく、厳密に実現した部品、制御された近似、未導出の統計入力、適用限界を分けた構成である。
