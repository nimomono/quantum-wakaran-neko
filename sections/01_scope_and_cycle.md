## 1.1 研究上の問い

本論文の目的は、明示的な古典Hamiltonian 系から、量子力学に特徴的な可逆力学と確率構造が有効理論として現れ得る範囲を明らかにすることである。量子力学をミクロHamiltonian の入力には使わず、得られた力学、測定操作、統計を判定するときに比較対象として使う。

有限次元Schrödinger 方程式を実正準座標へ写すことだけでは、量子力学の創発にならない。本稿は次を分けて要求する。

1. $L=2$ の同じ正準担体上で、状態空間、可逆操作、Rabi 振動を構成する。
2. その担体を滑らかな測定後状態、逐次測定、記録、reset へ接続する。
3. 継続するRabi 駆動と有限回の反復測定を同じM38周期で接続する。
4. 空間Schrödinger 型包絡は、通常の位置結合を持つ有限実振動子網から誤差付きで導く。
5. 一般有限 $L$ の測定回路と完全周期を、$L=2$ の達成から分離して評価する。
6. 4モード担体上で2つの論理部分系、局所操作代数、結合ゲートを定義する。
7. Bell型統計は、設定前基準測度から2担体準備、局所測定、永久記録、帰還までを前向き周期として構成し、Bellの前提を監査する。
8. 空間位相担体だけから粒子位置を読み込まず、独立の局在粒子トークン、初期作用比準備、等変力学、局所位置検出を構成する。

M38は1--3、M37は4、M35は5、M39は6、M41は7、M42は8を担う。Q1、Q2、Q3は有限モード正準担体の代数を共有するが、これらを1つのM0または同一ミクロハードウェアへ統合したとは主張しない。

## 1.2 導出状態と達成判定

導出結果は、厳密結果、近似結果、予想・未解決を区別する。装置の有限幅、比較境界、時計、記録、resetに由来する誤差は、理想式の導出状態と混同せず、明示上界または全変動距離で評価する。

本稿の「達成」は、固定された達成範囲で基準を厳密に満たす場合だけでなく、任意の $\epsilon>0$ に対して誤差が $\epsilon$ 未満となる有限自由度・有限パラメータの明示構成を選べる場合も含む。形式的な極限だけ、または構成のない収束仮定は含まない。Q1-4では $N_{\rm Z}$ と測定間隔列を先に有限値へ固定する。Q2-2の「条件付き達成」における条件は操作的接続という解釈であり、精度パラメータ条件ではない。

M37の正常モード包絡 $\widetilde b$ は、ミクロ振動子を解析するための厳密だが一般に非局所な正準変数である。独立した非局所物理場として追加しない。M42の $(Z,P_Z)$ はこれと異なり、R62が示した不足を補うために追加する独立の局在正準変数であり、$X(Z)$ はその粗視化セル位置である。

## 1.4 測度と結果空間の区別

理想有効担体の調製集団については

```math
C_M(t)
=
\mathbb E_{\mu_{\mathcal P,M}}
\left[
d_td_t^\dagger
\right]
```

と相関行列を定める。$\mu_{\mathcal P,M}$ は調製条件 $\mathcal P$ とプログラム $M$ を固定した集団測度であり、補助統計理論に使う。

M35の固定純粋準備 $\chi$ と固定基底 $W$ の周期では、

```math
d\mu_{\chi,W}^{\rm M35}
=
\frac{d\vartheta}{2\pi}
\otimes
\delta_*
```

がPoincaré 不変測度になる。$\delta_*$ は選択器角以外の内部準備集合を表す。

M38の固定有限 $N_{\rm Z}$ 段プログラムでは、

```math
d\mu_{\chi,N_{\rm Z}}^{\rm M38}
=
\frac{
d\vartheta_1\cdots d\vartheta_{N_{\rm Z}}
}{
(2\pi)^{N_{\rm Z}}
}
\otimes
\delta_*
```

が理想Poincaré 不変測度になる。$1,\alpha_1,\ldots,\alpha_{N_{\rm Z}}$ の有理数体上の1次独立性により、固定有限次元の角平行移動は一意エルゴード的である。Q1-2の2段測定は $N_{\rm Z}=2$ の場合である。

M42の固定初期担体 $b_0$ と固定有限 $K$ 更新プログラムでは、初期準備角と各更新角に

```math
d\mu_{b_0,K}^{\rm M42}
=
\frac{
d\vartheta_0d\vartheta_1\cdots d\vartheta_K
}{
(2\pi)^{K+1}
}
\otimes
\delta_{b_0,*}
```

を置く。$\vartheta_0$ は粒子トークンの初期作用比準備、$\vartheta_1,\ldots,\vartheta_K$ は局所更新に使う。固定 $K$ の積Haar測度と、無期限運転に必要な新規の選択器セル流は区別する。

M41では設定選択器、源選択器、A、B局所選択器の開始面積測度を

```math
d\mu_0^{\rm M41}
=
\frac{
d\xi_A\,d\xi_B\,
d\vartheta_{\rm s}\,
d\vartheta_A\,d\vartheta_B
}{
(2\pi)^5
}
\otimes
\delta_*
```

とする。測定開始面の設定条件付き測度は、前向き準備写像 $T_{xy}$ による押出し

```math
\mu_{\rm meas}^{xy}
=
\left(T_{xy}\right)_\#
\mu_0^{\rm M41}
\left(
\cdot\mid x,y
\right)
```

である。

これらの測度は役割が異なる。可変調製、可変基底、空間伝播、粒子トークン、M41の設定生成・2担体準備・外部記録までを同じ反復系へ統合する将来目標の母測度を $\mu_*$ と書く。本稿は $\mu_*$ の存在、不変性、エルゴード性を現行定理の仮定に使わない。

M39の非因子化生成と局所操作だけへの分解不能性は、操作誘導テンソル積とCNOT流の内部診断であり、Q2-1の合格条件ではない。Q2-1を構成するM39の読出し前4モード出力状態を $c$ と書く。M41はこの $c$ をA設定基底で階数2選択し、A担体を局所準備し、選択済みBブロックだけをB担体へ正準SWAPする。

Q2-2の条件付き達成は、この受渡しを「2つの物理的測定端で同じ共同統計を得る操作的接続」と読むことを条件とする。4モード状態全体を保存したまま、設定選択前に2つの独立物理部分系へ分配する状態的接続は未達である。

## 1.6 全モデル共通の非主張

主張範囲外の事項を、重複を避けて次の8群にまとめる。個別モデルのより細かな適用限界は各担当章末と第10章に示す。

1. 量子力学の全構造、一般Born則、Wallstrom問題、連続スペクトルを導出したこと。
2. M37、M38、M35、M39、M41、M42を1つのM0または同一ハードウェアへ統合したこと。共通なのは有限モード有効代数であり、特にM38の $QQ+PP$ 操作をM37の位置ばねだけから導いたとはしない。
3. 一般有限 $L$ の複数段完全周期、可変調製・可変基底を含む統一エルゴード周期、独立同分布型または二項分布型の有限標本統計、無反応なしの滑らかな厳密離散測定。
4. M37の局所作用が厳密保存されること、正常モード包絡が局所物理場であること、M42の等変性だけで初期Born型分布が生成されること、有限装置が節を厳密追跡すること、粒子トークンが担体の全エネルギー・質量・電荷を運ぶこと、連続空間または多粒子へ拡張済みであること。
5. M38の有限Zeno結果を、固定性能の1台による $N_{\rm Z}\to\infty$、有限間隔での完全凍結、全時間域の単調抑制、測定中のRabi項停止、摩擦またはresetだけによる抑制へ拡張すること。
6. M39を2つの独立物理担体または空間分離装置とみなすこと、単一担体内相関をBell実験とみなすこと、自然なミクロ結合または多項式資源の多量子ビット拡張を得たこと。
7. M41を標準的な空間分離Bell実験とみなすこと、枝条件付き準備後に設定を自由変更して同じ統計を保つこと、一般Tsirelson原理、一般非singlet状態の作用側チャネル除去、4モード状態全体の設定非依存な2部分系分配。
8. 有限閉鎖系の固定容量で永久記録を無期限に蓄積すること、結果履歴を含む全系を同一点へ押しつぶすこと、resetの熱力学的最小仕事、総エネルギー収支、資源下界を導いたこと。

配置拡散・Nelson経路、旧2成分誘導場、旧位置作用殻、前周期記憶モデルは現行主線に採用しない。再利用価値のある結果と不採用理由は研究メモまたは版履歴で管理する。

## 1.7 論文の読み方

第2章はQ1、Q2、Q3が共有する有限モード正準代数と、M35、M38、M39、M41、M42が再利用する装置部品を整理するが、全モデルを合成したM0ではない。第3章から第5章はQ1と一般有限基底測定、第6章から第8章はQ2、第9章はM37位相担体とM42粒子トークンからなるQ3系統を扱う。第10章は誤差、資源、反証条件、未完成目標を横断比較し、第11章で確立事項と未確立事項を分けて結論する。

付録Aは共通補題、付録BはM38の2モード完全周期、付録CはM38の有限Zeno周期、付録DはM35の一般有限基底構成、付録EはM39の4モード操作代数、付録FはM41の正準構成、付録GはM37の正常モード変換と包絡誤差、付録HはM42の最小跳躍過程、節正則化、Hamiltonian実装、誤差伝播を扱う。
