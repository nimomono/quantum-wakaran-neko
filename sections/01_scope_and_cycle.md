## 1.1 問題設定

Bell の定理は、局所応答、結果の確定性、測定設定独立性などを同時に満たす理論が、特定の Bell--CHSH 相関を再現できないことを示す [1,2]。古典 Hamiltonian モデルが Bell--CHSH 不等式を超える相関を与えるなら、Bell の前提の少なくとも1つが成立していない。本論文はこの論理を回避せず、軌道法則、準備測度、測定過程、終端条件、試行の数え方を個別に監査する。

扱う問題は次の2つである。

1. 補助的な有限 Fourier–Gauss 型経路法則から、Nelson 型作用の形式をどこまで定量的に得られるか。
2. 有限 Hamiltonian 装置部品に2境界統計原理を加えたとき、終端整合体積から Bell 型共同確率をどこまで計算でき、その物理的実現に何が残るか。

第1の問題には、第4章のパラメータ $C^1$ 収束定理として答える。第2の問題では、`[R]` を仮定した後の体積積分は厳密に実行できる。しかし、実験の試行頻度が `[R]` に従うことは Hamilton 方程式から導いていない。従って第II部の物理的 Bell 予測は仮説依存結果であり、完全な力学的導出ではない。

## 1.2 2部の論理的独立性

第I部は、有限 Fourier–Gauss 型駆動、有限分解能の前後記録、繰り込み済み作用を扱う。中心結果は、作用値と指定した有限次元パラメータ方向の第1変分が Guerra--Morato 型 Nelson 作用へ収束するという厳密な定量定理である。

第II部は、局所結果符号化器、固定指針、共通未来の比較器、2モード作用分配系、終端整合性を扱う。第I部の Nelson 極限は Bell 重みを生成しない。両者に共通するのは、局所の時間発展と、完結履歴へ置く統計法則を同一視しないという方法である。

従って、「線形 Gauss 型確率表示から Nelson 作用形式へ進む論理鎖」と、「有限 Hamiltonian 装置部品に2境界統計原理を加えて Bell 型統計へ進む論理鎖」は別である。第I部の厳密結果は `[R]` を必要とせず、第II部の Bell 計算は Nelson 作用を必要としない。

## 1.3 現行モデルと補助モデル

現行モデルは、有限 Hamiltonian 部分と外部自由度を弱く結合した系である。

```math
H_{\rm all}
=
H_{\rm fin}
+
H_{\rm ext}
+
\varepsilon_{\rm ext}H_{\rm link}
+
H_{\rm work}.
```

$H_{\rm fin}$ には生成源、設定制御器、局所装置、伝達ベクトル、比較器、作用分配系、時計、有限浴を含める。$H_{\rm ext}$ は記録安定化、熱交換、装置再準備に関わる外部環境、$H_{\rm work}$ は設定変更、パルス、消去へ仕事を供給する自由度である。

この現行モデルに対して、次の補助モデルを用いる。

| 補助モデル | 役割 | 現行モデルとの関係 |
|---|---|---|
| 1試行内の有限閉鎖系 | 正準写像、保存量、位相体積を厳密に計算する | 弱開放結合を測定窓で無視した近似 |
| 線形 Gauss 型確率表示 | 第I部の作用収束を証明する | 弱結合、線形化、時間尺度分離後の候補表示 |
| OU 表示 | 緩和と回転を具体化する | 開放部分系の計算例 |
| 最小結果符号化器 | 既存の2値符号を固定指針へ写す | 一般測定器の一部だけを抽出 |

閉鎖補助モデルの厳密結果を、そのまま弱開放な現行モデルの厳密結果と呼ばない。両者の接続には、交換エネルギー、観測時間、相関時間、有限幅、装置分解能を用いた近似評価が必要である。

## 1.4 1試行内の近似閉鎖窓

1試行の中心的な測定窓では、有限 Hamiltonian 部分の位相点を $z$、標準シンプレクティック行列を $J$ と書き、

```math
\dot z
=
J\nabla H_{\rm fin}(z)
```

を0次近似として用いる。各部品は滑らかな Hamiltonian 生成子を持ち、閉鎖補助モデルでは位相体積を保存する。操作順序は自律時計によって設定する。

この近似の小さい量を

```math
\varepsilon_{\rm open}
=
\frac{
\sup_{0\leq t\leq T}
\left|
E_{\rm fin}(t)-E_{\rm fin}(0)
\right|
}{
E_{\rm ref}
}
```

とする。適用条件は

```math
\varepsilon_{\rm open}\ll1,
\qquad
T\ll\tau_{\rm exch},
```

である。$\tau_{\rm exch}$ は外部との交換により中心的な作用または記録領域が変化する時間尺度である。

記録については

```math
\tau_{\rm meas}
\ll
\tau_{\rm record}
\ll
T_{\rm rec}
```

も要求する。$\tau_{\rm meas}$ は記録形成時間、$\tau_{\rm record}$ は必要な保持時間、$T_{\rm rec}$ は閉鎖補助モデルの再帰尺度である。実際の弱開放系では外部への流出が再帰を抑え得るが、その効果を抽象的な散逸項だけで済ませず、交換経路と収支を別に追跡する。

本論文が厳密に明示するのは、測定窓を構成する正準写像と比較窓 Hamiltonian である。生成源、設定制御器、全自由発展、外部自由度、全パルスを1本に統合した完成 Hamiltonian と、その一様誤差評価は未構成である。

## 1.5 エネルギー交換と試行周期

有限 Hamiltonian 部分のエネルギー収支を

```math
\Delta E_{\rm fin}
=
W_{\rm src}
+
W_{\rm ctrl}
+
W_{\rm reset}
+
Q_{\rm in}
-
Q_{\rm out}
```

と分ける。各項の意味は次である。

- $W_{\rm src}$：生成源と位相基準を準備する仕事。
- $W_{\rm ctrl}$：設定制御器と自律パルス時計へ供給する仕事。
- $W_{\rm reset}$：指針、応答モード、作用分配系、時計を再準備する仕事。
- $Q_{\rm in}$：外部揺らぎによるエネルギー流入。
- $Q_{\rm out}$：局所浴、記録安定化装置、外部環境への流出。

閉鎖補助モデルでは、これらは拡大した時計または仕事貯蔵自由度との内部交換として表せる。現行モデルでは、実験室の外部供給と排熱まで含めて追跡する。

繰り返し試行は次の4段階からなる。

1. **準備**：生成源、設定制御器、局所装置、作用分配系、時計を指定した入口巨視領域へ置く。
2. **測定と記録**：設定を生成し、局所相互作用で結果を形成し、固定指針へ増幅して記録する。
3. **比較と完了**：記録の写しを共通未来へ送り、差動作用と終端座標を読み出す。
4. **消去と再初期化**：記録を消去し、浴、作用分配系、時計、仕事貯蔵系を次の入口状態へ戻す。

記録消去と再設定は一般に外部へのエントロピーとエネルギーの移送を伴う [17,18]。確率的リセットと有限環境への散逸に関する既知の結果は、試行周期を構成するときの比較対象になる [33,34,40]。

現時点では、この周期が定常な2境界試行集団 `[R]` を自動生成することを導いていない。再初期化を導入しただけで `[R]` が得られるとは限らず、単なる結果依存の完了率または試行棄却なら事後選別になる。

## 1.6 第II部の仮定

第II部の仮定を次の5つに分ける。

### [H] Hamiltonian 装置部品

生成源、設定制御器、局所記録器、有限浴、共通未来の比較器、2モード作用分配系、相補的内部時計、パルス順序時計を有限個の正準対と滑らかな Hamiltonian 生成子で記述する。異なる測定設定と結果に別の Hamiltonian 関数を割り当てず、設定は制御器の初期巨視領域、結果は局所変数と指針領域で表す。

現在の明示モデルは、あらかじめ存在する2値の結果種を指針へ写す最小結果符号化器である。一般の

```math
A=\mathscr A(a,\lambda_A),
\qquad
B=\mathscr B(b,\lambda_B)
```

を到来信号との相互作用から形成する装置は未構成である。

### [P] 位相同期した生成源

左右へ送る2つの実2次元伝達ベクトルは、共通の位相基準と同じ基準作用を持つ。有限の振幅不一致と相対位相雑音は可視度 $V$ に含める。この条件は第I部の Gauss 型確率表示だけから導出されない。

### [S] 対称な基準準備

`[R]` を適用する前の準備 Hamiltonian、準備巨視領域、基準 Liouville 測度は、左右の結果種を独立に反転する2つの変換に不変である。4つの結果領域が1つの軌道に沿って相互遷移する必要はない。必要なのは、基準測度に関して4領域が同じ体積を持つことである。

### [M] 2モード作用分配系の入口測度

ソフトモードと残余作用モードは比較時刻に固定総作用殻

```math
J_s+J_0
=
\frac{E_\ell}{\omega_\ell}
```

上の正規化 Liouville 測度を持つ。直接の準備条件として用いる場合、ソフトモードのエネルギー密度は厳密に一様である。動的な典型化を用いる場合は、有限分解能での混合誤差と総作用漏れを評価する必要がある。

### [R] 2境界統計原理

基準初期密度 $\rho_S$ と全設定に共通な終端関数 $G_R\geq0$ に対し、物理的履歴測度を

```math
d\mu_R^{a,b}(z_i)
=
\frac{
\rho_S(z_i)
G_R\!\left(\Phi_{a,b}^{T}z_i\right)
}{
Z_{a,b}
}
d\Gamma_i
```

とする。$G_R$ は設定名、結果名、目標相関を引数に持たない。相補的内部時計は

```math
G_R
=
\mathbf1_{\{\Pi_R\geq0\}}
```

という半空間へ時計向き保存の意味を与えるが、その半空間だけを物理的集団として数える原理は与えない。

## 1.7 準備対称性と2モード幾何

比較器入口密度

```math
g_{AB}^{\rm ent}(h)
=
\frac{w_{AB}}{E_\ell}
```

のうち、$1/E_\ell$ は2モード作用殻の幾何から得る。$w_{AB}=1/4$ は `[S]` の準備対称性から得る。Hamiltonian の形だけでは初期密度を決められないため、準備測度という統計条件は残る。

弱開放系では、$E_\ell$ の漏れが小さい間だけ固定殻の結果を近似的に用いる。漏れが結果領域または測定設定に依存する場合は、`[S]` と `[M]` の双方を再監査する。

## 1.8 1試行の物理的時系列

1試行を次の10段階に分ける。

1. 位相同期した伝達ベクトル対、局所装置、作用分配系を準備する。
2. 左右の制御器巨視状態により設定 $a,b$ を生成する。
3. 到来変数、設定、局所装置微視状態の相互作用で結果を形成する。現行の明示計算では、この段階を結果種の入力で置き換える。
4. 応答モードが結果符号を受け取り、固定指針が増幅して記録する。
5. 局所浴と外部環境が一時情報を分散し、必要時間だけ記録を安定化する。
6. 記録の写しと伝達ベクトルを通常の時間順序で共通未来へ運ぶ。
7. 比較器が差動作用 $I_-$ を計算する。
8. ソフトモードエネルギー $h$ と差動作用 $\kappa I_-$ を相補時計で比較する。
9. 終端相対時計運動量 $\Pi_R(T)=E_*+\kappa I_- -h$ を読み出す。
10. 完了後に記録、浴、作用分配系、時計を次試行の入口巨視状態へ戻す。

`[R]` は9段階目の終端領域と初期準備を1つの完結履歴として照合する統計原理である。10段階目のリセット操作から `[R]` が導かれるかは未解決である。

左と右は局所記録が形成される前には共通浴を持たない。共通未来の相互作用は、すでに確定した記録の写しを処理する。このため Bell 相関を「共有浴雑音が左右へ順時間的に漏れた結果」とは解釈しない。

## 1.9 主要結果の確立度

第I部の結果を分ける。

| 主張 | 確立度 |
|---|---|
| 線形 Gauss 型条件付き作用の $C^1$ 収束 | 厳密結果 |
| Guerra--Morato 表示と Nelson 表示の一致 | 厳密結果 |
| 弱開放ミクロモデルから線形表示への縮約 | 予想・未解決 |
| 微視的運動による停留点選択 | 予想・未解決 |

第II部の結果を分ける。

| 主張 | 確立度 |
|---|---|
| 実2次元比較器の余弦恒等式 | 厳密結果 |
| 固定総作用殻の一様周辺 | 厳密結果 |
| 内部時計の自由運動を含む比較読出し | 閉鎖補助モデルで厳密結果 |
| `[R]` の下での終端整合体積と共同確率 | 厳密結果 |
| 実験の試行頻度が `[R]` に従うこと | 仮説依存結果 |
| 弱開放試行周期から `[R]` を導くこと | 予想・未解決 |
| 一般測定器の構成 | 予想・未解決 |

順時間的共有浴、結果依存滞在時間、多数の残余作用モードから純粋な余弦重みを得るモデルは不採用モデルであり、それぞれに否定的結果がある。

## 1.10 先行研究との位置関係

Nelson の確率力学、確率変分法、Guerra--Morato 作用には先行研究がある [3--6,35]。Gauss 型条件づけは固定区間平滑化、相反過程、Schrödinger 橋、経路単位の Gauss 型条件づけと関係する [15,16,26--28,36,37]。第I部の新規性は、指定した線形 Gauss 型クラスに対し、有限 Fourier 表示から繰り込み作用のパラメータ $C^1$ 極限を明示率付きで与える点に限定される。

2境界条件、局所逆因果モデル、測定設定独立性を緩めた Bell モデルにも先行研究がある [7--11,21--25]。共通未来と境界制約による選別という発想自体は新規ではない。第II部が追加するのは、局所指針、実2次元差動比較器、固定総作用を持つ2モード作用分配系、設定名を直接参照しない終端座標を有限 Hamiltonian 部品として接続し、条件付き計算と未導出の試行原理を分離する点である。

## 1.11 本論文が主張しないこと

本論文は次を主張しない。

- Bell の全仮定を保った古典モデルによる Bell 不等式の破れ。
- `[R]` が弱開放な Hamiltonian 力学、相補時計、再初期化だけから必然的に導かれること。
- 局所装置が一般の設定依存結果を到来信号から生成する完成測定器であること。
- 全装置、外部自由度、仕事貯蔵系を1本に統合した有限幅 Hamiltonian が完成していること。
- 弱開放ミクロモデルから第I部の一般線形確率表示が導出済みであること。
- 作用分配系の任意の初期分布が厳密に一様密度へ収束すること。
- 任意の偏った準備に対する非信号性。
- 余弦則または Tsirelson 限界が追加原理から一意に選ばれること。
- Bell 型共同確率が Born 則または Wallstrom 問題を解くこと。
- 第I部の作用収束が微視的な停留点選択または量子力学全体を導くこと。

## 1.12 論文の構成

第2章から第4章は、弱開放な現行モデルと閉鎖補助モデルの関係、Gauss 型条件づけ、作用形式の定量的 Nelson 極限を扱う。第5章から第7章は、測定・記録・外部交換を含む物理的課題、有限 Hamiltonian 装置部品、2モード作用分配系、2境界統計原理の下での Bell 型共同確率を扱う。第8章はモデルの運用状態、結果の確立度、近似誤差、否定結果、反証条件をまとめる。長い収束評価、正準計算、エネルギー収支、測定設定依存度、試行数監査は付録と `VALIDATION.md` に置く。
