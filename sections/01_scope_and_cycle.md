## 1.1 問題設定

本論文の目的は、明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が有効理論として出現し得るかを検証することである。量子力学をミクロ Hamiltonian の入力には使わず、得られた式と測定統計の特徴を判定するときだけ参照する。

現行稿は問題を次の3層へ分ける。

1. 有限正準位相担体の集団相関が、2次 Hamiltonian の下で閉じて発展することを示す。
2. 階数1相関の対角強度を、2モード作用殻と共通入口流束を介して位置入口頻度へ接続する。
3. 左右位相担体の交差相関、局所分析器、共通未来比較器、共通境界測度から Bell 型共同統計を得る。

3層は有限正準自由度という共通基礎を持つが、論理的には独立の追加条件を持つ。相関行列方程式だけから階数1準備は従わない。階数1統計振幅だけから粒子の位置頻度または連続軌道は従わない。2モード殻容量だけから共通流束または共通境界測度の物理的準備は従わない。

## 1.2 基礎的実在と統計状態

1試行の有限ミクロ状態を概略

```math
Z^\omega
=
\left(
X^\omega,
P_X^\omega,
b^\omega,
Y^\omega
\right)
```

と書く。$(X^\omega,P_X^\omega)$ は粒子、$b^\omega$ は有限位相担体、$Y^\omega$ は源、浴、分析器、比較器、時計、記録装置を含む。

複素統計振幅 $\chi$ は単一試行の正準変数ではない。共通調製条件 $\mathcal P$ に属する集団の相関行列 $C$ が階数1のときに、その因子として定まる。従って、単一試行の Hamiltonian に $C$ または $\chi$ を直接代入しない。装置との結合は各試行の $b^\omega$ と $Y^\omega$ の間にだけ置く。

空経路の位相変更が再結合後の頻度へ影響するには、粒子が通らなかった経路にも位相担体が必要である。本稿は粒子だけの軌道模型ではない。一方、位相担体は有限モードまたは有限空間グラフに限られ、独立した連続物質場とは解釈しない。

## 1.3 拡大全系と時間窓

有限部分を

```math
\begin{aligned}
H_{\rm fin}
={}&
H_{\rm particle}
+
H_{\rm ph}
+
H_{\rm source}
+
H_{\rm analyzer}
\\
&+
H_{\rm pointer}
+
H_{\rm return}
+
H_{\rm compare}
+
H_{\rm memory}
+
H_{\rm clk}
\end{aligned}
```

と書く。外部環境と仕事源を含む拡大全系は

```math
H_{\rm all}
=
H_{\rm fin}
+
H_{\rm ext}
+
\varepsilon_{\rm ext}H_{\rm link}
+
H_{\rm work}
```

である。拡大全系は Hamiltonian とし、有限部分だけを見た収支は

```math
\dot E_{\rm fin}
=
J_{\rm in}
-
J_{\rm out}
+
P_{\rm ctrl}
```

と表す。

| 窓 | 主な役割 | 理論上の扱い |
|---|---|---|
| 準備窓 | 共通源の初期化、相対振幅・相対位相の準備 | 有限正準回路。不要成分の処理には弱い外部交換を許す |
| 観測窓 | 位相担体の伝播、位相蓄積、再結合 | 2次 Hamiltonian を基本とする有限時間発展 |
| 測定窓 | 局所作用転送、入口通過、局所分析、比較、記録 | 1試行内の有限 Hamiltonian 写像と境界流束 |
| 再準備窓 | 外部記録の保持、補助系と源の再初期化 | 拡大全系での弱い開放流路 |

閉鎖線形 Hamiltonian 発展は相関行列の固有値を保存する。従って、準備窓で階数1または近似階数1の集団を作り、観測窓ではその欠陥の増加を制御する必要がある。

## 1.4 作用尺度と保存全位相作用

固定作用尺度を $\mathcal J_0>0$ とする。これは正準座標から無次元複素振幅を作り、時間発展の尺度を定める定数である。各試行の全位相作用は別の量

```math
I_{\rm ph}
=
\frac12
\sum_i
\left(
Q_i^2+P_i^2
\right)
=
\mathcal J_0b^\dagger b
```

である。共通位相回転に不変な $H_{\rm ph}$ の下で $I_{\rm ph}$ は保存される。単位作用セクターでは $b^\dagger b=1$ とし、$I_{\rm ph}=\mathcal J_0$ となる。固定尺度 $\mathcal J_0$ と試行状態に依存する保存量 $I_{\rm ph}$ を混同しない。

## 1.5 主定理1の範囲

第2章と第3章の主定理1は、次をまとめた有限次元結果である。

1. $H_{\rm ph}=b^\dagger h_Lb$ から $i\mathcal J_0\dot b=h_Lb$ が厳密に従う。
2. 共通の $h_L$ に従う集団では $i\mathcal J_0\dot C=[h_L,C]$ が厳密に閉じる。
3. 閉鎖線形発展では $C$ の固有値、階数、純度が保存される。
4. 共通源が階数1相関を準備すれば、その因子 $\chi$ は共通位相を除いて Schrödinger 型方程式に従う。
5. 近似階数1の欠陥は、干渉節の残留強度を上から抑える。

この定理は、一般の非線形 Hamiltonian のモーメント階層が閉じるとは主張しない。任意初期集団からの純化、連続空間極限、係数 $\mathcal J_0^2/(2m)$ の必然的導出、粒子軌道は含まない。

## 1.6 主定理2の範囲

第4章の主定理2は位置入口標本化に限定する。セル体積を吸収した相関行列から

```math
p_i
=
\frac{C_{ii}}{\operatorname{tr}C},
\qquad
\sum_i p_i=1
```

を定める。固定振幅の階数1共通源では、各試行で $I_i^\omega=\mathcal J_0p_i$ が成立する。この局所作用から入口作用 $A_i=A_{\rm tot}p_i$ を作り、排他的な全入口で未規格化流束因子が共通なら、

```math
P_i=p_i
```

となる。

$A_i$ は集団量 $C_{ii}$ を単一試行の Hamiltonian が読むことで設定しない。固定振幅の共通源が、同じ相対作用分配を各試行の $b^\omega$ に準備することを用いる。単一入口での理想交換は明示できるが、全位置を排他的に選ぶ局所転送と唯一結果形成の統合は未完成であり、主定理2の成立条件に残す。振幅が試行ごとに変動する場合への拡張には、境界流束と全作用の相関を別に評価する必要がある。

## 1.7 主定理3の範囲

第5章の主定理3は、共通境界測度下の Bell 共同確率である。論理の順序は次である。

1. 2つの固定源チャンネルが左右の反対称交差相関 $\Xi_0$ を準備する。
2. 左右の局所分析器が各側の位相担体だけを回転する。
3. 結果枝作用 $K_{AB}$ が余弦則を持つ。
4. 共通未来比較器が $K_{AB}$ を比較2モードの総作用へ転送する。
5. 2モード殻容量が比較作用に線形となる。
6. 4結果セクターで共通の境界測度を仮定する。
7. Bell 共同確率、非信号周辺、CHSH 値を得る。
8. 境界測度を生成側へ引き戻し、測定設定独立性の破れを特定する。

$\Xi$ は単粒子側の $C$ ではなく、左右相関の非対角ブロックである。比較器は過去の局所記録を変更しない。共通境界測度を通常の前向き周期が事後選別なしに生成することは、主定理3の仮定であって結論ではない。

## 1.9 本論文が主張しないこと

本論文は次を主張しない。

1. 独立した連続2成分誘導場の実在。
2. 任意初期集団からの階数1純化。
3. 古典振動子による Schrödinger 方程式表示そのものの新規性。
4. $h_L$ の係数と局所結合をより原始的な古典模型から必然的に導いたこと。
5. 非線形ミクロ Hamiltonian に対する無条件な相関行列閉包。
6. 粒子の連続軌道または全時刻での $|\psi|^2$ 分布。
7. Wallstrom 問題の解決または連続空間での循環量子化。
8. 任意基底に対する一般 Born 則。
9. 一般の複合状態または一般 Tsirelson 原理。
10. 共通境界測度を生成する完成した測定周期。
11. Bell の定理の否定。
12. 後の比較器が過去の記録を変更する逆因果制御。

配置拡散・Nelson 経路、旧2成分誘導場、局所作用整合浴、低速・高速交換模型は現行主線に採用しない。再利用価値のある結果と不採用理由は研究メモで管理する。
