## 1.1 問題設定

本論文の目的は、明示的な古典Hamiltonian 系から、量子力学に特徴的な可逆力学と確率構造が有効理論として現れ得る範囲を明らかにすることである。量子力学をミクロHamiltonian の入力には使わず、得られた力学、測定操作、統計を判定するときに比較対象として使う。

有限次元Schrödinger 方程式を実正準座標へ写すことだけでは、量子力学の創発にならない。本稿は次を分けて要求する。

1. $L=2$ の同じ正準担体上で、状態空間、可逆操作、Rabi 振動を構成する。
2. その担体を滑らかな測定後状態、逐次測定、記録、reset へ接続する。
3. 継続するRabi 駆動と有限回の反復測定を同じM38周期で接続する。
4. 空間Schrödinger 型包絡は、通常の位置結合を持つ有限実振動子網から誤差付きで導く。
5. 一般有限 $L$ の測定回路と完全周期を、$L=2$ の達成から分離して評価する。
6. 4モード担体上で2つの論理部分系、局所操作代数、結合ゲートを定義する。
7. Bell型統計は、設定前基準測度から2担体準備、局所測定、永久記録、帰還までを前向き周期として構成し、Bellの前提を監査する。

M38は1--3、M37は4、M35は5、M39は6、M41は7を担う。これらを1つのM0へ統合したとは主張しない。

M37の正常モード包絡 $\widetilde b$ は、ミクロ振動子を解析するための厳密だが一般に非局所な正準変数である。独立した非局所物理場として追加しない。

M38、M35、M39の複素基底操作は、局所位相回転と $QQ+PP$ 交換の有限列で実装する。$QQ+PP$ 交換は運動量間結合を含むため、M37の位置ばね網と同じハードウェアではない。Q1-1からQ1-4はM38内部、Q2-1はM39内部で閉じ、M37との統合を達成条件へ入れない。

## 1.3 現行測度と将来の統一測度

理想有効担体の調製集団については

```math
C_M(t)
=
\mathbb E_{\mu_{\mathcal P,M}}
\left[
d_td_t^\dagger
\right]
```

と相関行列を定める。$\mu_{\mathcal P,M}$ は調製条件 $\mathcal P$ とプログラム $M$ を固定した集団測度であり、補助統計理論に使う。

M35の固定純粋準備 $\chi$ と固定基底 $W$ の周期では、

```math
d\mu_{\chi,W}^{\rm M35}
=
\frac{d\vartheta}{2\pi}
\otimes
\delta_*
```

がPoincaré 不変測度になる。$\delta_*$ は選択器角以外の内部準備集合を表す。

M38の固定有限 $N_{\rm Z}$ 段プログラムでは、

```math
d\mu_{\chi,N_{\rm Z}}^{\rm M38}
=
\frac{
d\vartheta_1\cdots d\vartheta_{N_{\rm Z}}
}{
(2\pi)^{N_{\rm Z}}
}
\otimes
\delta_*
```

が理想Poincaré 不変測度になる。$1,\alpha_1,\ldots,\alpha_{N_{\rm Z}}$ の有理数体上の1次独立性により、固定有限次元の角平行移動は一意エルゴード的である。Q1-2の2段測定は $N_{\rm Z}=2$ の場合である。

M41では設定選択器、源選択器、A、B局所選択器の開始面積測度を

```math
d\mu_0^{\rm M41}
=
\frac{
d\xi_A\,d\xi_B\,
d\vartheta_{\rm s}\,
d\vartheta_A\,d\vartheta_B
}{
(2\pi)^5
}
\otimes
\delta_*
```

とする。測定開始面の設定条件付き測度は、前向き準備写像 $T_{xy}$ による押出し

```math
\mu_{\rm meas}^{xy}
=
\left(T_{xy}\right)_\#
\mu_0^{\rm M41}
\left(
\cdot\mid x,y
\right)
```

である。

これらの測度は役割が異なる。可変調製、可変基底、空間伝播、M41の設定生成・2担体準備・外部記録までを同じ反復系へ統合する将来目標の母測度を $\mu_*$ と書く。本稿は $\mu_*$ の存在、不変性、エルゴード性を現行定理の仮定に使わない。

## 1.4 主結果と担当章

本稿の主結果は次の5群である。ここでは結論と達成範囲だけを示し、物理構成、中心式、証明、誤差評価は担当章と付録へ置く。

| 対象 | 結論 | 判定と範囲 | 詳細 |
|---|---|---|---|
| Q1-1 | M38の同じ2モード担体上でBloch球、任意の $SU(2)$、自律Rabi振動を構成 | 達成。固定作用面、採用操作・測定代数 | 第4章、付録E |
| Q1-2 | 任意のBloch軸について作用比、測定後固有状態、同軸反復、異軸逐次分布を構成 | 達成。無反応込み、固定純粋入力、固定軸、任意精度 | 第4章、付録E |
| Q1-3 | 外部永久記録、内部逆計算、外部空セル交換、次周期復帰を構成 | 達成。固定有限プログラム、弱開放、任意精度 | 第4章、付録E |
| Q1-4 | 継続Rabi駆動下の固定有限回測定について全履歴則と短時間Zeno抑制を構成 | 達成。固定有限 $N_{\rm Z}$、無反応込み、任意精度 | 第4章、付録F |
| Q3-1 | M37の有限実振動子網から局所Schrödinger型包絡を導出 | 達成。$\eta<1$、実対称時間非依存演算子、有限時間 | 第2章、第3章、付録A |
| M35 | 一般有限基底の作用選択、測定後状態、内部逆計算、Born型長期頻度を構成 | 固定純粋準備・固定基底で厳密または任意精度。一般有限 $L$ の完全外部周期は未構成 | 第5章、付録B、付録C |
| Q2-1 | M39の厳密CNOT流とM35読出しを合成し、共同入力--出力統計を構成 | 達成。固定有限ベンチマーク、無反応込み、任意精度 | 第6章、付録G、R104--R106 |

M39の非因子化生成と局所操作だけへの分解不能性は、操作誘導テンソル積とCNOT流の内部診断であり、Q2-1の合格条件ではない。Q2-1が構成する統計の読出し前にあるM39の4モード出力状態を $c$ と書く。M41はこの $c$ をA設定基底で階数2選択し、A担体を局所準備し、選択済みBブロックだけをB担体へ正準SWAPする。

Q2-2の条件付き達成は、Q2-1と2つの測定端の接続を「M39の読出し前4モード出力状態 $c$ を利用して、2つの物理的測定端で同じ共同統計を得る操作的接続」と読むことを条件とする。4モード状態全体を保存したまま、設定選択前に2つの独立物理部分系へ分配する状態的接続は未達である。

M37、M38、M35、M39、M41を1つのM0へ統合したとは主張しない。モデル間の数学的受渡しを示した箇所も、配線、時計、外部記録、resetまで共通化した同一ハードウェアを意味しない。

## 1.6 本論文が主張しないこと

主張範囲外の事項を、重複を避けて次の8群にまとめる。個別モデルのより細かな適用限界は各担当章末と第9章に示す。

1. 量子力学の全構造、一般Born則、Wallstrom問題、連続スペクトルを導出したこと。
2. M37、M38、M35、M39、M41を1つのM0または同一ハードウェアへ統合したこと。特にM38の $QQ+PP$ 操作をM37の位置ばねだけから導いたとはしない。
3. 一般有限 $L$ の複数段完全周期、可変調製・可変基底を含む統一エルゴード周期、独立同分布型または二項分布型の有限標本統計、無反応なしの滑らかな厳密離散測定。
4. M37の局所作用が厳密保存されること、正常モード包絡が局所物理場であること、位相担体のセル選択だけで粒子の局所検出または連続軌道が得られること。
5. M38の有限Zeno結果を、固定性能の1台による $N_{\rm Z}\to\infty$、有限間隔での完全凍結、全時間域の単調抑制、測定中のRabi項停止、摩擦またはresetだけによる抑制へ拡張すること。
6. M39を2つの独立物理担体または空間分離装置とみなすこと、単一担体内相関をBell実験とみなすこと、自然なミクロ結合または多項式資源の多量子ビット拡張を得たこと。
7. M41を標準的な空間分離Bell実験とみなすこと、枝条件付き準備後に設定を自由変更して同じ統計を保つこと、一般Tsirelson原理、一般非singlet状態の作用側チャネル除去、4モード状態全体の設定非依存な2部分系分配。
8. 有限閉鎖系の固定容量で永久記録を無期限に蓄積すること、結果履歴を含む全系を同一点へ押しつぶすこと、resetの熱力学的最小仕事、総エネルギー収支、資源下界を導いたこと。

配置拡散・Nelson経路、旧2成分誘導場、旧位置作用殻、前周期記憶モデルは現行主線に採用しない。再利用価値のある結果と不採用理由は研究メモまたは版履歴で管理する。
