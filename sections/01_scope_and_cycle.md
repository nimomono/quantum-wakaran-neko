## 1.1 問題設定

Bell の定理は、局所応答、結果の確定性、測定設定独立性などを同時に満たす理論が、特定の Bell--CHSH 相関を再現できないことを示す [1,2]。古典 Hamiltonian モデルが Bell--CHSH 不等式を超える相関を与えるなら、Bell の前提の少なくとも1つが成立していない。本論文はこの論理を回避せず、軌道法則、準備測度、測定過程、境界条件、試行の数え方を個別に監査する。

扱う問題は次の2つである。

1. 補助的な有限 Fourier–Gauss 型経路法則から、Nelson 型作用の形式をどこまで定量的に得られるか。
2. 構造化有限浴の共通作用殻と境界適合条件から、Bell 型共同確率をどこまで導けるか。

第1の問題には、第4章のパラメータ $C^1$ 収束定理として答える。第2の問題では、共通作用殻上の Liouville 測度を入力すれば、残余ファイバー体積と Bell 型共同確率を厳密に計算できる。さらに、縮約された $U(3)$ 等方拡散の一意な定常分布として、その作用殻測度を力学的に準備できる。

ただし、縮約拡散を同じ有限 Hamiltonian 浴と常時の弱い外部交換から一様誤差付きで導く定理はない。従って、作用殻上の体積計算と、作用殻測度のミクロな生成を分ける。

## 1.2 2部の論理的独立性

第I部は、有限 Fourier–Gauss 型駆動、有限分解能の前後記録、繰り込み済み作用を扱う。中心結果は、作用値と指定した有限次元パラメータ方向の第1変分が Guerra--Morato 型 Nelson 作用へ収束するという厳密な定量定理である。

第II部は、1つの構造化有限浴、局所反応座標、静的な明・暗モード分解、共通境界3モード、作用殻拡散、境界適合ファイバーを扱う。第I部の Nelson 極限は Bell 重みを生成しない。両者に共通するのは、局所の時間発展と、完結履歴へ置く条件付き測度を同一視しないという方法である。

従って、「線形 Gauss 型確率表示から Nelson 作用形式へ進む論理鎖」と、「構造化浴の境界作用殻から Bell 型統計へ進む論理鎖」は別である。第I部の厳密結果は第II部の共通作用殻を必要とせず、第II部の Bell 計算は Nelson 作用を必要としない。

## 1.3 現行モデルと補助モデル

現行モデルは、有限 Hamiltonian 部分と外部自由度を弱く結合した系である。

```math
H_{\rm all}
=
H_{\rm fin}
+
H_{\rm ext}
+
\varepsilon_{\rm ext}H_{\rm link}
+
H_{\rm work}.
```

$H_{\rm fin}$ には生成源、設定制御器、局所装置、1つの構造化有限浴、固定指針、共通境界3モードを含める。$H_{\rm ext}$ は記録安定化、熱交換、作用殻幅の維持、装置再準備に関わる外部環境、$H_{\rm work}$ は設定変更、記録消去、再初期化へ仕事を供給する自由度である。

この式は、現行モデルが含むべき部分と交換経路を示す構成目標である。全ての自由項、外部結合、自律制御を1本に統合し、1周期を有限時間で実行する完成 Hamiltonian をすでに与えたという意味ではない。

現行モデルに対して、次の補助モデルを用いる。

| 補助モデル | 役割 | 現行モデルとの関係 |
|---|---|---|
| 1試行内の有限閉鎖系 | 正準写像、保存量、位相体積を厳密に計算する | 弱開放結合を短い測定窓で無視した近似 |
| 線形 Gauss 型確率表示 | 第I部の作用収束を証明する | 弱結合、線形化、時間尺度分離後の候補表示 |
| 最小結果符号化器 | 既存の2値符号を固定指針へ写す | 一般測定器の一部だけを抽出 |
| 3モード固定作用殻 | 境界適合ファイバーの体積を厳密に計算する | 弱開放系の狭い準定常殻を固定殻で近似 |
| 等方殻拡散 | 共通作用殻上の一意な定常測度を与える | 有限浴と外部交換を縮約した候補方程式 |
| 残余2モードの $U(2)$ 混合 | ファイバー内部の一様作用分配を示す | 全殻測度には不足することを示す比較モデル |

閉鎖補助モデルの厳密結果を、そのまま弱開放な現行モデルの厳密結果と呼ばない。両者の接続には、交換エネルギー、観測時間、浴相関時間、殻幅、有限分解能、局所セクター間の交差応答を用いた近似評価が必要である。

## 1.4 1試行内の近似閉鎖窓

1試行の局所測定窓では、有限 Hamiltonian 部分の位相点を $z$、標準シンプレクティック行列を $J$ と書き、

```math
\dot z
=
J\nabla H_{\rm fin}(z)
```

を0次近似として用いる。各部品は滑らかな Hamiltonian 生成子を持ち、閉鎖補助モデルでは位相体積を保存する。

外部交換の小さい量を

```math
\varepsilon_{\rm open}
=
\frac{
\sup_{0\leq t\leq T_{\rm meas}}
\left|
E_{\rm fin}(t)-E_{\rm fin}(0)
\right|
}{
E_{\rm ref}
}
```

とする。適用条件は

```math
\varepsilon_{\rm open}\ll1,
\qquad
T_{\rm meas}\ll\tau_{\rm exch}
```

である。$\tau_{\rm exch}$ は外部との交換により中心的な作用または記録領域が変化する時間尺度である。

記録については

```math
\tau_{\rm meas}
\ll
\tau_{\rm record}
\ll
T_{\rm rec}
```

も要求する。$\tau_{\rm meas}$ は記録形成時間、$\tau_{\rm record}$ は必要な保持時間、$T_{\rm rec}$ は閉鎖有限浴の再帰尺度である。現行モデルでは外部への漏れを常時完全には切らず、記録形成を乱さない強さに保ちながら、長時間の再位相化を抑える。

同じ浴の左右局所セクターを分離して扱うため、

```math
\varepsilon_{\rm loc}
=
\frac{
\displaystyle
\sup_{0\leq t\leq T_{\rm meas}}
\max\left(
\|\chi_{AB}(t)\|,
\|\chi_{BA}(t)\|
\right)
}{
\displaystyle
\sup_{0\leq t\leq T_{\rm meas}}
\min\left(
\|\chi_{AA}(t)\|,
\|\chi_{BB}(t)\|
\right)
}
\ll1
```

を要求する。$\chi_{XY}$ は反応座標 $Y$ への摂動が反応座標 $X$ に現れる線形応答核である。基底ベクトルが直交するだけでは十分でなく、有限時間応答核そのものが小さい必要がある。

## 1.5 エネルギー交換と試行周期

有限 Hamiltonian 部分のエネルギー収支を

```math
\Delta E_{\rm fin}
=
W_{\rm src}
+
W_{\rm ctrl}
+
W_{\rm reset}
+
Q_{\rm in}
-
Q_{\rm out}
```

と分ける。各項の意味は次である。

- $W_{\rm src}$：生成源と位相基準を準備する仕事。
- $W_{\rm ctrl}$：設定制御器と局所記録器へ供給する仕事。
- $W_{\rm reset}$：指針、反応座標、境界モードを再準備する仕事。
- $Q_{\rm in}$：外部揺らぎと作用殻の半径方向安定化による流入。
- $Q_{\rm out}$：局所浴、暗モード、外部環境への流出。

閉鎖補助モデルでは、これらは拡大した時計または仕事貯蔵自由度との内部交換として表せる。現行モデルでは、実験室の外部供給と排熱まで含めて追跡する。

繰り返し試行は次の5段階からなる。

1. **殻準備**：境界3モードを狭い総作用分布へ置き、殻接方向の浴拡散で偏りを緩和する。
2. **生成源と設定準備**：位相同期した伝達ベクトル対と左右の設定制御器を準備する。
3. **局所測定と記録**：左右の局所反応座標を介して結果を形成し、固定指針へ記録する。
4. **境界適合**：記録と伝達ベクトルを共通未来へ運び、静的な和・差基底と共通作用殻の条件に適合する履歴を定める。
5. **消去と再初期化**：記録を消去し、局所セクター、境界セクター、仕事貯蔵系を次の入口巨視状態へ戻す。

記録消去と再設定は一般に外部へのエントロピーとエネルギーの移送を伴う [17,18]。確率的リセットと有限環境への散逸に関する既知の結果は、試行周期を構成するときの比較対象になる [28,29,33]。

純粋な一方向漏れは殻半径を縮めるだけで、殻上の等方分布を作らない。必要なのは、殻接方向の非退化な混合と、半径方向の漏れ・流入の釣り合いである。これらを同じ有限浴と外部結合から導く部分は未完成である。

## 1.6 第II部の条件

第II部の条件を次の5つに分ける。

### [H] 構造化有限浴

生成源、設定制御器、局所記録器、境界3モード、有限浴を有限個の正準対と滑らかな Hamiltonian 生成子で記述する。浴の明・暗モード分解、左右の反応座標、共通境界セクターは時間に依存しない同じ正準基底で定める。局所測定窓では $\varepsilon_{\rm loc}\ll1$ とする。

現在の明示装置は、あらかじめ存在する2値の結果種を指針へ写す最小結果符号化器である。一般の

```math
A=\mathscr A(a,\lambda_A),
\qquad
B=\mathscr B(b,\lambda_B)
```

を到来信号との相互作用から形成する装置は未構成である。

### [P] 位相同期した生成源

左右へ送る2つの実2次元伝達ベクトルは、共通の位相基準と固定した総入力作用を持つ。和・差作用は

```math
I_+^{AB}+I_-^{AB}
=
2I_0
```

を満たす。有限の位相雑音は可視度 $V$ に含める。総入力作用の揺らぎは作用殻幅の誤差へ含め、中心定理では固定する。

### [S] 対称な結果セクター

境界条件を課す前の準備 Hamiltonian、準備巨視領域、基準 Liouville 測度は、左右の結果種を独立に反転する2つの変換に不変である。4つの結果セクターが1つの軌道に沿って相互遷移する必要はない。必要なのは、共通殻を切る前の基準質量、境界分解能、coarea Jacobian が4セクターで等しいことである。

### [C] 共通作用殻と境界適合

境界3モードは

```math
J_++J_s+J_r=C_0
```

という1つの共通作用殻を持つ。局所記録後の伝達ベクトルを静的な和・差基底へ写し、各結果セクターで

```math
J_+=I_+^{AB}(a,b)
```

を同じ物理的分解能で要求する。設定名や目標確率を直接引数に持つ結果別終端関数は置かない。

この条件は、共通未来を含む境界値問題を残す。共有浴だけで境界条件が不要になるわけではない。

### [D] 全殻等方拡散

準備窓の縮約生成子は、3モード共通殻の接方向で非退化かつ $U(3)$ 不変である。理想化した生成子を

```math
\mathcal L_{\rm iso}
=
D_\partial\Delta_{S^5}
```

とする。準備時間 $\tau_{\rm prep}$ は混合時間より十分長く、半径方向の殻幅は

```math
\varepsilon_C
=
\frac{\sigma_C}{C_0}
\ll1
```

を満たす。

この条件から共通殻上の正規化 Liouville 測度が一意な定常分布として従う。従って旧来の入口測度条件 `[M]` は、縮約拡散の定常結果 `[M_{\rm shell}]` へ置き換える。ただし、`[D]` 自体を同じ有限浴から導く部分は予想・未解決である。

旧来の Bell 固有な終端統計原理 `[R]` は用いない。Bell 重みは `[C]` と `[M_{\rm shell}]` の下で残余ファイバー体積から得る。

## 1.7 1試行の物理的時系列

1試行を次の9段階に分ける。

1. 境界3モードの総作用を $C_0$ 付近の狭い分布へ準備する。
2. 浴由来の殻接方向拡散を混合時間より長く作用させる。
3. 位相同期した伝達ベクトル対と局所装置を準備する。
4. 左右の制御器巨視状態により設定 $a,b$ を生成する。
5. 到来変数、設定、局所装置微視状態の相互作用で結果を形成する。現在の明示計算では、この段階を結果種の入力で置き換える。
6. 局所反応座標と固定指針が結果を記録する。左右の交差応答は $O(\varepsilon_{\rm loc})$ である。
7. 記録と伝達ベクトルを通常の時間順序で共通未来へ運び、静的な和・差基底へ写す。
8. 共通総作用殻と $J_+=I_+^{AB}$ の境界適合条件により、完結履歴のファイバーを定める。
9. 完了後に記録、浴、境界モードを次試行の入口巨視状態へ戻す。

境界条件に適合しない軌道は、記録後に捨てた試行とは定義しない。最初から同じ2境界値問題の解ではない。ただし、実験装置がこの集団を実現する際に開始数、記録数、完了数が結果または設定に依存して減るなら、操作上は事後選別になる。この監査は省略しない。

## 1.8 主要結果の導出状態

第I部の結果を分ける。

| 主張 | 導出状態 |
|---|---|
| 線形 Gauss 型条件付き作用の $C^1$ 収束 | 厳密結果 |
| Guerra--Morato 表示と Nelson 表示の一致 | 厳密結果 |
| 弱開放ミクロモデルから線形表示への縮約 | 予想・未解決 |
| 微視的運動による停留点選択 | 予想・未解決 |

第II部の結果を分ける。

| 主張 | 導出状態 |
|---|---|
| 実2次元和・差作用の余弦恒等式 | 厳密結果 |
| $U(2)$ 等方性だけではファイバー間質量が決まらないこと | 厳密結果。否定的結果 |
| $U(3)$ 等方拡散の定常分布が共通殻 Haar 測度になること | 縮約方程式の下で厳密結果。仮説依存 |
| 3モード共通殻の $J_+$ 周辺と残余ファイバー体積 | 厳密結果 |
| 共通殻、対称セクター、共通分解能の下での Bell 型共同確率 | 厳密結果。仮説依存 |
| 弱開放な有限浴から全殻等方拡散を導くこと | 予想・未解決 |
| 異方性、混合不足、殻幅、交差応答による補正 | 近似結果 |
| 一般測定器と境界適合を含む全試行周期 | 予想・未解決 |

固定された損失のない接合部は Liouville 測度を保存するが生成せず、残余2モードの $U(2)$ 混合は固定 $J_+$ の内部しか一様化しない。純粋な漏れも殻上等方化を与えない。これらは現行モデルの成立条件を限定する否定的結果として本文に残す。

## 1.9 Bell の前提監査

第II部の監査結果を先に要約する。

| 監査項目 | 現時点の結論 |
|---|---|
| 局所性 | 局所記録窓の左右交差応答は $O(\varepsilon_{\rm loc})$。共通未来の境界セクターは残る |
| 測定設定独立性 | 境界適合ファイバーが $a,b$ に依存するため成立しない |
| 結果の一意性 | 最小結果符号化器では一意。一般測定器は未構成 |
| 事後選別 | 理論上は2境界解集合を定義するが、装置実現では開始数・記録数・完了数の監査が必要 |
| 非信号性 | 対称セクターと共通分解能の下で厳密。偏った準備では未証明 |
| 試行測度 | 共通殻の Liouville 測度を履歴空間へ押し出す。浴からのミクロ導出は未完成 |

従って Bell の定理の前提違反は測定設定独立性にある。局所 Hamilton 方程式へ遠隔力を加えたことや、Bell の定理を否定したことによるものではない。

## 1.10 先行研究との位置関係

Nelson の確率力学、確率変分法、Guerra--Morato 作用には先行研究がある [3--6,30]。Gauss 型条件づけは固定区間平滑化、相反過程、Schrödinger 橋、経路単位の Gauss 型条件づけと関係する [15,16,25--27,31,32]。第I部の新規性は、指定した線形 Gauss 型クラスに対し、有限 Fourier 表示から繰り込み作用のパラメータ $C^1$ 極限を明示率付きで与える点に限定される。

2境界条件、局所逆因果モデル、測定設定独立性を緩めた Bell モデルにも先行研究がある [7--11,20--24]。共通未来と境界制約による設定依存履歴測度という発想自体は新規ではない。第II部が追加するのは、1つの構造化有限浴の局所反応座標と共通境界セクターを分け、3モード共通作用殻の残余ファイバー体積を Bell 重みへ接続し、2モード等方性の不足と全殻等方拡散の未導出性を明示する点である。

## 1.11 本論文が主張しないこと

本論文は次を主張しない。

- Bell の全仮定を保った古典モデルによる Bell 不等式の破れ。
- 共有浴にしただけで共通未来の境界条件が不要になること。
- 全殻 $U(3)$ 等方拡散が有限 Hamiltonian 浴だけから厳密に導かれたこと。
- 純粋なエネルギー漏れや固定された損失のない接合部が一様殻測度を生成すること。
- 残余2モードの $U(2)$ 等方性だけで Bell 重みが決まること。
- 局所装置が一般の設定依存結果を到来信号から生成する完成測定器であること。
- 全装置、外部自由度、仕事貯蔵系を1本に統合した有限幅 Hamiltonian が完成していること。
- 弱開放ミクロモデルから第I部の一般線形確率表示が導出済みであること。
- 任意の偏った準備に対する非信号性。
- 余弦則または Tsirelson 限界が追加原理から一意に選ばれること。
- Bell 型共同確率が Born 則または Wallstrom 問題を解くこと。
- 第I部の作用収束が微視的な停留点選択または量子力学全体を導くこと。

## 1.12 論文の構成

第2章から第4章は、弱開放な現行モデルと閉鎖補助モデルの関係、Gauss 型条件づけ、作用形式の定量的 Nelson 極限を扱う。第5章は1つの構造化有限浴、静的な明・暗モード分解、局所反応座標、共通未来の境界セクターを扱う。第6章は3モード共通作用殻、$U(2)$ の限界、$U(3)$ 等方拡散、残余ファイバー体積を導く。第7章は境界 Liouville 測度の履歴空間への押し出し、Bell 型共同確率、非信号性、Bell の前提監査を扱う。第8章は近似誤差、適用限界、反証条件、未解決問題をまとめる。主定理の収束評価と、本文の構造化浴・作用殻計算を支える正準計算だけを付録に置き、数値検算は `VALIDATION.md` に集約する。
