## 1.1 問題設定

本論文の目的は、明示的な古典Hamiltonian 系から、量子力学に特徴的な可逆力学と確率構造が有効理論として現れ得る範囲を明らかにすることである。量子力学をミクロHamiltonian の入力には使わず、得られた力学、測定操作、統計を判定するときに比較対象として使う。

有限次元Schrödinger 方程式を実正準座標へ写すことだけでは、量子力学の創発にならない。本稿は次を分けて要求する。

1. $L=2$ の同じ正準担体上で、状態空間、可逆操作、Rabi 振動を構成する。
2. その担体を滑らかな測定後状態、逐次測定、記録、reset へ接続する。
3. 継続するRabi 駆動と有限回の反復測定を同じM38周期で接続する。
4. 空間Schrödinger 型包絡は、通常の位置結合を持つ有限実振動子網から誤差付きで導く。
5. 一般有限 $L$ の測定回路と完全周期を、$L=2$ の達成から分離して評価する。
6. 4モード担体上で2つの論理部分系、局所操作代数、結合ゲートを定義する。
7. Bell型統計は、設定前基準測度から2担体準備、局所測定、永久記録、帰還までを前向き周期として構成し、Bellの前提を監査する。

M38は1--3、M37は4、M35は5、M39は6、M41は7を担う。これらを1つのM0へ統合したとは主張しない。

## 1.3 現行測度と将来の統一測度

理想有効担体の調製集団については

```math
C_M(t)
=
\mathbb E_{\mu_{\mathcal P,M}}
\left[
d_td_t^\dagger
\right]
```

と相関行列を定める。$\mu_{\mathcal P,M}$ は調製条件 $\mathcal P$ とプログラム $M$ を固定した集団測度であり、補助統計理論に使う。

M35の固定純粋準備 $\chi$ と固定基底 $W$ の周期では、

```math
d\mu_{\chi,W}^{\rm M35}
=
\frac{d\vartheta}{2\pi}
\otimes
\delta_*
```

がPoincaré 不変測度になる。$\delta_*$ は選択器角以外の内部準備集合を表す。

M38の固定有限 $N_{\rm Z}$ 段プログラムでは、

```math
d\mu_{\chi,N_{\rm Z}}^{\rm M38}
=
\frac{
d\vartheta_1\cdots d\vartheta_{N_{\rm Z}}
}{
(2\pi)^{N_{\rm Z}}
}
\otimes
\delta_*
```

が理想Poincaré 不変測度になる。$1,\alpha_1,\ldots,\alpha_{N_{\rm Z}}$ の有理数体上の1次独立性により、固定有限次元の角平行移動は一意エルゴード的である。Q1-2の2段測定は $N_{\rm Z}=2$ の場合である。

M41では設定選択器、源選択器、A、B局所選択器の開始面積測度を

```math
d\mu_0^{\rm M41}
=
\frac{
d\xi_A\,d\xi_B\,
d\vartheta_{\rm s}\,
d\vartheta_A\,d\vartheta_B
}{
(2\pi)^5
}
\otimes
\delta_*
```

とする。測定開始面の設定条件付き測度は、前向き準備写像 $T_{xy}$ による押出し

```math
\mu_{\rm meas}^{xy}
=
\left(T_{xy}\right)_\#
\mu_0^{\rm M41}
\left(
\cdot\mid x,y
\right)
```

である。

これらの測度は役割が異なる。可変調製、可変基底、空間伝播、M41の設定生成・2担体準備・外部記録までを同じ反復系へ統合する将来目標の母測度を $\mu_*$ と書く。本稿は $\mu_*$ の存在、不変性、エルゴード性を現行定理の仮定に使わない。

## 1.4 主結果1A：2モード可逆力学

M38の固定作用面を

```math
I_{\rm ph}
=
\frac12
\sum_{j=1}^2
\left(
Q_j^2+P_j^2
\right)
=
\mathcal J_0
```

とする。共通位相に不変なBloch 写像により、有効状態空間は $S^2$ になる。Bloch 成分のPoisson 代数は

```math
\{r_i,r_j\}
=
\frac{2}{\mathcal J_0}
\epsilon_{ijk}r_k
```

である。任意の実ベクトル $\boldsymbol\Omega$ に対する

```math
H_{\boldsymbol\Omega}
=
\frac{\mathcal J_0}{2}
b^\dagger
\left(
\boldsymbol\Omega\cdot\boldsymbol\sigma
\right)b
```

は

```math
\dot{\boldsymbol r}
=
\boldsymbol\Omega\times\boldsymbol r
```

を厳密に与える。局所位相回転と2モード交換のEuler 分解により、任意の $SU(2)$ を同じ担体上で実装できる。

駆動作用・角変数を加えた自律Hamiltonian は、共鳴振幅、一般化Rabi 振動数、離調による振幅低下を厳密に与える。従ってQ1-1はM38内部で達成である。

## 1.5 主結果1B：任意軸と逐次測定

任意の Bloch 軸 $\boldsymbol n$ と結果 $s=\pm1$ に対し、M38の出力作用比は

```math
p_s(\boldsymbol n)
=
\frac{1+s\boldsymbol n\cdot\boldsymbol r}{2}
```

である。安全セクターでは正準SWAP 後の信号が厳密に $|\boldsymbol n,s\rangle$ となる。

滑らかな有限時間Hamiltonian 流の連続性により、連結入力領域全体を相異なる2固有状態だけへ写すことはできない。本稿は比較境界の遷移領域を正式な無反応結果とし、無反応率を

```math
\delta_j
\leq
2\frac{w_{{\rm eff},j}}{\mathcal J_0}
+
\varepsilon_{{\rm cut},j}
```

で抑える。

同軸再測定では反対符号の安全結果が生じない。異軸測定では独立な2選択器を使い、理想共同分布

```math
P(s,t)
=
\frac{1+s\boldsymbol n\cdot\boldsymbol r}{2}
\frac{1+st\boldsymbol n\cdot\boldsymbol m}{2}
```

を得る。無反応を含む実分布との距離は $\delta_1+\delta_2$ 以下である。従ってQ1-2は制御された任意精度で達成である。

## 1.6 主結果1C：永久記録と弱開放周期

滑らかな比較ポインター $\Pi_j(z)$ と空の外部記録セルを

```math
G_{\rm rec}
=
\sum_{j=1}^2
P_j^R\Pi_j(z)
```

で結合する。理想入口 $P_j^R=0$ では装置へ反作用せず、記録座標だけが移動する。記録後に第2段、第1段の順で逆計算すれば、内部装置は準備点へ戻り、記録は外部セルへ残る。

外部空モードとの正準交換は

```math
\delta a^+
=
\cos\phi\,\delta a^-
+
\sin\phi\,\eta
```

を与える。完全交換では装置偏差を空セルへ置換し、部分交換では収縮する。局所作用・角時計、外部記録セル、reset セル流を加えると、固定有限プログラムの能動装置は次周期の準備集合へ任意精度で戻る。

有限 $K$ 実験周期は外部セルを含む有限閉鎖Hamiltonian 系へ埋め込める。無期限運転では外部セル流が必要であり、情報と旧偏差を消去していない。従ってQ1-3は制御された任意精度で達成である。

## 1.7 主結果1D：有限反復Zeno効果

初期信号を $z$ 軸の正固有状態とし、任意に指定した有限回数 $N_{\rm Z}$ だけ $z$ 測定を繰り返す。第 $j$ 区間のRabi 反転作用比を $q_j$ とすると、全履歴分布は

```math
\pi_{N_{\rm Z}}
(s_1,\ldots,s_{N_{\rm Z}})
=
\prod_{j=1}^{N_{\rm Z}}
\left[
(1-q_j)\mathbf1_{s_j=s_{j-1}}
+
q_j\mathbf1_{s_j=-s_{j-1}}
\right]
```

である。一度も反転しない確率と最終正占有率は

```math
S_{N_{\rm Z}}
=
\prod_{j=1}^{N_{\rm Z}}(1-q_j),
```

```math
F_{N_{\rm Z}}
=
\frac12
\left[
1+
\prod_{j=1}^{N_{\rm Z}}(1-2q_j)
\right]
```

となる。無反応、反転、再反転を含む全履歴を保持し、生存試行だけを再規格化しない。

等間隔 $\tau$ の有効反転率は短時間域で

```math
\Gamma_{\rm Z}(\tau)
=
-\frac{\log[1-q(\tau)]}{\tau}
=
\frac{\Omega^2}{4}\tau
+
O(\tau^3)
```

となる。各構成は同じ総観測時間の未測定対照と比較するが、異なる $N_{\rm Z}$ の間で総時間を共通に固定しない。

実装は1個の測定コア、$N_{\rm Z}$ 個の独立選択器、有限長の循環メモリー／reset セル列、永久記録セルを使う。測定コアの補助6対だけを段セルへSWAPし、信号は次のRabi 区間へ残す。全結果を記録した後に逆順復帰し、選択器ベクトルを進める。

測定窓中もRabi 項を非零に保つ。幅 $h_j$ の有限パルスは理想測定写像から $O(h_j)$ だけずれ、無反応込みの全履歴分布誤差は各段の条件付き全変動誤差の和以下になる。固定有限 $N_{\rm Z}$ ごとにこの誤差と周期帰還誤差を任意に小さくできるため、Q1-4は有限Zeno抑制の範囲で達成である。完全凍結または $N_{\rm Z}\to\infty$ に一様な固定性能は含まない。

下側反対称差モードへの射影を $\Pi_{\rm CX}$ とし、時計窓の面積を $A$ とすると、信号流は $e^{-iA\Pi_{\rm CX}}$ である。$A=\pi$ ではCNOTと厳密に一致し、積入力 $|+0\rangle$ を最大非因子化状態へ写す。非因子化生成は内部診断であってQ2-1の合格条件ではない。面積誤差と一般Hermitian 制御誤差には明示的な忠実度上界があり、ゲート単体は4信号正準対と1時計正準対で構成できる。

```math

\left(

\right)
=
\lambda_s
\left|
\left[
W_sU_{\rm CX}\chi_s
\right]_r
\right|^2
```

とし、有理入力頻度を持つ固定プログラムセルの有限直積で生成する。入力頻度近似、M35無反応、ゲート操作誤差の和により、無反応込み共同分布の全変動距離を任意に小さくできる。従ってQ2-1は、固定有限ベンチマーク、無反応込み、制御された任意精度の範囲で、2量子ビット型結合ゲートと同じ共同入力--出力統計を生成する有限古典Hamiltonian過程として達成である。独立した2物理担体、Bell測定、未知入力の完全過程トモグラフィー、結合項の自然なミクロ起源、指数コストを避ける多量子ビット拡張はM39単独に含まない。

## 1.11 主結果5：初期共通原因型2担体Bell測定周期

M41はM39のsinglet型4モード状態を

```math
c^x
=
\left(
W_x\otimes I_2
\right)c
=
\begin{pmatrix}
c_+^x\\
c_-^x
\end{pmatrix}
```

と階数2ブロックへ分け、源選択器で枝 $A$ を作用比

```math
P(A\mid x)
=
\frac{
\mathcal J_0
\left\|
c_A^x
\right\|^2
}{
\mathcal J_0
}
```

に従って選ぶ。安全枝のA方向をA物理担体へ準備し、選択済みBブロックをB物理担体へ正準SWAPして中央結合を停止する。A、B局所測定Hamiltonianは別々の正準変数だけに依存するためPoisson可換である。

B局所選択器の条件付き作用比と源枝作用比を掛けると分母が消え、

```math
\begin{aligned}
P(A,B\mid x,y)
&=
\frac{I_A^x}{\mathcal J_0}
\frac{K_B^{Axy}}{I_A^x}\\
&=
\left|
\langle A_x,B_y|c\rangle
\right|^2
\end{aligned}
```

を得る。singlet型では余弦共同確率、非信号周辺、標準設定のCHSH値 $2\sqrt2$、平面内2出力族の上界 $2\sqrt2$ が従う。

A設定に応じた階数2作用選択がA中央枝選択で結果 $A$ を形成し、A担体を $|A_x\rangle$ へ準備して選択済みBブロックをB担体へ正準SWAPする。中央結合停止後のA局所確認測定は同じ $A$ を確定的に記録し、B局所測定だけが条件付き結果 $B$ を形成する。

設定前基準測度は積Haar測度だが、測定開始面の2担体状態は設定生成後の前向き準備写像により $x$ に依存する。設定、singlet、枝ラベルを設定前開始面で同時に設定依存標本化したものではない。従ってBellの前提違反は測定設定独立性にあり、測定段階の局所因子化とは区別される。外部記録後は能動部を逆計算し、有限残差をresetセルへ交換する。

ここでQ2-2の「2つの測定端への接続」は、Q2-1の出力を利用して2つの物理担体を条件付き準備し、各担体への局所測定から目標共同統計を得る操作的接続を意味する。この意味では、Q2-2は固定有限設定、準備先行、非空間分離、singlet型、無反応込み、制御された任意精度の範囲で条件付き達成である。一方、M39の非因子化4モード状態全体を保存したまま、設定選択前に2つの独立物理部分系へ分配する状態的接続は未達であり、本稿は主張しない。
