## 1.1 問題設定

本論文の目的は、明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現し得るかを検証することである。量子力学をミクロ構成の入力には使わず、縮約後の式と比較するときだけ参照する。

中心問題を次の4点に分ける。

1. 有限2成分場との位相接続から、Madelung 作用と Schrödinger 型力学を得られるか。
2. 場強度と粒子密度の一致を定義として置かず、入口の Liouville 流束から位置の Born 型重みを得られるか。
3. 同じ場の対モードと局所分析器から Bell 余弦作用を得られるか。
4. 共通未来比較器と2モード境界測度から Bell 型共同統計を得て、Bell の前提違反と非信号条件を特定できるか。

本論文は、明記した縮約条件と境界条件の下で4点全てに部分的な結果を与える。ただし、共通境界測度の物理的準備、一般測定器、全構成を統合した反復可能な試行周期は未完成である。

## 1.2 拡大全系と弱開放な有限部分

有限部分を概略

```math
\begin{aligned}
H_{\rm fin}
={}&
H_{\rm obj}
+
H_{\rm field}
+
H_{\rm source}
+
H_{\rm analyzer}
+
H_{\rm pointer}\\
&
+
H_{\rm return}
+
H_{\rm read}
+
H_{\rm mix}
+
H_{\rm memory}
+
H_{\rm reset}
+
H_{\rm clk}
\end{aligned}
```

と書く。外部環境と仕事源まで含む拡大全系は

```math
H_{\rm all}
=
H_{\rm fin}
+
H_{\rm ext}
+
\varepsilon_{\rm ext}H_{\rm link}
+
H_{\rm work}
```

である。拡大全系は Hamiltonian とし、有限部分だけを見た収支を

```math
\dot E_{\rm fin}
=
J_{\rm in}
-
J_{\rm out}
+
P_{\rm ctrl}
```

と表す。常時の弱い外部交換は、欠陥成分の除去、有限再帰の抑制、記録安定化、反復時のgarbage処理に使う。Madelung 作用、coherent状態、作用殻の方向一様性、Bell 境界測度を、外部漏れから直接仮定しない。

1試行の測定窓では、外部交換の相対変化を小さくし、有限閉鎖 Hamiltonian 補助模型で正準写像、保存量、読み出し、逆計算、作用殻体積を計算する。試行間では、仕事源と外部流路を含めて再準備、記録保持、再初期化を扱う。

## 1.3 固定モード分解

基本的な実在場は、物理空間上の1つの2成分場

```math
\boldsymbol\Phi(x)
=
\begin{pmatrix}
\Phi_1(x)\\
\Phi_2(x)
\end{pmatrix}
```

だけである。粒子対に対して独立な6次元配置空間場を追加しない。

有限モード切断後の場モード空間を、装置の組立時に固定した直交部分空間へ分ける。

```math
\mathcal H_{\rm field}
=
\mathcal H_{\rm phase}
\oplus
\mathcal H_{\rm pair}^{A}
\oplus
\mathcal H_{\rm pair}^{B}
\oplus
\mathcal H_{\partial}^{\rm cmp}
\oplus
\mathcal H_{\rm dark}.
```

- $\mathcal H_{\rm phase}$ は粒子の位相接続を担う。
- $\mathcal H_{\rm pair}^{A}$ と $\mathcal H_{\rm pair}^{B}$ は、源から左右へ伝播し、局所分析器と戻り伝達を通る。
- $\mathcal H_{\partial}^{\rm cmp}$ は、共通未来領域に局在した2つの境界比較モードを含む。
- $\mathcal H_{\rm dark}$ は、混合角、位相保持、時計補助、garbage保持を担うが、結果依存作用を直接分配しない。

これらは別の実在場ではない。同じ場の固定正規モードである。設定 $a,b$、結果 $A,B$、目標密度を見て部分空間を選び直す構成は採用しない。

位相、対、比較部分空間の交差応答を

```math
\varepsilon_{\rm phase-pair},
\qquad
\varepsilon_{\rm phase-cmp},
\qquad
\varepsilon_{\rm pair-cmp}^{\rm off}
```

として管理する。最後の量は、比較窓以外で対モードと比較モードが結合する誤差である。

## 1.4 現行経路

| 経路 | ミクロな構成 | 得られるもの | 未完成な接続 |
|---|---|---|---|
| 位相接続 | $P-\mathcal J_\phi\mathbf a_\varepsilon(X)$ | 縮約作用、Madelung 方程式、局所 Schrödinger 型PDE、条件付き循環量子化 | coherent多様体の準備、維持、節の制御、停留点選択 |
| Born 型入口殻 | 活性モードと共有明反応座標の2モード殻 | 位置入口の Born 型 Liouville 流束 | 共通流束因子、一般測定器、再埋め込み |
| Bell 対モード | 反対称源、左右局所モード回転、共通未来比較器 | 余弦枝作用、2モード比較作用、条件付き Bell 共同確率 | 結果形成、共通境界測度の物理的準備、完全周期 |

位相接続が力学の主線である。Born 型入口殻と Bell 対モードは、その同じ2成分場の別の固定モードを用いる標本化・測定構成である。

## 1.5 採用しない経路

運動量結合による配置拡散経路は、現行モデル M0 の構成要素から外す。この経路は、有限線形誘導場の消去、自由速度相関、二側配置 Markov 拡散内部の Fisher 恒等式を含むが、次の理由で本論文の主線には使わない。

1. Brown 極限が未完成である。
2. 配置変数だけの Markov 閉鎖が未完成である。
3. 時間対称 Newton 則が配置拡散から自動的に従わない。
4. 位相接続と同じ有効係数を持つことが未導出である。
5. 位相接続縮約作用だけで Schrödinger 型PDEを得るため、現行主張に配置拡散を必要としない。

詳細と再利用可能な厳密結果は付録Dに保存する。

また、旧3モード Bell 模型の $U(3)$ 共通殻と残余ファイバー構成も現行模型から外す。旧模型は数学的な作用殻計算として有効だが、比較作用の生成が抽象的で、基準作用により理想可視度が低下する。新模型は $K_{AB}$ を比較2モードの総作用へ直接転送する。旧模型は研究メモへ保存する。

## 1.7 2種類の2モード殻

Born 側と Bell 側は、どちらも

```math
\Omega_2(A)
=
(2\pi)^2A
```

という同じ線形殻容量を使う。ただし、物理的な役割は異なる。

| 用途 | 総作用 | 比較するsector | 必要な共通条件 |
|---|---|---|---|
| 位置入口 | $A_i=A_{\rm tot}r_i^2\Delta V$ | 排他的な位置セル $i$ | 法線速度、障壁、coarea Jacobian、spectator因子 |
| Bell 比較 | $A_\partial^{AB}=\Gamma^2K_{AB}/2$ | 排他的な結果組 $(A,B)$ | 基準sector質量、境界密度、時計流束、coarea Jacobian、spectator因子 |

殻容量の線形性は厳密な幾何学的結果である。殻容量を実験頻度へ変える共通境界条件は、別の仮定である。

## 1.8 試行周期と全試行監査

位置入口と Bell 結果のどちらでも、境界反応面は排他的な和として扱う。

```math
\Gamma_\partial
=
\bigsqcup_\lambda
\Gamma_{\partial,\lambda}.
```

$\lambda$ は位置セル $i$ または結果組 $(A,B)$ を表す。各完全履歴は1つのsectorに属し、1周期に境界面を1回だけ正方向に横切る。

完全周期には少なくとも次が必要である。

1. coherent活性場、反対称対モード、比較器基準状態の準備。
2. 設定 $a,b$ の物理的生成。
3. 左右局所分析と結果形成。
4. 局所記録。
5. 戻り信号の有限伝播と共通未来比較。
6. 共通境界測度による全履歴の重み付け。
7. 外部記録への可逆コピー。
8. 比較混合、読み出し、戻り伝播、局所分析の逆計算。
9. 場、装置、時計、garbage自由度の再初期化。

本論文は、1の一部、3の局所モード回転、5の理想比較読み出し、6の条件付き測度、8の理想的な比較器逆計算を与える。一般的な結果形成、境界測度の物理的準備、長期反復は未解決である。

## 1.9 導出状態の読み方

本論文では次を区別する。

- 縮約多様体に制限した後の代数、変分、作用殻体積は、明記した条件の下で厳密である。
- 反対称源を準備した後の局所回転代数と理想比較読み出しは、補助模型内部で厳密である。
- 共通境界密度を仮定した後の Bell 共同確率と非信号性は、仮説依存の厳密結果である。
- ミクロ時間発展が coherent多様体または共通境界測度を準備することは別の主張である。
- 正規化された集団の Hamiltonian 押し出しは、結果sectorの総確率質量を殻容量に比例させない。
- 弱開放性は準備済み構造の安定化と反復の候補であり、coherent構造または境界密度を単独で生成しない。

この区別を各章の位置づけと第8章の誤差表へ反映する。
