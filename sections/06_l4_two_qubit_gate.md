## 6.1 M39と主張範囲

M38の2モード担体は、単一量子ビット型状態空間、任意の $SU(2)$、測定、記録、resetを同じ装置内で閉じた。しかし2モードを2進添字で並べるだけでは、2つの論理部分系、テンソル積、局所操作、結合ゲートは定義されない。本章では4モードの単一正準担体M39を別モデルとして導入し、2量子ビット型結合ゲートと同じ共同入力--出力統計を生成する有限古典Hamiltonian過程を構成する。結合ゲート内部に非分離状態が実在することはQ2-1の固定達成条件ではないが、M39では操作誘導テンソル積に関する非因子化も内部診断として示せる。

M39の主張は次の3段階から成る。

1. 2つの相互可換な局所操作代数により、4次元振幅空間へ操作誘導テンソル積を定める。
2. 局所操作と区別された差モード射影のHamiltonian 流により、4論理基底上でCNOTを厳密に実装する。
3. 有限パルス幅、結合強度、面積誤差、一般制御誤差、正準対数を定量化する。

4次元複素振幅を実正準座標で表すこと、およびHermitian 行列を2次Hamiltonian へ写すこと自体は既知である [34--37]。本章の役割は、その表示に局所操作代数、積状態条件、明示結合流、誤差、資源を加え、Q2-1の判定を閉じることである。

## 6.2 4モード固定作用担体

論理添字を $a,b\in\{0,1\}$ とし、4つの実正準対を

```math
b
=
\begin{pmatrix}
b_{00}\\
b_{01}\\
b_{10}\\
b_{11}
\end{pmatrix},
\qquad
b_{ab}
=
\frac{Q_{ab}+iP_{ab}}
{\sqrt{2\mathcal J_0}}
```

とまとめる。物理的な全作用は

```math
I_{\rm ph}
=
\frac12
\sum_{a,b}
\left(
Q_{ab}^2+P_{ab}^2
\right)
=
\mathcal J_0 b^\dagger b
```

である。固定作用面 $I_{\rm ph}=\mathcal J_0$ では $b^\dagger b=1$ となる。採用する操作・観測代数は共通位相

```math
b
\longmapsto
e^{i\gamma}b
```

を識別しないため、全有効状態空間は

```math
S^7/U(1)
\simeq
\mathbb{CP}^3
```

である。共通位相変数が古典位相空間から消えるのではなく、採用代数について同値な方向として縮約する。

Hermitian 行列 $K\in M_4(\mathbb C)$ に対し、実2次Hamiltonian を

```math
F_K
=
\mathcal J_0 b^\dagger Kb
```

と置く。正準括弧は

```math
\{F_K,F_L\}
=
-i\mathcal J_0
b^\dagger[K,L]b
```

を満たし、$F_K$ の流れは

```math
i\dot b
=
Kb
```

となる。従ってHermitian 生成子の有限流は、全作用と正準性を厳密に保存する。

## 6.3 操作誘導テンソル積

4モードの添字付けだけに依存せず、2つの局所操作代数を

```math
\mathcal A
=
M_2(\mathbb C)\otimes I_2,
\qquad
\mathcal B
=
I_2\otimes M_2(\mathbb C)
```

と指定する。任意のHermitian 行列 $A,B\in M_2(\mathbb C)$ について、対応する制御Hamiltonian は

```math
F_A^{(A)}
=
\mathcal J_0
b^\dagger(A\otimes I_2)b,
```

```math
F_B^{(B)}
=
\mathcal J_0
b^\dagger(I_2\otimes B)b
```

である。2つの行列代数は可換なので、

```math
\left\{
F_A^{(A)},F_B^{(B)}
\right\}
=0
```

となる。さらに $M_4(\mathbb C)$ 内で互いの可換代数は相手自身であり、両者が生成する複素行列代数は $M_4(\mathbb C)$ 全体になる。この操作構造を根拠として、

```math
\mathbb C^4
\simeq
\mathbb C_A^2
\otimes
\mathbb C_B^2
```

を定義する。これは1つの4モード物理担体内の論理分解であり、2つの独立した古典位相空間への物理分解ではない。本稿ではこの区別を「操作誘導テンソル積」と呼ぶ。

<!-- theorem-start:proposition -->
**命題（R104：局所操作代数による操作誘導テンソル積）**

固定作用4モード正準担体上に、正方形配線で2つの局所 $SU(2)$ 操作代数を実装する。両代数は互いに可換で、それぞれ $M_2(\mathbb C)\otimes I_2$ と $I_2\otimes M_2(\mathbb C)$ のHermitian 部分に一致する。これらは4次元振幅空間へ操作誘導テンソル積を定め、局所操作は積状態集合を保存する。
<!-- theorem-end:proposition -->

## 6.4 正方形配線による局所操作

各モードの作用と、2モード交換生成子を

```math
I_{ab}
=
\frac{Q_{ab}^2+P_{ab}^2}{2},
```

```math
G^X_{jk}
=
Q_jQ_k+P_jP_k
```

とする。論理部分系Aの $X$ 操作は正方形の縦の対辺、論理部分系Bの $X$ 操作は横の対辺を同じ強度で駆動する。

```math
G_A^X
=
G^X_{00,10}
+
G^X_{01,11},
```

```math
G_B^X
=
G^X_{00,01}
+
G^X_{10,11}.
```

対応する $Z$ 生成子は

```math
G_A^Z
=
I_{00}+I_{01}-I_{10}-I_{11},
```

```math
G_B^Z
=
I_{00}+I_{10}-I_{01}-I_{11}
```

である。これらは行列表現で、それぞれ $X\otimes I_2$、$I_2\otimes X$、$Z\otimes I_2$、$I_2\otimes Z$ に一致する。従ってM38と同じ局所位相回転と $QQ+PP$ 交換を対辺で同期させれば、

```math
U_A\otimes I_2,
\qquad
I_2\otimes U_B
```

を有限列で厳密に実装できる。

対辺を同じ制御信号で駆動することは局所性の定義の一部である。2辺の強度差、位相差、支持窓のずれは、理想局所代数からの漏れとして6.10節の一般制御誤差へ入れる。

## 6.5 積状態と局所保存量

4振幅を係数行列

```math
B(b)
=
\begin{pmatrix}
b_{00}&b_{01}\\
b_{10}&b_{11}
\end{pmatrix}
```

へ並べる。論理積状態であるための必要十分条件は

```math
\det B(b)
=0
```

である。非零規格化状態では、この条件は

```math
b_{ab}
=
u_av_b
```

という因子化と同値である。

局所操作の下で係数行列は

```math
B
\longmapsto
U_ABU_B^{\mathsf T}
```

と変換される。従って行列階数と $|\det B|$ は局所操作で保存される。規格化状態に対する非因子化指標を

```math
\mathcal C(b)
=
2|\det B(b)|
```

と置くと、積状態では0、最大非因子化状態では1になる。本稿ではこの指標を、単一4モード担体内の論理分解に対してだけ用いる。

## 6.6 差モード射影とCNOT生成子

制御論理値が1である下側2モードの反対称差モードを

```math
|d\rangle
=
\frac{|10\rangle-|11\rangle}{\sqrt2}
```

とする。この1次元部分空間への射影は

```math
\Pi_{\rm CX}
=
|d\rangle\langle d|
=
|1\rangle\langle1|_A
\otimes
\frac{I_2-X_B}{2}
```

である。対応する実2次Hamiltonian 生成子は

```math
G_{\rm CX}
=
\mathcal J_0
b^\dagger\Pi_{\rm CX}b
```

であり、正準座標では

```math
G_{\rm CX}
=
\frac14
\left[
(Q_{10}-Q_{11})^2
+
(P_{10}-P_{11})^2
\right]
```

となる。また、

```math
G_{\rm CX}
=
\frac12
\left(
I_{10}+I_{11}-G^X_{10,11}
\right)
```

なので、新しい次数の相互作用は要らない。必要なのは、局所 $X_B$ の対辺同時駆動と区別して、下側の $10\leftrightarrow11$ 辺だけを選ぶ制御チャネルである。

## 6.7 有限自律Hamiltonian と厳密CNOT

時計正準対を $(\tau,P_\tau)$、端で滑らかに0となる有限支持窓を $g(\tau)$ とし、

```math
H_{\rm CX}
=
P_\tau
+
g(\tau)G_{\rm CX}
```

と置く。$\dot\tau=1$ なので、信号の有限時間発展は窓面積

```math
A
=
\int g(\tau)\,\mathrm d\tau
```

だけで決まり、

```math
U(A)
=
e^{-iA\Pi_{\rm CX}}
=
I_4
+
\left(e^{-iA}-1\right)
\Pi_{\rm CX}
```

となる。$A=\pi$ では

```math
U(\pi)
=
I_4-2\Pi_{\rm CX}
=
U_{\rm CX}.
```

右辺は論理Aを制御、論理Bを標的とするCNOTである。4基底上の作用は

```math
|00\rangle
\longmapsto
|00\rangle,
\qquad
|01\rangle
\longmapsto
|01\rangle,
```

```math
|10\rangle
\longmapsto
|11\rangle,
\qquad
|11\rangle
\longmapsto
|10\rangle.
```

有限流なので可逆であり、行列がユニタリなので実8次元表示は正準である。全作用 $I_{\rm ph}$ も厳密に保存される。

<!-- theorem-start:proposition -->
**命題（R105：差モード射影による厳密CNOT流）**

R104の操作誘導テンソル積を持つ4モード担体で、下側反対称差モードへの射影生成子を用いる。面積 $\pi$ の滑らかな有限時計窓は、全作用と正準性を保存しながら4論理基底上でCNOTと厳密に一致する。この流れは局所操作だけで準備した積入力を非因子化状態へ写すため、局所操作の積へ分解できない。
<!-- theorem-end:proposition -->

## 6.8 局所分解不能性と論理相関

局所操作で準備できる積入力

```math
|+0\rangle
=
\frac{|00\rangle+|10\rangle}{\sqrt2}
```

へ厳密CNOTを作用させると、

```math
U_{\rm CX}|+0\rangle
=
\frac{|00\rangle+|11\rangle}{\sqrt2}
```

となる。出力係数行列の行列式は $1/2$ なので、

```math
\mathcal C_{\rm out}
=1
```

である。局所操作は行列階数を保存するため、$U_{\rm CX}$ は $U_A\otimes U_B$ の形へ分解できない。

出力の論理相関は

```math
\langle X_AX_B\rangle
=1,
\qquad
\langle Z_AZ_B\rangle
=1,
\qquad
\langle Y_AY_B\rangle
=-1
```

である。局所操作 $Z_A\otimes X_B$ を追加すると、

```math
\left(
Z_A\otimes X_B
\right)
\frac{
|00\rangle+|11\rangle
}{\sqrt2}
=
\frac{
|01\rangle-|10\rangle
}{\sqrt2}
=
|\Psi^-\rangle
```

となる。従ってM39は、第7章のM41が基本入力に使うsinglet型4モード状態を、CNOTと局所操作だけで準備できる。

ただし、これらはこの時点では単一4モード担体内の代数的相関である。空間的に分離した2測定翼の共同頻度、Bell非局所性、測定設定独立性の監査にはM39単独を使わない。M41はA基底で階数2ブロックを選んだ後だけ2物理担体へ転送し、M39状態全体を2担体へ複製しない。

## 6.9 有限時間、相互作用強度、面積誤差

固定作用面では射影の期待値から

```math
0
\leq
G_{\rm CX}
\leq
\mathcal J_0
```

を得る。$|g(\tau)|\leq g_{\max}$ なら、相互作用部分は

```math
|gG_{\rm CX}|
\leq
g_{\max}\mathcal J_0
```

である。非負パルスで面積 $\pi$ を作る動作時間 $T_{\rm g}$ は

```math
T_{\rm g}
\geq
\frac{\pi}{g_{\max}}
```

を満たす。端で滑らかに0となる窓には、任意の $T_{\rm g}>\pi/g_{\max}$ を使える。これは準備した固定作用と有限時計運動量のセクターで相互作用エネルギーが有限であるという主張であり、時計項 $P_\tau$ を含む全Hamiltonian が位相空間全体で上下に有界であるという主張ではない。

実面積を $A=\pi+\delta A$ とし、$\delta A\in[-\pi,\pi]$ を主値とする。面積誤差だけがあるときの厳密な診断量は次である。

| 評価量 | 値 |
|---|---:|
| 最悪入力の非忠実度 | $\sin^2(\delta A/2)$ |
| 平均ゲート非忠実度 | $\frac35\sin^2(\delta A/2)$ |
| 入力 $|10\rangle,|11\rangle$ の真理値表誤り | $\sin^2(\delta A/2)$ |
| 入力 $|00\rangle,|01\rangle$ の真理値表誤り | $0$ |
| $|+0\rangle$ 出力の目標非忠実度 | $\frac34\sin^2(\delta A/2)$ |
| $|+0\rangle$ 出力の非因子化指標 | $|\cos(\delta A/2)|$ |

平均ゲート忠実度は [43] の標準式を4次元ユニタリ行列へ適用して、

```math
F_{\rm avg}
=
1
-
\frac35
\sin^2
\frac{\delta A}{2}
```

となる。これは古典4モード流の行列を比較する診断量であり、量子チャネルをミクロ前提へ追加したものではない。

固定した振幅ゲージで行列を直接比較する作用素距離は

```math
d_{\rm mat}
=
\left\|
U(\pi+\delta A)-U_{\rm CX}
\right\|_{\rm op}
=
2
\left|
\sin\frac{\delta A}{2}
\right|.
```

一方、6.2節では共通位相を縮約した。従って物理的な操作距離は

```math
d_{\rm proj}
=
\inf_{\phi\in\mathbb R}
\left\|
U_{\rm CX}^\dagger U(\pi+\delta A)
-
e^{i\phi}I_4
\right\|_{\rm op}
=
2\sin\frac{|\delta A|}{4}
```

である。$d_{\rm mat}$ と $d_{\rm proj}$ を混同しない。

## 6.10 一般制御誤差

漏れ結合、対辺の制御不均衡、局所位相ずれ、時計窓の重なりを、信号方程式

```math
i\dot b
=
\left[
g(t)\Pi_{\rm CX}
+
\Delta K(t)
\right]b
```

のHermitian 誤差 $\Delta K(t)$ へまとめる。共通位相成分は有効状態を変えないため、積分誤差を

```math
\eta_{\rm g}
=
\inf_{c(t)\in\mathbb R}
\int_0^{T_{\rm g}}
\left\|
\Delta K(t)-c(t)I_4
\right\|_{\rm op}
\,\mathrm dt
```

と定める。実際の伝播行列を $\widetilde U$ とすると、ある共通位相 $\phi$ に対してDuhamel 評価は

```math
\left\|
\widetilde U
-
e^{i\phi}U_{\rm CX}
\right\|_{\rm op}
\leq
\min\{2,\eta_{\rm g}\}
```

を与える。任意の規格化入力 $|\psi\rangle$ について、目標出力との忠実度は

```math
1-F_\psi
\leq
\min\{1,\eta_{\rm g}^2\}.
```

$|+0\rangle$ 入力では、$\eta_{\rm g}<1/\sqrt2$ なら目標最大非因子化状態への忠実度が $1/2$ を超える。任意の積状態とこの目標状態の忠実度は最大 $1/2$ なので、実出力が非因子化状態であることを保証できる。

## 6.11 資源上界とM35による検算

CNOT流単体の明示資源上界は次である。

| 資源 | 上界 |
|---|---:|
| 信号正準対 | 4 |
| 時計正準対 | 1 |
| 合計 | 5 |
| CNOT用交換辺 | $10\leftrightarrow11$ の1本 |
| 単一モード作用項 | 2 |
| 新しい相互作用次数 | 0 |
| 比較ポインター、reset セル | 0 |

これは最小性の証明ではなく、1回のゲート流に対する上界である。

M35を $L=4$ で使うと、固定測定設定ごとにCNOT出力を長期頻度として検算できる。M35の内部資源は

```math
3L+4
=16
```

正準対である。M39の4信号対とM35の4信号対を同一視し、ゲート窓と必要な逆ゲート窓を既存時計へ追加するなら、固定設定ごとの能動正準対数は16のままである。計算基底の真理値表、$XX$、$YY$、$ZZ$ の3設定、無反応率を別々に検算できる。

このM35接続は、有限標本の独立同分布統計、未知装置の完全過程トモグラフィー、複数設定の自律切替、永久外部記録、空間的に分離した局所測定を与えない。Q2-1の根拠はM39の明示Hamiltonian と解析的誤差式であり、M35は補助検算である。

<!-- theorem-start:proposition -->
**命題（R106：有限時間安定性と資源上界）**

面積 $\pi$ の滑らかな時計窓は、4信号正準対と1時計正準対からなる有限自律Hamiltonian 上でCNOTを厳密に実行する。固定作用面上で相互作用エネルギーは有界であり、最大結合強度に応じた有限動作時間下界を持つ。面積誤差には厳密な忠実度式、一般Hermitian 制御誤差には共通位相を除いた積分作用素ノルム上界が成立する。

## 6.12 Q2-1の達成判定とM41への出力契約

Q2-1の合格条件と根拠の対応は次である。

| 合格条件 | 根拠 |
|---|---|
| 入力論理基底と一般重ね合わせ | R104 |
| 外付け行列でない明示Hamiltonian | R105 |
| 全基底入力への作用 | R105 |
| 積状態から非分離相関を生成 | R105 |
| 局所操作だけに分解不能 | R104、R105 |
| 有限時間忠実度と資源上界 | R106 |

従ってQ2-1は、2量子ビット型結合ゲートと同じ共同入力--出力統計を生成する有限古典Hamiltonian過程として達成と判定する。M39の操作誘導テンソル積と非因子化生成は、この達成を支える明示実装と内部診断である。ただし次はQ2-1の達成範囲に含まない。

1. 2つの独立した古典位相空間または物理担体。
2. 空間的に分離した2量子ビット型装置。
3. Bell 非局所性またはBell 実験。
4. 結合Hamiltonian の自然なミクロ起源。
5. 配線誤差を含む具体的工学実装。
6. $n$ 論理量子ビットへの多項式資源拡張。
7. 完全な未知装置認証。

直接モード符号化をそのまま一般化すると、$n$ 論理量子ビットに $2^n$ 複素モードが必要になる。従ってQ2-1の達成はQ2-3の進展ではあるが、隠れた指数コストを解消しない。

M41への出力契約は次である。M39は規格化4モード状態 $c$、操作誘導テンソル積、局所基底回路、singlet型準備を渡す。M41は

```math
c^x
=
\left(
W_x\otimes I_2
\right)c
=
\begin{pmatrix}
c_+^x\\
c_-^x
\end{pmatrix}
```

と分け、枝作用

```math
I_A^x
=
\mathcal J_0
\left\|
c_A^x
\right\|^2
```

を源選択器へ渡す。M39単独では2物理担体を作らないが、M41は枝選択後のA方向とBブロックを2つの物理的2モード担体へ正準転送する。Q2-1の根拠はR104--R106、Q2-2への読出し橋はR107--R111であり、役割を混同しない。
