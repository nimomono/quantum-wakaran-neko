## 5.1 M38から一般有限Lへの拡張範囲

M38で完全周期を得た2頂点装置から、任意有限配置グラフの固定準備・固定基底へ補助部品を拡張する。M35の主な役割は、任意有限基底を標準配置基底へ移す分析回路、任意に直接与えた複素振幅場に対する初期実現配置の作用比準備、実現配置の局所更新セル、検出配置に条件付けた場準備と履歴保存、作用区間による補助的な分布検算である。

第2章、第3章、第6章、第7章の主線では測定結果を実現配置 $X$ に一本化する。M35の作用区間ラベルを、$X$ と独立な第2の測定結果として併用しない。一般有限 $L$ の永久外部記録、複数段測定、弱開放resetまでを含むM38同等の完全外部周期は未構成である。

準備状態を

```math
\chi\in\mathbb C^L,
\qquad
\chi^\dagger\chi=1
```

とし、全作用を $I_{\rm ph}=\mathcal J_0$ に固定する。信号 $b$ に加え、同じ $L$ モードのテンプレート $t$ を置く。周期開始時は

```math
b=e_1,
\qquad
t=e_1
```

とする。

作用読出し用に $L$ 個の正準対 $(Q_k,P_k)$、閾値用に $(Q_U,P_U)$、内部結果記録用に $(Q_M,P_M)$、選択器に $(\vartheta,J_{\rm sel})$、時計に $(\tau,P_\tau)$ を用いる。従って明示構成の正準対数は

```math
L+L+L+1+1+1+1
=
3L+4
```

である。作用レジスターのうち $Q_1,\ldots,Q_{L-1}$ は、読出し後に累積比較ポインターとして再利用する。これは最小数の主張ではない。

## 5.2 一般作用区間公式と補助的な直接標本化

$L$ 個の複素振幅場の頂点を $b\in\mathbb C^L$ とする。測定する有限直交基底を $\{|u_k\rangle\}_{k=1}^L$ とし、これを標準基底へ移すユニタリ正準混合 $W$ を

```math
W|u_k\rangle
=
e_k
```

で定める。出力モードの作用と全位相作用は

```math
I_k
=
\mathcal J_0
\left|
\left(Wb\right)_k
\right|^2,
\qquad
I_{\rm ph}
=
\sum_{k=1}^L I_k
```

である。累積作用を

```math
S_0=0,
\qquad
S_k
=
\sum_{j=1}^kI_j
```

とする。選択器角 $\vartheta\in[0,2\pi)$ から

```math
u
=
\frac{\vartheta}{2\pi}
I_{\rm ph}
```

を作り、$S_{k-1}\leq u<S_k$ を結果 $k$ とする。境界を除けば結果区間は互いに素で全区間を覆うため、各試行で結果は唯一である。

<!-- theorem-start:theorem -->
**定理（一般作用区間公式）**
選択器角が $(b,W,\mathcal P)$ の下で条件付き一様であり、比較失敗または記録失敗を結果依存に除外しないとする。このとき

```math
P(k\mid b,W)
=
\frac{I_k}{I_{\rm ph}}
```

であり、集団平均は

```math
P(k\mid W,\mathcal P)
=
\mathbb E
\left[
\frac{I_k}{I_{\rm ph}}
\middle|
W,\mathcal P
\right]
```

となる。
<!-- theorem-end:theorem -->

この定理は階数1を要求しない。固定作用下の高階数公式、全作用変動の共分散補正、相関行列との関係は付録Aにまとめる。本章の自律周期定理は、1本の軌道上の固定純粋準備に限定する。共通モデルでは、この公式を任意初期場の実現配置準備または分布検算に使い、分析器出口で既存の $X$ を読む測定と置き換えない。

## 5.3 任意有限基底の局所正準回路

単一モード位相回転と隣接2モード交換の生成子を

```math
G_{Z,j}
=
\frac{(Q_j^b)^2+(P_j^b)^2}{2},
\qquad
G_{X,j}
=
Q_j^bQ_{j+1}^b+P_j^bP_{j+1}^b
```

とする。両者の有限流と交換子方向は隣接 $U(2)$ を生成するため、任意の $W\in U(L)$ は高々 $L(L-1)/2$ 個の隣接2モード変換と対角位相へ分解できる [38,39]。固定状態準備は $L-1$ 個以下で足りる。逆変換は順序と角を反転して厳密に得られる。

この回路は1次元鎖の $L-1$ 本の交換辺を時計順に再利用する。密な基底変換の直列深さは逐次配置で $O(L^2)$、並列配置で $O(L)$ である。$G_{X,j}$ は運動量間結合を含むため、M37の位置ばね網と同じハードウェアではない。回路分解と時計窓の正準実装は付録D.2--D.4に示す。

## 5.4 作用読出しと完全結果集合

基底回路後のモード作用を $I_k=\mathcal J_0|b_k|^2$、累積作用を $S_j=\sum_{k\leq j}I_k$ とする。選択器角から一様閾値 $u\in[0,I_{\rm ph})$ を作り、正準読出しと局所剪断で

```math
d_j
=
S_j-u,
\qquad
d_1\leq\cdots\leq d_{L-1}
```

を得る。双曲型増幅後の平坦な滑らか比較器は、安全結果 $k$ について

```math
d_j<0
\quad(j<k),
\qquad
d_j>0
\quad(j\geq k)
```

を厳密な0、1の旗へ変換する。比較境界と角切断の遷移領域は正式な無反応結果 $\varnothing$ とし、どの実結果へも割り当てない。

入力換算半幅を $w=Xe^{-\Lambda}$、角切断領域のHaar質量を $\varepsilon_{\rm cut}$ とすると、

```math
P(\varnothing)
\leq
\min\left\{
1,
2(L-1)\frac{w}{I_{\rm ph}}
+
\varepsilon_{\rm cut}
\right\}.
```

従って結果集合 $\{1,\ldots,L,\varnothing\}$ は全入力を覆い、無反応試行を除いて再規格化しない。作用読出し、累積剪断、比較器、境界測度の詳細は付録D.5--D.7、D.12に示す。

## 5.5 測定後状態と反復性

安全結果 $k$ の比較旗は、空テンプレートを隣接経路で $e_k$ へ運ぶ。信号 $b$ とテンプレート $t$ の正準SWAP

```math
G_{\rm sw}
=
i\left(b^\dagger t-t^\dagger b\right)
```

を作用させ、信号へ $W^\dagger$ を戻すと、

```math
b_{\rm post}
=
W^\dagger e_k
=
|u_k\rangle
```

となる。測定前情報はテンプレートへ移り、全系では可逆性を保つ。無反応では基底状態を主張しない。

<!-- theorem-start:theorem -->
**定理（安全セクターの条件付き測定後状態）**

固定純粋準備 $\chi$、固定基底 $\{|u_k\rangle\}$、安全セクター $\mathcal O_k$ の下で、結果 $k$ の測定直後の信号相関行列は $|u_k\rangle\langle u_k|$ である。無反応を含む無条件相関行列には、遷移領域の中間状態が別項として残る。
<!-- theorem-end:theorem -->

同じ基底を新しい空テンプレートで再測定すれば、安全結果 $k$ を確率1で得る。現在の装置を再利用する場合は、先に内部逆計算を完了する。経路、SWAP、保持、反復条件は付録D.7--D.9に示す。

## 5.6 自律周期と内部帰還

前向き操作を、準備、基底回路、作用読出し、累積比較、テンプレート経路、SWAP、測定後基底回路の順に置く。保持後は逆順・逆角で全操作を戻す。前向き写像の厳密な逆を使うため、無反応領域を含む信号、テンプレート、読出しレジスター、共役運動量は準備値へ戻る。内部記録を消去したのではなく、情報を元の信号と選択器状態へ戻している。

互いに重ならない滑らかな時計窓 $g_r(\tau)$ を使えば、全操作は

```math
H_{\chi,W}^{\rm cyc}
=
P_\tau
+
\sum_r
g_r(\tau)G_r
```

という1本の有限自律Hamiltonianへまとめられる。周期末に選択器角だけを $2\pi\alpha$、$\alpha\notin\mathbb Q$ だけ進める。時計運動量の帰還、選択器ドリフト、全入力での逆計算は付録D.9--D.11に示す。空間的に離れた各辺へ1つの時計信号を有限速度で配る配線は本章に含まない。

## 5.7 不変測度とBorn型長期頻度

Poincaré断面で選択器角以外の内部変数を準備値へ固定すると、周期写像は

```math
\vartheta
\longmapsto
\vartheta+2\pi\alpha
\pmod{2\pi}
```

となる。従ってHaar測度と準備点測度の積は不変であり、無理数回転の一意エルゴード性から安全結果区間の長期頻度が区間長へ収束する。理想Born型分布を $p^{\rm id}=(|\langle u_1|\chi\rangle|^2,\ldots,|\langle u_L|\chi\rangle|^2,0)$ とすると、

```math
D_{\rm TV}
\left(
p^{\rm cyc},
p^{\rm id}
\right)
=
p_{\varnothing}^{\rm cyc}
\leq
2(L-1)\frac{Xe^{-\Lambda}}{I_{\rm ph}}
+
\varepsilon_{\rm cut}.
```

<!-- theorem-start:theorem -->
**定理（局所滑らか作用区間周期による分布検算）**

任意の有限 $L$、固定純粋準備 $\chi$、固定有限直交基底 $\{|u_k\rangle\}$、任意の $\epsilon>0$ に対し、$3L+4$ 正準対からなる有限自律Hamiltonian周期を構成できる。作用区間ラベルの集合は $\{1,\ldots,L,\varnothing\}$ で、各試行のラベルは一意である。安全ラベルでは条件付き信号場が厳密な基底状態となり、無反応領域を含む全内部変数が周期末に準備値へ戻る。長期ラベル分布と理想Born型分布の全変動距離は $\epsilon$ 未満にできる。このラベル分布は共通モデルの実現配置分布を独立に検算する補助量である。
<!-- theorem-end:theorem -->

無理数回転は混合的でないため、長期頻度は得られるが独立同分布性や二項分布型有限標本揺らぎは従わない。Poincaré写像、無反応込み分布、資源計数の証明は付録D.10--D.13に示す。Q3-1からの包絡方向誤差を入力する場合は、第9.9節の $\varepsilon_{\rm dist}$ を装置側の全変動誤差へ加える。

## 5.8 適用範囲と残る課題

本章は、固定純粋準備・固定有限基底・有限次元・任意精度という範囲で、一般有限 $L$ の分析、実現配置準備、局所更新、条件付き場準備、分布検算を与える。2頂点の任意のBloch軸、同軸反復、異軸逐次測定、永久外部記録、弱開放resetは第3章のM38で閉じる。一般有限 $L$ については、複数段の独立更新セル、外部記録・resetセル流、長距離時計配線、完全周期の資源増加が残る。これらは独立した長期目標の達成判定ではなく、M35の適用限界と一般化課題として管理する。一般混合状態を1本の軌道から生成すること、混合的有限標本統計、連続スペクトルも本章の結果に含めない。
