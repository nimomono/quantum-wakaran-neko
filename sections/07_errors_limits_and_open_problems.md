## 7.1 対象範囲

本章は次の4つを同一視せずに集計する。

1. M38の2モード操作、2段測定、有限反復Zeno周期、外部記録、弱開放 reset 。
2. M37の局所振動子網による空間伝播。
3. M35の一般有限基底内部測定周期。
4. M36の条件付きBell 二側履歴模型。

M38はQ1-1からQ1-4を閉じるが、M37との同一ハードウェア化を含まない。M37からM35への接続は、状態方向誤差から有限基底分布誤差への数学的上界であり、同一装置の構成ではない。M0への統合、一般有限 $L$ の完全周期、量子計算機としての規模依存性は別の課題である。

## 7.2 M38の誤差台帳

M38の1回の前向き観測について、理想逐次分布と観測分布の全変動距離を、次の無次元誤差へ分ける。

```math
D_{\rm TV}^{\rm M38}
\leq
\delta_1+\delta_2
+
\varepsilon_{\rm op}
+
\varepsilon_{\rm clk}
+
\varepsilon_{\rm rec}
+
\varepsilon_{\rm port}.
```

| 誤差 | 内容 | 現行評価 |
|---|---|---|
| $\delta_1,\delta_2$ | 2段比較器の無反応質量 | 各段で $2w_{{\rm eff},j}/\mathcal J_0+\varepsilon_{{\rm cut},j}$ 以下 |
| $\varepsilon_{\rm op}$ | $SU(2)$ パルス面積、順序、生成子の実装誤差 | 理想正準回路では0、有限列の和上界 |
| $\varepsilon_{\rm clk}$ | 時計窓面積、重なり、作用帰還誤差 | 非重複理想窓では0 |
| $\varepsilon_{\rm rec}$ | 記録セルの共役運動量幅と読出し幅 | $T_R\sigma_PK_\Pi$ から状態誤差へ換算 |
| $\varepsilon_{\rm port}$ | 外部セルの流入・流出と接触時間のずれ | 個別実装で評価 |

比較幅の入力換算量は

```math
w_{\rm eff}
=
Xe^{-\Lambda}
+
\Delta_{\rm in}
+
e^{-\Lambda}\Delta_{\rm out}
```

である。増幅前誤差は双曲型増幅で減らない。増幅後の固定出力誤差だけが入力換算で小さくなる。

異なる単位の誤差を表のまま加えない。付録Eの順序に従い、正準状態誤差を状態方向誤差へ、状態方向誤差を比較境界移動量へ、境界移動量をHaar 質量と全変動距離へ変換する。上式の各 $\varepsilon$ は最終的に全変動距離へ換算した後の量である。

第2段、第1段、準備回路の逆計算残差と周期末 reset の交換誤差は、記録後に生じるため同じ観測の分布誤差へ入れない。これらを周期帰還誤差

```math
\varepsilon_{\rm ret}^{\rm M38}
\leq
\varepsilon_{\rm inv}
+
\varepsilon_{\rm rst}
```

として分け、次の実験周期の準備誤差へ伝播させる。長期の反復分布を評価するときだけ、その伝播分を次周期の前向き誤差へ加える。

## 7.3 有限Zeno周期の誤差

固定有限 $N_{\rm Z}$ の実結果空間を $\{+1,-1,\varnothing\}^{N_{\rm Z}}$ とし、理想履歴分布を無反応成分0で拡張する。第 $j$ 前向き段の条件付き全変動誤差を $\eta_j^{\rm fwd}$ とすると、

```math
D_{\rm TV}
\left(
p_{N_{\rm Z}},
\pi_{N_{\rm Z}}
\right)
\leq
1-
\prod_{j=1}^{N_{\rm Z}}
\left(
1-\eta_j^{\rm fwd}
\right)
\leq
\sum_{j=1}^{N_{\rm Z}}
\eta_j^{\rm fwd}
=
E_{N_{\rm Z}}^{\rm fwd}
```

である。

| 誤差 | 内容 | 現行評価 |
|---|---|---|
| $\delta_j$ | 第 $j$ 比較器の無反応質量 | $2w_{{\rm eff},j}/\mathcal J_0+\varepsilon_{{\rm cut},j}$ 以下 |
| $\varepsilon_{{\rm pulse},j}$ | 有限測定パルスと理想瞬時写像の差 | 固定作用殻上で有限パルス幅に比例 |
| $\varepsilon_{{\rm Rabi},j}$ | 測定窓中のRabi 項との非可換な重なり | $C_jh_j$ 以下 |
| $\varepsilon_{{\rm clk},j}$ | 時計窓面積、時刻中心、窓重なり | 非重複理想窓では0 |
| $\varepsilon_{{\rm rec},j}$ | 永久記録セルの反作用 | $T_{R,j}\sigma_{P,j}K_{\Pi,j}$ から換算 |
| $\varepsilon_{{\rm cell},j}$ | コア補助6対と段セルのSWAP | 理想交換では0、角誤差を状態誤差から換算 |

$\eta_j^{\rm fwd}$ は表の項を全て結果分布の全変動距離へ換算した後の和である。従って

```math
\left|
S_{N_{\rm Z}}^{\rm real}
-S_{N_{\rm Z}}
\right|
\leq
E_{N_{\rm Z}}^{\rm fwd},
```

```math
\left|
F_{N_{\rm Z}}^{\rm real}
-F_{N_{\rm Z}}
\right|
\leq
E_{N_{\rm Z}}^{\rm fwd}
```

となる。理想測定側と理想対照側の差が $E_{N_{\rm Z}}^{\rm fwd}$ と対照側誤差の和を超える範囲を、実装上の有限Zeno抑制として採用する。

逆計算、周期末 reset、選択器移動の誤差は、既に記録済みの同じ観測へ遡って作用しない。これらは周期帰還誤差 $\varepsilon_{\rm ret}$ として分け、次の実験周期の準備誤差へ伝播させる。固定有限 $N_{\rm Z}$ では

```math
E_{N_{\rm Z}}^{\rm fwd}<\epsilon,
\qquad
\varepsilon_{\rm ret}<\epsilon
```

を同時に選べば十分であり、$N_{\rm Z}\to\infty$ に一様な帯域上界を要求しない。

## 7.4 M37からM35への分布誤差

測定時刻の規格化局所包絡を $\widehat b_{\rm mic}$、目標有効状態を $\chi_L$ とする。任意有限基底について

```math
D_{\rm TV}
\left(
p^{\rm mic},p^L
\right)
\leq
\sqrt{
1-
\left|
\langle\widehat b_{\rm mic},\chi_L\rangle
\right|^2
}
```

である。装置誤差を加える場合は

```math
D_{\rm TV}^{\rm M35}
\leq
\varepsilon_{\rm dist}(T)
+
\varepsilon_{\rm prep}
+
\varepsilon_W
+
\varepsilon_{\rm read}
+
\varepsilon_{\rm cmp}
+
\varepsilon_{\rm cut}
+
\varepsilon_{\rm clk}
```

とする。

| 誤差 | 内容 | 現行評価 |
|---|---|---|
| $\varepsilon_{\rm dist}$ | M37の局所包絡と目標状態の方向差 | 第3章と第5.3節の解析上界 |
| $\varepsilon_{\rm prep}$ | 初期作用、相対位相、伝播時刻の再現誤差 | 完全準備系で未評価 |
| $\varepsilon_W$ | M35局所基底回路の誤差 | 理想 $QQ+PP$ 回路では0 |
| $\varepsilon_{\rm read}$ | 作用・閾値読出しと累積剪断の誤差 | 理想入口では0 |
| $\varepsilon_{\rm cmp}$ | 滑らかな比較幅 | $2(L-1)w_{\rm eff}/I_{\rm ph}$ 以下 |
| $\varepsilon_{\rm cut}$ | 角切断の接続領域 | 接続幅のHaar 質量 |
| $\varepsilon_{\rm clk}$ | 一般有限 $L$ の時計配線誤差 | 物理配線は未評価 |

第3章の自然時間では $\varepsilon_{\rm dist}=O(\eta)$ である。目標精度を $\epsilon$ とする単純な十分条件は

```math
\omega_0
=
O
\left(
\frac{\|h_L\|}{\mathcal J_0\epsilon}
\right)
```

である。最適性は主張しない。

## 7.5 M38の資源

M38の単純上界は次である。

| 装置 | 正準対数 |
|---|---:|
| Q1-1の信号担体 | 2 |
| 自律Rabi 装置 | 3 |
| $L=2$ M35測定1段 | 10 |
| 信号と時計を共有する2段測定器 | 17 |
| 外部記録セル | 2対／周期 |
| 外部 reset セル | 最大14対／周期 |
| Q1-4の再利用測定コア部分 | 10 |
| Q1-4の独立選択器・補助セル・記録 | 8対／測定段 |

2段測定器の17対は

```math
2+2\times7+1
```

からなる。共有するのは信号2対と時計1対であり、各段はテンプレート2、作用2、閾値1、内部記録1、選択器1の7対を持つ。

$K$ 実験周期を有限閉鎖Hamiltonian 系へ埋め込む単純上界は

```math
17+16K
```

正準対である。輸送自由度は含まない。能動装置の大きさは一定だが、永久記録と使用済みreset 状態の保存量は $O(K)$ で増える。有限閉鎖系の固定容量で無期限記録を行うとは主張しない。

Q1-4の1回の有限観測では、信号2対、測定コア補助6対、共通制御時計1対、Rabi 駆動作用・角1対を再利用する。各測定段は独立選択器1対、補助状態交換セル6対、永久記録セル1対を使う。従って単純上界は

```math
10+8N_{\rm Z}
```

である。$K$ 回の実験周期で選択器と補助状態交換セルを再利用し、永久記録を全て保持する場合は

```math
10+7N_{\rm Z}+KN_{\rm Z}
```

となる。有限誤差を無期限に補正する外部 reset セル流と輸送自由度は別に数える。測定コア数は1だが、可逆性、独立選択器、永久記録のため段数に比例する資源は残る。

## 7.6 一般有限基底装置の資源

M35の一般有限 $L$ 構成は

```math
N_{\rm pair}^{\rm meas}
=
3L+4
```

正準対を使う。内訳は信号 $L$、テンプレート $L$、作用レジスター $L$、閾値1、内部記録1、選択器1、時計1である。

任意の密な基底変換 $W$ は

```math
N_W
\leq
\frac{L(L-1)}2
```

個の隣接2モード混合と対角位相へ分解できる。逐次Givens 消去の深さは $O(L^2)$、互いに素な辺を並列化する配置では $O(L)$ である。累積剪断とテンプレート経路は $O(L)$ である。

一般有限 $L$ の複数段装置では、独立選択器、テンプレート、外部記録・reset セルの数が段数とともに増える。空間的に離れた各辺への時計配線と伝播遅延も必要になる。一般有限 $L$ の完全周期資源は未評価であり、M35の一般化課題として残る。

## 7.7 動作時間、作用、エネルギー

M38とM35の各時計窓はパルス面積を指定する。最大結合強度を制限しなければ物理時間を任意に短縮できるので、絶対動作時間の主張にはならない。意味のある評価には最大生成子ノルムまたは最大結合強度を固定する必要がある。

reset 交換の接触時間は

```math
T_{\rm rst}
=
\frac{\phi}{g}
```

である。弱結合では接触時間が長くなる。比較精度を上げると双曲型増幅率 $\Lambda$ とポインター座標範囲が増える。

M37のミクロエネルギーは厳密保存される。M38の各理想正準パルスと外部セル交換も全Hamiltonian 内では可逆である。しかし、準備装置、時計、記録媒体、外部セル輸送、低エントロピーセル供給まで含む総エネルギー収支は計算していない。Landauer 原理を引用するだけでは、具体的なreset の熱・仕事収支にならない [17,18]。

## 7.8 反復可能性

反復には4つの意味がある。

1. 同じ観測中に、測定後信号を次のRabi 区間と測定へ渡すこと。
2. 全結果記録後に段セルを逆順で戻し、内部装置を復帰させること。
3. 周期末 reset と選択器移動後に、同じ能動装置で次の実験周期を始めること。
4. 外部記録と使用済みreset セルまで含む全系を結果非依存の同一点へ戻すこと。

M38は1--3を構成する。Q1-4では1個の測定コアを使い、補助状態だけを段セルへ退避する。4はHamiltonian 流の1対1性と両立せず、要求しない。固定有限 $N_{\rm Z}$ と $K$ なら履歴を有限個の外部セルへ保存し、全系を有限閉鎖Hamiltonian として扱える。無期限運転では空セル流入と使用済みセル流出を持つ弱開放系として扱う。

M35の一般有限 $L$ では内部逆計算は構成済みだが、複数段測定と外部セル流は未構成である。

## 7.9 Bell 側の性能指標

Bell 模型では、共同分布だけでなく次を別々に監査する。

```math
\epsilon_{\rm joint}
=
\max_{x,y}
\frac12
\sum_{A,B}
\left|
P_{\rm obs}(A,B\mid x,y)
-w_{AB}^{xy}
\right|,
```

```math
\epsilon_{\rm ns}^{A}
=
\max_{x,y,y',A}
\left|
P(A\mid x,y)-P(A\mid x,y')
\right|,
```

```math
\epsilon_{\rm ns}^{B}
=
\max_{x,x',y,B}
\left|
P(B\mid x,y)-P(B\mid x',y)
\right|.
```

現行最小模型では非信号誤差が解析的に零である。非対称比較幅、伝送損失、境界Jacobianを含む完全模型の上界は未導出である。設定分布、整合支持質量、結果別基準密度、事後除外率も別に記録する。

## 7.10 導出済み部分と残る資源評価

本稿は次を定量化した。

1. M38のBloch 球、$SU(2)$、Rabi 遷移公式。
2. M38の2段無反応率と全変動距離上界。
3. 外部記録剪断の反作用上界、reset 交換の収縮上界。
4. 有限反復測定の全履歴則、短時間有効反転率、未測定対照。
5. 単一測定コア、循環段セル、継続Rabi 駆動の前向き誤差上界。
6. M38の2段能動正準対数17と、Q1-4の $10+8N_{\rm Z}$ 資源上界。
7. M37の作用素誤差、状態誤差、局所作用変動。
8. M37からM35への有限基底分布誤差。
9. M35の正準対数 $3L+4$ と基底回路深さ。

残る課題は、強度制約下の最小測定間隔、全時間域の抑制・増速境界、総エネルギー収支、雑音耐性、M38の長期安定性、資源下界、一般有限 $L$ の完全周期、多体系での規模依存性である。これらは各目標の検証項目またはM35の一般化課題であり、有限Zeno抑制を超える一般化または $n$ 量子ビット回路の実装コストを扱うQ2-3の達成とは数えない。Q2-3は未着手である。
