## 7.1 境界位相空間

1試行の全正準変数を $z\in\Gamma_{\rm all}$ とする。これには、粒子、2成分場、源、左右分析器、指針、戻りモード、比較モード、時計、記録、spectator自由度を含む。

結果sectorを排他的な和

```math
\Gamma_\partial
=
\bigsqcup_{A,B}
\Gamma_\partial^{AB}
```

とする。各 $\Gamma_\partial^{AB}$ では、局所記録は $(A,B)$ を持ち、時計は比較境界面を正方向に横切り、比較総作用制約

```math
J_{\rm R}+J_{\rm I}
=
A_\partial^{AB}
```

を満たす。

基準 Liouville 体積を

```math
d\Gamma_{\rm cmp}
=
dQ_{\rm R}\,dP_{\rm R}\,
dQ_{\rm I}\,dP_{\rm I}
```

とし、残る自由度、時計流束、境界面、coarea因子を境界密度 $\lambda_\partial^{AB}(z;a,b)$ へまとめる。

## 7.2 未規格化結果質量

結果sectorの基準多重度を $w_{AB}\geq0$ とする。未規格化結果質量を

```math
\widetilde W_{AB}(a,b)
=
w_{AB}
\int
\lambda_\partial^{AB}(z;a,b)
\delta
\left(
A_\partial^{AB}
-
J_{\rm R}
-
J_{\rm I}
\right)
d\Gamma_{\rm cmp}
d\Gamma_{\rm spec}
```

と定める。$\Gamma_{\rm spec}$ は、結果依存作用を直接分配しない自由度を表す。

理想共通条件は

```math
w_{AB}
=
\frac14,
```

```math
\lambda_\partial^{AB}(z;a,b)
=
\lambda_\partial(z;a,b)
```

である。共通因子は設定 $a,b$ に依存しても、4つの結果sectorで同じなら規格化で相殺する。ただし、作用分配座標に対して一定であるか、積分後の因子が全sectorで等しい必要がある。

$w_{AB}$ は、正規化済みの前向き初期集団が各sectorに持つ事前確率を意味しない。境界位相空間の各 Liouville 要素へ置く共通の基準密度または解多重度である。この区別をしないと、Hamiltonian 写像が保存するsector総質量と、未規格化殻容量を二重に数える。

## 7.3 2モード境界殻からの共同確率

<!-- theorem-start:theorem -->
**定理（共通境界測度下の Bell 共同確率）**
次を仮定する。

1. 第5章の余弦作用 $K_{AB}$。
2. 第6章の理想転送 $A_\partial^{AB}=\Gamma^2K_{AB}/2$。
3. $w_{AB}=1/4$。
4. 境界密度、時計流束、coarea Jacobian、spectator体積、解多重度が4つの結果sectorで共通。
5. 全sectorを同じ境界分解能で数える。

このとき、

```math
P(A,B\mid a,b)
=
\frac{
\widetilde W_{AB}
}{
\sum_{A',B'}
\widetilde W_{A'B'}
}
=
\frac14
\left[
1-AB\cos\Delta_{ab}
\right].
```
<!-- theorem-end:theorem -->

<!-- theorem-start:proof -->
**証明**
共通因子を $\Lambda_\partial(a,b)>0$ とまとめると、2モード殻容量から

```math
\widetilde W_{AB}
=
\frac14
\Lambda_\partial
(2\pi)^2
A_\partial^{AB}
\propto
K_{AB}.
```

第5章の総和 $\sum_{A,B}K_{AB}=\mathcal K$ により、

```math
P(A,B\mid a,b)
=
\frac{K_{AB}}{\mathcal K}.
```

余弦作用を代入する。
<!-- theorem-end:proof -->

この定理は、共通境界条件を置いた後の厳密結果である。境界条件自体を前向き初期分布から導いた結果ではない。

## 7.4 相関と CHSH 値

共同確率から

```math
E(a,b)
=
\sum_{A,B}
AB
P(A,B\mid a,b)
=
-\cos\Delta_{ab}
```

を得る。

有効角が

```math
\Delta_{ab}
=
-\frac{\pi}{4},
\qquad
\Delta_{ab'}
=
\frac{\pi}{4},
```

```math
\Delta_{a'b}
=
\frac{\pi}{4},
\qquad
\Delta_{a'b'}
=
\frac{3\pi}{4}
```

となる4設定を選べば、

```math
\left|
E(a,b)
+
E(a,b')
+
E(a',b)
-
E(a',b')
\right|
=
2\sqrt2.
```

これは理想余弦法則の CHSH 値である。任意の測定集合または一般的な Tsirelson 原理を古典模型から導いたことを意味しない。現模型は2出力の平面内回転に限定される。

位相可視度、戻り損失、背景作用を含めて

```math
E(a,b)
=
-V_{\rm Bell}\cos\Delta_{ab}
```

となる場合、標準角で

```math
|S_{\rm CHSH}|
=
2\sqrt2V_{\rm Bell}.
```

古典上限を超えるには $V_{\rm Bell}>1/\sqrt2$ が必要である。

## 7.5 非信号周辺

<!-- theorem-start:corollary -->
**系（対称共通境界測度下の非信号性）**
第7.3節の条件の下で、

```math
\sum_B
P(A,B\mid a,b)
=
\frac12,
```

```math
\sum_A
P(A,B\mid a,b)
=
\frac12.
```

従って観測周辺は遠隔設定に依存しない。
<!-- theorem-end:corollary -->

<!-- theorem-start:proof -->
**証明**
余弦共同確率を反対側の符号について足すと、$AB\cos\Delta_{ab}$ の項が相殺する。
<!-- theorem-end:proof -->

この非信号性は、結果sectorの対称性と共通因子に依存する。結果依存の境界密度、異なる coarea Jacobian、非対称な基準多重度、結果別の比較失敗率がある場合、非信号性は自動的に成立しない。

## 7.6 完全履歴測度

設定 $a,b$ を固定した Hamiltonian 境界値問題の解空間を $\mathcal S_{a,b}$ とし、境界位相点から完結履歴への解写像を

```math
\mathfrak S_{a,b}:
\Gamma_\partial^{a,b}
\longrightarrow
\mathcal S_{a,b}
```

とする。完全履歴測度は、境界 Liouville 測度を作用制約と境界密度で重み付けし、解写像で押し出して定める。

```math
\mu_{\rm hist}^{a,b}
=
\left(
\mathfrak S_{a,b}
\right)_*
\mu_\partial^{a,b}.
```

解空間へ直接 Liouville 測度を置くわけではない。解の非一意性、分岐、多重度、coarea Jacobian は $\lambda_\partial$ に含め、結果と設定で共通かを監査する。

## 7.7 生成側への引き戻しと測定設定独立性

境界面から生成側準備面までの Hamiltonian flowを $\Phi_{T\leftarrow0}^{a,b}$ とする。境界測度を準備面へ引き戻すと、

```math
\mu_{\rm prep}^{a,b}
=
\left(
\Phi_{T\leftarrow0}^{a,b}
\right)^*
\mu_\partial^{a,b}.
```

作用制約 $A_\partial^{AB}$ は $a,b$ に依存するため、一般に

```math
\rho(\Lambda\mid a,b)
\neq
\rho(\Lambda).
```

従って、Bell の前提違反は測定設定独立性にある。Bell の定理、CHSH不等式、時間対称境界条件、測定設定独立性を緩める模型との関係は [1,2,7--11,20--23] に対応する。

局所結果応答を十分な局所変数について

```math
A
=
A(a,\Lambda_A),
\qquad
B
=
B(b,\Lambda_B)
```

と書ける理想模型では、測定時の直接相互作用を空間的に局所に保てる。Bell 違反は、設定に依存する完全履歴集団から生じる。これは Bell の定理を否定せず、その前提の1つを明示的に外す構成である。

## 7.8 共通未来比較器の因果的役割

局所結果は、戻り信号が比較器へ到達する前に記録できる。通常の前向き因果だけなら、後の比較器は過去の記録を変更できない。本模型も、そのような前向き変更を主張しない。

比較器の役割は次の2つである。

1. 完結履歴に対する $K_{AB}$ を共通未来の局所相互作用として比較作用へ転送する。
2. 二側境界測度を定義する物理的な終端自由度を与える。

従って、比較器は過去へ制御信号を送る装置ではなく、生成からresetまでの全履歴に課す境界条件の終端である。

## 7.9 事後選別との区別と未解決点

通常の前向き初期分布から試行を発生させ、比較後に適合した履歴だけを残すなら、実験的な事後選別である。

本章の数学では、最初から全結果sectorの排他的な境界和へ測度を置き、境界測度に含まれる全履歴を数える。境界測度内部で結果別に履歴を捨てる操作はない。

しかし、この定義だけでは、実験準備が事後選別を使わず同じ測度を生成することを証明しない。必要なのは、

1. 設定生成器を含む反復可能な全周期。
2. 全開始数、局所記録数、比較完了数、reset完了数の一致。
3. 結果依存の失敗試行または停止時間を捨てないこと。
4. 共通境界密度を有限 Hamiltonian と弱開放流路から準備すること。

である。これは現模型最大の未解決問題である。

## 7.10 Bell 前提監査

| Bell 関連条件 | 現模型での状態 |
|---|---|
| 局所設定への局所応答 | 理想装置では維持する |
| 遠隔設定による瞬間的な測定力 | 導入しない |
| 測定設定独立性 | 境界測度の生成側pullbackで破れる |
| 観測非信号性 | 対称sectorと共通境界因子の下で成立 |
| 結果の一意形成 | 一般測定器として未構成 |
| 設定生成の独立な物理周期 | 未構成 |
| 実験的な無条件標本と境界測度の同一性 | 未証明 |
| 全試行の監査 | 完成周期とともに未解決 |

「局所 Hamiltonian である」ことだけでは Bell の局所因果性の全前提を満たすとは言えない。設定依存の完全履歴測度を含めて監査する必要がある。

## 7.11 旧3モード模型との置換

| 旧3モード模型 | 現2モード模型 |
|---|---|
| $J_+$ を固定して残余体積を数える | 比較作用そのものを2モード総作用にする |
| $U(3)$ 全殻準備が必要 | 比較2モードの $U(2)$ 殻内混合 |
| $J_*+I_-^{AB}$ | $K_{AB}$ に直接比例 |
| $J_*$ により理想可視度が低下 | 理想模型では追加基準作用なし |
| 比較作用の生成が抽象的 | $H_{\rm read}$ で明示 |
| 共通境界測度の準備が未解決 | この問題は残る |

旧模型の $U(2)$ 不足、$U(3)$ 共通殻、残余ファイバー計算は数学的結果として研究メモへ保存するが、現行論文の採用模型には使わない。

## 7.12 本章の結論

反対称対モードが作る $K_{AB}$ を2モード比較作用へ転送し、結果sector間で共通の境界密度を仮定すると、理想 Bell 共同確率、CHSH値 $2\sqrt2$、非信号周辺を得る。生成側へ引き戻した完全履歴測度は設定に依存し、Bell の測定設定独立性を満たさない。

共通境界測度を事後選別なしの実験周期として準備する部分は未解決であり、本章の条件付き定理を無条件の物理導出と呼ばない。
