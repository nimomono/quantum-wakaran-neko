## H.1 対応表

W型最低2正常モードを局在基底へ移した実正準対をM54のW2信号部分系と同定する。初期状態方向は実正準座標の準備済み古典入力として与え、その後の可逆制御と測定だけを現行結果へ接続する。

| 段階 | W型2モードでの指定 | 正本 |
|---|---|---|
| 初期入力 | 非零の準備済み実正準2モード信号 | 第2.4節、R187 |
| 閉鎖伝播 | W型低2モード生成子の正準流 | R135、第2章 |
| W型制御・診断 | 偶奇二重項と左右局在基底 | R140、第3章、第6章 |
| 作用保持 | 走行中W2の左右射影作用を正準保持座標へ写す | R189A、第3章 |
| decision接続 | 保持済み二作用を3状態open selectorの線形rateへ直接入力する | M65/R204A、付録Z |
| 2結果読出し | finite-time Born結果、endpoint、record/latch | R204D--R204F、付録Z |
| 測定後受渡し | 固定結果で $Z\mapsto P_bZ$ | R181D、付録P |

Q1の現行物理接続は

```math
\mathrm{M37\ W2}
\xrightarrow{\mathrm{R189A}}
(A_L,A_R)
\xrightarrow{\mathrm{M65/R204D}}
\xrightarrow{\mathrm{R181D}}
P_bZ
```

である。M65はQ1/Q2共通binary selectorであり、Q1ではR189A保持作用を直接入力する。

## H.2 役割境界

本付録は初期状態方向の物理的生成を証明しない。Q1-2の固定有限深さではR192を用いず、R181Dの非規格化選択成分を同じ試行の次段へ直接渡す。一般深さQ2-4の作用下限回復はR192の別責務であり、W型2モード制御の一部ではない。

M65 decisionに使った保持対は次回captureへ未処理のまま再接続しない。固定有限深さでは未使用保持対との正準SWAP、反復装置ではR179 open resetを使う。Born重みを外部から再準備する操作ではない。
