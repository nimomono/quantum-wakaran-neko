@chapter: 概要
@title: 構造化有限浴を持つ弱開放古典 Hamiltonian 系における Nelson 作用極限と境界作用殻測度の下での Bell 型統計
@status: 第I部の線形 Gauss 型作用収束は厳密結果である。第II部では、共通作用殻を仮定した残余ファイバー体積は厳密結果、浴による全殻等方拡散は縮約方程式の下で厳密だが、同じ有限浴からのミクロ導出は予想・未解決である。

本論文は、有限自由度の古典 Hamiltonian 系を基礎としながら、実験装置を外部との微小なエネルギー交換を伴う弱開放系として扱う。対象部分と外部自由度を合わせた拡大系を

```math
H_{\rm all}
=
H_{\rm fin}(z)
+
H_{\rm ext}(y)
+
\varepsilon_{\rm ext}H_{\rm link}(z,y)
+
H_{\rm work}
```

と書く。$H_{\rm fin}$ は生成源、測定器、1つの構造化有限浴、記録器、境界モードを含む有限 Hamiltonian 部分、$H_{\rm ext}$ は外部環境、$H_{\rm work}$ は設定変更、記録消去、再準備へ仕事を供給する自由度である。有限部分の収支は

```math
\dot E_{\rm fin}
=
J_{\rm in}
-
J_{\rm out}
+
P_{\rm ctrl}
```

であり、外部からの流入、外部への流出、制御仕事を区別して追跡する。

1試行の局所測定窓では

```math
\varepsilon_{\rm open}
=
\frac{
\sup_{0\leq t\leq T_{\rm meas}}
\left|
E_{\rm fin}(t)-E_{\rm fin}(0)
\right|
}{
E_{\rm ref}
}
\ll1
```

を要求する。これにより、有限 Hamiltonian 部分を測定窓内では近似的に閉じた補助モデルとして扱う。一方、外部へのごく弱い漏れと流入は常時存在し、準備、記録安定化、殻幅の維持、消去、再初期化では捨てない。

論文は2つの論理的に独立な問題を扱う。

1. 補助的な有限 Fourier–Gauss 型確率表示から、Nelson 型作用の形式をどこまで定量的に得られるか。
2. 1つの構造化有限浴が局所測定セクターと共通境界セクターを持つとき、境界作用殻の残余体積から Bell 型共同確率をどこまで導けるか。

第I部では、有限分解能の前後記録で条件づけた線形 Gauss 型経路法則を考える。時間刻み $h$ の繰り込み済み粗視化作用を $\mathcal A_{N,h}^{R,U}$ とすると、滑らかな有限次元パラメータ集合 $K$ 上で

```math
\left\|
\mathcal A_{N,h}^{R,U}
-
\mathcal A_{\rm GM}^{R,U}
\right\|_{C^1(K)}
\leq
C_K
\left(
\frac hT+
\frac{T^2}{Nh^2}
\right)
```

を得る。$h_N=TN^{-1/3}$ なら誤差は $O(N^{-1/3})$ である。極限作用は正の Gauss 型密度領域で Guerra--Morato 表示と Nelson 表示を持つ。

これは、定義した補助表示の作用値と有限次元パラメータ微分についての厳密結果である。弱開放ミクロモデルから一般の線形表示を導くこと、微視的運動が作用の停留点を選ぶこと、任意の Nelson 停留点を有限モデルで実現すること、Nelson 表示から量子力学全体を導くことは含まれない。

第II部は第I部の Nelson 極限から Bell 重みを導かない。構造化有限浴は、時間に依存しない正準基底で

```math
\mathcal B
\simeq
\mathcal B_A^{\rm loc}
\oplus
\mathcal B_B^{\rm loc}
\oplus
\mathcal B_\partial^{\rm glob}
\oplus
\mathcal B^{\rm dark}
```

と近似分解する。$\mathcal B_A^{\rm loc}$ と $\mathcal B_B^{\rm loc}$ は左右の反応座標を含む局所セクター、$\mathcal B_\partial^{\rm glob}$ は共通未来の境界作用を担うセクター、$\mathcal B^{\rm dark}$ は直接読み出さない暗モードである。これは複数の独立浴を置くことではなく、同じ浴の静的な明・暗モード分解である。

局所測定窓では、左右の交差応答を表す無次元量 $\varepsilon_{\rm loc}$ が十分小さいとする。従って局所記録は $O(\varepsilon_{\rm loc})$ の範囲で分離して扱える。左右が同じ有限浴に属することだけでは Bell 相関は生じず、共通未来の境界適合条件は残る。

局所記録後に共通未来へ運ばれる2つの実正準ベクトルを $u_A,u_B$ とする。静的な和・差基底の作用を

```math
I_+^{AB}
=
\frac14
\left\|
u_A+u_B
\right\|^2,
\qquad
I_-^{AB}
=
\frac14
\left\|
u_A-u_B
\right\|^2
```

と定める。固定総入力作用 $I_+^{AB}+I_-^{AB}=2I_0$ と位相同期した生成源の下で、

```math
\overline I_-^{AB}
=
I_0
\left[
1-ABV\cos\Delta_{ab}
\right],
```

```math
\overline I_+^{AB}
=
I_0
\left[
1+ABV\cos\Delta_{ab}
\right]
```

となる。余弦は量子振幅ではなく、2つの実2次元ベクトルの内積から生じる。

境界セクターには3つの複素正準モード

```math
a_+,
\qquad
a_s,
\qquad
a_r
```

を置き、それぞれの作用を $J_\nu=|a_\nu|^2$ とする。共通総作用殻は

```math
J_+ + J_s + J_r = C_0
```

である。結果セクターの境界適合条件は、和モードの作用を

```math
J_+
=
I_+^{AB}(a,b)
```

へ合わせる。同じ作用殻の中で残る2モードは

```math
J_s+J_r
=
C_0-I_+^{AB}.
```

固定 $J_+$ の下で残余2モードだけを $U(2)$ 等方にしても、異なる $J_+$ のファイバー間の相対質量は決まらない。必要なのは、3モード共通殻全体の測度である。

縮約された準備力学が概念的に

```math
\partial_t f
=
D_\partial
\Delta_{S^5}f
```

という非退化な $U(3)$ 等方拡散を持つなら、共通作用殻上の正規化 Liouville 測度が一意な定常分布になる。この縮約方程式の下での一意性は厳密結果である。有限 Hamiltonian 浴と常時の弱い外部交換から、この生成子を一様誤差付きで導くことは予想・未解決である。

共通作用殻上では、$J_+$ の周辺密度は

```math
p(J_+)
=
\frac{
2(C_0-J_+)
}{
C_0^2
},
\qquad
0\leq J_+\leq C_0
```

となる。従って、同じ分解能と同じ coarea Jacobian で結果セクターを切れば、その未規格化質量は

```math
W_{AB}
\propto
C_0-I_+^{AB}.
```

$C_0=J_*+2I_0$ と置くと、

```math
C_0-I_+^{AB}
=
J_*+I_-^{AB}.
```

4つの結果セクターの基準質量が左右の符号反転対称性により等しい場合、規格化された共同確率は

```math
P(A,B\mid a,b)
=
\frac14
\left[
1
-
V_{\rm eff}
AB\cos\Delta_{ab}
\right],
```

```math
V_{\rm eff}
=
\frac{I_0}{J_*+I_0}V
```

となる。$J_*=0$ かつ $V=1$ なら完全な余弦共同確率、CHSH 超過には $V_{\rm eff}>1/\sqrt2$ が必要である。

この導出は、結果ごとに終端関数を置かず、共通作用殻上の残余ファイバー体積を比較する。旧来の Bell 固有な終端統計原理 `[R]` と中央比較器は現行モデルから除く。ただし、共通未来を含む境界条件付けそのものを除いたわけではない。全境界正準位相空間の Liouville 測度を作用保存と境界適合条件で制限し、許容履歴空間へ押し出すという2境界構造は残る。

完全な微視履歴分布は、境界適合ファイバーが $a,b$ によって変わるため、一般に測定設定へ依存する。Bell の前提違反は測定設定独立性にあり、Bell の定理を否定しない。対称セクターでは一側周辺が $1/2$ となり非信号性が成り立つ。

主な未解決問題は、同じ構造化有限浴から3モード全殻の等方拡散を導くこと、一般測定器を構成すること、境界適合条件を含む1試行周期を外部交換まで含めて閉じること、偏った準備での非信号性、Born 則、Tsirelson 限界の選択、Wallstrom 問題である。
