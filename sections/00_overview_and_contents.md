@chapter: 概要
@title: 有限 Hamiltonian 部分を持つ弱開放系の縮約に向けた Nelson 作用極限と2境界 Bell 型統計
@status: 第I部の線形 Gauss 型作用収束は厳密結果である。第II部では `[R]` を仮定した体積計算は厳密結果だが、実験頻度への適用は予想・未解決であり、`[R]` に仮説依存する。

本論文は、有限自由度の古典 Hamiltonian 系を基礎としながら、実験装置を外部との微小なエネルギー交換を伴う弱開放系として扱う。対象部分と外部自由度を合わせた拡大系を

```math
H_{\rm all}
=
H_{\rm fin}(z)
+
H_{\rm ext}(y)
+
\varepsilon_{\rm ext}H_{\rm link}(z,y)
+
H_{\rm work}
```

と書く。$H_{\rm fin}$ は生成源、測定器、有限浴、比較器、時計を含む有限 Hamiltonian 部分、$H_{\rm ext}$ は外部環境、$H_{\rm work}$ は設定変更、パルス、再準備に仕事を供給する自由度である。有限部分の収支は

```math
\dot E_{\rm fin}
=
J_{\rm in}
-
J_{\rm out}
+
P_{\rm ctrl}
```

であり、外部からの流入、外部への流出、制御仕事を区別して追跡する。

1試行の測定窓では

```math
\varepsilon_{\rm open}
=
\frac{
\sup_{0\leq t\leq T}
\left|
E_{\rm fin}(t)-E_{\rm fin}(0)
\right|
}{
E_{\rm ref}
}
\ll1
```

を仮定し、有限 Hamiltonian 部分を近似的に閉じた補助モデルとして計算する。試行間には生成源の再準備、設定制御器への仕事供給、記録の安定化と消去、浴と作用分配系の再初期化が必要であり、この段階では開放性を捨てない。

論文は2つの独立な問題を扱う。

1. 補助的な有限 Fourier–Gauss 型確率表示から、Nelson 型作用の形式をどこまで定量的に得られるか。
2. 有限 Hamiltonian 装置部品と2境界統計原理を組み合わせたとき、Bell 型共同確率をどこまで計算でき、その物理的実現に何が未導出として残るか。

第I部では、有限分解能の前後記録で条件づけた線形 Gauss 型経路法則を考える。時間刻み $h$ の繰り込み済み粗視化作用を $\mathcal A_{N,h}^{R,U}$ とすると、滑らかな有限次元パラメータ集合 $K$ 上で

```math
\left\|
\mathcal A_{N,h}^{R,U}
-
\mathcal A_{\rm GM}^{R,U}
\right\|_{C^1(K)}
\leq
C_K
\left(
\frac hT+
\frac{T^2}{Nh^2}
\right)
```

を得る。$h_N=TN^{-1/3}$ なら誤差は $O(N^{-1/3})$ である。極限作用は正の Gauss 型密度領域で Guerra--Morato 表示と Nelson 表示を持つ。

これは、定義した補助表示の作用値と有限次元パラメータ微分についての厳密結果である。弱開放ミクロモデルから一般の線形表示を導くこと、微視的運動が作用の停留点を選ぶこと、任意の Nelson 停留点を有限モデルで実現すること、Nelson 表示から量子力学全体を導くことは含まれない。

第II部は第I部の Nelson 極限から Bell 重みを導かない。局所装置の明示部分は、既存の結果符号を固定指針へ写す最小結果符号化器であり、設定、到来変数、装置微視状態から結果を形成する一般測定相互作用は未構成である。

結果符号と設定位相を担う2つの実正準ベクトルを記録後の共通未来へ送ると、比較器の差動作用は

```math
\overline I_-^{AB}
=
I_0
\left[
1-ABV\cos\Delta_{ab}
\right]
```

となる。余弦は2つの実2次元ベクトルの内積から生じる。

比較器の未読変数には、1つのソフトモードと1つの残余作用モードを用いる。固定総作用殻

```math
E_\ell
=
\omega_\ell(J_s+J_0)
```

上の正規化 Liouville 測度では、ソフトモードエネルギー $h=\omega_\ell J_s$ は

```math
p(h)
=
\frac1{E_\ell},
\qquad
0\leq h\leq E_\ell
```

という一様周辺密度を持つ。これは閉鎖補助モデル内部の厳密結果である。多数の残余作用モードを持つ補助比較モデルでは累積分布が非線形となるため、純粋な余弦則には2モード条件が必要である。

4つの結果領域の基準質量は、準備 Hamiltonian、準備巨視領域、基準 Liouville 測度が左右の符号反転に不変であるという `[S]` の下でのみ等しくなる。

終端読出しには2つの内部時計の相対運動量 $\Pi_R$ を用いる。比較窓の閉鎖補助 Hamiltonian では、有限幅パルスの後に厳密に

```math
\Pi_R(T)
=
E_*+\kappa I_- -h
```

を得る。$\Pi_R(T)\geq0$ は、初期に選んだ時計向きの順序を終端まで保つ条件と一致する。

Hamilton 方程式は $\Pi_R(T)<0$ の軌道も許すため、時計相補性だけでは物理的な試行集団を選ばない。本論文では、基準初期密度 $\rho_S$ と全設定に共通な終端関数 $G_R$ から

```math
d\mu_R^{a,b}(z_i)
=
\frac{
\rho_S(z_i)
G_R\!\left(\Phi_{a,b}^{T}z_i\right)
}{
Z_{a,b}
}
d\Gamma_i
```

を定める追加原理を `[R]` と呼ぶ。

適用範囲

```math
0
\leq
E_*+\kappa\overline I_-^{AB}
\leq
E_\ell
```

と `[H,P,S,M,R]` の下では、位相体積積分から

```math
P_R(A,B\mid a,b)
=
\frac14
\left[
1-ABV_{\rm eff}\cos\Delta_{ab}
\right],
```

```math
V_{\rm eff}
=
\frac{\kappa I_0}{E_*+\kappa I_0}V
```

を厳密に得る。ただし、ここでは次の3つを分ける。

- `[R]` を仮定した後の終端整合体積と共同確率の計算は厳密結果であり、`[R]` に仮説依存する。
- 実験の無条件試行頻度がこの共同法則に従うことは予想・未解決であり、`[R]` に仮説依存する。
- 弱開放な準備・測定・記録・再初期化周期から `[R]` を導くことは中心的な予想・未解決である。

規格化因子は測定設定に依存せず、`[S]` の対称集団では非信号性が成り立つ。一方、完全な微視状態の事後分布は一般に測定設定へ依存する。Bell の前提違反は測定設定独立性にあり、Bell の定理を否定しない。

弱開放ミクロモデルからの線形表示、一般測定器、`[R]` の物理的生成、任意準備での非信号性、Born 則、Tsirelson 限界の一般原理からの選択、Wallstrom 問題は未解決である。不採用モデルの詳細と本文を実質的に支えない補助計算は論文へ収録せず、研究メモとして管理する。
