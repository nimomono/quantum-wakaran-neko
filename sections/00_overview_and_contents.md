@title: 概要

本論文は、有限自由度の古典 Hamiltonian 系を基礎とし、対象部分を外部との微小なエネルギー交換を伴う弱開放系として扱う。目的は、量子力学をミクロ構成の入力に置かず、量子力学に特徴的な力学と確率構造が有効理論として現れ得る範囲を明らかにすることである。

各試行で実在するものを、粒子、有限個の正準位相担体、源、浴、時計、測定器、比較器、記録装置の自由度に限定する。物理空間全体に独立した連続2成分誘導場は置かない。実正準対 $(Q_i,P_i)$ から、固定作用尺度 $\mathcal J_0>0$ を用いて

```math
b_i
=
\frac{Q_i+iP_i}{\sqrt{2\mathcal J_0}}
```

を定める。複素数は量子的公理ではなく、実2次元正準平面の表示である。共通調製条件 $\mathcal P$ に属する試行集団の相関行列を

```math
C(t)
=
\mathbb E
\left[
b^\omega(t)
\left(b^\omega(t)\right)^\dagger
\mid
\mathcal P
\right]
```

とする。$C$ は正半定値 Hermitian 行列であり、観測者の知識でなく、調製装置、ミクロ Hamiltonian、初期集団、境界条件によって定まる客観的な集団状態である。ただし、各試行で $C$ という物質が存在するとは解釈しない。

第1の主結果は、有限2次 Hamiltonian

```math
H_{\rm ph}
=
b^\dagger h_L(t)b,
\qquad
h_L(t)=h_L(t)^\dagger
```

から、各試行の振幅方程式と相関行列方程式

```math
i\mathcal J_0\dot b
=
h_Lb,
\qquad
i\mathcal J_0\dot C
=
\left[
h_L,C
\right]
```

が厳密に従うことである。閉鎖線形発展では $C$ の跡、固有値、階数、純度が保存される。従って、混合集団が観測中に自発的に階数1へ純化することはない。共通源と有限正準準備回路が階数1相関

```math
C
=
\Lambda
\chi\chi^\dagger,
\qquad
\chi^\dagger\chi=1
```

を準備した場合に限り、共通位相を除いて

```math
i\mathcal J_0\dot\chi
=
h_L\chi
```

を得る。階数1は、ほとんど全ての試行で $b^\omega=c^\omega\chi$ が成立することと同値であり、弱い統計条件ではない。本稿の改善点は、これを共通源から明示的に準備できることと、独立した物質場と粒子分布の同期を外せることにある。

空間グラフ上では、辺結合から離散 Laplacian、局所周波数から外部ポテンシャルを作る。これは局所的で疎な古典振動子網を与える一方、係数 $\mathcal J_0^2/(2m)$ をより原始的な古典機構から強制するものではない。古典振動子による Schrödinger 型方程式の表示自体は既知であり、本稿の新規性とはしない。中心課題は、相関行列、共通源、位置入口作用殻、Bell 境界測度を同じ有限 Hamiltonian 周期へ接続することにある。

階数1因子は分岐、位相蓄積、再結合によって干渉と節を生じる。最大固有値以外の相対重量を $\varepsilon_{\rm rank}$ とすると、理想的な節に残る確率は $\varepsilon_{\rm rank}$ 以下に抑えられる。本稿はこの検出強度を導くが、粒子の連続軌道または統計流に沿う運動則を導かない。

第2の主結果は、排他的な位置入口チャンネルに置いた2モード作用殻である。セル体積を振幅へ吸収して

```math
p_i
=
\frac{C_{ii}}{\operatorname{tr}C}
```

を規格化セル重みとする。階数1なら $p_i=|\chi_i|^2$ であり、連続密度表示 $\psi_i=\chi_i/\sqrt{\Delta V}$ では $p_i=|\psi_i|^2\Delta V$ となる。固定振幅の共通源 $b^\omega=e^{i\beta^\omega}\chi$ では、各試行で局所位相担体作用が $I_i^\omega=\mathcal J_0p_i$ となる。この単一試行作用から入口作用 $A_i=A_{\rm tot}p_i$ を局所的に転送し、全入口で流束因子が共通なら、2モード殻容量

```math
\Omega_2(A_i)
=
\left(2\pi\right)^2A_i
```

により $P_i=p_i$ を入口通過頻度として得る。これは位置入口標本化則であり、任意基底に対する一般 Born 則ではない。全位置を同時に直積化せず、単一結果を形成する排他的な全局所転送 Hamiltonian は未完成である。

第3の主結果は、左右の有限位相担体モード、反対称源、局所分析器、共通未来比較器、2モード境界作用殻を統合した条件付き Bell 統計である。Bell 側の左右交差相関を $\Xi$ と書き、単粒子側の正半定値相関行列 $C$ と区別する。反対称源と左右の局所回転から余弦枝作用を得る。比較器はその枝作用を比較2モードへ転送するが、Hamiltonian 読み出しと殻内混合だけでは結果セクター間の確率質量を作らない。4結果セクターで共通の境界密度、時計流束、余面積因子、付随自由度の体積、解多重度を仮定したときに限り、

```math
P
\left(
A,B
\mid
a,b
\right)
=
\frac14
\left[
1
-
AB\cos\Delta_{ab}
\right]
```

を得る。理想対称条件では非信号周辺と CHSH 値 $2\sqrt2$ が従う。完全履歴集団は設定に依存するため、Bell の前提違反は測定設定独立性にある。Bell の定理を否定せず、後の比較器が過去の局所記録を変更する機構も導入しない。

本文は6章から成る。第1章で模型と主張の範囲、第2章で有限正準位相担体、共通源、階数1相関、第3章で相関行列力学、空間グラフ、干渉と節、第4章で位置入口作用殻、第5章で Bell 交差相関と共通境界測度、第6章で誤差、反証条件、未解決問題を扱う。正準計算、階数1の同値条件、作用殻積分、装置 Hamiltonian は付録へ置く。

最大の未解決問題は4つある。第1に、局所古典結合から Schrödinger 型係数を設計値でなく必然的に得ること。第2に、全位置に広がる位相担体作用を単一試行の排他的な位置入口へ局所的に転送すること。第3に、統計相関から粒子の連続運動を導くこと。第4に、Bell 共通境界測度を事後選別なしの反復可能な測定周期として実現することである。
