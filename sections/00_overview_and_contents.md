@title: 概要

本論文は、有限自由度の古典Hamiltonian系を土台とし、量子力学に特徴的な可逆力学、測定操作、結合ゲート、空間伝播、粒子位置、Bell型統計が、どの仮定と誤差の下で現れ得るかを検証する。Q1、Q2、Q3は有限モード正準担体を共通の有効代数とするが、ミクロ実装と装置周期は役割別に分ける。1つの統一M0または同一ハードウェアを構成したとは主張しない。

| 系列 | 有効担体 | ミクロ・装置モデル | 中心結果と制限 |
|---|---|---|---|
| Q1 | 2モード正準担体 | M38、M35 | Bloch球、任意の $SU(2)$、Rabi振動、逐次測定、永久記録、弱開放reset、固定有限Zeno周期。無反応込み |
| Q2 | 4モード正準担体 | M39、M41 | 操作誘導テンソル積、CNOT共同入力--出力統計、2測定端のsinglet余弦統計。固定有限ベンチマーク、準備先行、非空間分離 |
| Q3 | 空間セル有限モード担体 | M37、M42 | 位置ばね網からのSchrödinger型位相担体、局在1粒子トークン、Born型等変性、節一様有限率近似、固定時刻局所検出。弱結合・有限時間・初期作用比準備 |

M38では、固定作用2モード担体を共通位相に不変な操作・測定代数について縮約し、Bloch球とPoisson代数を得る。同じ担体上の局所位相回転と $QQ+PP$ 交換は任意の $SU(2)$ を生成し、自律駆動はRabi振動を厳密に与える。M35型の滑らかな作用選択器を接続すると、任意のBloch軸についてBorn型重み、排他的安全結果、測定後固有状態、同軸反復、異軸逐次分布が得られる。比較境界は正式な無反応結果とし、その質量を任意に小さくする。

外部記録セルへの正準剪断、内部逆計算、外部空セルとの正準交換を加えると、記録を残したまま能動装置を次周期の準備集合へ戻せる。さらに1個の測定コアと有限長の循環メモリー／resetセル列により、継続Rabi駆動下で固定有限回の反復測定を行う。短時間域の有効反転率は

```math
\Gamma_{\rm Z}(\tau)
=
\frac{\Omega^2}{4}\tau
+
O(\tau^3)
```

であり、理想履歴分布からの全変動距離と周期帰還誤差を別々に任意精度へ抑えられる。以上からQ1-1からQ1-4を各限定範囲で達成と判定する。

M35は一般有限 $L$ の固定純粋準備と固定基底について、隣接2モード回路、作用読出し、滑らかな比較、測定後状態、内部逆計算を1本の有限自律Hamiltonian周期へまとめる。長期結果分布と理想Born型分布の全変動距離は比較幅と角切断幅で制御できる。ただし一般有限 $L$ の複数段測定、永久外部記録、弱開放reset、長距離時計配線は未完成である。

M39は単一4モード担体上に2つの可換な局所操作代数を実装し、操作誘導テンソル積を定める。下側反対称差モードへの射影を $\Pi_{\rm CX}$ とすると、面積 $\pi$ の有限時計窓は

```math
e^{-i\pi\Pi_{\rm CX}}
=
U_{\rm CX}
```

となる。固定された有限個の入力、積出力基底、入力頻度について、この流れをM35の4モード読出し周期へ挿入する。入力ラベル、2ビット出力、無反応からなる共同分布をCNOT目標分布へ任意精度で近づけられるため、Q2-1を達成と判定する。非因子化生成と局所操作だけへの分解不能性は内部診断であり、合格条件ではない。

M41が受け取るのは、Q2-1を構成するM39の読出し前4モード出力状態 $c$ である。M41はこれをA設定基底で階数2ブロックへ分け、A中央枝選択で結果 $A$ を形成する。安全枝ではA担体を対応する局所状態へ準備し、選択済みBブロックだけをB担体へ正準SWAPする。中央結合停止後、A局所確認測定は同じ $A$ を記録し、B局所測定が条件付き結果 $B$ を作る。singlet型の理想共同分布は

```math
P(A,B\mid x,y)
=
\frac14
\left[
1-AB\cos(x-y)
\right]
```

であり、非信号周辺、標準設定のCHSH値 $2\sqrt2$、平面内2出力族の上界 $2\sqrt2$ が従う。設定前基準測度は積Haar測度だが、設定生成後の前向き準備写像により測定開始面の完全状態がA設定へ依存する。従って測定段階の局所因子化は保たれる一方、Bellの測定設定独立性は成立しない。

Q2-2は、M39の読出し前4モード出力状態を利用して2つの物理的測定端で同じ共同統計を得る「操作的接続」と読む限り、固定有限設定、準備先行、非空間分離、singlet型、無反応込み、制御された任意精度の範囲で条件付き達成と判定する。非因子化4モード状態全体を保存したまま設定選択前に2つの独立物理部分系へ分配する「状態的接続」は未達である。

Q3では、M37の通常の位置結合を持つ有限実振動子網から局所回転包絡を作る。局所包絡は反回転項を含む厳密式を満たし、行列平方根を使う正常モード包絡は厳密だが一般に非局所である。弱結合量

```math
\eta
=
\frac{2\|h_L\|}{\mathcal J_0\omega_0}
<1
```

の下で、自然時間における局所包絡と目標Schrödinger型解の差を $O(\eta)$ で抑える。Q3-1は、有限自由度、実対称時間非依存演算子、弱結合・有限時間の範囲で達成と判定する。

M42はM37を位相担体サブモデルとして含み、独立の局在正準変数 $(Z,P_Z)$ と粗視化セル位置 $X=X(Z)$ を粒子トークンとして追加する。理想有限グラフでは標準辺流を再現する最小跳躍率をモデル定義として採用し、初期分布 $P(X_0=i)=|b_i(0)|^2$ を作用比選択器で準備すれば、$P(X_t=i)=|b_i(t)|^2$ が等変に保たれる。等変性だけで初期Born型分布を生成したとはしない。最小率の非一意性、節での特異性、一様有界率による有限時間厳密節追跡のno-goを明記する。

有限装置では正部分と分母を滑らかに正則化する。任意の有限時間と精度について、節を除外せず、正則化、M37包絡、時間離散化、局所選択、辺輸送、時計、検出の各誤差を全変動距離で抑える有限Hamiltonian構成を選べる。Poincaré断面ではトークンは1セル、輸送中は1辺チャネル上にあり、固定時刻の局所検出器はその位置を読む。ただし連続空間極限、多粒子、粒子のエネルギー・質量・電荷、初回到達を含む2重スリット完全装置は未達である。

本文は5部11章から成る。第1部は問題設定と共通言語、第2部はM38とM35によるQ1、第3部はM39とM41によるQ2、第4部はM37とM42によるQ3、第5部は誤差、資源、反証条件、未完成目標、結論を扱う。長い代数計算、正準変換、誤差証明、資源計数は本文順に並べた付録A--Hへ置く。
