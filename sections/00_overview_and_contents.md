@title: 概要

本論文は、有限自由度の古典Hamiltonian系を土台とし、量子力学に特徴的な可逆力学、測定操作、結合ゲート、空間伝播、位置、Bell型統計が、どの仮定と誤差の下で現れ得るかを検証する。改訂の中心は、Q1、Q2、Q3を同じ**有限配置グラフ上の複素振幅場-実現配置モデル**として定義した点にある。

有限配置集合を $\Omega$、複素振幅場を $b\in\mathbb C^{|\Omega|}$、各試行で1つだけ実現している配置を $X\in\Omega$ とする。Hermitianグラフプログラム $h(t)$ は

```math
i\mathcal J_0\dot b=h(t)b
```

を生成し、その局所辺流から実現配置の最小遷移率を定める。$P(X=z)=|b_z|^2$ は等変に保たれる。鋭い基準状態 $b=e_{z_0}$、$X=z_0$ から同じ準備回路を両者へ作用させれば、任意の固定準備後にこの分布を得るため、Q1とQ2ではBorn型初期分布を開始面へ別に書き込まない。

| 系列 | 配置集合 | 主なモデル | 中心結果と制限 |
|---|---|---|---|
| Q1 | $\{0,1\}$ | M38、M35、M42共通則 | Bloch球、任意の $SU(2)$、Rabi振動、分析器後の $X$ 読出し、逐次測定、永久記録、固定有限Zeno周期。無反応込み |
| Q2 | $\{00,01,10,11\}$、$X=(X_A,X_B)$ | M39、M41、M42共通則 | 操作誘導テンソル積、CNOT、共同実現配置による入力--出力統計、2端のsinglet余弦統計。固定有限ベンチマーク、準備先行、非空間分離 |
| Q3 | 有限空間グラフ | M37、M42 | 位置ばね網からのSchrödinger型複素振幅場、空間実現配置、等変性、節一様有限率近似、固定時刻局所検出。弱結合・有限時間 |

無向辺 $e=\{u,v\}$ の差モード射影を

```math
\Pi_e
=
\frac12
(|u\rangle-|v\rangle)
(\langle u|-\langle v|)
```

とすると、共通辺生成子は

```math
G_e
=
\mathcal J_0b^\dagger\Pi_eb
=
\frac14
\left[(Q_u-Q_v)^2+(P_u-P_v)^2\right].
```

Q1の交換、Q2のCNOT、Q3のLaplacian伝播は、頂点作用項と同じ辺生成子の異なる有限プログラムである。共通なのは有効モデルであり、設計済みの $QQ+PP$ 交換とM37の位置ばねによる近似実装は区別する。全系列を同じ物理部品、同じ時計周期、同じ反復母測度へまとめたM0は未完成である。

Q1の測定では、基底分析器を複素振幅場と実現配置へ同じプログラムで作用させ、出口の $X$ を読む。検出後は $X$ を制御ラッチとして結果を記録し、場を対応固有状態へ条件付き準備する。この構成は任意軸測定、同軸反復、異軸逐次分布、永久記録、帰還、固定有限Zeno周期を与える。M35の作用区間、滑らかな比較、更新角は、任意初期場に対する実現配置準備、局所更新、条件付き場準備、分布検算を有限Hamiltonian化する補助機構であり、$X$ と別の測定結果を生成しない。

Q2では単一4頂点複素振幅場上に2つの可換な局所操作代数を定める。$10\leftrightarrow11$ の差モード射影について

```math
e^{-i\pi\Pi_{\rm CX}}
=
U_{\rm CX}
```

である。同じ準備、CNOT、積分析器プログラムを共同実現配置へ作用させると、固定有限入力集合の2ビット入力--出力分布を目標CNOT分布へ任意精度で近づけられる。さらに同じ1辺生成子を4振動子のM37型位置ばね網で近似でき、その誤差を弱結合量の明示関数で抑える。

M41では、鋭い共同配置からsinglet型場と共同実現配置を設定と独立に準備する。その後、A設定分析器を中央の場と $X$ へ作用させて $X_A=A$ を読み、A端場と条件付きB端場、B配置を準備する。中央結合停止後に局所分析器を作用させ、B端で $X_B=B$ を読む。理想共同分布は

```math
P(A,B\mid x,y)
=
\frac14
\left[1-AB\cos(x-y)\right]
```

であり、非信号周辺と標準CHSH値 $2\sqrt2$ が従う。局所測定Hamiltonianは可換だが、A設定は中央分析器と条件付き2端準備に既に使われるため、測定開始面の完全状態は設定に依存し、Bellの測定設定独立性は成立しない。Q2-2は操作的接続、準備先行、非空間分離という範囲で条件付き達成である。

Q3ではM37の位置結合振動子網から局所回転包絡を作る。弱結合量 $\eta<1$ の下で、有限時間の局所包絡を目標Schrödinger型複素振幅場へ $O(\eta)$ で近づける。M42の共通実現配置則をこの空間グラフへ特殊化し、節を含む理想最小率を滑らかに正則化する。有限時間と精度を固定すれば、正則化、離散化、局所選択、1辺輸送、時計、検出の誤差を全変動距離で抑える有限Hamiltonian構成を選べる。固定時刻位置検出は得ており、Q3-4とQ3-5ではこれを単一障壁または有限2重スリットの準備、伝播、位相制御、完全結果集合へ統合する。Q3-2の限定的な位相量子化回答、Q3-3の弱開放デコヒーレンス、Q3-4とQ3-5の具体的装置統合はいずれも未達である。初回到達、吸収、時間積分流束は未導出だが、Q3-4とQ3-5の固定達成条件より強い拡張として分ける。連続空間極限、多粒子、質量・電荷・全エネルギーも未達である。

本文は5部11章から成る。第1部は共通モデル、第2部はQ1、第3部はQ2、第4部はQ3、第5部は誤差、資源、反証条件、未完成目標、結論を扱う。長い代数計算、正準変換、誤差証明、資源計数は本文順に並べた付録A--Hへ置く。
