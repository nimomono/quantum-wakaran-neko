@chapter: 概要
@title: 有限 Hamiltonian 部分を持つ弱開放系の縮約に向けた Nelson 作用極限と2境界 Bell 型統計
@status: 現行モデルは有限 Hamiltonian 部分を持つ弱開放系である。第I部の線形 Gauss 型作用収束は厳密結果、第II部の物理的 Bell 予測は `[R]` に依存する仮説依存結果である。

本論文は、有限自由度の古典 Hamiltonian 系を基礎としながら、実験装置を外部との微小なエネルギー交換を伴う弱開放系として扱う。対象部分と外部自由度を合わせた拡大系を

```math
H_{\rm all}
=
H_{\rm fin}(z)
+
H_{\rm ext}(y)
+
\varepsilon_{\rm ext}H_{\rm link}(z,y)
+
H_{\rm work}
```

と書く。$H_{\rm fin}$ は生成源、測定器、有限浴、比較器、時計を含む有限 Hamiltonian 部分、$H_{\rm ext}$ は外部環境、$H_{\rm work}$ は設定変更、パルス、再準備に仕事を供給する自由度である。拡大系を Hamiltonian として記述できても、$z$ だけを見ればエネルギーは保存されず、

```math
\dot E_{\rm fin}
=
J_{\rm in}
-
J_{\rm out}
+
P_{\rm ctrl}
```

となる。$J_{\rm in}$、$J_{\rm out}$ は外部からの流入と外部への流出、$P_{\rm ctrl}$ は仕事貯蔵系からの制御仕事である。

1試行の測定窓では、

```math
\varepsilon_{\rm open}
=
\frac{
\sup_{0\leq t\leq T}
\left|
E_{\rm fin}(t)-E_{\rm fin}(0)
\right|
}{
E_{\rm ref}
}
\ll1
```

を仮定し、有限 Hamiltonian 部分を近似的に閉じた補助モデルとして計算する。試行間には生成源の再準備、設定制御器への仕事供給、記録の安定化と消去、浴と作用分配系の再初期化が必要であり、この段階では開放性を捨てない。したがって、閉じた有限系は現行モデルそのものではなく、1試行内の中心機構を分離する補助モデルである。

論文は2つの独立な問題を扱う。

1. 補助的な有限 Fourier–Gauss 型確率表示から、Nelson 型作用の形式をどこまで定量的に得られるか。
2. 有限 Hamiltonian 装置部品と2境界統計原理を組み合わせたとき、Bell 型共同確率をどこまで明示的に計算でき、その物理的実現には何が未導出として残るか。

第I部では、有限分解能の前後記録で条件づけた線形 Gauss 型経路法則を考える。時間刻み $h$ の繰り込み済み粗視化作用を $\mathcal A_{N,h}^{R,U}$ とすると、滑らかな有限次元パラメータ集合 $K$ 上で

```math
\left\|
\mathcal A_{N,h}^{R,U}
-
\mathcal A_{\rm GM}^{R,U}
\right\|_{C^1(K)}
\leq
C_K
\left(
\frac hT+
\frac{T^2}{Nh^2}
\right)
```

を得る。$h_N=TN^{-1/3}$ なら誤差は $O(N^{-1/3})$ である。極限作用は正の Gauss 型密度領域で Guerra--Morato 表示と Nelson 表示を持つ。

これは、定義した線形 Gauss 型確率表示の作用値と有限次元パラメータ微分についての厳密結果である。次は別の主張であり、本論文では未解決である。

- 弱開放なミクロモデルの縮約から、定理で用いる一般の時間依存線形確率表示を導くこと。
- 微視的 Hamiltonian 運動が粗視化作用の停留点を選ぶこと。
- 任意の Nelson 停留点を有限モデルの停留点列で実現すること。
- Nelson 作用形式から量子力学全体を導くこと。

第II部は第I部の Nelson 極限から Bell 重みを導かない。局所装置の明示部分は、既存の結果符号を固定指針へ写す最小結果符号化器である。設定、到来変数、装置微視状態から結果を形成する一般測定相互作用、増幅、安定記録、消去、再初期化までを統合した測定器は未構成である。

結果符号と設定位相を担う2つの実正準ベクトルを記録後の共通未来へ送ると、比較器の差動作用は

```math
\overline I_-^{AB}
=
I_0
\left[
1-ABV\cos\Delta_{ab}
\right]
```

となる。余弦は確率公理ではなく、2つの実2次元ベクトルの内積から生じる。

比較器の未読変数には、1つのソフトモードと1つの残余作用モードを用いる。固定総作用殻

```math
E_\ell
=
\omega_\ell(J_s+J_0)
```

上の正規化 Liouville 測度では、ソフトモードのエネルギー $h=\omega_\ell J_s$ は

```math
p(h)
=
\frac1{E_\ell},
\qquad
0\leq h\leq E_\ell
```

という一様周辺密度を持つ。これは固定総作用殻を準備した補助モデル内部の厳密結果である。弱開放な現行モデルでは、比較窓中の相対的な総作用変化

```math
\varepsilon_\ell
=
\frac{
\sup_t
\left|
E_\ell(t)-E_\ell(0)
\right|
}{
E_\ell(0)
}
```

が小さく、しきい値が殻の両端から離れているときに、累積重みの補正を $O(\varepsilon_\ell)$ と評価する。漏れが結果または測定設定と相関すれば、この補正は可視度の一様な低下だけでは済まず、高次調波または非信号性残差を生み得る。

4つの結果領域の基準質量は、固定総作用殻の幾何だけでは決まらない。準備 Hamiltonian、準備巨視領域、基準 Liouville 測度が左右の符号反転に不変であるという `[S]` の下でのみ、

```math
w_{++}
=
w_{+-}
=
w_{-+}
=
w_{--}
=
\frac14
```

が従う。

終端読出しには2つの内部時計の相対運動量 $\Pi_R$ を用いる。比較窓の閉鎖補助 Hamiltonian では、有限幅パルスの後に厳密に

```math
\Pi_R(T)
=
E_*+\kappa I_- -h
```

を得る。従って

```math
\Pi_R(T)\geq0
```

は、初期に選んだ時計向きの順序を終端まで保つ条件と一致する。

一方、Hamilton 方程式は $\Pi_R(T)<0$ の軌道も許す。相補的時計が与えるのは終端半空間の力学的意味であり、その半空間に入る履歴だけを物理的試行として数える原理ではない。本論文では、基準初期密度 $\rho_S$ と全設定に共通な終端関数 $G_R$ から

```math
d\mu_R^{a,b}(z_i)
=
\frac{
\rho_S(z_i)
G_R\!\left(\Phi_{a,b}^{T}z_i\right)
}{
Z_{a,b}
}
d\Gamma_i
```

を定める追加原理を `[R]` と呼ぶ。

適用範囲

```math
0
\leq
E_*+\kappa\overline I_-^{AB}
\leq
E_\ell
```

と `[H,P,S,M,R]` の下では、位相体積積分から厳密に

```math
P_R(A,B\mid a,b)
=
\frac14
\left[
1-ABV_{\rm eff}\cos\Delta_{ab}
\right],
```

```math
V_{\rm eff}
=
\frac{\kappa I_0}{E_*+\kappa I_0}V
```

を得る。ここで確立度を分ける必要がある。

- `[R]` を仮定した後の終端整合体積と共同確率の計算は厳密結果である。
- 実験の無条件試行頻度が `[R]` に従うという物理的主張は仮説依存結果である。
- `[R]` が弱開放な準備・測定・記録・再初期化周期から生じることは予想・未解決である。

規格化因子は測定設定に依存せず、`[S]` の対称集団では非信号性が成り立つ。ただし、完全な微視状態の事後分布は一般に測定設定へ依存する。Bell の前提違反は測定設定独立性に現れ、Bell の定理を否定しない。

現在のモデルと結果の位置づけをまとめる。

| 対象 | 運用状態または確立度 | 内容 |
|---|---|---|
| 有限 Hamiltonian 部分を持つ弱開放系 | 現行モデル | 流入、流出、制御仕事、記録、消去、再初期化を含む |
| 1試行内の閉鎖有限系 | 補助モデル | $\varepsilon_{\rm open}\ll1$ の測定窓で用いる |
| 線形 Gauss 型確率表示 | 補助モデル | 第I部の厳密な作用収束定理の対象 |
| 最小結果符号化器 | 補助モデル | 一般測定器ではない |
| 作用形式の $C^1$ 収束 | 厳密結果 | 指定した線形 Gauss 型族で成立 |
| 固定殻の一様周辺と比較読出し | 厳密結果 | 閉鎖補助モデルと明示条件の下で成立 |
| Bell 型共同確率の代数計算 | 厳密結果 | `[R]` を含む仮定の下で成立 |
| Bell 型共同確率の物理的試行予測 | 仮説依存結果 | `[R]` と未構成の試行周期に依存 |
| 弱開放系から `[R]` を得ること | 予想・未解決 | 現在の中心課題 |
| 順時間的共有浴、滞在時間、多数の残余作用モード | 不採用モデル | 純粋な Bell 余弦重みの生成に失敗 |

Born 則、Tsirelson 限界の一般原理からの選択、Wallstrom 問題、任意準備での非信号性も未導出である。本文は、物理的入力、相互作用、保存量、エネルギー交換、近似、結果の確立度を中心に述べる。長い正準計算、収束評価、2境界照合、測定設定依存度、試行数監査は付録と `VALIDATION.md` に分けて置く。
