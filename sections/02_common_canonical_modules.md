## 2.1 共通モジュールと統一M0の違い

Q1、Q2、Q3は、有限個の実正準対からなる線形担体を共通の有効代数として使う。M35、M38、M39、M41、M42は、2次Hamiltonian流、滑らかな時計窓、作用読出し、選択、履歴保存も再利用する。ただし、信号モード数、ミクロ実装、準備集合、測定プログラム、外部セル、Poincaré断面はモデルごとに異なる。以下は記法と局所部品の一覧であって、全てを1周期へ合成したM0の構成ではない。

| 共通部品 | 主な利用先 | 担当する詳細 |
|---|---|---|
| 有限モード正準担体 | M26、M35、M38、M39、M41、M42 | 第2章から第9章 |
| 局所位相回転と $QQ+PP$ 交換 | M38、M35、M39 | 付録B、付録D、付録E |
| 作用区間、滑らかな比較、無反応 | M38、M35、M39、M41、M42 | 付録A、付録B、付録D、付録F、付録H |
| 時計窓、外部記録、逆計算、reset | M38、M41、M42 | 付録B、付録C、付録F、付録H |
| 無理数回転と積トーラス平行移動 | M35、M38、M39、M41、M42 | 付録Aから付録H |

M37は通常の位置ばね網からQ3の有限モード担体を弱結合・有限時間で近似する。Q1とQ2の設計済み $QQ+PP$ 交換を同じミクロハードウェアから導いたものではない。M42はM37を担体サブモデルとして使うが、独立の粒子トークンと更新装置を追加する。

## 2.2 実正準対と複素モード

各信号モードに実正準対 $(Q_j,P_j)$ を置き、固定作用尺度 $\mathcal J_0>0$ に対して

```math
b_j
=
\frac{Q_j+iP_j}{\sqrt{2\mathcal J_0}}
```

と書く。全作用は $\mathcal J_0 b^\dagger b$ であり、Hermitian行列 $K$ に対応する2次Hamiltonian $\mathcal J_0 b^\dagger Kb$ は $i\dot b=Kb$ を与える。この対応は有限次元Schrödinger方程式の実正準表示だが、それだけで測定統計、記録、reset、空間ミクロ起源を導いたことにはならない。

## 2.3 有限モード担体の3つの利用法

一般の有限 $L$ モード担体を、Q1では $L=2$、Q2では $L=4$、Q3では $L$ を空間セル数として使う。共通位相 $b\mapsto e^{i\gamma}b$ に不変な観測量を使う場合、物理的な方向変数は射影空間上にある。M38ではこの縮約がBloch球を、M39では4モード担体上の論理分解を与える。Q3ではモード添字をグラフ頂点として読み、M37が目標担体を近似する。固定作用面と高階数集団の区別は付録Aで整理する。

<!-- theorem-start:proposition -->
**命題（有限モード担体のQ1--Q2--Q3共通構造）**
実正準対から作る $b\in\mathbb C^L$ とHermitian行列 $h$ に対し、$H_h=b^\dagger hb$ は

```math
i\mathcal J_0\dot b
=
hb
```

を与える。実対称なグラフLaplacian型 $h$ の各辺項は、実正準座標で

```math
g_{ij}|b_i-b_j|^2
=
\frac{g_{ij}}{2\mathcal J_0}
\left[
(Q_i-Q_j)^2
+
(P_i-P_j)^2
\right]
```

となる。従ってM39の差モード射影とQ3のLaplacian辺は同じ有限モード代数の要素である。
<!-- theorem-end:proposition -->

これはR112である。共通なのは有効代数であり、物理的実装は同じでない。M39は位置・運動量の差を含む設計済み生成子を厳密に使う。M37は位置ばねだけから同じ目標 $h_L$ を弱結合近似として得る。

## 2.4 局所位相回転、交換、Laplacian辺

単一モード作用 $[(Q_j)^2+(P_j)^2]/2$ は局所位相回転を、$Q_jQ_k+P_jP_k$ は2モード交換を生成する。有限列はM38の $SU(2)$、M35の任意有限基底回路、M39の局所操作代数に使う。差モード2次形式を空間グラフの全辺へ足すとLaplacian項になる。ただし交換項と差モード項は運動量間結合を含むため、M37の位置ばね網と同じ物理部品だとは主張しない。

## 2.5 作用読出し、滑らかな比較、無反応

モード作用を正準レジスターへ読み、選択器角から作る閾値と比較する。滑らかな有限Hamiltonian写像で全入力を厳密な離散値へ写すことはできないため、比較境界を正式な無反応結果 $\varnothing$ とする。結果集合へ無反応を含め、無反応試行を除いて分布を再規格化しない。境界質量は比較幅と角切断幅で任意に小さくできる。

M42ではこの機構を位置結果の直接標本化ではなく、待機または隣接辺を選ぶ局所更新へ使う。可変な現在セル作用を全区間長とするため、条件付き率の除算器は不要である。有限履歴にはM38の有限選択器トーラス、可変全作用にはM41の作用比選択を再利用する。初期トークンを全セル作用比に従って準備する大域過程と、その後の局所更新は区別する。

## 2.6 時計窓と有限自律プログラム

時計正準対 $(\tau,P_\tau)$ と互いに重ならない滑らかな窓 $g_r(\tau)$ を使い、有限個の生成子を指定順に起動する。各担当章の「自律Hamiltonian」は、この有限時計プログラムを含む意味で使う。窓幅を短くする場合は最大結合強度と動作時間の交換関係を残し、無限帯域を暗黙に仮定しない。

## 2.7 外部記録、逆計算、reset

理想空記録セルへの正準剪断は、セルの共役運動量を0に置くと能動部へ反作用せず、結果を残したまま内部写像を逆実行できる。有限残差は外部空セルとの正準SWAPで交換する。固定有限回は有限閉鎖系へ埋め込めるが、無期限運転は空セル流入と使用済みセル流出を持つ弱開放系として扱う。結果履歴を含む全系の同一点帰還は要求しない。

## 2.8 一意エルゴード性と非独立同分布性

選択器角の無理数回転、または有限次元トーラス上の有理独立な平行移動は、Haar測度に関して一意エルゴード的である。従って区間体積から長期頻度を得られる。ただし回転は混合的でなく、結果列の独立同分布性、二項分布型有限標本揺らぎ、中心極限定理は従わない。各モデルは長期頻度と有限標本統計を区別して判定する。
