@status: 現行模型の誤差を、源準備、階数欠陥、相関閉包、局所空間結合、干渉、位置作用転送、入口流束、Bell 境界測度、完全周期に分ける。旧2成分誘導場に固有の動径欠陥、位相接続誤差、粒子・場同期誤差は現行誤差から外す。

## 6.1 誤差の分離

現行模型の主要誤差を次のように分ける。

| 記号 | 内容 | 中心結論への影響 |
|---|---|---|
| $\varepsilon_{\rm src}$ | 共通源の相対振幅・相対位相準備誤差 | 初期相関方向と全作用をずらす |
| $\varepsilon_{\rm rank}$ | 最大固有値以外の相対重量 | 節の残留強度、出力分布、可視度を変える |
| $\varepsilon_{\rm close}$ | 非線形項または試行依存 $h$ による相関閉包誤差 | 交換子発展と階数保存を破る |
| $\varepsilon_{\rm loc}$ | 空間グラフの不要な遠距離結合と交差応答 | 局所性と意図した $h_L$ を破る |
| $\varepsilon_{\rm disc}$ | 離散 Laplacian と連続演算子の差 | Schrödinger 型連続近似をずらす |
| $\varepsilon_{\rm phase}$ | 位相雑音と経路依存損失 | 干渉可視度を低下させる |
| $\varepsilon_{\rm tr}$ | 局所位相担体から入口作用への転送誤差 | $A_i/A_{\rm tot}$ を $p_i$ からずらす |
| $\varepsilon_{\rm sample}$ | 位置入口の流束因子の非共通性 | Born 型位置入口頻度をずらす |
| $\varepsilon_{\rm Bell}$ | Bell枝作用、比較転送、境界因子の総偏差 | 共同分布、非信号性、CHSH 値をずらす |
| $\varepsilon_{\rm cyc}$ | 源、記録、比較器、補助系の周期誤差 | 試行間の再現性と無条件頻度を破る |

これらは独立とは限らない。例えば源位相誤差は階数欠陥と干渉可視度の両方へ寄与する。それでも、どの段階で生じた誤差かを記録し、1つの総誤差だけで原因を隠さない。

## 6.2 源準備誤差

理想出力を $e^{i\beta^\omega}\chi_0$ とし、実出力を

```math
b^\omega
=
e^{i\beta^\omega}\chi_0
+
\delta b^\omega
```

と書く。源準備誤差を

```math
\varepsilon_{\rm src}^2
=
\mathbb E
\left\|
\delta b^\omega
\right\|^2
```

とする。共通位相方向のずれは $C$ に影響しないため、実際には $\chi_0$ と直交する成分を測るのがよい。作用揺らぎと方向揺らぎも分ける。

源の絶対位相が一様でも $C$ は階数1になり得る。従って $\mathbb E[b]$ の小ささを準備失敗と判定しない。検査すべき量は $C$ の主固有方向と階数欠陥である。

## 6.3 階数欠陥と節

第3章の命題により、理想節の残留確率は

```math
p_{\rm node}
\leq
\varepsilon_{\rm rank}
```

である。これは装置誤差を含まない相関行列だけの上界である。再結合器誤差 $\varepsilon_U$ と位相誤差 $\varepsilon_{\rm phase}$ があれば、概ね

```math
p_{\rm node}
\lesssim
\varepsilon_{\rm rank}
+
O\left(\varepsilon_U^2\right)
+
O\left(\varepsilon_{\rm phase}^2\right)
```

となる。節で相対誤差を使うと分母が零になるため、絶対強度または全変動距離で評価する。

閉鎖線形発展では $\varepsilon_{\rm rank}$ は保存される。観測中に値が増減するなら、非線形項、試行依存行列、外部流路、条件付けのいずれかが働いている。

## 6.4 相関閉包誤差

閉包残差 $D_C$ を

```math
i\mathcal J_0\dot C
-
\left[h,C\right]
=
D_C
```

で定める。有限観測時間 $[0,T]$ の積分誤差を

```math
\varepsilon_{\rm close}(T)
=
\frac1{\mathcal J_0}
\int_0^T
\left\|D_C(t)\right\|_{\rm op}
\,dt
```

とする。Duhamel 表示により、理想共役発展との差は $\varepsilon_{\rm close}(T)$ で抑えられる。

4次以上の項を持つ場合は、$D_C$ の小ささを $C$ だけから仮定しない。元の有限ミクロ試行を直接計算し、4次モーメント、振幅範囲、観測時間を変えて検証する。

## 6.5 局所空間結合と離散化

$h_L$ の物理的実装では次を別に監査する。

1. 辺の外に不要な遠距離結合がないか。
2. $Q$ と $P$ の結合行列が同じか。
3. 局所ポテンシャル項が全作用を意図せず増減させないか。
4. 境界条件が目標とする離散演算子と一致するか。
5. 格子幅を変えたとき誤差が期待次数で減るか。

任意の大域 Hermitian 行列を装置へ直接書き込めば、局所性は説明できない。本稿は疎なグラフ結合へ限定する。

また、$\mathcal J_0^2/(2m)$ は現模型の設計係数である。係数を調整した後に Schrödinger 型方程式と一致することは検証になるが、その係数がより原始的な古典系から生じることの導出にはならない。

## 6.6 位置標本化誤差

主定理2は固定振幅の階数1共通源に限定される。全振幅が試行ごとに変動する場合は、入口作用と流束因子の相関を追加で評価しなければならず、次の試行非依存誤差式だけでは足りない。

入口作用を

```math
A_i
=
A_{\rm tot}
\left(
p_i+\eta_i
\right),
\qquad
\sum_i\eta_i=0
```

とし、流束因子を $\lambda_i=\lambda(1+\delta_i)$ とする。すると

```math
P_i
=
\frac{
\left(p_i+\eta_i\right)
\left(1+\delta_i\right)
}{
\sum_j
\left(p_j+\eta_j\right)
\left(1+\delta_j\right)
}
```

である。1次では作用転送誤差 $\eta_i$ と流束非対称性 $\delta_i$ が別々に現れる。

最重要の構造誤差は、全位置へ同時に2モード殻を置く直積化である。この場合、容量は $\prod_iA_i$ に比例し、セルごとの線形相対頻度を与えない。各履歴が1つの入口だけを通る排他的な和であることを、装置 Hamiltonian と試行数の両方で確認する。

## 6.7 Bell 誤差

理想未規格化質量を $cK_{AB}$、実際の質量を $W_{AB}$ とし、

```math
\varepsilon_{\rm Bell}
=
\frac{
\sum_{A,B}
\left|
W_{AB}-cK_{AB}
\right|
}{
c\mathcal K
}
```

と定める。$\varepsilon_{\rm Bell}<1$ なら、規格化後の共同分布と理想分布の全変動距離は

```math
d_{\rm TV}
\leq
\frac{\varepsilon_{\rm Bell}}{1-\varepsilon_{\rm Bell}}
```

で抑えられる。

$\varepsilon_{\rm Bell}$ は少なくとも次へ分解する。

1. 反対称源の振幅・位相誤差。
2. 左右局所回転の角度誤差。
3. 戻り伝播の損失、分散、交差応答。
4. 比較器の初期作用と有限パルス誤差。
5. 境界密度、時計流束、余面積因子、解多重度の結果依存性。
6. 結果依存の失敗率と事後選別。

CHSH 値だけでなく、一側周辺の反対側設定依存性と全開始試行に対する採用率を別に計算する。

## 6.8 Bell の前提監査

| 監査項目 | 現行模型の状態 |
|---|---|
| 局所応答 | 左右分析器と局所記録は局所和。交差応答は $\varepsilon_{\rm loc}$ へ入れる |
| 測定設定独立性 | 境界測度の生成側引き戻しが設定に依存するため成立しない |
| 結果の一意性 | 既存の2値結果セクターを記録する最小装置のみ。一般的な唯一結果形成は未完成 |
| 事後選別 | 理論上は禁止。実装では全開始数、記録数、比較完了数、再初期化数の監査が必要 |
| 非信号性 | 理想対称共同分布では厳密。非対称準備と有限誤差を含む一般条件は未証明 |
| 試行測度 | 共通境界 Liouville 測度を仮定。前向き周期による物理的準備は未完成 |

Bell の定理に矛盾するとは主張しない。CHSH不等式の破れは測定設定独立性を満たさない完全履歴集団で得られる。

## 6.9 反証条件

次のいずれかが成立すれば、対応する中心主張は棄却または縮小しなければならない。

1. 共通源の物理的準備で $\varepsilon_{\rm rank}$ が再現可能に小さくならない。
2. 階数欠陥を減らしても干渉節の残留強度が上界に従わない。
3. 元の有限2次 Hamiltonian と交換子方程式が一致しない。
4. 局所疎結合を保つと目標 $h_L$ を実装できない。
5. 格子細分化で離散化誤差が減らない。
6. 排他的な位置入口を作ると作用殻の線形重みが失われる。
7. 局所作用転送または流束因子が必然的に位置依存となり、補正できない。
8. Bell 共同確率を得る実装が結果依存の試行除外を必要とする。
9. Bell 共通境界測度が、設定依存性を初期分布へ直接書き込む以外に準備できない。
10. 非信号性が有限誤差の下で安定しない。

## 6.10 旧2成分誘導場を外したことによる後退

現行改訂は旧模型の全結果を保存しない。次は現行主張から撤回する。

1. 物理空間上の実在2成分誘導場。
2. 位相接続 Hamiltonian による粒子誘導。
3. 標本場のエネルギーノルム集中。
4. 粒子密度・流束と場強度・場流束の同期。
5. 連続単価場に基づく条件付き循環量子化。
6. 動径欠陥、局所作用欠陥、低速・高速場縮約を現行主定理の準備機構とすること。

従って Q3 は未達へ戻り、Q1の根拠は有限相関行列力学へ変更される。理論の単純化と引き換えに、粒子の連続運動を明示的に未解決へ分離した。

## 6.11 最重要の未解決問題

1. $h_L$ の局所結合構造と係数を、量子力学的演算子の転記でなく、より原始的な有限古典模型から導く。
2. 共通源の階数1方向を、任意の設計入力でなく、物理的準備条件から選ぶ。
3. 非線形項を含む有限時間の相関閉包誤差を制御する。
4. 全位置へ広がる局所位相担体作用を、1試行1結果の排他的入口へ局所的に転送する。
5. 位置入口の共通流束因子を装置 Hamiltonian から導く。
6. 統計相関から粒子の連続流束と軌道を導く。
7. 空間グラフの閉路巻数、節、位相すべり、連続補間を統合し、Wallstrom 問題へ改めて回答する。
8. 井戸型・調和型ポテンシャル、トンネル効果、Rabi 振動を定量検証する。
9. 反対称 Bell 源を反復可能な有限 Hamiltonian 装置で準備し、相対位相を保持する。
10. Bell 共通境界測度を、事後選別なしの設定生成・結果形成・記録・比較・再初期化周期として実現する。
11. 非対称準備と有限誤差を含む一般的な非信号条件を示す。
12. 平面内2出力を超える複合状態と一般測定器へ拡張する。
