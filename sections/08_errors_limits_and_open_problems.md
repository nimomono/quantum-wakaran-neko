## 8.1 対象範囲

本章は次の5つを同一視せずに集計する。

1. M38の2モード操作、2段測定、有限反復Zeno周期、外部記録、弱開放 reset 。
2. M37の局所振動子網による空間伝播。
3. M35の一般有限基底内部測定周期。
4. M39の4モード2論理部分系とCNOT型結合流。
5. M41の設定生成、2担体準備、局所Bell型測定、外部記録、帰還周期。

M38はQ1-1からQ1-4、M39はQ2-1、M41はQ2-2を各限定範囲で閉じるが、M37との同一ハードウェア化を含まない。M41はM39、M35、M38の構成部品を再利用するが、既存装置を配線変更なしの同一ハードウェアとして統合したとは主張しない。M37からM35への接続は、状態方向誤差から有限基底分布誤差への数学的上界であり、同一装置の構成ではない。M38の $\varepsilon_{\rm op}$、M39のゲート誤差、M41の共同分布誤差は対象周期が異なるため機械的に合算しない。M0への統合、一般有限 $L$ の完全周期、量子計算機としての規模依存性は別の課題である。

## 8.2 M38の誤差台帳

M38の1回の前向き観測について、理想逐次分布と観測分布の全変動距離を、次の無次元誤差へ分ける。

```math
D_{\rm TV}^{\rm M38}
\leq
\delta_1+\delta_2
+
\varepsilon_{\rm op}
+
\varepsilon_{\rm clk}
+
\varepsilon_{\rm rec}
+
\varepsilon_{\rm port}.
```

| 誤差 | 内容 | 現行評価 |
|---|---|---|
| $\delta_1,\delta_2$ | 2段比較器の無反応質量 | 各段で $2w_{{\rm eff},j}/\mathcal J_0+\varepsilon_{{\rm cut},j}$ 以下 |
| $\varepsilon_{\rm op}$ | $SU(2)$ パルス面積、順序、生成子の実装誤差 | 理想正準回路では0、有限列の和上界 |
| $\varepsilon_{\rm clk}$ | 時計窓面積、重なり、作用帰還誤差 | 非重複理想窓では0 |
| $\varepsilon_{\rm rec}$ | 記録セルの共役運動量幅と読出し幅 | $T_R\sigma_PK_\Pi$ から状態誤差へ換算 |
| $\varepsilon_{\rm port}$ | 外部セルの流入・流出と接触時間のずれ | 個別実装で評価 |

比較幅の入力換算量は

```math
w_{\rm eff}
=
Xe^{-\Lambda}
+
\Delta_{\rm in}
+
e^{-\Lambda}\Delta_{\rm out}
```

である。増幅前誤差は双曲型増幅で減らない。増幅後の固定出力誤差だけが入力換算で小さくなる。

異なる単位の誤差を表のまま加えない。付録Eの順序に従い、正準状態誤差を状態方向誤差へ、状態方向誤差を比較境界移動量へ、境界移動量をHaar 質量と全変動距離へ変換する。上式の各 $\varepsilon$ は最終的に全変動距離へ換算した後の量である。

第2段、第1段、準備回路の逆計算残差と周期末 reset の交換誤差は、記録後に生じるため同じ観測の分布誤差へ入れない。これらを周期帰還誤差

```math
\varepsilon_{\rm ret}^{\rm M38}
\leq
\varepsilon_{\rm inv}
+
\varepsilon_{\rm rst}
```

として分け、次の実験周期の準備誤差へ伝播させる。長期の反復分布を評価するときだけ、その伝播分を次周期の前向き誤差へ加える。

## 8.3 有限Zeno周期の誤差

固定有限 $N_{\rm Z}$ の実結果空間を $\{+1,-1,\varnothing\}^{N_{\rm Z}}$ とし、理想履歴分布を無反応成分0で拡張する。第 $j$ 前向き段の条件付き全変動誤差を $\eta_j^{\rm fwd}$ とすると、

```math
D_{\rm TV}
\left(
p_{N_{\rm Z}},
\pi_{N_{\rm Z}}
\right)
\leq
1-
\prod_{j=1}^{N_{\rm Z}}
\left(
1-\eta_j^{\rm fwd}
\right)
\leq
\sum_{j=1}^{N_{\rm Z}}
\eta_j^{\rm fwd}
=
E_{N_{\rm Z}}^{\rm fwd}
```

である。

| 誤差 | 内容 | 現行評価 |
|---|---|---|
| $\delta_j$ | 第 $j$ 比較器の無反応質量 | $2w_{{\rm eff},j}/\mathcal J_0+\varepsilon_{{\rm cut},j}$ 以下 |
| $\varepsilon_{{\rm pulse},j}$ | 有限測定パルスと理想瞬時写像の差 | 固定作用殻上で有限パルス幅に比例 |
| $\varepsilon_{{\rm Rabi},j}$ | 測定窓中のRabi 項との非可換な重なり | $C_jh_j$ 以下 |
| $\varepsilon_{{\rm clk},j}$ | 時計窓面積、時刻中心、窓重なり | 非重複理想窓では0 |
| $\varepsilon_{{\rm rec},j}$ | 永久記録セルの反作用 | $T_{R,j}\sigma_{P,j}K_{\Pi,j}$ から換算 |
| $\varepsilon_{{\rm cell},j}$ | コア補助6対と段セルのSWAP | 理想交換では0、角誤差を状態誤差から換算 |

$\eta_j^{\rm fwd}$ は表の項を全て結果分布の全変動距離へ換算した後の和である。従って

```math
\left|
S_{N_{\rm Z}}^{\rm real}
-S_{N_{\rm Z}}
\right|
\leq
E_{N_{\rm Z}}^{\rm fwd},
```

```math
\left|
F_{N_{\rm Z}}^{\rm real}
-F_{N_{\rm Z}}
\right|
\leq
E_{N_{\rm Z}}^{\rm fwd}
```

となる。理想測定側と理想対照側の差が $E_{N_{\rm Z}}^{\rm fwd}$ と対照側誤差の和を超える範囲を、実装上の有限Zeno抑制として採用する。

逆計算、周期末 reset、選択器移動の誤差は、既に記録済みの同じ観測へ遡って作用しない。これらは周期帰還誤差 $\varepsilon_{\rm ret}$ として分け、次の実験周期の準備誤差へ伝播させる。固定有限 $N_{\rm Z}$ では

```math
E_{N_{\rm Z}}^{\rm fwd}<\epsilon,
\qquad
\varepsilon_{\rm ret}<\epsilon
```

を同時に選べば十分であり、$N_{\rm Z}\to\infty$ に一様な帯域上界を要求しない。

## 8.4 M37からM35への分布誤差

測定時刻の規格化局所包絡を $\widehat b_{\rm mic}$、目標有効状態を $\chi_L$ とする。任意有限基底について

```math
D_{\rm TV}
\left(
p^{\rm mic},p^L
\right)
\leq
\sqrt{
1-
\left|
\langle\widehat b_{\rm mic},\chi_L\rangle
\right|^2
}
```

である。装置誤差を加える場合は

```math
D_{\rm TV}^{\rm M35}
\leq
\varepsilon_{\rm dist}(T)
+
\varepsilon_{\rm prep}
+
\varepsilon_W
+
\varepsilon_{\rm read}
+
\varepsilon_{\rm cmp}
+
\varepsilon_{\rm cut}
+
\varepsilon_{\rm clk}
```

とする。

| 誤差 | 内容 | 現行評価 |
|---|---|---|
| $\varepsilon_{\rm dist}$ | M37の局所包絡と目標状態の方向差 | 第3章と第5.3節の解析上界 |
| $\varepsilon_{\rm prep}$ | 初期作用、相対位相、伝播時刻の再現誤差 | 完全準備系で未評価 |
| $\varepsilon_W$ | M35局所基底回路の誤差 | 理想 $QQ+PP$ 回路では0 |
| $\varepsilon_{\rm read}$ | 作用・閾値読出しと累積剪断の誤差 | 理想入口では0 |
| $\varepsilon_{\rm cmp}$ | 滑らかな比較幅 | $2(L-1)w_{\rm eff}/I_{\rm ph}$ 以下 |
| $\varepsilon_{\rm cut}$ | 角切断の接続領域 | 接続幅のHaar 質量 |
| $\varepsilon_{\rm clk}$ | 一般有限 $L$ の時計配線誤差 | 物理配線は未評価 |

第3章の自然時間では $\varepsilon_{\rm dist}=O(\eta)$ である。目標精度を $\epsilon$ とする単純な十分条件は

```math
\omega_0
=
O
\left(
\frac{\|h_L\|}{\mathcal J_0\epsilon}
\right)
```

である。最適性は主張しない。

## 8.5 M38の資源

M38の単純上界は次である。

| 装置 | 正準対数 |
|---|---:|
| Q1-1の信号担体 | 2 |
| 自律Rabi 装置 | 3 |
| $L=2$ M35測定1段 | 10 |
| 信号と時計を共有する2段測定器 | 17 |
| 外部記録セル | 2対／周期 |
| 外部 reset セル | 最大14対／周期 |
| Q1-4の再利用測定コア部分 | 10 |
| Q1-4の独立選択器・補助セル・記録 | 8対／測定段 |

2段測定器の17対は

```math
2+2\times7+1
```

からなる。共有するのは信号2対と時計1対であり、各段はテンプレート2、作用2、閾値1、内部記録1、選択器1の7対を持つ。

$K$ 実験周期を有限閉鎖Hamiltonian 系へ埋め込む単純上界は

```math
17+16K
```

正準対である。輸送自由度は含まない。能動装置の大きさは一定だが、永久記録と使用済みreset 状態の保存量は $O(K)$ で増える。有限閉鎖系の固定容量で無期限記録を行うとは主張しない。

Q1-4の1回の有限観測では、信号2対、測定コア補助6対、共通制御時計1対、Rabi 駆動作用・角1対を再利用する。各測定段は独立選択器1対、補助状態交換セル6対、永久記録セル1対を使う。従って単純上界は

```math
10+8N_{\rm Z}
```

である。$K$ 回の実験周期で選択器と補助状態交換セルを再利用し、永久記録を全て保持する場合は

```math
10+7N_{\rm Z}+KN_{\rm Z}
```

となる。有限誤差を無期限に補正する外部 reset セル流と輸送自由度は別に数える。測定コア数は1だが、可逆性、独立選択器、永久記録のため段数に比例する資源は残る。

## 8.6 一般有限基底装置の資源

M35の一般有限 $L$ 構成は

```math
N_{\rm pair}^{\rm meas}
=
3L+4
```

正準対を使う。内訳は信号 $L$、テンプレート $L$、作用レジスター $L$、閾値1、内部記録1、選択器1、時計1である。

任意の密な基底変換 $W$ は

```math
N_W
\leq
\frac{L(L-1)}2
```

個の隣接2モード混合と対角位相へ分解できる。逐次Givens 消去の深さは $O(L^2)$、互いに素な辺を並列化する配置では $O(L)$ である。累積剪断とテンプレート経路は $O(L)$ である。

一般有限 $L$ の複数段装置では、独立選択器、テンプレート、外部記録・reset セルの数が段数とともに増える。空間的に離れた各辺への時計配線と伝播遅延も必要になる。一般有限 $L$ の完全周期資源は未評価であり、M35の一般化課題として残る。

## 8.7 M39のゲート誤差と資源

面積誤差 $\delta A\in[-\pi,\pi]$ だけがある場合、M39の厳密値は次である。

| 評価量 | 値 |
|---|---:|
| 最悪入力の非忠実度 | $\sin^2(\delta A/2)$ |
| 平均ゲート非忠実度 | $\frac35\sin^2(\delta A/2)$ |
| 制御値1の真理値表誤り | $\sin^2(\delta A/2)$ |
| $|+0\rangle$ 出力の目標非忠実度 | $\frac34\sin^2(\delta A/2)$ |
| $|+0\rangle$ 出力の非因子化指標 | $|\cos(\delta A/2)|$ |

固定ゲージ距離と共通位相縮約後の距離は、それぞれ

```math
d_{\rm mat}
=
2
\left|
\sin\frac{\delta A}{2}
\right|,
```

```math
d_{\rm proj}
=
2\sin\frac{|\delta A|}{4}
```

である。M39の有効状態は共通位相を縮約しているため、物理的な操作誤差には $d_{\rm proj}$ を使う。

一般制御誤差は

```math
\eta_{\rm g}
=
\inf_{c(t)\in\mathbb R}
\int_0^{T_{\rm g}}
\left\|
\Delta K(t)-c(t)I_4
\right\|_{\rm op}
\,\mathrm dt
```

でまとめる。

- パルス面積は $(g_{\rm real}-g)\Pi_{\rm CX}$ として入る。
- 対辺の強度不均衡は局所代数外への差生成子として入る。
- 局所位相ずれは $Z$ 生成子の残差として入る。
- 時計窓の重なりは同時作動生成子の残差として入る。
- 意図しない交換辺は漏れ結合行列として入る。

実伝播行列は、ある位相 $\phi$ について

```math
\left\|
\widetilde U
-
e^{i\phi}U_{\rm CX}
\right\|_{\rm op}
\leq
\min\{2,\eta_{\rm g}\}
```

を満たす。ゲート単体は信号4対と時計1対の合計5正準対、M35による固定設定検算は16正準対である。直接モード符号化を $n$ 論理量子ビットへ拡張すると信号だけで $2^n$ モードを要するため、5対という値をQ2-3の一般資源評価へ外挿しない。

## 8.8 動作時間、作用、エネルギー

M38、M35、M39の各時計窓はパルス面積を指定する。最大結合強度を制限しなければ物理時間を任意に短縮できるので、絶対動作時間の主張にはならない。M39の非負CNOT窓は $T_{\rm g}\geq\pi/g_{\max}$ を満たす。一般に意味のある評価には最大生成子ノルムまたは最大結合強度を固定する必要がある。

reset 交換の接触時間は

```math
T_{\rm rst}
=
\frac{\phi}{g}
```

である。弱結合では接触時間が長くなる。比較精度を上げると双曲型増幅率 $\Lambda$ とポインター座標範囲が増える。

M37のミクロエネルギーは厳密保存される。M38の各理想正準パルスと外部セル交換も全Hamiltonian 内では可逆である。しかし、準備装置、時計、記録媒体、外部セル輸送、低エントロピーセル供給まで含む総エネルギー収支は計算していない。Landauer 原理を引用するだけでは、具体的なreset の熱・仕事収支にならない [17,18]。

## 8.9 反復可能性

反復には4つの意味がある。

1. 同じ観測中に、測定後信号を次のRabi 区間と測定へ渡すこと。
2. 全結果記録後に段セルを逆順で戻し、内部装置を復帰させること。
3. 周期末 reset と選択器移動後に、同じ能動装置で次の実験周期を始めること。
4. 外部記録と使用済みreset セルまで含む全系を結果非依存の同一点へ戻すこと。

M38は1--3を構成する。Q1-4では1個の測定コアを使い、補助状態だけを段セルへ退避する。4はHamiltonian 流の1対1性と両立せず、要求しない。固定有限 $N_{\rm Z}$ と $K$ なら履歴を有限個の外部セルへ保存し、全系を有限閉鎖Hamiltonian として扱える。無期限運転では空セル流入と使用済みセル流出を持つ弱開放系として扱う。

M35の一般有限 $L$ では内部逆計算は構成済みだが、複数段測定と外部セル流は未構成である。

## 8.10 Bell 側の性能指標

M41では、外部記録までの前向き誤差と、記録後の帰還誤差を分ける。前向き共同分布の全変動距離は

```math
\begin{aligned}
\epsilon_{\rm fwd}
\leq{}&
\delta_{\rm set}
+
\delta_{\rm s}
+
\delta_A^{\rm loc}
+
\delta_B^{\rm loc}\\
&+
\varepsilon_{\rm tr}
+
\varepsilon_{\rm act}
+
\varepsilon_{\rm rec}
+
\varepsilon_{\rm clk}^{\rm fwd}
\end{aligned}
```

で抑える。$\delta_{\rm set}$ は設定比較、$\delta_{\rm s}$ は階数2源選択、$\delta_A^{\rm loc},\delta_B^{\rm loc}$ は局所測定の無反応質量である。$\varepsilon_{\rm tr}$ は2担体転送、$\varepsilon_{\rm act}$ は一般状態での可変作用テンプレート切断、$\varepsilon_{\rm rec}$ は外部記録、$\varepsilon_{\rm clk}^{\rm fwd}$ は観測終了までの時計誤差を全変動距離へ換算した量である。singlet型では枝作用が常に $\mathcal J_0/2$ なので、$\varepsilon_{\rm act}=0$ とできる。

B側の可変作用比較だけを取り出すと、入力換算半幅 $w_B$、作用読出し境界移動量 $\Delta_B$ に対し、

```math
\delta_B^{\rm loc}
\leq
4\frac{w_B+\Delta_B}{\mathcal J_0}
+
\varepsilon_{{\rm cut},B}
+
\varepsilon_{\rm act}
```

である。源枝確率との積で分母が消えるため、無条件上界は正の枝作用下限を必要としない。各稀な枝の条件付き精度を一様に保証する場合だけ作用下限が必要である。

記録後の誤差は

```math
\varepsilon_{\rm ret}
\leq
\varepsilon_{\rm inv,A}
+
\varepsilon_{\rm inv,B}
+
\varepsilon_{\rm inv,tr}
+
\varepsilon_{\rm inv,s}
+
\varepsilon_{\rm inv,x}
+
\varepsilon_{\rm inv,src}
+
\varepsilon_{\rm inv,set}
+
\varepsilon_{\rm rst}
+
\varepsilon_{\rm clk}^{\rm ret}
```

とする。$\varepsilon_{\rm ret}$ は次周期の準備誤差へ入り、既に記録された同じ観測の共同分布へ遡って加えない。

理想singlet分布が非信号的なら、各設定対で全変動距離が $\epsilon_{\rm fwd}$ 以下であることから、

```math
\left|
P_{\rm obs}
\left(
B\mid x,y
\right)
-
P_{\rm obs}
\left(
B\mid x',y
\right)
\right|
\leq
2\epsilon_{\rm fwd}
```

を得る。A側も同様である。無反応を数値0としてCHSH相関を計算する場合は、

```math
\left|
S_{\rm obs}-S_{\rm id}
\right|
\leq
8\epsilon_{\rm fwd}.
```

従って

```math
\epsilon_{\rm fwd}
<
\frac{\sqrt2-1}{4}
```

なら、有限誤差下でもCHSH不等式の破れが残る。

共同分布誤差、一側周辺差、設定無反応、源無反応、局所無反応を別々に記録する。無反応試行を除いて分母を変える評価は使わない。
