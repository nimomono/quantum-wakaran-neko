## 9.1 有限Zeno効果の達成範囲（Q1-4）

Q1-4は、任意に指定した有限測定回数 $N_{\rm Z}$ と有限間隔列について達成とする。理想履歴分布、一度も反転しない確率、最終正占有率は

```math
\pi_{N_{\rm Z}}
=
\prod_{j=1}^{N_{\rm Z}}
\left[
(1-q_j)\mathbf1_{s_j=s_{j-1}}
+
q_j\mathbf1_{s_j=-s_{j-1}}
\right],
```

```math
S_{N_{\rm Z}}
=
\prod_{j=1}^{N_{\rm Z}}(1-q_j),
\qquad
F_{N_{\rm Z}}
=
\frac12
\left[
1+
\prod_{j=1}^{N_{\rm Z}}(1-2q_j)
\right]
```

である。等間隔の短時間域では

```math
\Gamma_{\rm Z}(\tau)
=
-\frac{\log[1-q(\tau)]}{\tau}
=
\frac{\Omega^2}{4}\tau
+
O(\tau^3)
```

となる。

各構成は次を満たさなければならない。

1. 同じ総観測時間の未測定対照を置く。
2. 異なる $N_{\rm Z}$ の間では、生存確率だけでなく有効反転率を比較する。
3. 無反応、反転、再反転を含む全履歴を保持する。
4. 全前向き測定窓でRabi 項を非零に保つ。
5. 測定中の摩擦または観測後reset だけで抑制を説明しない。
6. 理想測定側と未測定対照側の差が全誤差上界を超えることを確認する。

共鳴半周期を $N_{\rm Z}\geq2$ 等分する有限ベンチマークでは、未測定生存確率は0、測定側は

```math
\cos^{2N_{\rm Z}}
\left(
\frac{\pi}{2N_{\rm Z}}
\right)
>0
```

となる。完全凍結、$N_{\rm Z}\to\infty$ に一様な固定性能、全時間域での単調抑制は達成範囲に含めない。

## 9.2 一般有限次元への適用範囲と限界

M35は一般有限 $L$ の任意基底回路、Born 型長期頻度、測定後状態、内部逆計算を与える。これは一般有限次元で成立する定理の適用範囲であり、独立した長期目標の達成判定には使わない。第4章のM38で構成した要素を一般有限 $L$ へ拡張する場合は、少なくとも次が必要である。

1. 一般有限 $L$ の有効純粋状態空間と共通位相縮約。
2. 任意の $U(L)$ 操作と一般時間依存駆動。
3. 独立選択器を持つ複数段の異基底逐次測定。
4. 外部記録セルへの結果非依存正準コピー。
5. 一般有限 $L$ の外部 reset セル交換。
6. 空間的に離れた各辺への時計配線と遅延上界。
7. 自由度、時計窓数、外部セル数の規模依存性。

2モードでの達成を、記号だけ一般の $L$ へ置き換えたものは一般化と数えない。

## 9.3 2量子ビット型結合ゲート（Q2-1）

M39は、単一4モード正準担体上に2つの可換な局所操作代数を実装し、操作誘導テンソル積を定める。差モード射影の面積 $\pi$ 流はCNOTと厳密に一致し、積入力から最大非因子化状態を生成する。合格条件との対応は次である。

| 合格条件 | 根拠 |
|---|---|
| 入力論理基底と一般重ね合わせ | R104 |
| 外付け行列演算でない明示Hamiltonian | R105 |
| 全基底入力に対する作用 | R105 |
| 積状態から非分離相関を生成 | R105 |
| 局所操作だけに分解不能 | R104、R105 |
| 有限時間忠実度と資源上界 | R106 |

従ってQ2-1は、2量子ビット型結合ゲートと同じ共同入力--出力統計を生成する有限古典Hamiltonian過程として達成である。M39の操作誘導テンソル積と非因子化生成は明示実装と内部診断であり、固定達成条件が非分離状態の実在を別に要求するわけではない。2つの独立物理担体、Bell測定、結合項の自然なミクロ起源、具体的工学実装、多項式資源での規模拡張、完全未知装置認証はQ2-1の達成範囲に含めない。

## 9.4 Bell 型測定統計（Q2-2）

M41は、M39のsinglet型出力をA設定基底で階数2選択し、A方向とBブロックを2つの物理的2モード担体へ正準転送する。転送後は中央結合を停止し、互いに可換なA、B局所測定Hamiltonianで結果を作る。合格条件との対応は次である。

| 合格条件 | 根拠 |
|---|---|
| Q2-1出力から2物理担体を準備 | R107、R108 |
| A設定の非選択測定でB枝間コヒーレンスを失う | R108 |
| 測定中のA--B直接結合なし | R110 |
| 各側の局所結果と永久記録 | R110 |
| Born型共同分布とsinglet余弦則 | R110、R111 |
| CHSH不等式の破れ | R111 |
| 平面内2出力族のTsirelson上界 | R111 |
| 非信号性 | R111 |
| 測定設定独立性の破れ | R110、R111 |
| 有限幅、無反応、能動部帰還 | R107、R109、R110 |

従ってQ2-2は、固定有限設定、準備先行、非空間分離、singlet型、無反応込み、制御された任意精度の範囲で達成である。

達成範囲外の拡張は次である。

1. 2担体準備後に自由変更される設定。
2. 空間的に隔たった設定選択、長距離空間分離、有限伝播速度を持つ時計配線。
3. 一般非singlet状態でのB作用側チャネル除去。
4. 平面内2出力を超える一般Tsirelson原理。
5. 独立同分布型の有限標本揺らぎ。
6. 多量子ビットへの多項式資源拡張。

これらをQ2-2の未達条件へ戻さない。標準的な空間分離Bell実験と同じ自由設定条件を満たすと主張した場合は、M41の達成範囲を越えるため反証または主張撤回が必要である。

## 9.5 量子ゲート型計算機の実装コスト（Q2-3）

Q2-3には、$n$ 量子ビット、回路深さ $d$、目標誤差 $\epsilon$ に対する少なくとも次の増加率が必要である。

1. 信号と補助装置の正準対数。
2. 局所結合数と最大並列度。
3. 時計窓数と動作時間。
4. 制御角、比較器、reset セルの必要精度。
5. 永久記録と使用済みセルの容量。
6. 隠れた指数コストの有無。

M38の17対と1周期当たり16外部セルは $n=1$、M39の5対は1回の2論理部分系ゲートの予備値であり、Q2-3の達成とは数えない。M39の直接モード符号化をそのまま拡張すると信号モード数が $2^n$ になるため、現時点では指数コストを避けていない。

## 9.6 位相量子化（Q3-2）

有限グラフ上で辺位相差を定義するだけでは、連続空間の単価性、節の生成・消滅、閉路変形に対する巻数保存を得られない。Q3-2には少なくとも次が必要である。

1. 辺内部の補間場または許容配置条件。
2. 非零領域での閉路巻数の整数性。
3. 節を通る位相すべりの有限Hamiltonian 記述。
4. 格子細分化に対する巻数の安定性。
5. 追加量子化条件を別の形で仮定していないこと。

閉路位相を数値的に丸めて整数へ投影するだけでは達成としない。

## 9.7 束縛状態（Q3-3）

時間非依存 $h_L$ の固有ベクトルが有効解として存在することはQ3-1から従う。しかしQ3-3は、井戸型・調和型ポテンシャルについて次を要求する。

1. 有限振動子パラメータからのスペクトルと固有ベクトル。
2. 格子幅、領域幅、搬送周波数に対する収束。
3. 基底状態と複数の励起状態の節構造。
4. エネルギー測定器との接続。
5. 弱開放条件下の状態選択または安定性。

固有ベクトルを初期条件として入れるだけでは、状態選択を示したことにならない。

## 9.8 トンネル効果（Q3-4）

障壁高、幅、入射エネルギーを掃引し、透過率を目標Schrödinger 解と比較する。少なくとも

```math
\epsilon_{\rm tun}
=
\max_{r\in\mathcal R}
\left|
T_{\rm micro}(r)-T_L(r)
\right|
```

を有限領域 $\mathcal R$ で評価する。熱浴温度、古典的共鳴、障壁越えエネルギーの寄与を分離し、熱活性化だけで同じ透過率を説明できないことを検査する。

## 9.9 2重スリット干渉（Q3-5）

第3章の2経路干渉は位相担体の出力作用を与えるが、粒子検出を導かない。Q3-5には次が必要である。

1. 各検出セルに局所的な単一試行変数だけからなる結合。
2. 有限観測窓の時間積分流束。
3. 作動、無反応、複数作動を含む完全結果集合。
4. 各試行で唯一の局所記録を得る条件。
5. 検出網内の信号伝播速度と比較時間。
6. スリット開閉に対する分布と総検出率の変化。

点粒子の連続軌道は1つの候補だが、Q3-5の必須形式とはしない。

## 9.10 達成済み主張の反証条件

現行主張は、次のいずれかが起きれば反証または範囲縮小が必要である。

1. 固定作用面のBloch ベクトルが単位球面を満たさない。
2. $G_Z,G_X$ の有限列が目標 $SU(2)$ を再構成しない、または正準性・作用を保存しない。
3. 自律Rabi Hamiltonian の数値軌道が解析遷移公式と一致しない。
4. 同軸再測定で反対符号の安全結果が生じる。
5. 異軸共同分布の全変動距離が $\delta_1+\delta_2$ を超える。
6. 外部記録剪断が理想空セル入口で装置へ反作用する。
7. 記録後の逆計算で内部装置が準備値へ戻らない。
8. 外部セル交換が正準性を失う、または収縮上界を破る。
9. Q1-4の全履歴分布が $E_{N_{\rm Z}}^{\rm fwd}$ の全変動距離上界を超える。
10. Q1-4の前向き測定窓でRabi 項の係数が零になる。
11. 観測中の摩擦または観測後reset だけでQ1-4の抑制が生じる。
12. 無反応または反転履歴を除外してQ1-4の分布を再規格化する。
13. 補助状態交換セルのSWAP が信号を変える。
14. 固定有限 $N_{\rm Z}$ の選択器ベクトルが積Haar 測度を持たない。
15. 有限Zenoベンチマークで、同じ総時間の未測定対照との差が誤差上界以下になる。
16. $L=2$ M35測定段の正準対数を10以外として資源評価する。
17. M37の $\eta<1$ の例で生成子上界または有限時間上界が破れる。
18. M35の無反応込み分布が導出上界を超える。
19. M41の階数2源枝頻度が $I_A^x/\mathcal J_0$ に一致しない。
20. M41の非選択B相関行列が $\operatorname{Tr}_A(cc^\dagger)$ と一致しない、またはA設定に依存する。
21. M37とM38を同一ハードウェアとして暗黙に扱う。
22. 未構成のM0または $\mu_*$ を現行定理の仮定として使う。
23. M39の2つの局所操作代数が可換でない、または積状態の階数1条件を保存しない。
24. 差モード生成子の面積 $\pi$ 流が4基底上でCNOTと一致しない。
25. M39の実8次元流が正準性または全作用保存を破る。
26. $|+0\rangle$ 入力の出力係数行列が階数2にならない。
27. 面積誤差の忠実度式または共通位相縮約距離が数値検算と一致しない。
28. M39の単一担体内相関を空間分離Bell 統計として扱う。
29. M41の2担体準備後もA、B局所測定Hamiltonianが可換でない、または中央結合が残る。
30. M41の源枝作用とB条件付き作用比の積がBorn型共同分布に一致しない。
31. M41のsinglet共同分布の一側周辺が反対側設定へ依存する。
32. M41の標準CHSH値が $2\sqrt2$ に一致しない、または平面内上界 $2\sqrt2$ を超える。
33. 無反応試行を除外してM41の共同分布またはCHSH値を再規格化する。
34. 観測後の帰還誤差を、既に記録された同じM41周期の前向き分布へ遡って加える。
35. 設定依存状態を前向き準備写像から作らず、目的共同分布を設定条件付き初期測度へ直接書き込む。
36. M41を準備後の自由設定変更または空間分離Bell局所性の検証として扱う。
37. 生成物と章別正本で式、結果ID、目標の現在地が一致しない。

## 9.11 最重要の未解決問題

Q1-1からQ1-4をM38、Q2-1をM39、Q2-2をM41で閉じた後の中心課題は、次の3本に分かれる。

1. Q2-3では、M39の $2^n$ 直接モードコストを監査し、多量子ビット回路の物理自由度、時間、精度、記録、resetの規模依存性を評価する。
2. Q3-2からQ3-5では、M37の空間包絡を位相量子化、束縛状態、トンネル、局所検出へ拡張する。
3. M41の達成範囲を越える拡張として、準備後設定変更、空間分離、一般状態の作用側チャネル除去、独立同分布型標本統計を検査する。

一般有限 $L$ への拡張は、M35の適用限界と一般化課題として並行して管理する。M37、M38、M35、M39、M41を1つのM0と統一母測度へまとめることは、その後の統合目標である。特にM37とM38の同一ハードウェア化はQ1-3の達成条件ではなく、M41の2担体も空間分離または準備後自由設定を含まない。
