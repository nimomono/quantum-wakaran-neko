## Q.1 目的と供給対象

M54の一般 $n$ 特殊化は、$2^n$ 信号モード、ゲート 作業領域、R181Dの未処理／正則化容量指針変数、選択機構、選別機構用作業領域、大きさ方向-接続端環境、R162 衝突素子、外部記録を使う。これらを回路出力に応じて外部生成せず、試行開始前に用意した貯蔵部から時計自由度順に供給する。

有限運転では必要貯蔵部全体を初期状態に含める。無期限運転では同じ局所規則を持つ低温流入と使用済み流出を仮定する。有限閉ハミルトニアン系が低作用未使用を無制限に増やすとは主張しない。

## Q.2 一様貯蔵部 添字

貯蔵部モードの添字は

```math
(\mathrm{kind},k,r,j)
```

とする。$\mathrm{kind}$ は信号、指針変数、選択機構、選別機構、衝突、大きさ方向、記録の有限種類、$k$ は回路または読出し段、$r$ は未使用化回、$j$ は部分系 添字である。隣接添字へ同じ形の結合器を置く有限生成規則を使い、外部プログラムは個々の $j$ を列挙しない。

## Q.3 反復部分SWAP

有効 貯蔵部を $W_r$、流入する低温層を $E_r$ とする。対応対へ、一様有限規則から作る同一の静的二次ハミルトニアンによる同じ2モード回転を一括作用させると

```math
W_{r+1}=C_rW_r+S_rE_r,
\qquad
\|C_r\|\leq\rho<1.
```

各対の全変換は実正準かつ可逆で、低温側出力を使用済みへ保持する。有効成分だけを捨てない。$\|E_r\|\leq\eta_{\rm cold}$ なら

```math
\|W_R\|
\leq
\rho^R\|W_0\|
+\eta_{\rm cold}\sum_{j=0}^{R-1}\rho^j
\leq
\rho^RR_{\rm in}
+\frac{\eta_{\rm cold}}{1-\rho}.
```

## Q.4 集約低温条件

Q2-4で必要なのはモードごとの温度上界ではなく、貯蔵部全体の集約 ノルム上界である。特に、未使用 モードが零でも有限作用を注入する独立加法ノイズ 下限が各モードに残れば、$2^n$ モードの集約誤差は一般に増大する。この場合R179の多項式精度条件を満たさず、R186第4項の全自由度に加わる加法ノイズ障害に対応する。各モードの振幅に比例して位相だけを揺らす乗法ノイズは同じ理由では排除しない。

許される供給は、厳密不変な未使用状態、または貯蔵部全体で $\eta_{\rm cold}=O(\epsilon/\operatorname{poly}(n,d))$ を保証する一様収縮条件である。低温供給源の受動容量、装置体積、総作用移送、総熱は指数的でもよいが、外部制御器がモードごとに較正してはならない。

## Q.5 根入力

一般 $n$ 入力はR181Bの反復テンソル積状態の生成で作らない。定数次元供給源 パケット $s$ を一様木 結合器へ入れ、$0^n$ 根モードと未使用素子群の間で部分SWAPする。理想的には

```math
Z_{0^n}=s,
\qquad
Z_x=0\quad(x\neq0^n).
```

他の計算基底入力は回路先頭のR181C $X$ ゲートで作る。未知振幅表の注入はR179の接続部に含めない。

## Q.6 衝突素子と選択機構供給

R181Dの各節点はR161率を有限時間近似するR162 衝突素子を使う。素子の初期分布は回路出力、未処理容量、将来の選択機構値と独立に取り、結果成分に依存しない同じ有限局所分布から供給する。容量依存性はR170の局所相互作用にだけ入る。

選択機構と選別機構用作業領域は未使用幅以内へ部分SWAPで準備する。使用後は、選択機構結果、選別機構に退避した非選択信号、衝突履歴、大きさ方向-接続端履歴を使用済みへ送る。結果を保持したまま全てを同じ未使用点へ戻さない。

## Q.7 R179の証明

<!-- theorem-start:proof -->
**証明（R179）**

Q.3の幾何級数評価により、$R_{\rm in}\leq\exp p_1(n,d)$ なら

```math
R
=
O\!\left(
n+\log d+\log(1/\varepsilon_{\rm blank})
\right)
```

回の一様部分SWAPで有効 貯蔵部を所望の未使用幅へ入れられる。Q.2の添字規則により外部命令は貯蔵部次元でなく回数に比例する。Q.5が根入力、Q.6が衝突、選択機構、選別機構、使用済み供給を与える。各供給核の全変動距離または安全-集合失敗率を足せば

```math
\varepsilon_{179}
\leq
C_{\rm root}
(\varepsilon_{\rm blank}+\varepsilon_{\rm src}+\varepsilon_{\rm swap})
+\varepsilon_{\rm coll}
+\varepsilon_{\rm selector}
+\varepsilon_{\rm clock}.
```

供給法則は回路出力確率を含まず、決定論的な下流写像は全変動距離を増やさない。以上で本文のR179を得る。
<!-- theorem-end:proof -->

## Q.8 資源境界と非主張

外部プログラム長、未使用化回、時計自由度精度、衝突精度は $n,d,1/\epsilon$ の多項式である。信号、作業領域、履歴、低温、使用済みの受動自由度と状態容量、総作用移送、総熱は $2^n\operatorname{poly}(n,d,1/\epsilon)$ まで許す。これは通常の効率的古典シミュレーションではない。

R179は次を主張しない。

1. 低温 浴を有限閉ハミルトニアン系から無制限に生成すること。
2. 有限貯蔵部を無期限運転し、使用済み素子を履歴なしに未使用へ戻すこと。
3. 指数的な受動容量、装置体積、総熱を多項式へ削減すること。
4. 結果確率、振幅表、モード別較正値を外部から供給すること。
5. 旧等重み-ビット、二進しきい値、開口 記録領域をR181Dに必要とすること。
