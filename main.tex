\chapter*{概要}

\addcontentsline{toc}{chapter}{概要}

本論文は、有限自由度の古典 Hamiltonian 系を基礎とし、対象部分を外部との微小なエネルギー交換を伴う弱開放系として扱う。目的は、量子力学をミクロ構成の入力に置かず、量子力学に特徴的な力学と確率構造が縮約された有効理論として現れ得るかを検証することである。

現行模型の力学的な主線は、有限2成分誘導場の位相接続経路である。運動量結合による配置拡散経路は、実在的な確率軌道を構成する別の候補として付録Dへ移し、現行模型から外す。従って、本論文は配置 Markov 過程または Nelson 確率過程の実在を、Schrödinger 型力学の前提にしない。

有限セル \(i\) の2成分場を

\[
\boldsymbol\Phi_i
=
r_i
\begin{pmatrix}
\cos\theta_i\\
\sin\theta_i
\end{pmatrix},
\qquad
j_i
=
\Phi_{1,i}\Pi_{2,i}
-
\Phi_{2,i}\Pi_{1,i}
\]

とする。正準1形式は有限次元で厳密に

\[
\sum_i
\boldsymbol\Pi_i\cdot d\boldsymbol\Phi_i
=
\sum_i
\left(
p_{r,i}\,dr_i+j_i\,d\theta_i
\right)
\]

となる。規格化 \(\sum_i r_i^2\Delta V=1\) と固定全位相作用

\[
\mathcal J_\phi
=
\sum_i j_i\Delta V
\]

の下で、回転エネルギーは

\[
E_{\rm rot}
=
\frac{\mathcal J_\phi^2}{2I}
+
\sum_i
\frac{
\left(
j_i-\mathcal J_\phi r_i^2
\right)^2
}{
2Ir_i^2
}
\Delta V
\]

と分解できる。従ってエネルギー最小配置は \(j_i=\mathcal J_\phi r_i^2\) である。これは固定作用sector内の厳密な最小化結果であり、閉鎖 Hamiltonian 流がこの配置へ吸引されることを意味しない。

セル体積を吸収した振幅 \(R_i\) と局所作用 \(J_i\) を用い、局所作用欠陥を

\[
\delta J_i
=
J_i
-
\frac{
\mathcal J_\phi R_i^2
}{
\sum_kR_k^2
}
\]

とする。本稿は、動径運動量と \(\delta J_i\) の正定値エネルギーを \(1/\epsilon_{\rm s}\) で高速化した有限 Hamiltonian を追加する。有限 \(\epsilon_{\rm s}\) の正確な Legendre 変換により、有界な低速枝では

\[
P_i
=
O
\left(
\epsilon_{\rm s}
\right),
\qquad
\delta J_i
=
O
\left(
\epsilon_{\rm s}
\right)
\]

を得る。さらに、準備窓だけ有限振幅浴と位相差に結合した有限作用交換浴を作動させる。作用交換浴は共通位相回転に不変なので \(\mathcal J_\phi\) を厳密に保存し、余弦・正弦結合の対は位相固定項を作らない。固定振幅・短記憶・低温の準備近似では局所作用欠陥を減衰させる。ただし、観測中の相対位相運動を変えないよう、準備後は浴を切り離す。

さらに、\(N=1\) を厳密制約として課し、固定 \(\mathcal J_\phi\) と共通位相の商を取る。単体内点の局所正準座標では、有限特異 Hamiltonian は

\[
\begin{aligned}
H_{\epsilon_{\rm s}}^{\rm chart}
={}&
H_0(\xi,\varphi)
+
\frac{
2
}{
\epsilon_{\rm s}M
}
p_\xi^{\mathsf T}
G_q^{-1}
p_\xi
\\
&+
\frac{
1
}{
2\epsilon_{\rm s}I
}
\left(
p_\varphi-\mathcal J_\phi\xi
\right)^{\mathsf T}
G_\varphi^{-1}
\left(
p_\varphi-\mathcal J_\phi\xi
\right)
\end{aligned}
\]

へ正確に変換でき、2つの慣性行列は

\[
G_q^{-1}
=
G_\varphi
\]

を満たす。内点臨界点まわりで位相反転対称性と正定値 Hessian 条件を置くと、2次模型は低速帯と \(O(\epsilon_{\rm s}^{-1})\) の高速帯へ分かれる。高速symplectic部分空間と同型の有限補助系を零状態から交換角 \(\pi/2\) で結合すれば、高速成分を補助系へ完全に移せる。交換後の運動は局所2次縮約方程式を \(O(\epsilon_{\rm s})\) の残差で満たす。

この正定値2次結果は、現行の Madelung 縮約へまだ無条件には適用できない。位相勾配エネルギーの二重計数を除くと、場側の位相 Hessian は半正定値または零になり得る。有限規格化ペナルティ、粒子-場混合、時間依存基準経路、非線形高速再励起も未解析である。従って、示したのは高速法線成分の条件付き除去であり、特定の停留経路または Schrödinger 解の選択ではない。

2つの準備機構の役割も異なる。有限振幅浴と作用交換浴は局所的だが近似的であり、同型高速モード交換は大域的・精密調整型だが正定値2次模型では厳密である。どちらも、異なる標本を共通の \((r,\theta)\) へ集中させる coherent集中、\(r^2=\rho\) の密度同期、単流束化、節の制御を導かない。

正則化した位相接続を

\[
\mathbf a_\varepsilon
=
\frac{
\Phi_1\nabla\Phi_2
-
\Phi_2\nabla\Phi_1
}{
|\boldsymbol\Phi|^2+\varepsilon^2
}
\]

とし、粒子 Hamiltonian を

\[
H_{\rm p}
=
\frac{
\left|
P-\mathcal J_\phi\mathbf a_\varepsilon(X)
\right|^2
}{
2m
}
+
V(X)
\]

とする。coherent集中、局所作用分配、密度同期、単流束化、動径断熱化、節から離れた極限の下で、場の正準項と粒子の接続項は物質微分結合を与える。\(S=-\mathcal J_\phi\theta\) と定めると、縮約作用は

\[
\mathcal A_{\rm red}
=
\int
\left[
\frac m2\rho|v|^2
-
\rho V
-
\rho
\left(
\partial_tS+v\cdot\nabla S
\right)
-
\kappa
\left|
\nabla\sqrt\rho
\right|^2
\right]
\,dx\,dt
\]

となる。係数整合

\[
\kappa
=
\frac{\mathcal J_\phi^2}{2m}
\]

の下で、変分は Madelung 方程式を与える。従って

\[
\hbar_{\rm eff}
=
|\mathcal J_\phi|,
\qquad
\psi
=
\sqrt\rho
\exp
\left(
\frac{iS}{\hbar_{\rm eff}}
\right)
\]

は節を避ける局所領域で Schrödinger 型方程式を満たす。これは位相接続縮約作用からの直接結果であり、配置拡散経路を使用しない。Nelson の現在速度表示との一致は、同じ作用の別表示としてのみ用いる。

単価な2成分場では

\[
\oint
\nabla\theta\cdot d\ell
=
2\pi n
\]

であるため、条件付き循環量子化を得る。節の生成・消滅、正則化極限、全ての物理的流れが単価な場から準備されることは未解決であり、Wallstrom 問題を全面的に解いたとは主張しない。

位置の Born 型入口重みは2モード作用殻から得る。局所作用を

\[
A_i
=
A_{\rm tot}r_i^2\Delta V
\]

とし、選択された活性モードと1つの共有明反応座標が \(K_i+I=A_i\) を分配すると、

\[
\Omega_2(A_i)
=
(2\pi)^2A_i
\]

である。排他的な入口チャンネルの法線速度、障壁、coarea Jacobian、spectator因子が共通なら、正方向 Liouville 流束は \(A_i\) に比例し、

\[
P_i
=
r_i^2\Delta V,
\qquad
\rho_{{\rm in},i}
=
r_i^2
\]

を得る。これは位置入口分布に限定された Born 型結果であり、任意基底の一般測定則ではない。

Bell 側でも、新しい配置空間場は導入しない。同じ2成分場の固定された直交モード部分空間から、左右へ進む2出力モードを切り出す。左右モード間の低ランク相関を

\[
C_{\mu\nu}
=
\sum_{r=1}^{2}
\eta_r
z^A_{\mu r}
\left(
z^B_{\nu r}
\right)^*
\]

と定義する。\(C\) は独立した正準場ではなく、基礎モードから作る派生量である。共役を含むため、共通内部位相回転に対して不変である。

2つの直交源チャンネルが反対称源

\[
C_0
=
\sqrt{\frac{\mathcal K}{2}}
\begin{pmatrix}
0&1\\
-1&0
\end{pmatrix}
\]

を準備し、左右の局所分析器が出力モードを \(R(\alpha_a)\)、\(R(\alpha_b)\) で回すと、結果枝作用は

\[
K_{AB}
=
\left|
e_A^{\mathsf T}
R(\alpha_a)
C_0
R(\alpha_b)^{\mathsf T}
e_B
\right|^2
=
\frac{\mathcal K}{4}
\left[
1-AB\cos\Delta_{ab}
\right],
\]

\[
\Delta_{ab}
=
2
\left(
\alpha_a-\alpha_b
\right)
\]

となる。局所分析器は場の共通内部位相を回すのではなく、固定された2出力モード添字を局所的に回す。

左右の記録後、戻りモードは有限速度で共通未来の比較領域へ伝播する。そこに同じ誘導場の2つの境界比較モード

\[
(Q_{\rm R},P_{\rm R}),
\qquad
(Q_{\rm I},P_{\rm I})
\]

を置き、理想比較パルスを

\[
H_{\rm read}
=
g_{\rm read}(\vartheta)
\left[
P_{\rm R}\operatorname{Re}C
+
P_{\rm I}\operatorname{Im}C
\right]
\]

とする。比較運動量が零で、他の自由発展を無視できるなら、入力モードを乱さず

\[
Q_{\rm R}^{\rm out}
=
\Gamma\operatorname{Re}C_{AB},
\qquad
Q_{\rm I}^{\rm out}
=
\Gamma\operatorname{Im}C_{AB}
\]

を得る。従って比較2モードの総作用は

\[
A_\partial^{AB}
=
\frac{\Gamma^2}{2}K_{AB}.
\]

2モード殻容量は線形なので、

\[
\Omega_2
\left(
A_\partial^{AB}
\right)
=
(2\pi)^2A_\partial^{AB}
\propto
K_{AB}.
\]

ただし、読み出し写像、殻上の等方混合、結果頻度を区別しなければならない。Hamiltonian 読み出しは空の比較器を殻上の1点へ移し、\(U(2)\) 混合は準備された集団を殻上で混ぜるが、正規化済みの結果セクター総質量を殻容量倍にはしない。Bell 重みを得るには、各比較殻へ共通密度または共通流束を置く二側境界準備条件が別に必要である。

結果セクターの基準質量が \(w_{AB}=1/4\)、境界密度、時計速度、coarea因子、spectator体積が全結果で共通なら、

\[
P(A,B\mid a,b)
=
\frac14
\left[
1-AB\cos\Delta_{ab}
\right]
\]

を得る。対称性により一側周辺は \(1/2\) である。境界測度を生成側へ Hamiltonian flow で引き戻すと一般に

\[
\rho(\Lambda\mid a,b)
\neq
\rho(\Lambda)
\]

となる。従って Bell の前提違反は測定設定独立性にある。共通未来比較器が前向き因果として過去の局所記録を変更するわけではない。

本改訂の中心的な前進は、厳密規格化・固定作用下の単体局所正準形を導き、正定値定数係数2次模型では低速・高速分離と高速成分の可逆な完全交換を示したことである。局所的な有限準備浴も別の近似機構として維持した。位置の Born 型入口標本化、同じ2成分場の低ランク対モードから得る Bell 余弦作用、共通未来比較器による2モード作用転送は変更していない。

力学側の次の中心課題は、半正定値・零モード版を証明し、有限規格化、粒子-場を含む時間依存M0、非線形再励起へ拡張することである。測定側の最大課題は、殻容量に比例する共通境界測度を、結果別の事後選別を用いない実験周期として準備し、coherent集中、密度同期、記録、逆計算、準備浴と交換補助系の再初期化まで統合することである。

\hypertarget{ux554fux984cux8a2dux5b9a}{%
\section{問題設定}\label{ux554fux984cux8a2dux5b9a}}

本論文の目的は、明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現し得るかを検証することである。量子力学をミクロ構成の入力には使わず、縮約後の式と比較するときだけ参照する。

中心問題を次の4点に分ける。

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  有限2成分場との位相接続から、局所作用整合と動径低速化を部分的に準備し、Madelung 作用と Schrödinger 型力学を得られるか。
\item
  場強度と粒子密度の一致を定義として置かず、入口の Liouville 流束から位置の Born 型重みを得られるか。
\item
  同じ場の対モードと局所分析器から Bell 余弦作用を得られるか。
\item
  共通未来比較器と2モード境界測度から Bell 型共同統計を得て、Bell の前提違反と非信号条件を特定できるか。
\end{enumerate}

本論文は、明記した縮約条件と境界条件の下で4点全てに部分的な結果を与える。ただし、共通境界測度の物理的準備、一般測定器、全構成を統合した反復可能な試行周期は未完成である。

有限部分を概略

\[
\begin{aligned}
H_{\rm fin}
={}&
H_{\rm obj}
+
H_{\rm field}
+
H_{\rm prep}
+
H_{\rm source}
+
H_{\rm analyzer}
+
H_{\rm pointer}\\
&
+
H_{\rm return}
+
H_{\rm read}
+
H_{\rm mix}
+
H_{\rm memory}
+
H_{\rm reset}
+
H_{\rm clk}
\end{aligned}
\]

と書く。準備項は

\hypertarget{ux6709ux9650ux30bbux30ebux304bux3089ux59cbux3081ux308bux7406ux7531}{%
\section{有限セルから始める理由}\label{ux6709ux9650ux30bbux30ebux304bux3089ux59cbux3081ux308bux7406ux7531}}

有限モード切断した場では、振幅 \(r(x)\)、位相 \(\theta(x)\)、局所作用 \(j(x)\) は任意の独立関数ではない。切断された場多様体上の従属変数である。そこで、最初に有限個のセルを持つ正準系を定義し、連続表示はその後の近似として扱う。

セル \(i=1,\ldots,L\) に2成分正準対

\[
\boldsymbol\Phi_i
=
\begin{pmatrix}
\Phi_{1,i}\\
\Phi_{2,i}
\end{pmatrix},
\qquad
\boldsymbol\Pi_i
=
\begin{pmatrix}
\Pi_{1,i}\\
\Pi_{2,i}
\end{pmatrix}
\]

を置く。Poisson 括弧は

\[
\left\{
\Phi_{\alpha,i},
\Pi_{\beta,j}
\right\}
=
\delta_{\alpha\beta}\delta_{ij}.
\]

\(r_i>0\) の領域で

\[
\boldsymbol\Phi_i
=
r_i
\begin{pmatrix}
\cos\theta_i\\
\sin\theta_i
\end{pmatrix}
\]

と書き、

\[
p_{r,i}
=
\boldsymbol\Pi_i\cdot
\frac{\boldsymbol\Phi_i}{r_i},
\]

\[
j_i
=
\Phi_{1,i}\Pi_{2,i}
-
\Phi_{2,i}\Pi_{1,i}
\]

と定める。

\begin{proposition}[有限セル極座標の正準1形式]
$r_i>0$ の各セルで、

$$
\boldsymbol\Pi_i\cdot d\boldsymbol\Phi_i
=
p_{r,i}\,dr_i
+
j_i\,d\theta_i
$$

が成立する。従って $(r_i,p_{r,i})$ と $(\theta_i,j_i)$ は正準対である。
\end{proposition}

\begin{proof}
単位ベクトル

$$
e_{r,i}
=
\begin{pmatrix}
\cos\theta_i\\
\sin\theta_i
\end{pmatrix},
\qquad
e_{\theta,i}
=
\begin{pmatrix}
-\sin\theta_i\\
\cos\theta_i
\end{pmatrix}
$$

を用いると、

$$
d\boldsymbol\Phi_i
=
e_{r,i}\,dr_i
+
r_ie_{\theta,i}\,d\theta_i.
$$

$p_{r,i}=\boldsymbol\Pi_i\cdot e_{r,i}$ と $j_i=r_i\boldsymbol\Pi_i\cdot e_{\theta,i}$ を代入すればよい。
\end{proof}

\[

\]

とする。理想縮約では \(\mathcal N_\Phi=1\) を用いる。有限装置では、規格化逸脱を

\[

=

\left(

\[

\section{固定作用下の局所作用分配}\label{ux56faux5b9aux4f5cux7528ux4e0bux306eux5c40ux6240ux4f5cux7528ux5206ux914d}}

\frac{\mathcal J_\phi^2}{2I}
\sum_i r_i^2\Delta V

\frac{\mathcal J_\phi^2}{2I}.

\hypertarget{ux6e96ux5099ux7a93ux3068ux89b3ux6e2cux7a93ux306eux5206ux96e2}{%

\end{enumerate}

  ミクロ運動の粗視化が \(\mathcal A_{\rm red}\) の時間依存停留経路を支配すること。
\item
  一般の節構造を含む領域で同じ縮約を制御すること。
\end{enumerate}

実在的な前後 Markov 経路を構成する別候補は付録Dへ記録するが、本章の導出には使用しない。

\begin{statusbox}
位置づけ：一般作用殻体積、2モード殻の線形重み、共通流束因子の下での位置入口密度、直接作用分配次元の剛性は厳密結果である。等方準備と標本化後の再埋め込みは未完成である。

\hypertarget{ux4e00ux822cux4f5cux7528ux6bbbux4f53ux7a4d}{%
\section{一般作用殻体積}\label{ux4e00ux822cux4f5cux7528ux6bbbux4f53ux7a4d}}

\(n\)個の複素正準モードを

\[
a_k
=
\frac{
q_k+ip_k
}{
\sqrt2
},
\qquad
J_k
=
|a_k|^2
\]

とする。作用角変数では

\[
dq_k\,dp_k
=
dJ_k\,d\theta_k.
\]

固定総作用

\[
\sum_{k=1}^nJ_k=A,
\qquad
J_k\geq0
\]

の未規格化 Liouville 殻容量を

\[
\Omega_n(A)
=
\int
\delta
\left(
A-\sum_{k=1}^nJ_k
\right)
\prod_{k=1}^n
dJ_k\,d\theta_k
\]

と定める。

\begin{theorem}[一般作用殻容量]
$A>0$ に対し、

$$
\Omega_n(A)
=
\frac{
(2\pi)^n
}{
(n-1)!
}
A^{n-1}.
$$
\end{theorem}

\begin{proof}
角変数の積分が $(2\pi)^n$ を与える。残る作用変数の積分は、$J_k\geq0$ と $\sum_kJ_k=A$ が作る $(n-1)$ 次元単体のデルタ測度であり、$A^{n-1}/(n-1)!$ である。
\end{proof}

このべき指数が Born 型重みと Bell 型重みを決める。

\hypertarget{ux5c40ux6240ux4f5cux7528ux3068ux6392ux4ed6ux7684ux5165ux53e3ux30c1ux30e3ux30f3ux30cdux30eb}{%
\section{局所作用と排他的入口チャンネル}\label{ux5c40ux6240ux4f5cux7528ux3068ux6392ux4ed6ux7684ux5165ux53e3ux30c1ux30e3ux30f3ux30cdux30eb}}

第3章の活性場強度をセル表示へ戻し、

\[
\sum_i r_i^2\Delta V
=
1
\]

とする。全入口作用 \(A_{\rm tot}>0\) をセルへ

\[
A_i
=
A_{\rm tot}r_i^2\Delta V
\]

と割り当てる。

入口反応面は

\[
\Gamma_\partial
=
\bigsqcup_i
\Gamma_{\partial,i}
\]

という排他的な和とする。1つの履歴が通過するのは1つの \(\Gamma_{\partial,i}\) だけである。他セルの入口殻を同時に積分しない。

比較器または反応座標は全チャンネルで共有する。粒子位置窓 \(\chi_i(X)\) が、セル \(i\) の活性モードと共有明反応座標を選択的に結合する。各排他的sectorで、活性側に残る作用を \(K_i\)、共有反応座標の作用を \(I\) とし、

\[
K_i+I=A_i
\]

を課す。

\hypertarget{ux30e2ux30fcux30c9ux6bbbux306eux7ddaux5f62ux5bb9ux91cf}{%
\section{2モード殻の線形容量}\label{ux30e2ux30fcux30c9ux6bbbux306eux7ddaux5f62ux5bb9ux91cf}}

\(n=2\) の一般定理から、

\[
\Omega_2(A_i)
=
(2\pi)^2A_i.
\]

正方向入口流束を

\[
\mathscr F_i
=
\int_{\Gamma_{\partial,i}}
\left(
\dot s_i
\right)_+
d\mu_i
\]

とする。\(s_i\) は反応面の法線座標、\(d\mu_i\) は作用殻、spectator自由度、coarea因子を含む誘導測度である。

作用殻の線形容量以外を流束因子 \(\lambda_i\) へまとめ、

\[
\mathscr F_i
=
\lambda_i\Omega_2(A_i)
\]

と書く。\(\lambda_i\) は、法線速度、障壁透過、反応面の向き、coarea Jacobian、spectatorモードの体積、有限入口窓を含む。

\begin{theorem}[2モード入口殻からの Born 型位置重み]
全チャンネルで

$$
\lambda_i=\lambda>0
$$

が成立し、各開始履歴を正方向入口通過として1回ずつ数えるなら、

$$
P_i
=
\frac{
\mathscr F_i
}{
\sum_j\mathscr F_j
}
=
r_i^2\Delta V.
$$

従ってセル平均の入口密度は

$$
\rho_{{\rm in},i}
=
r_i^2.
$$
\end{theorem}

\begin{proof}
共通 $\lambda$ と $\Omega_2(A_i)=(2\pi)^2A_i$ により、

$$
P_i
=
\frac{A_i}{\sum_jA_j}.
$$

$\sum_jA_j=A_{\rm tot}$ と $A_i=A_{\rm tot}r_i^2\Delta V$ を代入する。
\end{proof}

これは場強度を確率と定義した結果ではない。入口反応面を横切る Liouville 流束の相対頻度として得た結果である。

\hypertarget{ux5171ux901aux6d41ux675fux6761ux4ef6ux3068ux8aa4ux5dee}{%
\section{共通流束条件と誤差}\label{ux5171ux901aux6d41ux675fux6761ux4ef6ux3068ux8aa4ux5dee}}

一般には、基準流束因子 \(\lambda>0\) に対する相対偏差を

\[
\frac{\lambda_i}{\lambda}
=
1+\delta_i
\qquad
\sum_i
r_i^2\Delta V\,\delta_i
=
0
\]

と定義する。すると

\[
P_i
=
\frac{
r_i^2\Delta V
\left(
1+\delta_i
\right)
}{
\sum_j
r_j^2\Delta V
\left(
1+\delta_j
\right)
}.
\]

従って

\[
\varepsilon_{\rm flux}
=
\max_i|\delta_i|
\]

が Born 型重みからの主要な1次誤差になる。位置依存の障壁、セル体積、窓関数、法線速度を同じにしただけでは十分でなく、coarea Jacobian と解多重度も共通でなければならない。

\hypertarget{ux4f5cux7528ux5206ux914dux6b21ux5143ux306eux525bux6027}{%
\section{作用分配次元の剛性}\label{ux4f5cux7528ux5206ux914dux6b21ux5143ux306eux525bux6027}}

活性モードに加えて、作用を直接受け取る独立な明反応方向が \(q\) 個あるとする。固定総作用殻は \(q+1\) モードなので、

\[
\Omega_{q+1}(A_i)
\propto
A_i^q.
\]

\begin{proposition}[直接作用分配次元の剛性]
共通流束因子の下で、入口重みは

$$
P_i
\propto
\left(
r_i^2\Delta V
\right)^q.
$$

Born 型の線形則を得るには $q=1$ が必要である。
\end{proposition}

この結果は、任意に多数の比較器または明反応座標を追加できないことを示す否定的結果である。追加自由度が作用を直接分配せず、共通 spectator因子としてだけ現れるなら線形則を壊さない。

\hypertarget{ux30e2ux30fcux30c9ux6bbbux306eux7b49ux65b9ux6df7ux5408ux3068ux5883ux754cux5bc6ux5ea6}{%
\section{2モード殻の等方混合と境界密度}\label{ux30e2ux30fcux30c9ux6bbbux306eux7b49ux65b9ux6df7ux5408ux3068ux5883ux754cux5bc6ux5ea6}}

排他的チャンネル \(i\) で、選択された活性モードと共有明反応座標を

\[
a_i
=
\begin{pmatrix}
a_{{\rm A},i}\\
a_{\rm R}
\end{pmatrix}
\]

とする。2モード総作用は

\[
A_i
=
a_i^\dagger a_i.
\]

暗モード \(z_{\rm D}\) が殻接方向だけを混ぜる候補 Hamiltonian を

\[
H_{\rm mix}^{(i)}
=
\varepsilon_{\rm mix}
\chi_i(X)
\sum_\alpha
\xi_\alpha(z_{\rm D})
a_i^\dagger T_\alpha a_i
\]

とする。\(T_\alpha\) は \(u(2)\) の Hermitian 生成子である。

\[
\left\{
A_i,
H_{\rm mix}^{(i)}
\right\}
=
0
\]

なので、暗モードが混合を駆動しても2モード総作用は保存される。暗モードへ作用を直接移す座標結合は、\(K_i+I=A_i\) を壊すため採用しない。

Born 側で必要なのは、各排他的sectorの2モード殻全体に対する \(U(2)\) 等方性である。第6章の Bell 比較殻も2モード全殻を使うため、両者の容量は同じ線形則に従う。

ただし、等方混合とsector間の頻度を区別しなければならない。正規化された初期集団を Hamiltonian 写像で押し出しても、排他的sector \(i\) の総確率質量は保存される。\(U(2)\) 混合は殻上の角分布を変えるが、

\[
\mu_i
\longmapsto
\left(
\mathcal U_i
\right)_*\mu_i
\]

によって \(\mu_i(\Gamma_{\partial,i})\) を \(\Omega_2(A_i)\) 倍にはしない。従って、Born 型頻度には、全sectorへ共通の未規格化境界密度または共通流束を置く条件が別に必要である。第4.3節の \(\lambda_i=\lambda\) はこの条件を表す。

この区別は Bell 側でも同じである。2モード殻容量の線形性は厳密だが、容量に比例する境界測度を実験周期が準備することは未解決である。

\hypertarget{ux4e00ux822c-born-ux5247ux3068ux306eux533aux5225}{%
\section{一般 Born 則との区別}\label{ux4e00ux822c-born-ux5247ux3068ux306eux533aux5225}}

本章の結果は次に限定される。

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  位置入口チャンネルの標本頻度である。
\item
  2モード作用殻と1つの直接作用分配方向を使う。
\item
  チャンネル間で流束因子が共通である。
\item
  入口前に \(A_i=A_{\rm tot}r_i^2\Delta V\) が準備されている。
\item
  入口履歴を事後的に捨てない。
\end{enumerate}

任意基底、一般の射影測定、連続スペクトルの有限分解能、複合系の一般 Born 則は示していない。それでも、確率重みを場強度の定義として置かず、作用殻の次元と Liouville 流束から位置重みを出した点で部分達成である。

\hypertarget{ux6a19ux672cux5316ux5f8cux306eux518dux57cbux3081ux8fbcux307fux554fux984c}{%
\section{標本化後の再埋め込み問題}\label{ux6a19ux672cux5316ux5f8cux306eux518dux57cbux3081ux8fbcux307fux554fux984c}}

2モード殻を混合すると、活性側に残る作用 \(K_i\) は一般に標本化前の値と異なる。そのままでは、入口重みを与えた \(r_{\rm in}\) と、その後の位相接続力学を担う \(r\) が一致しない。

完全周期には、

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  結果情報を暗モードまたは記録器へ可逆に転送する。
\item
  活性場を同じ coherent部分空間へ再埋め込みする。
\item
  共有明反応座標を基準状態へ戻す。
\item
  全位相作用 \(\mathcal J_\phi\) と規格化を保つ。
\item
  結果別に履歴を捨てず、次試行を同じ準備分布から始める。
\end{enumerate}

ことが必要である。再埋め込み誤差を

\[
\varepsilon_{\rm reset}
\]

とする。本章は \(\varepsilon_{\rm reset}\) を有限 Hamiltonian 周期から小さくする構成を与えない。第6章の比較器では、結果を外部記録へコピーした後の理想的な逆計算を構成するが、入口側の活性場再埋め込みまで自動的に解決しない。

付録Eの準備浴は、再埋め込み後に残る局所作用欠陥 \(J_i-\mathcal J_\phi q_i\) と動径運動量 \(P_i\) を再び小さくする局所的な候補である。付録Fの同型高速モード交換補助系も、正定値2次模型では再埋め込み後の高速法線成分を完全に補助系へ移す候補になる。

しかし、どちらも標本化前の振幅 \(q_i\) 自体を復元せず、結果情報の可逆転送、共有明反応座標の復元、garbage処理、全チャンネルで偏りのない再準備を行わない。同型交換では、さらに補助系へ移った高速情報とエネルギーを次試行前に処理する必要がある。従って、再埋め込み問題を部分的な法線欠陥除去へ分解するが、\(\varepsilon_{\rm reset}\) 全体を解決しない。

\hypertarget{ux7269ux7406ux7a7aux9593ux4e0aux306e1ux3064ux306eux5834}{%
\section{物理空間上の1つの場}\label{ux7269ux7406ux7a7aux9593ux4e0aux306e1ux3064ux306eux5834}}

Bell 粒子対に対しても、基本的な場変数は物理空間上の2成分場

\[
\boldsymbol\Phi(x)
=
\begin{pmatrix}
\Phi_1(x)\\
\Phi_2(x)
\end{pmatrix}
\]

とその正準運動量だけである。2粒子の配置 \((X_A,X_B)\) 上に独立な場を置かない。

複素表示 \(\zeta=\Phi_1+i\Phi_2\) を用い、第2.12節の固定モード展開から左右へ進む局在モードを

\[
z^A_{\mu r},
\qquad
z^B_{\nu r},
\qquad
\mu,\nu\in\{+,-\},
\qquad
r\in\{1,2\}
\]

とする。\(\mu,\nu\) は各局所分析器の2出力モード、\(r\) は互いに直交する源チャンネルである。源チャンネルは、同じ場の異なる周波数、時間スロット、空間正規モードなどとして実装できる。

モード射影は場の正準1形式から誘導される。同じ固定直交基底を場座標と場運動量へ用いる限り、有限モード係数は正準である。設定または結果ごとに基底を選び直さない。

\hypertarget{ux4f4eux30e9ux30f3ux30afux76f8ux95a2ux884cux5217}{%
\section{低ランク相関行列}\label{ux4f4eux30e9ux30f3ux30afux76f8ux95a2ux884cux5217}}

左右モードの相関を

\[
C_{\mu\nu}
=
\sum_{r=1}^{2}
\eta_r
z^A_{\mu r}
\left(
z^B_{\nu r}
\right)^*
\]

と定める。行列表示では

\[
C
=
\sum_{r=1}^{2}
\eta_r
z^{A,(r)}
\left(
z^{B,(r)}
\right)^\dagger.
\]

従って \(\operatorname{rank}C\leq2\) である。

\(C\) は独立した場ではない。基礎モード \(z^A,z^B\) から計算される派生量であり、独自の Poisson 括弧または独自の運動方程式を与えない。共通内部回転

\[
z^A
\longmapsto
e^{i\beta}z^A,
\qquad
z^B
\longmapsto
e^{i\beta}z^B
\]

に対し、\(C\) は不変である。この共役規約により、比較 Hamiltonian と保存位相作用 \(\mathcal J_\phi\) の対称性を両立できる。

\hypertarget{ux53cdux5bfeux79f0ux6e90}{%
\section{反対称源}\label{ux53cdux5bfeux79f0ux6e90}}

理想源が準備する相関行列を

\[
C_0
=
\sqrt{\frac{\mathcal K}{2}}
\begin{pmatrix}
0&1\\
-1&0
\end{pmatrix},
\qquad
\mathcal K>0
\]

とする。これは2つのランク1項へ

\[
C_0
=
\sqrt{\frac{\mathcal K}{2}}
\left[
e_+e_-^{\mathsf T}
-
e_-e_+^{\mathsf T}
\right]
\]

と分解できる。従って、2つの直交源チャンネルで実係数の代表点を準備すれば、低ランク構成から \(C_0\) を得られる。

この節で厳密なのは、準備された2チャンネルから \(C_0\) を合成する代数である。場と対生成装置の有限 Hamiltonian が、任意の初期状態からこの反対称源へ到達することは別の準備問題である。相対位相が失われると2チャンネル間の干渉項が消えるため、源から比較器までの位相保持が必要である。

\hypertarget{ux5de6ux53f3ux306eux5c40ux6240ux5206ux6790ux5668}{%
\section{左右の局所分析器}\label{ux5de6ux53f3ux306eux5c40ux6240ux5206ux6790ux5668}}

設定 \(a,b\) に対応するモード角を \(\alpha_a,\alpha_b\) とする。左右の分析器は局所モードだけを

\[
z^{A,(r)}
\longmapsto
R(\alpha_a)z^{A,(r)},
\]

\[
z^{B,(r)}
\longmapsto
R(\alpha_b)z^{B,(r)}
\]

と回転する。ここで

\[
R(\alpha)
=
\begin{pmatrix}
\cos\alpha&-\sin\alpha\\
\sin\alpha&\cos\alpha
\end{pmatrix}.
\]

相関行列の表示は

\[
C(a,b)
=
R(\alpha_a)
C_0
R(\alpha_b)^{\mathsf T}
\]

となるが、物理的に回しているのは \(C\) ではなく、A側とB側の局所場モードである。

A側の正準座標を \((Q^A_{\mu r},P^A_{\mu r})\) とすれば、回転生成子を

\[
G_A
=
\sum_r
\left(
Q^A_{+r}P^A_{-r}
-
Q^A_{-r}P^A_{+r}
\right)
\]

と書ける。局所 Hamiltonian

\[
H_A
=
\dot\alpha_a(\vartheta)G_A
\]

がA側だけの回転を生成する。B側も同様であり、

\[
H_{\rm analyzer}
=
H_A(a)+H_B(b)
\]

は空間的に分離した局所和である。

\hypertarget{ux7d50ux679cux679dux632fux5e45}{%
\section{結果枝振幅}\label{ux7d50ux679cux679dux632fux5e45}}

結果ポート \(A,B\in\{+1,-1\}\) の基底ベクトルを \(e_A,e_B\) とする。結果組 \((A,B)\) に対応する相関振幅を

\[
C_{AB}(a,b)
=
e_A^{\mathsf T}
C(a,b)
e_B
\]

と定め、枝作用を

\[
K_{AB}
=
|C_{AB}|^2
\]

とする。

\begin{theorem}[反対称対モードの余弦作用]
反対称源 $C_0$ と実回転 $R(\alpha_a)$、$R(\alpha_b)$ の下で、

$$
K_{AB}
=
\frac{\mathcal K}{4}
\left[
1-AB\cos\Delta_{ab}
\right],
$$

$$
\Delta_{ab}
=
2
\left(
\alpha_a-\alpha_b
\right)
$$

が成立する。さらに、

$$
\sum_{A,B}K_{AB}
=
\mathcal K,
\qquad
\sum_BK_{AB}
=
\sum_AK_{AB}
=
\frac{\mathcal K}{2}.
$$
\end{theorem}

\begin{proof}
$\delta=\alpha_a-\alpha_b$ とする。反対称行列と回転の積を直接計算すると、同符号ポートでは

$$
K_{++}
=
K_{--}
=
\frac{\mathcal K}{2}\sin^2\delta,
$$

異符号ポートでは

$$
K_{+-}
=
K_{-+}
=
\frac{\mathcal K}{2}\cos^2\delta
$$

を得る。$\cos2\delta=\cos\Delta_{ab}$ を用いれば主式が従う。総和と周辺和は主式を符号について足せばよい。
\end{proof}

この定理は、設定依存する余弦作用の生成を局所モード回転から与える。結果頻度はまだ与えない。

\hypertarget{ux7269ux7406ux89d2ux3068ux306eux5bfeux5fdc}{%
\section{物理角との対応}\label{ux7269ux7406ux89d2ux3068ux306eux5bfeux5fdc}}

数式中の基本角はモード回転角 \(\alpha\) であり、観測装置の表示角と常に同じとは限らない。

\begin{itemize}
\tightlist
\item
  光子偏光型では \(\alpha_a=a\)、\(\alpha_b=b\) と置けば、\(\Delta_{ab}=2(a-b)\) となる。
\item
  平面内のスピン型測定では \(\alpha_a=a/2\)、\(\alpha_b=b/2\) と置けば、\(\Delta_{ab}=a-b\) となる。
\end{itemize}

この対応を固定せずに \(\Delta_{ab}\) を物理角と呼ぶと、余弦の角度が2倍ずれる。本論文では、一般式では \(\Delta_{ab}\) を用い、特定実験との比較時に \(\alpha(a)\) を明示する。

\hypertarget{ux5c40ux6240ux7d50ux679cux3068ux5171ux540cux91cfux306eux5f79ux5272ux5206ux62c5}{%
\section{局所結果と共同量の役割分担}\label{ux5c40ux6240ux7d50ux679cux3068ux5171ux540cux91cfux306eux5f79ux5272ux5206ux62c5}}

A側の局所装置だけでは \(C_{AB}\) を計算できない。B側のモードも必要だからである。従って \(K_{AB}\) を空間的に離れた測定時刻の瞬間的な局所力へ使わない。

局所測定窓では、各側が次を行う。

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  設定に応じて局所モードを回転する。
\item
  2つの出力ポートを形成する。
\item
  既存の局所結果sector \(A\) または \(B\) を指針へ記録する。
\item
  結果ポートと源チャンネルの振幅を戻りモードへ写す。
\end{enumerate}

本論文の局所装置は、既存の2値結果sectorをポートと記録へ符号化する最小模型である。連続したミクロ状態から安定な唯一結果を形成する一般測定器は構成していない。

\hypertarget{ux6709ux9650ux4f1dux64adux3068ux5171ux901aux672aux6765}{%
\section{有限伝播と共通未来}\label{ux6709ux9650ux4f1dux64adux3068ux5171ux901aux672aux6765}}

左右の戻りモードは、局所記録後に有限速度で共通未来領域へ伝播する。遅延応答を記号的に

\[
z_{\rm ret}^{A}(t)
=
\int
G_A(t-s)z_{\rm out}^{A}(s)\,ds,
\]

\[
z_{\rm ret}^{B}(t)
=
\int
G_B(t-s)z_{\rm out}^{B}(s)\,ds
\]

と書く。\(G_A,G_B\) の支持は、各局所測定から共通未来比較窓までの伝播時間より前に現れない。

理想式では比較窓で

\[
z_{\rm ret}^{A}
=
z_{\rm out}^{A},
\qquad
z_{\rm ret}^{B}
=
z_{\rm out}^{B}
\]

となる規格化を用いる。損失、分散、チャンネル混合、相対位相ずれは第8章の誤差へ含める。

\hypertarget{ux4f4dux76f8ux96d1ux97f3ux3068ux53efux8996ux5ea6}{%
\section{位相雑音と可視度}\label{ux4f4dux76f8ux96d1ux97f3ux3068ux53efux8996ux5ea6}}

2つの源チャンネルの相対位相に揺らぎ \(\varphi\) があると、干渉項は

\[
\chi_\phi
=
\left\langle
e^{i\varphi}
\right\rangle
\]

で減衰する。対称な位相雑音で \(\chi_\phi\) が実なら、

\[
K_{AB}
=
\frac{\mathcal K}{4}
\left[
1
-
ABV_\phi\cos\Delta_{ab}
\right],
\qquad
V_\phi
=
\chi_\phi.
\]

戻り伝達の左右利得が異なる場合は、総規格化と可視度の両方が変わる。理想 Bell 法則には、結果と設定によらない共通利得、および十分小さい相対位相雑音が必要である。

\hypertarget{ux672cux7ae0ux306eux7d50ux8ad6}{%
\section{本章の結論}\label{ux672cux7ae0ux306eux7d50ux8ad6}}

同じ物理空間上の2成分場から、2つの直交源チャンネルと左右の固定出力モードを切り出すことで、独立な6次元場を使わず Bell 余弦作用を構成できる。低ランク相関 \(C\) は派生量であり、左右の局所分析器は基礎場モードだけを回す。

ここまでで得たのは \(K_{AB}\) の生成である。\(K_{AB}\) を共通未来で物理的な比較作用へ写し、完全履歴の境界測度と結ぶ過程を第6章と第7章で扱う。

\hypertarget{ux5171ux901aux672aux6765ux6bd4ux8f03ux5668ux30682ux30e2ux30fcux30c9ux5883ux754cux4f5cux7528ux6bbb}{%
\chapter{共通未来比較器と2モード境界作用殻}\label{ux5171ux901aux672aux6765ux6bd4ux8f03ux5668ux30682ux30e2ux30fcux30c9ux5883ux754cux4f5cux7528ux6bbb}}

\begin{statusbox}
位置づけ：理想比較パルスによる相関振幅の非反作用読み出し、比較総作用と Bell 枝作用の比例、2モード殻容量、比較器の理想逆計算は補助模型内部で厳密である。等方な境界集団と共通境界密度の物理的準備は未完成である。
\end{statusbox}

\hypertarget{ux5171ux901aux672aux6765ux306eux5883ux754cux6bd4ux8f03ux30e2ux30fcux30c9}{%
\section{共通未来の境界比較モード}\label{ux5171ux901aux672aux6765ux306eux5883ux754cux6bd4ux8f03ux30e2ux30fcux30c9}}

左右の戻り信号が局所的な有限伝播で合流できる領域は、両測定事象の共通未来にある。比較器は空間全体に瞬間的に共有された自由度ではなく、共通未来のreset領域へ局在した、同じ2成分誘導場の境界集団モードとする。

比較振幅の実部と虚部を読む2つの正準対を

\[
(Q_{\rm R},P_{\rm R}),
\qquad
(Q_{\rm I},P_{\rm I})
\]

とする。これらは局所測定中には暗く、比較窓だけ戻りモードへ結合する。

局所結果座標を \(s_A,s_B\) とし、結果sectorで1となる滑らかな窓を \(\chi_A(s_A)\)、\(\chi_B(s_B)\) とする。選択された戻り相関振幅を

\[
C(s_A,s_B)
=
\sum_{A,B}
\chi_A(s_A)
\chi_B(s_B)
C_{AB}
\]

と定める。排他的な理想sectorでは、1つの履歴について \(C(s_A,s_B)=C_{AB}\) である。

\hypertarget{ux7406ux60f3ux6bd4ux8f03-hamiltonian}{%
\section{理想比較 Hamiltonian}\label{ux7406ux60f3ux6bd4ux8f03-hamiltonian}}

比較読み出しを

\[
H_{\rm read}
=
g_{\rm read}(\vartheta)
\left[
P_{\rm R}\operatorname{Re}C(s_A,s_B)
+
P_{\rm I}\operatorname{Im}C(s_A,s_B)
\right]
\]

とする。\(\vartheta\) は試行周期を制御する時計角である。比較窓の入口条件を

\[
Q_{\rm R}
=
P_{\rm R}
=
Q_{\rm I}
=
P_{\rm I}
=
0
\]

とする。

Hamilton 方程式は

\[
\dot Q_{\rm R}
=
g_{\rm read}(\vartheta)
\operatorname{Re}C,
\qquad
\dot Q_{\rm I}
=
g_{\rm read}(\vartheta)
\operatorname{Im}C,
\]

\[
\dot P_{\rm R}
=
\dot P_{\rm I}
=
0.
\]

入力戻りモード \(z\) への反作用は

\[
\dot z\big|_{\rm read}
=
\left\{
z,H_{\rm read}
\right\}
\]

であり、右辺は \(P_{\rm R}\) または \(P_{\rm I}\) に比例する。両運動量は初期に零で、そのまま零なので、理想パルス中の入力モードは変化しない。

\begin{theorem}[理想比較読み出し]
比較窓で他の自由発展を無視でき、$C=C_{AB}$ が一定なら、

$$
\Gamma
=
\int_{\rm read}
g_{\rm read}(t)\,dt
$$

に対して

$$
Q_{\rm R}^{\rm out}
=
\Gamma\operatorname{Re}C_{AB},
\qquad
Q_{\rm I}^{\rm out}
=
\Gamma\operatorname{Im}C_{AB},
$$

$$
P_{\rm R}^{\rm out}
=
P_{\rm I}^{\rm out}
=
0
$$

が厳密に成立する。理想パルス中、入力戻りモードは変化しない。
\end{theorem}

\begin{proof}
$P_{\rm R}=P_{\rm I}=0$ は Hamilton 方程式により保存されるため、入力モードへの反作用は零である。従って $C$ は比較結合によって変化しない。$Q_{\rm R}$ と $Q_{\rm I}$ の方程式を比較窓で積分する。
\end{proof}

\(C\) は共通内部回転に不変なので、中性な比較正準対を用いた \(H_{\rm read}\) も共通内部回転に不変である。従って理想比較は保存位相作用 \(\mathcal J_\phi\) を壊さない。

\hypertarget{ux6bd4ux8f03ux7dcfux4f5cux7528}{%
\section{比較総作用}\label{ux6bd4ux8f03ux7dcfux4f5cux7528}}

比較2モードの作用を

\[
J_{\rm R}
=
\frac12
\left(
Q_{\rm R}^2+P_{\rm R}^2
\right),
\qquad
J_{\rm I}
=
\frac12
\left(
Q_{\rm I}^2+P_{\rm I}^2
\right)
\]

とし、総作用を

\[
A_\partial
=
J_{\rm R}+J_{\rm I}
\]

とする。

\begin{corollary}[比較作用への転送]
理想比較読み出し後の結果sector $(A,B)$ では、

$$
A_\partial^{AB}
=
\frac{\Gamma^2}{2}
|C_{AB}|^2
=
\frac{\Gamma^2}{2}K_{AB}.
$$
\end{corollary}

第5章の余弦作用を代入すると、

\[
A_\partial^{AB}
=
\frac{\Gamma^2\mathcal K}{8}
\left[
1-AB\cos\Delta_{ab}
\right].
\]

旧3モード模型の基準作用 \(J_*\) は現れない。結果依存作用を比較2モードの総作用へ直接転送するからである。

\hypertarget{ux30e2ux30fcux30c9ux5185ux90e8ux306eux4f5cux7528ux4fddux5b58ux6df7ux5408}{%
\section{2モード内部の作用保存混合}\label{ux30e2ux30fcux30c9ux5185ux90e8ux306eux4f5cux7528ux4fddux5b58ux6df7ux5408}}

複素比較モードを

\[
c_\partial
=
\begin{pmatrix}
c_{\rm R}\\
c_{\rm I}
\end{pmatrix},
\qquad
c_\nu
=
\frac{
Q_\nu+iP_\nu
}{
\sqrt2
}
\]

とする。\(A_\partial=c_\partial^\dagger c_\partial\) である。

同じ誘導場の未読暗モード \(z_{\rm D}\) が混合角を供給する候補 Hamiltonian を

\[
H_{\rm mix}
=
g_{\rm mix}(\vartheta)
\sum_\alpha
\xi_\alpha(z_{\rm D})
c_\partial^\dagger
T_\alpha
c_\partial
\]

とする。\(T_\alpha\) は \(u(2)\) の Hermitian 生成子である。

\begin{proposition}[比較総作用の保存]
暗モード変数が比較正準対と独立なら、

$$
\left\{
A_\partial,
H_{\rm mix}
\right\}
=
0.
$$
\end{proposition}

従って混合は比較2モード殻に接し、\(A_\partial^{AB}\) を変えない。

暗モードの初期角度集団と制御された \(U(2)\) 変換の押し出しが Haar 分布を与えるなら、各固定 \(A_\partial^{AB}\) 殻上で一様な角分布を準備できる。ただし、単一位相点の決定論的 Hamiltonian 発展が確率分布を無から生成するわけではない。必要なのは暗モードを含む初期集団の準備である。

\hypertarget{ux30e2ux30fcux30c9ux6bbbux5bb9ux91cf}{%
\section{2モード殻容量}\label{ux30e2ux30fcux30c9ux6bbbux5bb9ux91cf}}

一般作用殻定理の \(n=2\) の場合から、

\[
\Omega_2(A)
=
(2\pi)^2A,
\qquad
A>0.
\]

従って、

\[
\Omega_2
\left(
A_\partial^{AB}
\right)
=
(2\pi)^2
\frac{\Gamma^2}{2}
K_{AB}.
\]

\begin{corollary}[Bell 比較殻の線形容量]
理想比較模型では、

$$
\Omega_2^{AB}
\propto
K_{AB}.
$$
\end{corollary}

比較に直接参加する作用分配方向は、実部と虚部を受ける2モードだけでなければならない。追加暗モードが \(A_\partial^{AB}\) を直接分配すると、\(n>2\) の一般式により容量は \(K_{AB}\) の高いべきとなる。追加自由度は混合角、時計、位相保持、記録、garbageだけを担う。

\hypertarget{ux8aadux307fux51faux3057ux5199ux50cfux6df7ux5408ux5883ux754cux6e2cux5ea6ux306eux533aux5225}{%
\section{読み出し写像、混合、境界測度の区別}\label{ux8aadux307fux51faux3057ux5199ux50cfux6df7ux5408ux5883ux754cux6e2cux5ea6ux306eux533aux5225}}

3つの操作を区別する。

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \(H_{\rm read}\) は、空の比較器を固定殻上の1点へ移す。
\item
  \(H_{\rm mix}\) は、準備された集団を同じ殻上で混ぜる。
\item
  境界測度は、異なる結果sectorと異なる殻の間に未規格化質量を置く。
\end{enumerate}

1と2は Hamiltonian 写像である。正規化された各sectorの集団 \(\mu_{AB}\) に対し、

\[
\mu_{AB}
\longmapsto
\left(
\mathcal U_{AB}
\right)_*
\mu_{AB}
\]

としても、

\[
\left(
\mathcal U_{AB}
\right)_*
\mu_{AB}
\left(
\Gamma^{AB}
\right)
=
\mu_{AB}
\left(
\Gamma^{AB}
\right)
\]

である。従って、読み出しと \(U(2)\) 混合だけでは、sector総質量を \(\Omega_2(A_\partial^{AB})\) に比例させられない。

Bell 重みには、比較殻上へ全sector共通の未規格化密度または流束を置く境界準備条件が別に必要である。この条件を第7章で明示する。殻容量と頻度を同一視しないことが、本改訂の中心的な制限である。

\hypertarget{ux6709ux9650ux30d1ux30ebux30b9ux3068ux521dux671fux6761ux4ef6ux306eux8aa4ux5dee}{%
\section{有限パルスと初期条件の誤差}\label{ux6709ux9650ux30d1ux30ebux30b9ux3068ux521dux671fux6761ux4ef6ux306eux8aa4ux5dee}}

理想読み出しからの主なずれは次である。

\begin{itemize}
\tightlist
\item
  比較器の初期座標 \(Q_\nu^{\rm in}\)。
\item
  比較器の初期運動量 \(P_\nu^{\rm in}\)。
\item
  比較中の入力モード自由発展。
\item
  比較モード自身の自由発展。
\item
  有限幅の結果窓 \(\chi_A,\chi_B\)。
\item
  戻りモードの損失、分散、交差混合。
\item
  時計パルス面積 \(\Gamma\) の試行差。
\end{itemize}

相対誤差を \(\varepsilon_{\rm pulse}\) とまとめると、

\[
A_\partial^{AB}
=
\frac{\Gamma^2}{2}
K_{AB}
\left[
1+O(\varepsilon_{\rm pulse})
\right]
+
A_{\rm bg}^{AB}.
\]

\(A_{\rm bg}^{AB}\) は初期比較振幅と非理想自由発展から生じる背景作用である。結果依存の背景は余弦可視度だけでなく周辺対称性も壊し得る。

理想式で \(K_{AB}=0\) となるsectorは殻の端にある。有限分解能、初期比較幅、読み出し雑音があると零作用の点に有限背景が生じるため、端点近傍は独立に評価する。

\hypertarget{ux6642ux8a08ux30681ux56deux306eux6bd4ux8f03ux7a93}{%
\section{時計と1回の比較窓}\label{ux6642ux8a08ux30681ux56deux306eux6bd4ux8f03ux7a93}}

時計正準対を \((\vartheta,I_\vartheta)\) とし、

\[
H_{\rm clk}
=
\Omega I_\vartheta
\]

とする。すると \(\dot\vartheta=\Omega\) である。各相互作用を時計角の互いに重ならない窓関数 \(g_k(\vartheta)\) で作動させる。

比較反応面を

\[
\Gamma_\partial
=
\left\{
\vartheta=\vartheta_\partial,
\quad
\dot\vartheta>0
\right\}
\]

とする。1周期に時計角が1度だけこの面を横切る構成なら、比較イベントの重複計数を防げる。ただし、全初期履歴がこの面へ到達することと、結果別に失敗履歴を捨てないことは別に監査する必要がある。

\hypertarget{ux5c40ux6240ux8a18ux9332ux3068ux6bd4ux8f03ux306eux9806ux5e8f}{%
\section{局所記録と比較の順序}\label{ux5c40ux6240ux8a18ux9332ux3068ux6bd4ux8f03ux306eux9806ux5e8f}}

左右の指針を \((Y_A,\Pi_A)\)、\((Y_B,\Pi_B)\) とする。局所記録 Hamiltonian の代表形を

\[
H_{\rm rec}
=
-g_A(\vartheta)Y_A\sigma_A(s_A)
-
g_B(\vartheta)Y_B\sigma_B(s_B)
\]

とする。パルス面積を1に規格化すれば、理想sectorで

\[
\Pi_A^{\rm out}=A,
\qquad
\Pi_B^{\rm out}=B
\]

を得る。

この記録は、戻り信号が共通未来比較器へ到達する前に局所的に作れる。比較器は記録内容を前向きに変更しない。共同頻度に比較作用を使うには、試行全体へ置く二側境界測度として解釈しなければならない。

\hypertarget{ux53efux9006ux306aux6bd4ux8f03ux5668ux9006ux8a08ux7b97}{%
\section{可逆な比較器逆計算}\label{ux53efux9006ux306aux6bd4ux8f03ux5668ux9006ux8a08ux7b97}}

境界通過後、結果を空の外部記録セル \((M_A,M_B)\) へ可逆にコピーする。その後、

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \(U(2)\) 混合を逆実行する。
\item
  比較読み出しを \(-H_{\rm read}\) で逆実行する。
\item
  戻り伝達を逆実行する。
\item
  局所分析器を逆実行する。
\item
  内部指針と結果座標を基準状態へ戻す。
\end{enumerate}

混合の制御履歴と暗モード状態を保持し、正確な逆変換を実行できる理想模型では、読み出し前の

\[
Q_{\rm R}
=
Q_{\rm I}
=
P_{\rm R}
=
P_{\rm I}
=
0
\]

へ戻る。入力戻りモードは理想読み出しで乱されていないため、比較器の逆計算は有限 Hamiltonian で構成できる。

ただし、異なる結果を外部に残したまま、外部記録も含む全自由度を同じ1点へ戻すことはできない。Hamiltonian flowは1対1だからである。反復には、大きな記録テープ、garbageモード、仕事源、弱く結合した環境のいずれかが必要である \cite{landauer1961,bennett1982}。

\hypertarget{ux81eaux5f8bux7684ux306aux5168-hamiltonian}{%
\section{自律的な全 Hamiltonian}\label{ux81eaux5f8bux7684ux306aux5168-hamiltonian}}

試行周期の有限部分は概略

\[
\begin{aligned}
H_{\rm cycle}
={}&
H_{\rm particles}
+
H_{\rm field}
+
H_{\rm prep}
+
H_{\rm source}
+
H_{\rm analyzer}
+
H_{\rm pointer}\\
&
+
H_{\rm return}
+
H_{\rm read}
+
H_{\rm mix}
+
H_{\rm memory}
+
H_{\rm reset}
+
H_{\rm clk}
\end{aligned}
\]

と書ける。外部時間依存を時計角依存 \(g_k(\vartheta)\) へ置換し、時計と仕事源を全系に含めれば、自律的な有限 Hamiltonian として表現できる。

\(H_{\rm prep}\) は、付録Eの有限振幅浴・作用交換浴と、付録Fの高速部分・同型補助部分・交換結合を含み得る。観測窓ではこれらを切り離す。高速交換補助系へ移った情報とエネルギーは、比較器の理想逆計算では消えないため、試行間の再初期化対象に含める。

本章は各項の理想部分と順序を与えるが、全ての窓を同時に滑らかで有限幅にし、交差誤差、記録安定性、境界測度準備、長期resetを一様に制御する完成模型は与えない。

\hypertarget{ux672cux7ae0ux306eux7d50ux8ad6-1}{%
\section{本章の結論}\label{ux672cux7ae0ux306eux7d50ux8ad6-1}}

共通未来の2つの境界比較モードは、Bell 相関振幅の実部と虚部を、入力戻りモードを理想的には乱さず比較総作用へ転送する。その2モード殻容量は \(K_{AB}\) に線形であり、旧3モード模型の基準作用を必要としない。

一方、Hamiltonian 読み出しと殻内混合は、結果sector間の確率質量を作らない。Bell 頻度には共通境界測度の準備が別に必要である。

\hypertarget{ux5883ux754cux4f4dux76f8ux7a7aux9593}{%
\section{境界位相空間}\label{ux5883ux754cux4f4dux76f8ux7a7aux9593}}

1試行の全正準変数を \(z\in\Gamma_{\rm all}\) とする。これには、粒子、2成分場、源、左右分析器、指針、戻りモード、比較モード、時計、記録、spectator自由度を含む。

結果sectorを排他的な和

\[
\Gamma_\partial
=
\bigsqcup_{A,B}
\Gamma_\partial^{AB}
\]

とする。各 \(\Gamma_\partial^{AB}\) では、局所記録は \((A,B)\) を持ち、時計は比較境界面を正方向に横切り、比較総作用制約

\[
J_{\rm R}+J_{\rm I}
=
A_\partial^{AB}
\]

を満たす。

基準 Liouville 体積を

\[
d\Gamma_{\rm cmp}
=
dQ_{\rm R}\,dP_{\rm R}\,
dQ_{\rm I}\,dP_{\rm I}
\]

とし、残る自由度、時計流束、境界面、coarea因子を境界密度 \(\lambda_\partial^{AB}(z;a,b)\) へまとめる。

\hypertarget{ux672aux898fux683cux5316ux7d50ux679cux8ceaux91cf}{%
\section{未規格化結果質量}\label{ux672aux898fux683cux5316ux7d50ux679cux8ceaux91cf}}

結果sectorの基準多重度を \(w_{AB}\geq0\) とする。未規格化結果質量を

\[
\widetilde W_{AB}(a,b)
=
w_{AB}
\int
\lambda_\partial^{AB}(z;a,b)
\delta
\left(
A_\partial^{AB}
-
J_{\rm R}
-
J_{\rm I}
\right)
d\Gamma_{\rm cmp}
d\Gamma_{\rm spec}
\]

と定める。\(\Gamma_{\rm spec}\) は、結果依存作用を直接分配しない自由度を表す。

理想共通条件は

\[
w_{AB}
=
\frac14,
\]

\[
\lambda_\partial^{AB}(z;a,b)
=
\lambda_\partial(z;a,b)
\]

である。共通因子は設定 \(a,b\) に依存しても、4つの結果sectorで同じなら規格化で相殺する。ただし、作用分配座標に対して一定であるか、積分後の因子が全sectorで等しい必要がある。

\(w_{AB}\) は、正規化済みの前向き初期集団が各sectorに持つ事前確率を意味しない。境界位相空間の各 Liouville 要素へ置く共通の基準密度または解多重度である。この区別をしないと、Hamiltonian 写像が保存するsector総質量と、未規格化殻容量を二重に数える。

\hypertarget{ux30e2ux30fcux30c9ux5883ux754cux6bbbux304bux3089ux306eux5171ux540cux78baux7387}{%
\section{2モード境界殻からの共同確率}\label{ux30e2ux30fcux30c9ux5883ux754cux6bbbux304bux3089ux306eux5171ux540cux78baux7387}}

\begin{theorem}[共通境界測度下の Bell 共同確率]
次を仮定する。

1. 第5章の余弦作用 $K_{AB}$。
2. 第6章の理想転送 $A_\partial^{AB}=\Gamma^2K_{AB}/2$。
3. $w_{AB}=1/4$。
4. 境界密度、時計流束、coarea Jacobian、spectator体積、解多重度が4つの結果sectorで共通。
5. 全sectorを同じ境界分解能で数える。

このとき、

$$
P(A,B\mid a,b)
=
\frac{
\widetilde W_{AB}
}{
\sum_{A',B'}
\widetilde W_{A'B'}
}
=
\frac14
\left[
1-AB\cos\Delta_{ab}
\right].
$$
\end{theorem}

\begin{proof}
共通因子を $\Lambda_\partial(a,b)>0$ とまとめると、2モード殻容量から

$$
\widetilde W_{AB}
=
\frac14
\Lambda_\partial
(2\pi)^2
A_\partial^{AB}
\propto
K_{AB}.
$$

第5章の総和 $\sum_{A,B}K_{AB}=\mathcal K$ により、

$$
P(A,B\mid a,b)
=
\frac{K_{AB}}{\mathcal K}.
$$

余弦作用を代入する。
\end{proof}

この定理は、共通境界条件を置いた後の厳密結果である。境界条件自体を前向き初期分布から導いた結果ではない。

\hypertarget{ux76f8ux95a2ux3068-chsh-ux5024}{%
\section{相関と CHSH 値}\label{ux76f8ux95a2ux3068-chsh-ux5024}}

共同確率から

\[
E(a,b)
=
\sum_{A,B}
AB
P(A,B\mid a,b)
=
-\cos\Delta_{ab}
\]

を得る。

有効角が

\[
\Delta_{ab}
=
-\frac{\pi}{4},
\qquad
\Delta_{ab'}
=
\frac{\pi}{4},
\]

\[
\Delta_{a'b}
=
\frac{\pi}{4},
\qquad
\Delta_{a'b'}
=
\frac{3\pi}{4}
\]

となる4設定を選べば、

\[
\left|
E(a,b)
+
E(a,b')
+
E(a',b)
-
E(a',b')
\right|
=
2\sqrt2.
\]

これは理想余弦法則の CHSH 値である。任意の測定集合または一般的な Tsirelson 原理を古典模型から導いたことを意味しない。現模型は2出力の平面内回転に限定される。

位相可視度、戻り損失、背景作用を含めて

\[
E(a,b)
=
-V_{\rm Bell}\cos\Delta_{ab}
\]

となる場合、標準角で

\[
|S_{\rm CHSH}|
=
2\sqrt2V_{\rm Bell}.
\]

古典上限を超えるには \(V_{\rm Bell}>1/\sqrt2\) が必要である。

\hypertarget{ux975eux4fe1ux53f7ux5468ux8fba}{%
\section{非信号周辺}\label{ux975eux4fe1ux53f7ux5468ux8fba}}

\begin{corollary}[対称共通境界測度下の非信号性]
第7.3節の条件の下で、

$$
\sum_B
P(A,B\mid a,b)
=
\frac12,
$$

$$
\sum_A
P(A,B\mid a,b)
=
\frac12.
$$

従って観測周辺は遠隔設定に依存しない。
\end{corollary}

\begin{proof}
余弦共同確率を反対側の符号について足すと、$AB\cos\Delta_{ab}$ の項が相殺する。
\end{proof}

この非信号性は、結果sectorの対称性と共通因子に依存する。結果依存の境界密度、異なる coarea Jacobian、非対称な基準多重度、結果別の比較失敗率がある場合、非信号性は自動的に成立しない。

\hypertarget{ux5b8cux5168ux5c65ux6b74ux6e2cux5ea6}{%
\section{完全履歴測度}\label{ux5b8cux5168ux5c65ux6b74ux6e2cux5ea6}}

設定 \(a,b\) を固定した Hamiltonian 境界値問題の解空間を \(\mathcal S_{a,b}\) とし、境界位相点から完結履歴への解写像を

\[
\mathfrak S_{a,b}:
\Gamma_\partial^{a,b}
\longrightarrow
\mathcal S_{a,b}
\]

とする。完全履歴測度は、境界 Liouville 測度を作用制約と境界密度で重み付けし、解写像で押し出して定める。

\[
\mu_{\rm hist}^{a,b}
=
\left(
\mathfrak S_{a,b}
\right)_*
\mu_\partial^{a,b}.
\]

解空間へ直接 Liouville 測度を置くわけではない。解の非一意性、分岐、多重度、coarea Jacobian は \(\lambda_\partial\) に含め、結果と設定で共通かを監査する。

\hypertarget{ux751fux6210ux5074ux3078ux306eux5f15ux304dux623bux3057ux3068ux6e2cux5b9aux8a2dux5b9aux72ecux7acbux6027}{%
\section{生成側への引き戻しと測定設定独立性}\label{ux751fux6210ux5074ux3078ux306eux5f15ux304dux623bux3057ux3068ux6e2cux5b9aux8a2dux5b9aux72ecux7acbux6027}}

境界面から生成側準備面までの Hamiltonian flowを \(\Phi_{T\leftarrow0}^{a,b}\) とする。境界測度を準備面へ引き戻すと、

\[
\mu_{\rm prep}^{a,b}
=
\left(
\Phi_{T\leftarrow0}^{a,b}
\right)^*
\mu_\partial^{a,b}.
\]

作用制約 \(A_\partial^{AB}\) は \(a,b\) に依存するため、一般に

\[
\rho(\Lambda\mid a,b)
\neq
\rho(\Lambda).
\]

従って、Bell の前提違反は測定設定独立性にある。Bell の定理、CHSH不等式、時間対称境界条件、測定設定独立性を緩める模型との関係は \cite{bell1964,chsh1969,wharton2010,wharton_argaman2020,hall2010,leifer_pusey2017,wood_spekkens2015,price_wharton2023,price_wharton2024,argaman2010,hossenfelder_palmer2020} に対応する。

局所結果応答を十分な局所変数について

\[
A
=
A(a,\Lambda_A),
\qquad
B
=
B(b,\Lambda_B)
\]

と書ける理想模型では、測定時の直接相互作用を空間的に局所に保てる。Bell 違反は、設定に依存する完全履歴集団から生じる。これは Bell の定理を否定せず、その前提の1つを明示的に外す構成である。

\hypertarget{ux5171ux901aux672aux6765ux6bd4ux8f03ux5668ux306eux56e0ux679cux7684ux5f79ux5272}{%
\section{共通未来比較器の因果的役割}\label{ux5171ux901aux672aux6765ux6bd4ux8f03ux5668ux306eux56e0ux679cux7684ux5f79ux5272}}

局所結果は、戻り信号が比較器へ到達する前に記録できる。通常の前向き因果だけなら、後の比較器は過去の記録を変更できない。本模型も、そのような前向き変更を主張しない。

比較器の役割は次の2つである。

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  完結履歴に対する \(K_{AB}\) を共通未来の局所相互作用として比較作用へ転送する。
\item
  二側境界測度を定義する物理的な終端自由度を与える。
\end{enumerate}

従って、比較器は過去へ制御信号を送る装置ではなく、生成からresetまでの全履歴に課す境界条件の終端である。

\hypertarget{ux4e8bux5f8cux9078ux5225ux3068ux306eux533aux5225ux3068ux672aux89e3ux6c7aux70b9}{%
\section{事後選別との区別と未解決点}\label{ux4e8bux5f8cux9078ux5225ux3068ux306eux533aux5225ux3068ux672aux89e3ux6c7aux70b9}}

通常の前向き初期分布から試行を発生させ、比較後に適合した履歴だけを残すなら、実験的な事後選別である。

本章の数学では、最初から全結果sectorの排他的な境界和へ測度を置き、境界測度に含まれる全履歴を数える。境界測度内部で結果別に履歴を捨てる操作はない。

しかし、この定義だけでは、実験準備が事後選別を使わず同じ測度を生成することを証明しない。必要なのは、

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  設定生成器を含む反復可能な全周期。
\item
  全開始数、局所記録数、比較完了数、reset完了数の一致。
\item
  結果依存の失敗試行または停止時間を捨てないこと。
\item
  共通境界密度を有限 Hamiltonian と弱開放流路から準備すること。
\end{enumerate}

である。これは現模型最大の未解決問題である。

\hypertarget{ux6700ux7d42ux7d50ux8ad6}{%
\section{最終結論}\label{ux6700ux7d42ux7d50ux8ad6}}

有限2成分場の正準構造と位相接続を用いると、coherent縮約多様体上で Madelung 作用と局所 Schrödinger 型方程式を得る。保存位相作用は有効作用定数となり、単価な非零場は条件付き循環量子化を与える。この主線は配置拡散を前提にしない。

局所作用整合と動径低速化については、厳密規格化・固定作用下で単体局所chart Hamiltonianと慣性逆恒等式を得た。正定値定数係数2次模型では低速・高速帯を分離し、高速成分を同型有限補助系へ完全に交換できる。局所的な有限作用交換浴と振幅浴は別の準備候補であり、固定振幅・短記憶・低温近似で欠陥エネルギーを減少させる。

これらは coherent多様体全体または M0 の停留経路選択を導かない。現行の Madelung 縮約に必要な半正定値位相 Hessian、有限規格化ペナルティ、粒子-場を含む全 Hessian、時間依存基準経路、非線形高速再励起は未完成である。

2モード作用殻の Liouville 流束は、共通流束因子と単一の直接作用分配方向の下で、位置の Born 型入口密度を与える。

同じ2成分場の2つの直交源チャンネルは、反対称低ランク相関を通じて Bell 余弦作用を与える。共通未来の2つの比較モードは、その相関振幅の実部と虚部を比較総作用へ転送する。共通境界測度を仮定すれば、2モード殻の線形容量から Bell 共同確率、CHSH値、非信号周辺を得る。生成側へ引き戻した完全履歴測度は設定に依存し、Bell の測定設定独立性を満たさない。

本論文は、Schrödinger 型力学、局所2次模型の高速法線成分除去、位置の Born 型入口重み、Bell 余弦作用、2モード比較作用を1つの2成分場アーキテクチャへ整理した。しかし、半正定値・零モードを含むM0全体の縮約、coherent集中、密度同期、共通境界測度、一般的な結果形成、coherent場の再埋め込み、反復可能な完全周期を1本の有限 Hamiltonian から導いていない。この境界を超えて主張しない。

\right)
=
\mu_\lambda
\left(
\Gamma_\lambda
\right).
$$

特に $\mu_\lambda$ が規格化されていれば、$U(2)$ 混合後もsector総質量は1であり、$\Omega_2(A_\lambda)$ には比例しない。
\end{proposition}

\begin{proof}
押し出し測度の定義から、

$$
\mu_\lambda'
\left(
\Gamma_\lambda
\right)
=
\mu_\lambda
\left(
\mathcal U_\lambda^{-1}
\Gamma_\lambda
\right).
$$

$\mathcal U_\lambda^{-1}\Gamma_\lambda=\Gamma_\lambda$ を用いる。
\end{proof}

一方、未規格化 Liouville 殻容量は

\[
\Omega_2(A_\lambda)
=
\int
\delta
\left(
A_\lambda-J_1-J_2
\right)
d\Gamma
\]

であり、異なる半径の殻を同じ密度で数えるときの測度である。従って、容量比例頻度には、sectorごとに別々に規格化した集団ではなく、全sectorへ共通の境界密度または流束を置く必要がある。

\hypertarget{ux6d41ux675fux898fux683cux5316ux3068ux5168ux8a66ux884cux76e3ux67fb}{%
\section{流束規格化と全試行監査}\label{ux6d41ux675fux898fux683cux5316ux3068ux5168ux8a66ux884cux76e3ux67fb}}

位置入口または Bell 結果の確率を

\[

=
\frac{\mathscr F_\lambda}{\sum_{\lambda'}\mathscr F_{\lambda'}}
\]

と定義するには、分母が全開始試行の入口通過を数えなければならない。次を監査する。

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  各開始試行は高々1つの排他的境界面を正方向に横切る。
\item
  境界へ到達しない試行を無言で除外しない。
\item
  複数回交差を1試行としてどう数えるかを固定する。
\item
  結果別に異なる停止時間または滞在時間を頻度へ重複計上しない。
\item
  記録失敗、再埋め込み失敗、再初期化失敗を結果依存に捨てない。
\item
  局所記録数、比較完了数、外部記録数、reset完了数を結果別に監査する。
\item
  Bell 側では設定生成に失敗した周期も無言で除外しない。
\end{enumerate}

これらを満たさなければ、作用殻容量が正しくても実験の無条件頻度にはならない。数学的な境界測度が全履歴を数えることと、実験準備がその測度を事後選別なしで生成することは別である。

\hypertarget{ux518dux57cbux3081ux8fbcux307fux5199ux50cfux306bux5fc5ux8981ux306aux4fddux5b58ux91cf}{%
\section{再埋め込み写像に必要な保存量}\label{ux518dux57cbux3081ux8fbcux307fux5199ux50cfux306bux5fc5ux8981ux306aux4fddux5b58ux91cf}}

\end{proof}

この定理は正定値2次部分模型の結果である。現行の Madelung 縮約へ無条件に適用しない。

\hypertarget{ux4f4eux901fux90e8ux5206ux7a7aux9593ux4e0aux306eux7e2eux7d04ux6b8bux5dee}{%
\section{低速部分空間上の縮約残差}\label{ux4f4eux901fux90e8ux5206ux7a7aux9593ux4e0aux306eux7e2eux7d04ux6b8bux5dee}}

\(\mathcal E_{\rm s}^{\epsilon}\) を前節の低速固有モードが張る実不変部分空間とする。正定値2次模型では、その上の解は全時間で有界であり、各時間微分も初期エネルギーにより一様に抑えられる。

形式的な1階縮約方程式は

\[
Ax
-
g_\phi\dot y
=
0,
\]

\[
By
+
g_\phi\dot x
=
0.
\]

完全2次方程式との差は

\[
\mathcal R_{\rm s}
=
\begin{pmatrix}
-\epsilon_{\rm s}\ddot x\\
-\epsilon_{\rm s}\ddot y
\end{pmatrix}.
\]

\begin{proposition}[低速部分空間上の全時間残差]
初期状態を $\mathcal E_{\rm s}^{\epsilon}$ に置き、初期2次エネルギーを一定に抑えると、十分小さい $\epsilon_{\rm s}$ に対し、

$$
\sup_{t\in\mathbb R}
\left\|
\mathcal R_{\rm s}(t)
\right\|
\leq
C\epsilon_{\rm s}
$$

となる。$C$ はそのエネルギー上界には依存するが、時刻と $\epsilon_{\rm s}$ には依存しない。
\end{proposition}

これは各時刻の方程式残差である。低速固有振動数の \(O(\epsilon_{\rm s})\) 補正により、縮約軌道との位相差は一般に \(O(\epsilon_{\rm s}t)\) と蓄積し得る。従って、軌道差が全時間で \(O(\epsilon_{\rm s})\) とは結論しない。

また、この残差は局所2次化された場chartの1階方程式に対するものである。粒子密度、粒子流速、密度同期を含む完全な Madelung 作用の変分残差ではない。

\hypertarget{ux9ad8ux901frieszux5c04ux5f71}{%
\section{高速Riesz射影}\label{ux9ad8ux901frieszux5c04ux5f71}}

2次 Hamiltonian の線形生成子を \(\mathscr L_{\epsilon}\) とする。十分小さい \(\epsilon_{\rm s}\) では、低速固有値と高速固有値は分離している。高速固有値だけを囲む複素輪郭 \(\gamma_{\rm f}\) を取り、

\[
\Pi_{\rm f}^{\epsilon}
=
\frac{1}{2\pi i}
\oint_{\gamma_{\rm f}}
\left(
z-\mathscr L_{\epsilon}
\right)^{-1}
\,dz
\]

と定める。実高速部分空間は、共役な正負固有値の射影を合わせて得る。

\begin{proposition}[高速スペクトル射影]
正定値2次模型では、$\Pi_{\rm f}^{\epsilon}$ と

$$
\Pi_{\rm s}^{\epsilon}
=
I-\Pi_{\rm f}^{\epsilon}
$$

は2次流と交換する。対応する実部分空間は不変かつsymplecticであり、2次 Hamiltonian は低速部分と高速部分の直和へ分かれる。
\end{proposition}

この射影は一般に全セルへ広がる。従って、固定グラフ辺だけへ結合する付録Eの局所作用交換浴と同じ局所機構ではない。

\hypertarget{ux540cux578bux6709ux9650ux88dcux52a9ux7cfbux306bux3088ux308bux9ad8ux901fux6210ux5206ux4ea4ux63db}{%
\section{同型有限補助系による高速成分交換}\label{ux540cux578bux6709ux9650ux88dcux52a9ux7cfbux306bux3088ux308bux9ad8ux901fux6210ux5206ux4ea4ux63db}}

高速部分空間を Williamson 正準座標で

\[
H_{\rm f}
=
\frac12
\sum_{k=1}^{n}
\omega_{{\rm f},k}
\left(
Q_k^2+P_k^2
\right)
\]

と書く。同じ振動数を持つ補助正準対 \((\widetilde Q_k,\widetilde P_k)\) と

\[
\widetilde H_{\rm f}
=
\frac12
\sum_{k=1}^{n}
\omega_{{\rm f},k}
\left(
\widetilde Q_k^2
+
\widetilde P_k^2
\right)
\]

を置く。交換生成子を

\[
H_{\rm ex}
=
\sum_{k=1}^{n}
\left(
Q_k\widetilde P_k
-
P_k\widetilde Q_k
\right)
\]

とし、内部時計で制御された結合係数を \(\chi_{\rm ex}(t)\) とする。

\[
\Theta_{\rm ex}
=
\int
\chi_{\rm ex}(t)
\,dt
\]

を交換角と呼ぶ。\(H_{\rm ex}\) は \(H_{\rm f}+\widetilde H_{\rm f}\) と Poisson 可換なので、自由回転と交換回転を分離できる。

\begin{theorem}[同型高速モードの完全交換]
補助系が対象高速部分と同型で、交換窓の間に他の結合を無視できるとする。共通自由回転を除いた座標は

$$
\begin{pmatrix}
z_{\rm f}^{\rm out}\\
\widetilde z_{\rm f}^{\rm out}
\end{pmatrix}
=
\begin{pmatrix}
\cos\Theta_{\rm ex} & -\sin\Theta_{\rm ex}\\
\sin\Theta_{\rm ex} & \cos\Theta_{\rm ex}
\end{pmatrix}
\begin{pmatrix}
z_{\rm f}^{\rm in}\\
\widetilde z_{\rm f}^{\rm in}
\end{pmatrix}.
$$

$\widetilde z_{\rm f}^{\rm in}=0$ と $\Theta_{\rm ex}=\pi/2$ の下で、

$$
z_{\rm f}^{\rm out}
=
0
$$

となり、対象系の高速成分は補助系へ完全に移る。
\end{theorem}

この操作は散逸でなく、有限正準系間の可逆な状態交換である。交換後も全情報と高速エネルギーは補助系に残る。次試行までに補助系を零状態へ戻すには、外部記録または排熱を含む別の再初期化過程が必要である。

定理は厳密制約後の局所2次chart内部で成立する。交換結合を元の全場変数へ大域的に持ち上げ、節を越えて規格化と \(\mathcal J_\phi\) を保存する構成は未完成である。

\hypertarget{ux4ea4ux63dbux89d2ux3068ux88dcux52a9ux521dux671fux72b6ux614bux306eux8aa4ux5dee}{%
\section{交換角と補助初期状態の誤差}\label{ux4ea4ux63dbux89d2ux3068ux88dcux52a9ux521dux671fux72b6ux614bux306eux8aa4ux5dee}}

高速2次エネルギーが定めるノルムを \(\|\cdot\|_{H_{\rm f}}\) とする。前節の正確な同型模型では、

\[
\left\|
z_{\rm f}^{\rm out}
\right\|_{H_{\rm f}}
\leq
\left|
\cos\Theta_{\rm ex}
\right|
\left\|
z_{\rm f}^{\rm in}
\right\|_{H_{\rm f}}
+
\left|
\sin\Theta_{\rm ex}
\right|
\left\|
\widetilde z_{\rm f}^{\rm in}
\right\|_{H_{\rm f}}.
\]

\(\Theta_{\rm ex}=\pi/2+\delta\Theta\) なら、

\[
\left\|
z_{\rm f}^{\rm out}
\right\|_{H_{\rm f}}
\leq
\left|
\delta\Theta
\right|
\left\|
z_{\rm f}^{\rm in}
\right\|_{H_{\rm f}}
+
\left\|
\widetilde z_{\rm f}^{\rm in}
\right\|_{H_{\rm f}}
+
O
\left(
|\delta\Theta|^2
\right).
\]

従って、交換角誤差は振幅に1次、残留エネルギーに2次で入り、補助系の非零初期エネルギーはそのまま対象へ戻り得る。

補助 Hamiltonian の複製誤差、Riesz射影の実装誤差、交換窓中の非線形項は Duhamel 型積分として加わる。これらの一様な定数と連続極限での規模依存性は未評価である。

\hypertarget{ux534aux6b63ux5b9aux5024ux4f4dux76f8hessianux3068ux96f6ux30e2ux30fcux30c9}{%
\section{半正定値位相Hessianと零モード}\label{ux534aux6b63ux5b9aux5024ux4f4dux76f8hessianux3068ux96f6ux30e2ux30fcux30c9}}

現行の Madelung 縮約では、位相勾配エネルギーを粒子流速側へ整理し、場側で二重計数しない。この分割では \(B\) は半正定値、極端には零になり得る。

1自由度で

\[
A>0,
\qquad
B=0,
\qquad
C=0
\]

とすると、特性式は

\[
\omega^2
\left[
\epsilon_{\rm s}^2\omega^2
-
\epsilon_{\rm s}A
-
g_\phi^2
\right]
=
0.
\]

高速振動数は

\[
\omega_{\rm f}
=
\frac{
\sqrt{
g_\phi^2
+
\epsilon_{\rm s}A
}
}{
\epsilon_{\rm s}
}
\]

として残る。一方、低速側は正の振動数でなく零モードになる。一般初期値では零固有値の一般化固有空間に沿う線形成長が生じ得る。

この例は、高速帯の存在に \(B>0\) が必須でないことを示す。しかし、一般の \(B\geq0\)、混合 Hessian、零固有値のJordan構造を含めて、

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  高速帯だけを一様に分離すること。
\item
  高速Riesz射影の正準性を保つこと。
\item
  低速一般化部分空間の多項式成長を評価すること。
\item
  高速交換後の残差を観測時間に一様に抑えること。
\end{enumerate}

は未証明である。正定値定理を現行 M0 へ適用するために場側へ人工的な位相剛性を戻してはならない。

\hypertarget{ux6709ux9650ux898fux683cux5316ux30daux30caux30ebux30c6ux30a3ux306eux4e2dux9593ux5e2f}{%
\section{有限規格化ペナルティの中間帯}\label{ux6709ux9650ux898fux683cux5316ux30daux30caux30ebux30c6ux30a3ux306eux4e2dux9593ux5e2f}}

厳密制約を使わず、有限 \(\Lambda_N\) で規格化方向を残すと、その局所偏差を \(\eta_N=N-1\) として概略

\[
H_N^{(2)}
=
\frac{
p_N^2
}{
2\epsilon_{\rm s}M_N
}
+
\frac{
\Lambda_N
}{
2
}
\eta_N^2
\]

が現れる。\(\Lambda_N=O(1)\) なら、

\[
\omega_N
=
O
\left(
\epsilon_{\rm s}^{-1/2}
\right).
\]

これは \(O(1)\) の低速帯と \(O(\epsilon_{\rm s}^{-1})\) の高速帯の間にある中間帯である。実際の係数と混合は \(H_0\)、規格化方向、相対位相方向の全 Hessian に依存する。

従って、厳密制約模型の2帯定理を有限 \(\Lambda_N\) 模型へ直接移せない。有限ペナルティ模型には、少なくとも3帯を許す別のスペクトル解析が必要である。

\hypertarget{ux975eux7ddaux5f62ux6642ux9593ux4f9dux5b58ux5168m0ux3078ux306eux9650ux754c}{%
\section{非線形、時間依存、全M0への限界}\label{ux975eux7ddaux5f62ux6642ux9593ux4f9dux5b58ux5168m0ux3078ux306eux9650ux754c}}

本付録の厳密交換定理は、固定内点の定数係数2次模型に対する結果である。完全な局所 Hamiltonian では、

\[
G_q
=
G_q(q),
\qquad
G_\varphi
=
G_\varphi(q)
\]

であり、\(H_0\) は3次以上の項を持つ。これらは低速運動から高速成分を再生成し得る。適用には、初期振幅、観測時間、\(\epsilon_{\rm s}\)、スペクトル間隙に依存する再励起率の評価が必要である。

基準となる停留経路が時間依存なら、HessianとRiesz射影も時間に依存する。

\[
\dot\Pi_{\rm f}^{\epsilon}
\neq
0
\]

であるため、射影の回転自体が低速成分と高速成分を混合する。断熱条件と幾何学的接続項を含む別の定理が必要になる。

さらに、現行 M0 には粒子座標、粒子運動量、密度、位相接続、装置、準備浴が含まれる。全系を2次化すると粒子-場混合 Hessian が現れる。本付録は場chart内部の高速法線成分を扱うが、M0全体の停留経路または特定の Schrödinger 解を選ばない。

従って、本付録が示すのは、

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  厳密制約下の局所正準形。
\item
  正定値2次模型での低速・高速分離。
\item
  理想同型補助系への高速成分の可逆な完全交換。
\item
  交換後の局所2次縮約方程式に対する \(O(\epsilon_{\rm s})\) 残差。
\end{enumerate}

までである。coherent集中、密度同期、単流束化、節、半正定値位相 Hessian、一般の時間依存停留経路は解決していない。
