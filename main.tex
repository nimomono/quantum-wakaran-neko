\chapter{問題設定と研究の判定基準}\label{ux554fux984cux8a2dux5b9aux3068ux7814ux7a76ux306eux5224ux5b9aux57faux6e96}

\section{問うこと}\label{ux554fux3046ux3053ux3068}

古典的な微視的力学と、準備・環境・観測の明示的な物理機構から、量子力学に特徴的な数理・統計構造をどこまで\textbf{追加の量子公理なしに}得られるかを調べる。

目標は量子力学の既知の式を別記号に置き換えることではなく、その式と観測統計が成立する物理的条件、また成立しない場合の障害を区別することである。

\section{出発点の候補}\label{ux51faux767aux70b9ux306eux5019ux88dc}

有限Hamiltonian系、連続場、有限または無限の熱浴、開放確率系などを候補に含める。ただし、どの候補も採用するには少なくとも次を明示する必要がある。

\begin{itemize}
\tightlist
\item
  一試行の状態変数と、その状態が従う発展法則
\item
  相互作用、外部駆動、初期分布・境界条件、必要な正則性
\item
  観測量と、単一試行で確定する記録
\item
  確率過程への縮約または極限の具体的手順
\item
  系統的近似を使う場合の適用域と誤差
\end{itemize}

候補間の同等性は、座標変換、縮約、観測操作の各段階で検証する。

\section{結果の4区分}\label{ux7d50ux679cux306e4ux533aux5206}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{証明済み：} すべての仮定の下で数学的な結論が導かれ、検証可能な証明がある。
\item
  \textbf{条件付き：} 特定の物理的または数学的構成を入力すれば結論が成立するが、その入力の微視的起源は示されていない。
\item
  \textbf{数値的：} 明記した模型・パラメータ領域・精度で数値的に支持されるが、一般証明はない。
\item
  \textbf{未解決：} 主張を成立させるための機構、必要条件、または証明が不足している。
\end{enumerate}

反例・不可能性・成立条件の制限も同じ区分と証拠規則で扱う。単一主張を複数の証拠が支える場合は、それぞれの射程を別に記す。

\section{量子力学との比較での注意}\label{ux91cfux5b50ux529bux5b66ux3068ux306eux6bd4ux8f03ux3067ux306eux6ce8ux610f}

\begin{itemize}
\tightlist
\item
  複素表現を得ることと、物理的な非可換観測量を得ることは別問題。
\item
  Euclideanな確率経路重みと、実時間の干渉位相は別問題。
\item
  平衡分布や条件付き密度からFisher情報が計算できることと、その変分力が微視的力学から必然的に出ることは別問題。
\item
  量子現象ごとの入力・出力統計の再現と、同一基礎模型からの統一的導出は別問題。
\item
  Bell型共同統計の再現には、設定独立性・局所因子化・非信号性などの前提を個別に監査する必要がある。
\end{itemize}
