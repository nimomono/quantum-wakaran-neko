# 第2期研究：編集用の入口

> 状態：**再構築中**（未完成）。具体的な量子力学の微視的導出はまだ主張しない。

## 目的

古典的な微視的力学と明示的な統計的縮約を出発点に、量子力学に特徴的な構造がどこまで導かれるかを、過去のモデル構成・結果番号・達成ラベルから独立に検証する。

現在の論文の唯一の正本は [../sections/](../sections/00_purpose_and_scope.md) である。旧版の論文・付録・verifierを現在の原稿に混ぜない。

## 原則

1. 入力と導出を区別する。Schrödinger方程式、Born則、Fisher項、作用尺度、非局所相関を置いた場合は、その入力自身を導いたとは呼ばない。
2. 一試行の物理的変数と、集団分布・複素表示・観測記録を混同しない。
3. 主張ごとに仮定、証明、数値的根拠、誤差、反例、射程を紐づける。
4. 否定的結果も研究成果として保存する。
5. 数学的な同型と物理的な量子構造の生成を区別する。
6. 個別現象の再現と、一つの機構からの統一的な導出を区別する。
