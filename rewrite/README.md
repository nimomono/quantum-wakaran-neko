## 目的

古典的な微視的力学と明示的な統計的縮約を出発点に、量子力学に特徴的な構造がどこまで導かれるかを、過去のモデル構成・結果番号・達成ラベルから独立に検証する。

現段階で、粒子・場・有限浴・無限浴・開放系のいずれかを唯一の基礎実体とは決めない。候補となる物理模型は、変数・相互作用・初期準備・外部境界・観測操作を提示した後、各々の導出結果によって比較する。

## 新体系の原則

1. **入力と導出を区別する。** 既知の量子方程式、Born則、Fisher項、拡散係数、複素位相、非局所相関を入力した場合、後段の再現だけでそれらを微視的に導いたとは呼ばない。
2. **一試行と統計集団を区別する。** 微視的状態、縮約された確率分布、複素表示、測定記録を混同しない。
3. **主張ごとに証拠を残す。** 仮定・定義域・結論・証明・近似誤差・反例・検算コードを紐づける。
4. **否定的結果を保存する。** 成立しなかった主張も、その条件や障害が特定できれば研究成果として記録する。
5. **量子との同型と物理的生成を分ける。** 数式がSchrödinger型であることは、非可換な観測や実時間干渉の生成を意味しない。
6. **現象別の再現と統一模型を分ける。** 別々の装置で各量子現象を再現したことは、単一の古典模型による統一的導出を意味しない。
