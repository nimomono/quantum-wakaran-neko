# quantum-wakaran-neko

量子、なんもわからん。

## このプロジェクトの目標

古典的な粒子、振動子、熱浴、測定器を組み合わせたとき、量子力学に特徴的な運動や確率が、どこまで有効理論として現れるかを調べるプロジェクトである。

ここでいう有効理論とは、装置全体の自由度のうち観測する変数だけを残し、直接観測しない環境や内部自由度をまとめて記述する理論を指す。

量子力学の方程式を古典振動子の方程式へ書き換えるだけでは、測定結果やBorn則の起源を説明したことにはならない。本プロジェクトでは、粒子、振動子、熱浴、測定器、記録装置を含む具体的なモデルを作り、次の点を調べる。

- 量子状態に似た状態空間と可逆操作が、どの古典力学から生じるか
- 1回の試行で結果がどのように一つに定まるか
- 多数回の試行で、結果の頻度がなぜ振幅の二乗に比例するのか
- 測定後の状態、外部記録、装置のリセットを同じ過程として記述できるか
- 確率、仕事、熱、エントロピーの流れが、どの自由度から生じるか
- どこまでが厳密な結果で、どこからが近似や追加仮定なのか

存在論上は、各試行の粒子位置、実振動子座標、熱浴、制御器、記録器を物理状態として扱う。実振動子の位置と運動量をまとめたM54の複素記憶部 $Z$ は実状態の派生表示である。解析上の状態方向 $c$、第2モーメント $C_Z$、Q3の位置分布は多数試行の統計量であり、単一試行の制御器へ書き戻さない。

長期的な目標は二つある。

1. 明示的な古典力学モデルから、量子力学の基本構造、代表的な現象、測定統計、空間力学をどこまで再現できるかを調べ、その成立条件と限界を明らかにする。
2. 同じ構造を複合系と量子情報処理へ拡張し、結合ゲート、Bell型統計、有限ゲート合成、一般回路の量子出力標本化までどこまで再現できるかを調べる。Q2-4ではこの応用に限って、内部の受動自由度と外部から装置を利用するための複雑度を分けて評価する。

これは量子力学を否定する試みでも、量子力学全体を古典力学から導出したと主張するものでもない。再現できた構造と、まだ導出できていない構造を分けて検証する。

## 論文の概要

**古典力学系からの量子型有効構造：W型2モード操作・測定、共同浴ゲート、空間伝播、Bell型統計**

現行論文では、研究課題を次の三段階に分けている。

Q1、Q2、Q3は、有限正準信号と有限配置を持つM54の異なる有効状態構成として扱う。M54は物理テンプレート準備、テンソル積状態の生成、永続記憶部ゲート、R164の条件付き作用容量、R161の静的/移動分布の整合、R162の有限衝突、R170の静的選択・固定、R181Dの段階的射影選別を同じ状態型へまとめる。M37はQ3の空間信号部分系の局所位置ばね物理実装層であり、R187条件下ではQ1 W2制御用信号系も同じM37形式の弱結合W型振動子網で実装する。M54の共通状態構成を共有すること、M37信号系を共有すること、同じ完成ハードウェアを共有することは区別する。

M54のR181A準備接続端は、物理テンプレート、ポンプ、不要方向を捨てる排出先、時計自由度を明示し、同じ初期分布を目標状態方向へ押し出す。R181Aだけが作るのは統計状態であって排他的結果ではない。R164は同じ試行信号から条件付き配置分布を作り、R161がその整合を担う。Q1/Q2ではR170が静的な排他的選択を有限後段窓へ固定し、外部記録はR112または系列固有記録機構が後段で行う。Q3では空間-移動特殊化が開始面で選んだ同じ粒子を輸送して終時刻に記録する。

確率を排他的結果へ変換する機構は有限作用殻へ一本化し、有限正準回路は信号の操作、比較、記録、逆計算にだけ使う。この共通部分は複数の装置が満たす入出力契約であり、それだけで一つの完成した物理装置を構成したという意味ではない。

共通の読出し定理は、決めた入力時刻の有限信号を保持し、作用殻の状態数、有限時間の再平衡化、局所固定機構を通して、排他的な結果または無反応を後の時刻に記録する。単一量子ビット型装置とBell型装置はこの共通定理へ、それぞれ固有の分析器と条件付き応答だけを追加する。

物理的な導出の主線には、局所的に結合した古典振動子の運動から弱結合W型の低い2正常モードを取り出し、単一量子ビット型操作へ接続する経路を採用する。R187は中央の局所ばね結合を弱くする有限W型族で $J/G\to0$ を構成し、傾斜時の結合後の低2モード部分空間とM37厳密正常モードの分裂較正を用いて、固定した任意の $SU(2)$ 操作を任意精度で元の振動子信号系へ持ち上げる。精度を上げると総制御時間は増え得る。測定結果を選ぶ仕組みと、複合系の共同状態を保持する仕組みは別に接続する。

### 1. 単一量子ビット型装置

二重井戸型の古典系が持つ低い2モードと、粒子位置、環境自由度を組み合わせる。

このモデルでは、M54の2モード特殊化が実振動子初期種集団を目標Bloch状態方向へ準備し、任意の $SU(2)$ 操作とRabi振動を構成する。また、各試行に与えられた作用と、二つの結果成分が持つ古典状態数から、準備済み状態方向の振幅の二乗に比例するBorn型重みが排他的結果へ移る条件を示している。 さらに、無限自由度の古典Drude浴を許す条件では、固定済み正作用容量を2作用LC殻へ渡して総作用を保存したまま作用分配を有限時間で一様化し、対称作用開口からR161の静的平方根遷移kernelへ接続するR190A--R190Cを与える。これはR162の一般有限衝突を置き換えず、反復衝突のrenewalと測定周期全体の単一ミクロ装置統合は別条件として残す。有限浴への持上げは本経路の必要条件ではなく、有限性自体を検査する独立強化課題である。

単一量子ビット型の可逆操作は達成している。Born分布、同軸反復分布、異軸逐次分布も、明示した開放ミクロモデルと誤差条件のもとで導出している。測定後状態は結果別テンプレートを外から差し替えず、R181Dの階数1 射影選別機構と方向を変えない振幅再調整で同じ単一試行信号上に作り、そのまま次段へ渡す。さらにR189A--R189Cでは、R187の同一M37 W2信号系で零傾斜Rabiを停止せず作用容量だけを保持し、固定済み容量から選択結果を形成した後に走行中の階数1射影選別を完了する。$N=2$、$\Omega_\kappa T=\pi/2$ の有限証人では測定運転の終端生存確率 $3/4$、自由・空操作対照 $1/2$、理想余裕 $1/4$ を得るため、Q1-2を達成とする。

有限局所ハミルトニアン実装または有限閉鎖ハミルトニアンへの持ち上げ、永久記録、内部逆計算、リセット、周期全体の仕事・熱・エントロピー収支は、Q1-2の達成条件ではない。これらは現行モデルを強める実装・熱力学的研究課題として残す。

### 2. 複合系ゲート、Bell型統計、一般回路標本化

2つのQ1型接続端と、受動的な4モード信号、逆演算用補助記憶部、作業領域、時計自由度履歴を含む永続状態浴であるM54を使う。R181Bは入力係数を外部で読み取らずに $Z_S=a\otimes b$ を作る可逆テンソル積状態の生成、R181Cは同じ $Z_S$ 上のCNOT・局所操作・逆演算の有限ゲート列、R181Dは末端だけのBorn型測定機構接続を与える。内部モードを浴へ任せ、制御器は接続端、持ち上げ窓、ゲート種、対象、作用窓、末端読出しだけを扱う。

さらに、M54の実際の1試行末端信号を中央でA設定基底のブロックへ分け、選択ブロックを供給源とする2端Hopf受信機構から二つの測定端へ渡す。設定先行準備、切断後の条件付き局所因子化、各端の局所分析と記録、次周期への帰還を一つのBell周期として構成し、Bell型の余弦共同確率、CHSH不等式の破れ、Tsirelson限界、非信号性を同じ計算の中で再現する。受信機構全体の単一装置統合は条件として残る。

ただし、一方の測定設定が中央の準備過程へ入るため、Bellの定理で仮定される測定設定独立性は成立しない。したがってBellの定理との矛盾ではなく、標準的な空間分離・自由設定のBell実験を再現したものでもない。

R181B/R181Cにより、積入力を非分離な共同内部状態へ移す有限ハミルトニアンへの持ち上げとCNOT、参照系安定な合成、逆演算を同じ永続記憶部上で構成した。R181Dの共通射影容量固定、R170選択・固定、必要な局所記録、制御付き選別機構、方向を変えない振幅再調整、転送の一体化を条件として末端Born分布へ接続するため、Q2-1は条件付き達成である。内部4モードの存在自体は失敗条件ではなく、個別モードの外部初期化・較正・個別指定・読出しを要しないことが条件である。

3量子ビット型二段ゲート合成は、R181Bをゲート列の前に2回使って8モード信号を作り、R181CのA--B、B--C二次生成子を同じ記憶部へ順に作用させる。R177はGHZ--$T$--逆演算のコヒーレント出力と完全位相緩和出力の全変動距離が $1/(2\sqrt2)$ であることを示す。末端ではM54静的状態構成のR170を前段に使うR181Dを8モードへ特殊化する。同じ末端接続条件が残るため、Q2-3も条件付き達成である。

一般回路では、$n$ 量子ビットを $L=2^n$ 受動信号モードへ直接符号化する。R181Cが固定有限局所ゲートを全非作用部分へ一括作用させ、R181Dが各出力ビットで未処理の射影子容量を作る。静的選択はR164の作用容量をR190の無限Drude浴・作用開口へ渡し、R179の定常流入浴で反復renewalを保つ。結果はR170の吸収指針変数へ固定してから可逆選別機構を開き、方向を変えない振幅再調整で選択状態方向を標準作用へ戻す。結果相関履歴は流出浴へ流し、有限低温／使用済み貯蔵部とR178Dは現行因果鎖から外す。旧固定体積の開口と二進しきい値記録領域は現行因果鎖から外した。

これにより、外部プログラム、制御チャネル、精度、反復回数、総時間を多項式へ抑える部品構成と合成誤差を得た。R186はさらに、指数モード数それ自体と外部精度を分離し、疎な静的製造誤差や独立位相ノイズが次元数に依存せずに抑えられる範囲と、空モードにも作用を注入する全自由度に加わる加法ノイズが指数ノイズ抑制を要求する範囲を分ける。残る条件は、静的部分系配線、射影結果の固定機構、R190/R179静的選択機構、R170吸収指針変数、制御付き選別機構、方向を変えない振幅再調整、開放リセット/供給接続部を一つの具体的な一様装置族へ統合し、その局所誤差とノイズがR186の許容条件を満たすことを示すことである。指数的な信号・作業領域・履歴・低温・使用済み容量と総熱は現行規則で許す。最終確率表の事前計算、希少成功の事後選別、状態依存除算は使わない。

### 3. 空間量子力学

Q3ではM54空間移動状態構成を使う。1回の試行には、実数の位置・運動量からなる信号自由度、1個の粒子位置がある。粒子の局所jumpは明示的な開放Poisson reservoirが担い、有限衝突素子と全微視的履歴を能動状態へ持たない。複素信号は実正準対をまとめた表示であり、多数試行から作る第2モーメントが階数1なら、その因子として量子力学の波動関数に対応する複素状態方向を読む。状態方向自体を単一試行の粒子へ書き戻さない。

R164が与える条件付き配置分布に対し、一般R161は確率流と活動量から整合率を作る。Q1・Q2では $j=0$ の静的詳細釣合い特殊化として測定面へ再平衡化し、Q3では信号の確率流を持つ移動特殊化として同じ粒子分布を全時刻保存する。正則化 $\delta>0$ により節でも有限率を保ち、階数1集団では位置分布が振幅二乗へ $\delta/(1+\delta)$ 以内で一致する。

空間信号の理想運動はM54空間状態構成の実正準ハミルトニアンで厳密に書ける。M37はこれを局所的な古典振動子と位置ばねだけで実装する模型で、R86がSchrödinger型包絡への有限時間誤差を与える。R184ではM37開始面の作用 $S_{\rm ref}$ を各試行で固定し、正則化背景を輸送中の非保存局所作用へ追随させない。この規約で移動整合率と位置分布への誤差を評価し、有限衝突素子、時計自由度、記録を含む完全結果誤差までまとめる。

R185ではR161が同じ経路分布から与える後退率を使い、前進・後退平均微分を定義する。1次元の一様背景・節を含まない滑らかな領域では、時間対称平均加速度が外力に一致し、残差は格子幅について $O(a^2)$、正則化について $O(\delta)$ になる。有限衝突経路との比較を介さず、R185はR161/R162が定める同じ前向き経路法則のBayes後退率から時間対称Newton則を導く。これにより固定有限時間・1次元有限格子・節を含まない滑らかな部分系でQ3-2は達成である。M37からの直接加速度縮約、連続空間一様極限、多粒子は強化課題として残る。

空間Schrödinger型力学Q3-1、井戸型・調和型・W型の束縛状態Q3-3A--Q3-3Cは達成している。有限障壁のトンネル効果Q3-4A、W型のトンネル振動Q3-4B、2経路干渉Q3-5は、同じ粒子の移動分布の整合へ接続した上で単一装置統合を条件に達成としている。位相量子化Q3-6、一般的な連続空間極限、多粒子系は未完成である。
