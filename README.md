# quantum-wakaran-neko

量子、なんもわからん。

## このプロジェクトの目標

古典的な粒子、振動子、熱浴、測定器を組み合わせたとき、量子力学に特徴的な運動や確率が、どこまで有効理論として現れるかを調べるプロジェクトである。

ここでいう有効理論とは、装置全体の自由度のうち観測する変数だけを残し、直接観測しない環境や内部自由度をまとめて記述する理論を指す。

量子力学の方程式を古典振動子の方程式へ書き換えるだけでは、測定結果やBorn則の起源を説明したことにはならない。本プロジェクトでは、粒子、振動子、熱浴、測定器、記録装置を含む具体的なモデルを作り、次の点を調べる。

- 量子状態に似た状態空間と可逆操作が、どの古典力学から生じるか
- 1回の試行で結果がどのように一つに定まるか
- 多数回の試行で、結果の頻度がなぜ振幅の二乗に比例するのか
- 測定後の状態、外部記録、装置のリセットを同じ過程として記述できるか
- 確率、仕事、熱、エントロピーの流れが、どの自由度から生じるか
- どこまでが厳密な結果で、どこからが近似や追加仮定なのか

存在論上は、各試行の粒子位置、実振動子座標、熱浴、制御器、記録器を物理状態として扱う。実振動子の位置と運動量をまとめた複素信号は実状態の派生表示である。M51の $c,C_Z$ とQ3のrayは多数試行の統計量だが、M52の $Z_S$ は1試行の実正準状態から得る派生信号である。統計量を単一試行の装置へ直接書き戻さず、各試行の実状態だけを次の物理過程へ渡す。

長期的な目標は二つある。

1. 明示的な古典力学モデルから、量子力学の基本構造、代表的な現象、測定統計を再現し、その成立条件と限界を明らかにする。
2. 同じ仕組みを利用し、量子コヒーレンスを前提としない巨視的な古典系で、2部分系の結合ゲート、Bell型測定、3部分系の二段ゲート合成、一般回路の量子出力サンプリングを調べる。各目標は、その機能を支える明示的なモデルと結果から独立に判定する。

これは量子力学を否定する試みでも、量子力学全体を古典力学から導出したと主張するものでもない。再現できた構造と、まだ導出できていない構造を分けて検証する。

## 論文の概要

**古典力学系からの量子型有効構造：W型2モード操作・測定、共同bathゲート、空間伝播、Bell型統計**

現行論文では、研究課題を次の三段階に分けている。

三つの段階で使う古典モデルは同じではない。一方で、実正準担体のseed集団を開放流でrank-one統計へ準備するM51、信号集団の規格化第2モーメントを運ぶ法則、各試行の信号方向を枝統計へ渡すray平均、複素信号の各成分が持つ作用から古典状態数を作って一つの結果を記録する仕組みは共通している。

M51では、物理template、pump、不要方向を捨てるsink、準備portを開閉するclockを明示し、実担体のミクロdriftを与える。同じseed測度をこの開放流で押し出すことで、目標rayの二乗を対角に持つ第2モーメントを有限時間で準備する。M51が作るのは統計状態であり、排他的な測定結果ではない。単一量子ビット型装置とBell型装置ではM50/R170が排他的結果を作る。空間模型では、準備時に作った1個の粒子位置をM37担体に沿ってM42が輸送する。

確率を排他的結果へ変換する機構は有限作用殻へ一本化し、有限正準回路は信号の操作、比較、記録、逆計算にだけ使う。この共通部分は複数の装置が満たす入出力契約であり、それだけで一つの完成した物理装置を構成したという意味ではない。

共通の読出し定理は、決めた入力時刻の有限信号を保持し、作用殻の状態数、有限時間の再平衡化、局所ラッチを通して、排他的な結果または無反応を後の時刻に記録する。単一量子ビット型装置とBell型装置はこの共通定理へ、それぞれ固有の分析器と条件付き応答だけを追加する。

### 1. 単一量子ビット型装置

二重井戸型の古典系が持つ低い2モードと、粒子位置、環境自由度を組み合わせる。

このモデルでは、M51の2モード特殊化が実振動子seed集団を目標Bloch rayへ準備し、任意の $SU(2)$ 操作とRabi振動を構成する。また、各試行に与えられた作用と、二つの結果枝が持つ古典状態数から、準備済みrayの振幅の二乗に比例するBorn型重みが排他的結果へ移る条件を示している。

単一量子ビット型の可逆操作は達成している。Born分布、同軸反復分布、異軸逐次分布も、明示した開放ミクロモデルと誤差条件のもとで導出している。Q1-2全体が部分達成なのは、同じ総時間の零傾斜Rabi自由発展と、測定中もRabi駆動を止めない有限回測定を、無反応を含む全履歴とtiltだけの対照を使って比較するZeno部分が未達だからである。

有限局所Hamiltonian実装または有限閉鎖Hamiltonianへの持ち上げ、永久記録、内部逆計算、reset、周期全体の仕事・熱・エントロピー収支は、Q1-2の達成条件ではない。これらは現行モデルを強める実装・熱力学的研究課題として残す。

### 2. 複合系ゲート、Bell型統計、一般回路標本化

2つのQ1型portと、受動的な4mode信号、anti-register、work、clock履歴を含む永続状態bath M52を使う。R176Aは入力係数を外部で読み取らずに $Z_S=a\otimes b$ を作る可逆tensor-lift、R176Bは同じ $Z_S$ 上のCNOT・局所操作・逆演算の有限gate列、R176Cは末端だけのBorn型instrument接続を与える。内部modeをbathへ任せ、controllerはport、lift窓、gate種、対象、作用窓、末端読出しだけを扱う。

さらに、M52の実際の1試行末端信号を中央でA設定basisのblockへ分け、選択blockをsourceとするpaired-Hopf receiverから二つの測定端へ渡す。設定先行準備、切断後の条件付き局所因子化、各端の局所分析と記録、次周期への帰還を一つのBell周期として構成し、Bell型の余弦共同確率、CHSH不等式の破れ、Tsirelson限界、非信号性を同じ計算の中で再現する。receiver全体の単一装置統合は条件として残る。

ただし、一方の測定設定が中央の準備過程へ入るため、Bellの定理で仮定される測定設定独立性は成立しない。したがってBellの定理との矛盾ではなく、標準的な空間分離・自由設定のBell実験を再現したものでもない。

R176A/Bにより、積入力を非分離な共同内部状態へ移す有限Hamiltonian liftとCNOT、参照系安定な合成、逆演算を同じ永続register上で構成した。R176Cの容量pointer--作用殻境界、有限fiber混合の枝対称性、SWAPから記録までの一体化を条件として末端Born分布へ接続するため、Q2-1は条件付き達成である。内部4modeの存在自体は失敗条件ではなく、個別modeの外部初期化・較正・address・読出しを要しないことが条件である。Bell型測定統計は別の固定目標として独立に判定する。

3量子ビット型二段ゲート合成は、R176Aをgate列の前に2回使って8mode信号を作り、R176BのA--B、B--C二次生成子を同じregisterへ順に作用させる。R177はGHZ--$T$--逆演算のcoherent出力と完全dephasing出力の全変動距離が $1/(2\sqrt2)$ であることを示す。末端ではM50/R164/R170を含むR176Cを8modeへ特殊化する。同じ末端接続条件が残るため、Q2-3も条件付き達成である。

一般回路にはM53を置く。$n$ 量子ビットを $L=2^n$ 受動signal modeへ直接符号化し、R178Aが固定有限局所gateを全spectator sectorへ一括作用させる。R178Bは信号作用を二枝の非規格化容量へlatchし、R164はその容量比をBorn型状態数へ解釈する。R178Cは可逆2枝filter、条件付き確率のtelescoping、希少枝を無反応へ送る逐次Born標本化を与える。R178D--R178Fは逆掃除できるhistoryの範囲、fixed-volume fresh tape、最小index規則、同じ容量を読む滑らかな二channel apertureを与え、R164の状態数因子を重ねて掛けない。R179は一定精度partial SWAPの反復と回路非依存dyadic tapeによりblank-bankを供給する。

これにより、外部program、制御channel、精度、反復回数、総時間を多項式へ抑える部品構成と合成誤差を得た。残る条件は、静的sector配線、projector latch、repump、history掃除、smooth aperture、cold/spent境界、clockを一つの具体的な一様装置族へ統合することである。指数的なsignal・work・history・cold・spent容量と総熱は現行規則で許すため、Q2-4はこの物理統合を条件に条件付き達成である。最終確率表の事前計算、希少成功の事後選別、離散tapeと連続一様lawのtotal variation同一視は使わない。

### 3. 空間量子力学

M51の開放流で初期のrank-one統計を準備し得る契約を置き、局所的に結合した有限個の古典振動子から、空間格子上のSchrödinger型時間発展を有限時間・明示誤差付きで導く。

一回の試行では、各格子点の実振動子の位置と運動量から派生複素包絡を作る。多数試行の第2モーメントが階数1なら、その統計因子として空間全体の複素rayが得られる。このrayは、有限時間の範囲でSchrödinger方程式に従う波動関数と同じ形で発展する。複素rayを粒子や振動子とは別の実体として追加しているわけではない。

各試行には振動子担体とは別に1個の局在粒子位置を置く。準備終了面で、その試行の担体信号から初期位置を一度だけ作り、その後は局所辺bathを介して同じ粒子を有限グラフ上で輸送する。理想極限では粒子位置の集団分布が振幅の二乗に沿い、有限装置では節の正則化、担体誤差、有限bath、clock、記録の誤差を明示する。終時刻に別の粒子位置を再抽選しない。

有限グラフ上では、低位束縛状態、有限環境による純位相緩和、障壁値より低い状態のトンネル型確率移動、最小2経路の干渉を構成している。

空間Schrödinger型力学と束縛状態・純位相緩和は達成している。トンネル効果と2重スリット干渉は、波動的な確率分布と局在粒子輸送への接続を得ているが、M51の準備port、M37の振動子網、M42の局所辺bathと記録を一つの有限局所装置へ統合していないため、条件付き達成である。

位相量子化は未達だが、凍結を解除した。閉路巻数、零点を避ける変形での不変性、節を介した位相すべり、格子細分化安定性、非整数モノドロミー排除を一つの有限局所構成で示す課題として再開する。一般的な連続空間極限と多粒子系も未完成である。

### この論文の到達範囲

本論文が示しているのは、量子力学のいくつかの構造が、明示的な古典系の運動、状態数、環境との相互作用、条件付けから現れ得るということである。

現時点では、単一量子ビット型装置、M52、Bell型装置、M53、空間モデルは異なる古典モデルを使っている。これは上表の個別達成判定と両立する。M52では固定2・3入力のtensor-liftと永続gate列を得たが、末端instrumentの全物理境界の一体化は条件として残る。M53では一般回路の一出力標本を多項式外部制御と多項式総時間で作る部品定理を得たが、全部品の一様装置統合は条件として残る。別の実装努力目標であるQ2-1からQ2-4の共通ハードウェア族、Q1--Q3を一つの反復周期へ統合した理論、量子力学全体の導出も未完成である。
