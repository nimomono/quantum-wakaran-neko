# quantum-wakaran-neko

量子、なんもわからん。

## 目的

明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。有限自由度の古典 Hamiltonian 系を基礎とし、外部との微小なエネルギー交換を伴う弱い開放系まで含めて、確率構造が生じる物理的機構を追跡する。

| ID | 長期目標 | 現在地 | 達成判定の中心 | 残る課題 |
|---|---|---|---|---|
| Q1 | Schrödinger 型有効力学 | 部分達成 | 明示的な古典ミクロモデルから、適用範囲と誤差を伴う有効時間発展として導く | $h_L$ の係数をより原始的な古典模型から導くこと、非線形閉包、連続極限、粒子運動との接続 |
| Q2 | Born 則 | 部分達成 | 確率重みを外から置かず、準備、力学、測定過程から導く | 高階数源の軌道生成、混合的有限標本統計、粒子検出、連続スペクトル、滑らかな安定結果形成 |
| Q3 | 位相量子化 | 未達 | 循環量子化、節、単価性、位相すべりを統合し、 Wallstrom 問題へ回答する | 空間グラフの閉路巻数、節、位相すべり、連続補間の統合 |
| Q4 | 束縛状態 | 未達 | 井戸型・調和型ポテンシャルで固有エネルギー、確率密度、節、状態選択、安定性を再現する | 定量検証、エネルギー測定、状態選択、安定性 |
| Q5 | トンネル効果 | 未達 | 障壁高、幅、入射エネルギーに対する透過率を再現し、古典的熱活性化と区別する | 透過率の定量導出と熱活性化との識別 |
| Q6 | Rabi 振動 | 未達 | 駆動2準位系の振動数、振幅、離調依存性を再現する | 駆動2準位系の明示的なモデルと定量検証 |
| Q7 | 2重スリット干渉 | 未達 | 準備、伝播、干渉、局所検出を含む明示的なモデルから位置分布を再現する | 空間セル標本化と粒子の局所検出・連続軌道との接続 |
| Q8 | 2量子ビット型結合ゲート | 未着手 | 2つの論理自由度に対する CNOT 型または制御位相型の結合操作を、外付けの行列演算ではなく明示的な古典 Hamiltonian 装置として実現する | 最小符号化、結合 Hamiltonian、入力状態に対する作用、相関生成、忠実度の検証 |

| Q10 | 完全な操作・測定周期 | 部分達成 | 準備、必要な操作、設定生成、結果形成、増幅、外部記録、内部消去、再初期化を1周期として構成し、同じ装置で連続反復できるようにする | 操作列との統合、永久外部記録、同一装置の直後反復、滑らかな安定結果形成、 Bell 整合支持 |
| Q11 | Zeno 効果 | 未着手 | 同じミクロモデルから、反復測定間隔を短くしたときの遷移抑制を定量的に再現し、摩擦、力学の停止、事後選別と区別する | Rabi 型遷移と反復測定の接続、生存確率の測定間隔依存の導出 |
| Q12 | 性能と資源増加の評価 | 未着手 | 忠実度、雑音耐性、エネルギー収支、動作時間、必要自由度の系サイズ依存性を評価する | 性能指標の定義と規模依存性の測定 |
