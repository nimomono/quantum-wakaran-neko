# quantum-wakaran-neko

量子、なんもわからん。

## 目的

明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。有限自由度の古典 Hamiltonian 系を土台とし、外部自由度との弱結合を含めて、エネルギー交換型とエネルギー保存型の開放性を区別しながら確率構造が生じる物理的機構を追跡する。

## 長期目標の現在地

### 第1段階：単一量子ビット型装置

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q1-1 | 単一量子ビット型可逆力学 | Bloch 球、共通位相不変性、任意の $SU(2)$ 操作、Rabi 振動を同じ担体で実現 | 達成 |
| Q1-2 | 射影測定操作 | 任意の Bloch 軸で Born 重み、排他的結果、測定後状態、反復性、逐次測定を導出 | 達成 |
| Q1-3 | 完全操作・測定周期 | 準備から永久記録、内部逆計算、弱開放 reset、次周期への復帰までを閉じる | 達成 |
| Q1-4 | Zeno 効果 | 同じミクロモデルで Rabi 型遷移と反復測定を接続し、遷移抑制を定量導出 | 達成 |

### 第2段階：複合系・量子計算

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q2-1 | 2量子ビット型結合ゲート | 2量子ビット型結合ゲートと同一の共同入力--出力統計を有限古典Hamiltonian過程で生成 | 達成 |
| Q2-2 | Bell 型測定統計 | Q2-1出力を2つの測定端へ接続し、余弦共同確率、CHSH不等式の破れ、Tsirelson 限界、非信号性、測定設定独立性の破れを導出 | 条件付き達成 |
| Q2-3 | 量子ゲート型計算機の実装コスト | 量子ビット数、回路深さ、目標誤差に対する実装資源の増加率と隠れた指数コストを評価 | 未着手 |

### 第3段階：空間量子力学

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q3-1 | 空間 Schrödinger 型有効力学 | 局所振動子網から空間格子上の Schrödinger 型時間発展を誤差付きで導出 | 達成 |
| Q3-2 | 位相量子化 | 巻数、節、単価性、位相すべりを統合し、Wallstrom 問題へ限定的に回答 | 未達（凍結中） |
| Q3-3 | 束縛状態 | 1次元井戸型・調和型の低位固有状態と、エネルギー占有率を保つ有限時間デコヒーレンスを導出 | 達成 |
| Q3-4 | トンネル効果 | 障壁値未満のエネルギー状態が障壁反対側へ位置確率を移すことを示し、位置読出しへ接続 | 達成 |
| Q3-5 | 2重スリット干渉 | 有限グラフの2経路入力でコヒーレント分布の混合との差と相対位相依存性を示し、位置読出しへ接続 | 達成 |

詳しい達成判定、根拠、残る課題、直前版IDとの対応は [PROJECT_STATUS.md](PROJECT_STATUS.md) で管理する。

draft-37では第2段階としてR123--R125を追加した。Q3-3は、1次元井戸型・調和型の低位スペクトル、密度、節、収束と、注目系エネルギーを保存する有限環境純位相緩和を導出した。Q3-4は3頂点有限障壁で障壁値未満状態の反対側確率増分、Q3-5は2頂点再結合器でコヒーレント入力と混合の差・相対位相差を厳密に示し、いずれもM42の固定時刻位置読出しへ接続した。改訂後の固定範囲でQ3-3からQ3-5を達成と判定する。Q3-2は未達のまま凍結する。

draft-36では固定目標の方針を変更した。Q3-2は未達のまま凍結し、Q3-3はエネルギー保存型の純位相緩和、Q3-4とQ3-5は最小有限グラフと位置読出しへの接続へ判定範囲を変更した。この版では導出を追加せず、Q3-3からQ3-5は未達のまま保った。

draft-35では、固定目標、モデル非依存な達成判定、現在の実現方針を分離した。Q3-2を限定されたWallstrom回答へ明確化し、Q3-3の状態選択を弱開放デコヒーレンスへ置き換えた。Q3-4とQ3-5では固定時刻の位置読出しを現在の実現方針とし、初回到達、吸収、時間積分流束を固定目標より強い将来拡張へ分けた。Q3-2からQ3-5は全て未達のままである。

draft-34ではQ1、Q2、Q3を有限配置グラフ上の複素振幅場 $b$ と実現配置 $X$ の共通モデルへ統合した。鋭い基準配置から同じ準備回路で $P(X=z)=|b_z|^2$ を作り、測定結果を分析器出口の $X$ に一本化する。M35は初期配置準備、局所更新、条件付き場準備、分布検算の補助モジュールへ整理した。Q2のCNOTとBell周期を共同配置で閉じ、M37型1辺位置ばねによるCNOT場近似も明示した。
