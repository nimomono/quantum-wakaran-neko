# quantum-wakaran-neko

量子、なんもわからん。

## このプロジェクトの目標

古典的な粒子、振動子、熱浴、測定器を組み合わせたとき、量子力学に特徴的な運動や確率が、どこまで有効理論として現れるかを調べるプロジェクトである。

ここでいう有効理論とは、装置全体の自由度のうち観測する変数だけを残し、直接観測しない環境や内部自由度をまとめて記述する理論を指す。

量子力学の方程式を古典振動子の方程式へ書き換えるだけでは、測定結果やBorn則の起源を説明したことにはならない。本プロジェクトでは、粒子、振動子、熱浴、測定器、記録装置を含む具体的なモデルを作り、次の点を調べる。

- 量子状態に似た状態空間と可逆操作が、どの古典力学から生じるか
- 1回の試行で結果がどのように一つに定まるか
- 多数回の試行で、結果の頻度がなぜ振幅の二乗に比例するのか
- 測定後の状態、外部記録、装置のリセットを同じ過程として記述できるか
- 確率、仕事、熱、エントロピーの流れが、どの自由度から生じるか
- どこまでが厳密な結果で、どこからが近似や追加仮定なのか

長期的な目標は二つある。

1. 明示的な古典力学モデルから、量子力学の基本構造、代表的な現象、測定統計を再現し、その成立条件と限界を明らかにする。
2. 同じ仕組みを利用し、量子コヒーレンスを前提としない巨視的な古典系で、量子ゲートと同型の状態操作を実現する。

これは量子力学を否定する試みでも、量子力学全体を古典力学から導出したと主張するものでもない。再現できた構造と、まだ導出できていない構造を分けて検証する。

## 論文の概要

**古典力学系からの量子型有効構造：W型2モード操作・測定、有限配置ゲート、空間伝播、Bell型統計**

現行論文では、研究課題を次の三段階に分けている。

三つの段階で使う古典モデルは同じではない。一方で、複素信号の各成分が持つ作用から各結果に対応する古典状態数を作り、その状態数に従って一つの結果を記録する読出し機構は共通している。確率を作る機構はこの有限作用殻モジュールに一本化し、有限正準回路は信号の操作、比較、記録、逆計算にだけ使う。

共通の読出し定理は、決めた入力時刻の有限信号を保持し、作用殻の状態数、有限時間の再平衡化、局所ラッチを通して、排他的な結果または無反応を後の時刻に記録する。単一量子ビット型装置とBell型装置はこの共通定理へ、それぞれ固有の分析器と条件付き応答だけを追加する。

### 1. 単一量子ビット型装置

二重井戸型の古典系が持つ低い2モードと、粒子位置、環境自由度を組み合わせる。

このモデルでは、Bloch球に相当する状態空間、任意の $SU(2)$ 操作、Rabi振動を構成できる。また、各試行に与えられた作用と、二つの結果枝が持つ古典状態数から、振幅の二乗に比例するBorn型重みが現れる条件を示している。

単一量子ビット型の可逆操作は達成している。射影測定と完全な操作・測定周期は部分達成であり、状態数を準備する機構、測定器の反作用、記録とリセットを含む一周期全体のエネルギー・エントロピー収支が残っている。

### 2. 2量子ビット型ゲートとBell型統計

有限4モードの古典担体、環境自由度、二つの粒子位置を使い、CNOTゲートと同じ共同入力–出力統計を生成する。

さらに、中央で準備した状態を二つの測定端へ渡し、それぞれで局所的な分析と記録を行うことで、Bell型の余弦共同確率、CHSH不等式の破れ、Tsirelson限界、非信号性を同じ計算の中で再現する。

ただし、一方の測定設定が中央の準備過程へ入るため、Bellの定理で仮定される測定設定独立性は成立しない。したがってBellの定理との矛盾ではなく、標準的な空間分離・自由設定のBell実験を再現したものでもない。

CNOT型統計は達成している。Bell型測定統計は、固定singlet型、固定された有限個の測定設定、測定前の準備、非空間分離という範囲での条件付き達成である。

### 3. 空間量子力学

局所的に結合した有限個の古典振動子から、空間格子上のSchrödinger型時間発展を有限時間・明示誤差付きで導く。

空間上の各点に対応する振動子の振幅と位相をまとめると、空間全体に広がる複素振幅が得られる。この複素振幅は、有限時間の範囲でSchrödinger方程式に従う波動関数と同じ形で発展する。

位置を読むときは、決められた時刻に各試行の振動子信号を取り出す。その信号から、それぞれの位置に対応する古典状態数を作り、有限時間の再平衡化を経て、一つの位置だけを局所的に記録する。これにより、その時刻の振幅の二乗に従う位置分布を、各試行の排他的な位置結果へ接続する。

示しているのは、ある時刻の複素振幅を、その後の位置測定結果へ変換する過程であり、測定前の粒子軌道ではない。集団平均との接続は、一つの一般ray平均定理の中で、階数1、試行ごとの作用が固定された高階数、作用が変動する場合の補正を分けて扱う。

有限グラフ上では、低位束縛状態、有限環境による純位相緩和、障壁値より低い状態のトンネル型確率移動、最小2経路の干渉を構成している。

空間Schrödinger型力学と束縛状態・純位相緩和は達成している。トンネル効果と2重スリット干渉は、波動的な確率分布と位置読出しへの接続を得ているが、振動子網から位置記録までを一つの有限局所Hamiltonian装置へ統合していないため、条件付き達成である。

位相量子化、一般的な連続空間極限、多粒子系は未完成である。

### この論文の到達範囲

本論文が示しているのは、量子力学のいくつかの構造が、明示的な古典系の運動、状態数、環境との相互作用、条件付けから現れ得るということである。

現時点では、単一量子ビット型装置、2量子ビット型装置、空間モデルは異なる古典モデルを使っている。これらを一つのハードウェアと一つの反復周期へ統合した理論、一般の多量子ビット系で指数的な実装コストを避ける構成、量子力学全体の導出は得られていない。
