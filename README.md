# quantum-wakaran-neko

量子、なんもわからん。

## 目的

明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。有限自由度の古典 Hamiltonian 系を基礎とし、外部との微小なエネルギー交換を伴う弱い開放系まで含めて、確率構造が生じる物理的機構を追跡する。

## 現在の中心成果

- 全 Liouville 方程式から、連続の式、運動量収支、条件付き分散分解を厳密に導出した。
- 二側 Markov 拡散における Fisher 応力の恒等式と、線形 Gauss 型補助モデルにおける Guerra--Morato／Nelson 作用への収束を示した。
- 3モード共通作用殻の残余ファイバー体積から、指定した対称性と境界条件の下で Bell 型余弦共同確率を導出した。この構成では測定設定独立性が成立せず、対称セクターの一側周辺分布は設定に依存しない。

## 最大の未解決問題

補助モデルで得た Fisher／Nelson 構造と Bell 型統計を、同じ明示的な弱開放古典 Hamiltonian 系から一貫して導出することである。特に、構造化誘導場から二側 Markov 拡散と Fisher 閉鎖を、適用範囲と誤差評価を伴って導くことが最重要課題として残っている。
