# quantum-wakaran-neko

量子、なんもわからん。

## プロジェクトのスタンス

- 明示的な古典Hamiltonian系から、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。物理系は、有限古典Hamiltonian系を基礎としつつ、外部との微小なエネルギー交換を伴う弱い開放系として扱う。
- 開放性を抽象的な散逸項だけで済ませず、Hamiltonian、外部自由度との結合、エネルギーの交換経路と収支を示し、物理的実体を追跡できるモデルとして記述する。
- 理論構成では量子力学を前提や説明原理に使わず、得られた結果との比較に限って言及する。
- 確率式の再現だけでなく、ミクロな力学、縮約、境界条件、統計条件のどこから確率構造が生じるかを追跡する。
- Bell の定理を否定せず、Bell 不等式の破れを測定過程に伴う測定設定独立性の破れとして力学的に説明することを目指す。
- 現行モデル、補助モデル、不採用モデルを分け、結果は厳密、近似、予想・未解決へ分類する。仮説依存、否定的結果、成立条件は必要に応じて付記し、問題を別の仮説へ移しただけでは解決とみなさない。

詳しくは [PROJECT_STANCE.md](PROJECT_STANCE.md) を参照。

## モデルの運用状態

| モデル | 状態 |
|---|---|
| 粒子・装置・構造化誘導場・外部流路を持つ弱開放系 | 現行モデル |
| 1試行内の有限閉鎖系、線形誘導場、二側 Markov 拡散、線形 Gauss 型確率表示、Gauss 幅 Routh 縮約、最小結果符号化器、3モード境界作用殻、U(3) 等方殻拡散 | 補助モデル |
| 残余2モードの U(2) 混合 | 補助モデル。全殻測度には不足することを示す比較に限定 |
| 終端関数・中央比較器・相補時計、順時間的共有浴、結果依存滞在時間による Bell 重みづけ | 不採用モデル。詳細は `notes/` |

## 現在の到達状況

| 結果 | 導出状態 |
|---|---|
| 全 Liouville 方程式からの連続の式と運動量収支 | 厳密結果 |
| 線形誘導場の Green 作用素による消去 | 指定した境界条件の下で厳密結果 |
| 二側 Markov 拡散内部の浸透速度と Fisher 応力恒等式 | 厳密結果。仮説依存 |
| Gauss 幅の Routh–Fisher 一致 | 指定した補助モデル内部の厳密結果 |
| 線形 Gauss 型作用形式のパラメータ $C^1$ 収束と Nelson 表示 | 補助モデルの厳密結果 |
| 静的な誘導場基底と実2次元和・差作用 | 厳密結果 |
| 残余2モードの U(2) 等方性だけではファイバー間質量を決められないこと | 厳密結果。否定的結果 |
| U(3) 等方殻拡散の一意な定常測度 | 縮約方程式の下で厳密結果。仮説依存 |
| 3モード共通殻の周辺密度と残余ファイバー体積 | 厳密結果 |
| 共通殻、対称セクター、共通分解能の下での Bell 型余弦共同確率 | 厳密結果。仮説依存 |
| 局所交差応答、異方性、混合不足、作用殻幅、有限分解能による補正 | 近似結果 |
| ミクロ誘導場から二側 Markov 拡散への縮約と Fisher 閉鎖 | 中心的な予想・未解決 |
| 同じ誘導場からの全殻拡散、一般測定器、境界適合を含む試行周期、Nelson 停留点選択 | 予想・未解決 |
| 任意の偏った準備での非信号性、Born 則、一般原理からの Tsirelson 限界、Wallstrom 問題 | 予想・未解決 |

Bell 固有の終端関数と中央比較器は現行モデルから除いた。ただし、共通未来の境界適合と2境界条件付けそのものは残る。Bell の前提違反は、境界適合ファイバーによる測定設定独立性の破れにある。

第I部と第II部は、構造化誘導場、固定射影、二側条件付け、弱い外部交換という物理構成を共有する。ただし、同じ具体的パラメータ集合から Fisher 縮約と Bell 縮約が同時に成立する定理はまだない。

詳しくは [PROJECT_STATUS.md](PROJECT_STATUS.md) を参照。
