# quantum-wakaran-neko

量子、なんもわからん。

## 目的

明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。有限自由度の古典 Hamiltonian 系を基礎とし、外部との微小なエネルギー交換を伴う弱い開放系まで含めて、確率構造が生じる物理的機構を追跡する。

## 現在の中心成果

- 運動量結合した有限誘導場について、運動量2次形式の正定値条件、時間反転対称性、正確な配置流束、自由速度揺らぎと反作用記憶項の分離を導出した。
- 配置変数の二側 Markov 拡散における Fisher 項と量子ポテンシャルの恒等式、および線形 Gauss 型補助モデルにおける Guerra--Morato／Nelson 作用への収束を示した。
- 3モード共通作用殻の残余ファイバー体積から、指定した対称性と境界条件の下で Bell 型余弦共同確率を導出した。この構成では測定設定独立性が成立せず、対称セクターの一側周辺分布は設定に依存しない。

## 最大の未解決問題

補助モデルで得た Fisher／Nelson 構造と Bell 型統計を、同じ明示的な弱開放古典 Hamiltonian 系から一貫して導出することである。特に、運動量結合した有限誘導場から配置拡散極限、配置変数だけの Markov 性、時間対称 Newton 則を、適用範囲と誤差評価を伴って導くことが最重要課題として残っている。
