# quantum-wakaran-neko

量子、なんもわからん。

## 目的

明示的な古典力学モデルから、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。有限自由度の閉鎖Hamiltonianモデルと、駆動、散逸、雑音、エネルギー・エントロピー流を明示した開放古典モデルを区別し、確率構造が生じる物理的機構を追跡する。開放モデルの採用にHamiltonianへの持ち上げを必須とはしないが、仮定した確率項をミクロ力学から導出済みとは呼ばない。

## 長期目標の現在地

### 第1段階：単一量子ビット型装置

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q1-1 | 単一量子ビット型可逆力学 | Bloch 球、共通位相不変性、任意の $SU(2)$ 操作、Rabi 振動を同じ担体で実現 | 達成 |
| Q1-2 | 射影測定操作 | 任意の Bloch 軸で Born 重み、排他的結果、測定後状態、反復性、逐次測定を導出 | 部分達成。bath方向吸引は有限時間評価済み。完全matching、枝別matching、経路ごとの局所滞在が残る |
| Q1-3 | 完全操作・測定周期 | 準備から永久記録、内部逆計算、弱開放 reset、次周期への復帰までを閉じる | 部分達成。切断後保存、周期間matching帰還、総収支が残る |
| Q1-4 | Zeno 効果 | 同じミクロモデルで Rabi 型遷移と反復測定を接続し、遷移抑制を定量導出 | 未達（凍結中） |

### 第2段階：複合系・量子計算

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q2-1 | 2量子ビット型結合ゲート | 2量子ビット型結合ゲートと同一の共同入力--出力統計を有限古典Hamiltonian過程で生成 | 達成 |
| Q2-2 | Bell 型測定統計 | Q2-1出力を2つの測定端へ接続し、余弦共同確率、CHSH不等式の破れ、Tsirelson 限界、非信号性、測定設定独立性の破れを導出 | 条件付き達成 |
| Q2-3 | 量子ゲート型計算機の実装コスト | 量子ビット数、回路深さ、目標誤差に対する実装資源の増加率と隠れた指数コストを評価 | 未着手 |

### 第3段階：空間量子力学

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q3-1 | 空間 Schrödinger 型有効力学 | 局所振動子網から空間格子上の Schrödinger 型時間発展を誤差付きで導出 | 達成 |
| Q3-2 | 位相量子化 | 巻数、節、単価性、位相すべりを統合し、Wallstrom 問題へ限定的に回答 | 未達（凍結中） |
| Q3-3 | 束縛状態 | 1次元井戸型・調和型の低位固有状態と、エネルギー占有率を保つ有限時間デコヒーレンスを導出 | 達成 |
| Q3-4 | トンネル効果 | 障壁値未満のエネルギー状態が障壁反対側へ位置確率を移すことを示し、位置読出しへ接続 | 達成 |
| Q3-5 | 2重スリット干渉 | 有限グラフの2経路入力でコヒーレント分布の混合との差と相対位相依存性を示し、位置読出しへ接続 | 達成 |
