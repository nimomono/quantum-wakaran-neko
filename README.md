# quantum-wakaran-neko

量子、なんもわからん。

## 目的

明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。有限自由度の古典 Hamiltonian 系を基礎とし、外部との微小なエネルギー交換を伴う弱い開放系まで含めて、確率構造が生じる物理的機構を追跡する。

| Q4 | 束縛状態 | 井戸型・調和型で固有状態と安定性を再現 | 未達 |
| Q5 | トンネル効果 | 透過率を再現し熱活性化と区別 | 未達 |
| Q6 | Rabi 振動 | 振動数・振幅・離調依存性を再現 | 未達 |
| Q7 | 2重スリット干渉 | 準備から局所検出までを含む位置分布を再現 | 未達 |
| Q8 | 2量子ビット型結合ゲート | 古典 Hamiltonian 装置で CNOT 型または制御位相型操作を実現 | 未着手 |

| Q10 | 完全な操作・測定周期 | 準備から記録・消去・再初期化までを連続反復 | 部分達成<br>**残る課題**：Q1位置ばね網とQ2交換回路の統合、局所時計配線、永久外部記録、弱開放reset、直後反復 |

| Q12 | 性能と資源増加の評価 | 性能と必要資源の系サイズ依存性を評価 | 部分達成<br>**残る課題**：絶対動作時間、総エネルギー収支、雑音耐性、長期安定性、資源下界 |
