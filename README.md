# quantum-wakaran-neko

量子、なんもわからん。

## プロジェクトのスタンス

- 明示的な有限古典Hamiltonian系を中核とし、微小なエネルギー流出を伴う弱い開放系から、量子力学に特徴的な確率構造が有効理論として出現する条件を明らかにする。
- 開放性を抽象的な散逸項だけで済ませず、Hamiltonian、外部自由度との結合、エネルギーの流出経路と収支を示し、物理的実体を追跡できる模型として記述する。
- 理論構成では量子力学を前提や説明原理に使わず、得られた結果との比較に限って言及する。
- 確率式の再現だけでなく、ミクロな力学、縮約、境界条件、統計条件のどこから確率構造が生じるかを追跡する。
- Bellの定理を否定せず、Bell不等式の破れを測定過程に伴う測定設定独立性の破れとして力学的に説明することを目指す。
- 導出、仮定、近似、数値確認、解釈、未解決、否定結果を区別し、問題を別の仮定へ移しただけでは解決とみなさない。

詳しくは [PROJECT_STANCE.md](PROJECT_STANCE.md) を参照。
