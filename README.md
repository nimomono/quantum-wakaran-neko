# quantum-wakaran-neko

量子、なんもわからん。

## 目的

明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。有限自由度の古典 Hamiltonian 系を基礎とし、外部との微小なエネルギー交換を伴う弱い開放系まで含めて、確率構造が生じる物理的機構を追跡する。

## 長期目標の現在地

| ID | 長期目標 | 現在地 | 達成判定の中心 | 残る課題 |
|---|---|---|---|---|
| Q1 | Schrödinger 型有効力学 | 部分達成 | 古典模型から Schrödinger 型時間発展を導出 | 係数のミクロ導出、非線形閉包、連続極限、粒子運動との接続 |
| Q2 | Born 則 | 部分達成 | 準備・力学・測定から Born 重みを導出 | 高階数源、有限標本統計、粒子検出、連続スペクトル |
| Q3 | 位相量子化 | 未達 | 循環量子化・節・単価性を統合し Wallstrom 問題に回答 | 閉路巻数、節、位相すべり、連続補間の統合 |
| Q4 | 束縛状態 | 未達 | 井戸型・調和型で固有状態と安定性を再現 | 定量検証、エネルギー測定、状態選択 |
| Q5 | トンネル効果 | 未達 | 透過率を再現し熱活性化と区別 | 透過率の定量導出と識別 |
| Q6 | Rabi 振動 | 未達 | 振動数・振幅・離調依存性を再現 | 駆動2準位模型と定量検証 |
| Q7 | 2重スリット干渉 | 未達 | 準備から局所検出までを含む位置分布を再現 | 空間セル標本化と粒子検出・連続軌道の接続 |
| Q8 | 2量子ビット型結合ゲート | 未着手 | 古典 Hamiltonian 装置で CNOT 型または制御位相型操作を実現 | 2自由度符号化、結合 Hamiltonian、作用・忠実度の検証 |
| Q9 | Bell 型測定統計 | 部分達成 | 余弦統計、CHSH 不等式の破れ、Tsirelson 限界、非信号性を一貫して導出 | 整合支持・基準密度の導出、一般 Tsirelson 原理、誤差下の非信号性 |
| Q10 | 完全な操作・測定周期 | 部分達成 | 準備から記録・消去・再初期化までを連続反復 | 操作列、永久外部記録、直後反復、安定結果形成 |
| Q11 | Zeno 効果 | 未着手 | 反復測定による遷移抑制を定量再現し、散逸などと区別 | Rabi 遷移と測定周期の接続、生存確率の間隔依存 |
| Q12 | 性能と資源増加の評価 | 未着手 | 性能と必要資源の系サイズ依存性を評価 | 指標の定義と規模依存性の測定 |

詳しい達成判定、根拠、残る課題は [PROJECT_STATUS.md](PROJECT_STATUS.md) で管理する。
