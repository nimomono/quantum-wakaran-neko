# quantum-wakaran-neko

量子、なんもわからん。

## 目的

明示的な古典 Hamiltonian 系から、量子力学に特徴的な確率構造が縮約された有効理論として出現しうるかを明らかにする。有限自由度の古典 Hamiltonian 系を基礎とし、外部との微小なエネルギー交換を伴う弱い開放系まで含めて、確率構造が生じる物理的機構を追跡する。

## 長期目標の現在地

### 第1段階：単一量子ビット型装置

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q1-1 | 単一量子ビット型可逆力学 | Bloch 球、共通位相不変性、任意の $SU(2)$ 操作、Rabi 振動を同じ担体で実現 | 達成 |
| Q1-2 | 射影測定操作 | 任意の Bloch 軸で Born 重み、排他的結果、測定後状態、反復性、逐次測定を導出 | 達成 |
| Q1-3 | 完全操作・測定周期 | 準備から永久記録、内部逆計算、弱開放 reset、次周期への復帰までを閉じる | 達成 |
| Q1-4 | Zeno 効果 | 同じミクロモデルで Rabi 型遷移と反復測定を接続し、遷移抑制を定量導出 | 達成 |

### 第2段階：複合系・量子計算

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q2-1 | 2量子ビット型結合ゲート | テンソル積構造と少なくとも1種類のエンタングリングゲートを明示装置で実現 | 達成 |
| Q2-2 | Bell 型測定統計 | 余弦統計、CHSH 不等式の破れ、Tsirelson 限界、非信号性、測定設定独立性の破れを導出 | 達成 |
| Q2-3 | 量子ゲート型計算機の実装コスト | 量子ビット数、回路深さ、目標誤差に対する実装資源の増加率と隠れた指数コストを評価 | 未着手 |

### 第3段階：空間量子力学

| ID | 長期目標 | 達成判定の中心 | 現在地 |
|---|---|---|---|
| Q3-1 | 空間 Schrödinger 型有効力学 | 局所振動子網から空間格子上の Schrödinger 型時間発展を誤差付きで導出 | 達成 |
| Q3-2 | 位相量子化 | 閉路巻数、節、単価性、位相すべりを統合し Wallstrom 問題に回答 | 未達 |
| Q3-3 | 束縛状態 | 井戸型・調和型で固有値、密度、節、状態選択、安定性を再現 | 未達 |
| Q3-4 | トンネル効果 | 透過率を導き、熱活性化や古典的障壁越えと区別 | 未達 |
| Q3-5 | 2重スリット干渉 | 準備、空間伝播、干渉、局所検出を含む位置分布を導出 | 未達 |

詳しい達成判定、根拠、残る課題、直前版IDとの対応は [PROJECT_STATUS.md](PROJECT_STATUS.md) で管理する。
